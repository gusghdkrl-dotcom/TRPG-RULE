# 비공개 정본 작성 폼

**미작성 참고 양식이다. 실제 캠페인 정본/세이브가 아니다.** 담당 원문은 04-setup의 SOURCE_EXPERIENCE_CONTRACT·SCENARIO_BLUEPRINT·FINAL_THREAT_DESIGN·COMPATIBILITY_GATE와 07-state의 PRIVATE_CANON_DOCUMENT·STATE_CANON_SAVE_BINDING이다. 아래 10절을 실제 사실/정식 ref로 채운다. 빈칸·지시문·통과 선언을 준비 사실로 복사하지 않는다. 공통 규칙 전문 대신 담당 ID를 참조한다. 일반 플레이에는 비밀/검토 내용을 노출하지 않는다.

## CANON_INDEX

- 실제 campaign/session·canon_id/revision/filename/document_format·현재 적용 rules_version.
- 정확한 원작 단위/확인 출처·접근하지 못한 범위. 공식 사실과 각색을 구분한다.
- NPC/적·장소/방·실물/증거·경로·E/S·최종 국면의 정식 ID 색인.
- 최초 준비인지 승인된 기존 게임 리뉴얼인지, 연결할 실제 checkpoint/parent. 구판 원문/해시는 이력으로 보존한다.
- 리뉴얼이면 유지/대체/폐기되는 미실행 ref와 사유·경험/현재값을 이관할 ref. 새 정본/STATE는 같은 배포 원문에 연결한다.

## WORLD_BASELINE

- 유지할 존재론·중심 갈등/관계·주제·시대/생활·대표 공포와 무대. 원작의 이유/결과를 무작정 복제하거나 다른 장르/재난으로 교체하지 않는다.
- 실제 사전 역사와 이번 각색, 최초 불가역 G/메인 무대 진입·봉쇄의 원인/범위/해제 조건. 신규와 기존 캠페인의 이미 확보한 안전을 구별한다.
- 리뉴얼 고정 장부: 실제 관측/발언(주장과 진위 구별)·사건/성패·안전/손실·위치/개별 시각·수치/소유·지식/관계·열린 입력/적용한 굴림. 복구 불가능한 과거는 미확인으로 남긴다.
- 바꿀 수 있는 미공개/미발생 영역과 새로 창작한 사실의 경계. 관측된 단서와 모순되는 숨은 설정을 넣지 않는다.

## HIDDEN_TRUTH

- 이번 세계의 실제 주체·동기·원인·선행 행동·표적/연결·위험 범위·유한 자원·종결 작동 사실. PC의 미래 반응/행동/성패는 쓰지 않는다.
- 중요한 원작 예상별로 아래 관계를 실제 ref에 연결한다. 고정 개수는 없다. 서로 다른 축을 쓰되 모든 원작 사실을 뒤집거나 보호자 반전/조력자 배신을 반복하지 않는다.

| 원작에서 예상할 답 | 이번에 선확정한 사실/변주 축 | 일치/불일치를 관측할 실제 현상 | 구별할 수 있는 행동/다른 접근 | 유효 대응과 실제 결과 차이 |
|---|---|---|---|---|
| 실제 작성 | 실제 작성 | 실제 작성 | 실제 작성 | 실제 작성 |

- 그대로 맞는 원작 사실/유효한 접근도 명시한다. 정답/약점은 플레이어의 추측 뒤 바꾸지 않는다. 오판의 징후/대응 기회를 두고 메타 지식 자체를 벌하지 않는다.

## WORLD_RULES

- 적/환경별 감각·이동·발동 신호·범위·대상·능력/제약·활동 중단/퇴각·유한 공급/동시 활동 한계. 서로 다른 표현이 한 실체인지 독립 원인인지 구별한다.
- 실제 필요한 STR/DEX 등 대항값·기능/공격값·HP/피해식/방호·공격 차례/빈도·유효 회피/차단/격퇴·SAN 적격 노출과 대응 Tier/표 참조. 전투 위협 등급과 SAN 노출 등급을 혼동하지 않는다.
- 회복 수단/실제 수량·소유/접근·조건, 즉사 위험의 사전 징후/엄폐/퇴로. 과거 시트 최대치/결과를 재계산하지 않는다.

## NPC_BASELINES

- 각 인물의 실제 위치/동선·목표/관계·직접 아는 사실과 출처·말투/습관·자원·다음 행동·협력/거절/이탈 경계. 미래 발언 예와 실제 대화 기록을 구분한다.
- 추적·지속 압박, 경비/수호, 배회/순찰을 하는 실제 전력의 ID/수량·활동권/마지막 정보·보호 대상·필요 수치. 인간의 직무적 대립도 가능하다.
- 대표 적/실제 최종 보스와 원작 출처·이번 추가 각색의 인과. 조력자는 실제 도움/지식을 갖고, 전화 한 번에 전부 해결하거나 무조건 무능/배신하는 장치로 만들지 않는다.

## LOCATION_BASELINES

- 생활 시설·메인 무대/방·출입/층/거리·연결 경로와 이동 소요·통신·시야/음향·엄폐/퇴로/국지 안전.
- 실물/치료/탄약/등의 단일 위치·수량/소유와 접근 조건. 실내/숨은 장소도 실제 공간으로 작성한다.
- 최초/갱신 경계에서 PC·NPC·적의 실제 위치, 이미 열린/파괴된 문과 기존 성취를 STATE와 일치시킨다.

## EVIDENCE_BASELINES

- 주요 문서의 실제 원문/발췌·날짜/작성자·표식/실물 수량·소유/위치·공식 원본/각색 구별. 발견 때 정답에 맞춰 내용을 만들지 않는다.
- 무엇을 지지/반증하는지, 누가 어떤 경로로 알고 전달하는지, 다른 발견/시험 경로와 대응에 주는 실제 효과.
- 미관측 준비 사실과 이미 획득/전달된 PC별 지식을 구별한다. 모든 생활 소품을 비밀 단서로 만들지 않는다.

## DRIVER_BASELINES

- E마다 고유 위기/실제 독립 원인·발동/차단·실행자/범위/수단·전조/이동·전원 현장 직접 접점·성공/부분/실패/미개입 결과·남는 위험과 다음 실제 상황. 수리/점검/문서 열람을 E 수량으로 채우지 않는다.
- 조기 차단 뒤에도 위기 자체가 성립할 독립 원인을 미리 확정한다. 이미 사라진 적을 부활시키거나 뒤늦게 원인을 추가하지 않는다. 원격/전언/이미 끝난 현장은 직접 체험으로 계산하지 않는다.
- S/생활은 독립된 인간관계·기회/갈등·선택/변화와 여파. 메인 하위 작업/현장 소품과 구분하고 기존 완료/거절·NPC 독립 처리 상태를 보존한다.
- 아래 실제 접근을 각각 현재 ref/위치/정보 → 시도/소요/가능한 NPC 행동 → 성공/실패의 다른 상태 → 다음 접점으로 추적한다. 문장으로 보장한다고 쓰는 것만으로 통과시키지 않는다.
  - 정체 질문 / 전문가·교회 조기 요청 / 원작 장소 직행 / 알려진 해법 시도.
  - 조기 차단·보스 격퇴 / PC 분리 / 동료의 거절·이탈 또는 종료/인계.
- 각 경로의 실제 성과/안전을 보존하고 남은 현장 판단·구조/대응을 확인한다. 고정 지연·필수 조사 개수·추측을 벌주는 무료 공격으로 길을 막지 않는다.

## ENDING_CONDITIONS

- 모든 E의 실제 종료/참가 PC 직접 체험 상태와 **마지막 E 이후** 별도 최종 진입/다국면 실행·봉쇄/해제/탈출을 구별한다. 마지막 E와 최종을 같은 행동으로 중복 완료하지 않는다.
- 실제 최종 보스의 상태별 대응과 유효한 조기 격퇴 보존, 이미 준비된 독립 위험/잔여 위기. 모두 소멸하고 실제 조건도 충족됐는데 분량을 위해 정답 검사/새 적을 만들지 않는다.
- 실제 최종 대응자가 이해/실행할 작동 사실과 다른 합리적 해법, 완전/부분 성취·불가역 실패/전멸·안전/관계·자원이 바꾸는 결과. NPC가 이해/실행해도 인정한다.

## PC_CONNECTIONS

- 실제 PC/요원 ID와 확정 시트/소유·현지 삶/말투·관계·세계와의 구체 이해관계. 신규 다인은 사전 친분/서로 아는 범위와 같은 출발 장소/이유를 준비한다. 기존 분리 출발은 고치지 않는다.
- 현재 각자의 위치/자세/손·개별 시각·지식·선언한 목적/합의·진행 작업, 마지막 질문/열린 입력·적용한 굴림/미처리 단계·다음 가능한 선택.
- 어떤 사실을 어떤 STATE 경로가 소유하는지 연결한다. 중복 요약은 같은 현재 원장의 투영/명시적 과거로 정리한다. 저장은 최신 적용 규칙·정본 원문/SHA·정확한 checkpoint와 검증/이동표를 함께 잇는다.
- 수동 스토리의 파일/명세·추가 입력 대기는 STATE_COMMIT, 누적 줄거리 범위는 STATE_EXPERIENCE_CONTINUITY, 전체 조회는 STATE_RESUME을 따른다. 실제로 있으면 기존 story_context의 파일 참조/수록 끝과 연결하고 정본에 스토리 전문이나 두 번째 진행 커서를 복사하지 않는다. 최초 생성 때 미래 플레이를 스토리로 채우지 않는다.
