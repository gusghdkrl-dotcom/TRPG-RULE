# 연쇄 대재난·병렬 PC·본부 브리핑 인수 검증표

**범위:** 신규 세계/미확정 챕터. 기존 RE:2 verified 정본/체크포인트, 소유 카드·보상·NPC·기존 시각에는 소급 패치를 적용하지 않는다. 이 문서는 **모의 입력·예상 결과**의 테스트 명세이며, 실제 게임 플레이/실제 DB 쓰기 검증의 증거가 아니다.

## A. 첫 사건과 후속 타이머

| 시험 | 입력/세계 조건 | 기대 결과 |
|---|---|---|
| A1 첫 사건 | PC 시작 17:10, E01 고정 시각 18:00, 20턴 대화로 실제 15분 경과 | 17:25에는 E01 미시작. 실제 18:00 도달 시 세계에서 시작. 턴 수가 트리거 아님 |
| A2 빠른 해결 | E01 실제 18:30 종료, E02 정본 유예 20분 | E02는 18:50 발생, 준비·교류 가능; PC의 직접 관측은 별도 판단 |
| A3 깊게 즐기는 해결 | E01 실제 21:15 종료, 같은 E02 20분 유예 | E02는 21:35 발생. E01 동안의 생활·교류/전투 길이는 제한하지 않음 |
| A4 무관여 | PC가 E01에 불참, NPC/적이 19:05 실제 국면 종료 | PC 완료 입력 없어도 19:05에 E02 유예 예약. PC가 멀다면 화면 밖 소식 누출 없음 |
| A5 이탈과 세계 종료 분리 | PC가 현장 18:10 철수, NPC가 19:00까지 대응 | 단순 PC 철수=세계 종료 아님. 정본 종료 조건에 따라 실제 19:00 이후 유예 예약 가능 |
| A6 긴 준비 | E02 유예 20분, PC가 30분 수리를 시작 | 실제 20분에 발생한 변화가 PC에게 도달하면 작업을 그때 중단/잔여 10분 보존 |
| A7 준비가 매우 좋음 | 격리 시설 확보, 도시 외부에서 대규모 습격 발생 | 실제 재난의 광범위한 손실·위협은 발생; 격리된 NPC·차단한 통로에 확정 피해를 부과하지 않음 |
| A8 독립 사건 | 선행 E03 진행 중 정부 작전의 자체 물리 조건 성립 | 독립 사건은 기다리지 않고 시작. 기존 정본 이유/실제 이동·전파 없으면 억지로 PC에게 노출 불가 |
| A9 정본 보존 | RE:2 기존 정본 날짜 및 verified checkpoint 로드 | 새 유예로 기존 E01~E08을 재산정하지 않고 기존 시각/개체·진행/안전 유지 |
| A10 재개/교대 | E01 종료/다음 유예 예약 뒤 다시 load 또는 PC 교대 | 종료·예약·발생 event ID 단일 처리, 타이머 재시작/이중 피해/유예 초기화 없음 |

## B. 2~3인 PC 병렬 시간선(#3)

| 시험 | 입력/세계 조건 | 기대 결과 |
|---|---|---|
| B1 공동 대화 | PC1/PC2 19:00~19:10 동일 대화 | 세계 10분만 경과, 두 PC의 경험 10분 |
| B2 분리 활동 | PC1 19:00~19:30 수리, PC2 19:00~19:20 탐색·19:20~19:30 교류 | 세계 30분만 경과, 50분 아님 |
| B3 미선언 PC | PC1 19:30까지, PC2 19:10 이후 미선언·영향 가능 | PC2의 19:10~19:30 선택을 자동 포기/휴식으로 처리하거나 충돌하는 19:30 결과 선확정 금지 |
| B4 19:15 위험 도달 | 19:00 시작한 30분 작업, 19:15 직접 침수/습격 | 15분만 진행, 잔여 15분과 위치·대응 대기 보존 |
| B5 공동 열쇠 | 분리된 PC 둘이 동일한 열쇠/차량 사용 선언 | 실제 사용 선후·이동 가능성 처리, 동시에 두 장소에 복제 불가 |
| B6 사건 전파 | 19:15 현장 A에서 발생, PC2는 닿지 않는 현장 B | 세계 발생 1회, PC2에게 무료 지식/행동 없음; 실제 연락/접촉 시만 공개 |
| B7 3인 PC | 3인이 동시/분리·합류, E02 유예 진행 | 같은 하나의 세계 타이머, PC별 활동의 경과 중복 정산 금지 |

## C. 본부 ON 현지 실무 브리핑(#5)

| 시험 | 입력 | 기대 결과 |
|---|---|---|
| C1 서로 다른 세계 | 서로 다른 시대·지역에서 출격 브리핑 | 통화/대략 물가·교통·통신·생활수준·기후가 실제 지역별로 달라짐 |
| C2 예산/교통 질문 | 유효한 현지 소지금과 이동거리·연락 방법 질문 | 확인 가능한 실무 범위로 설명, 근사치는 근사라고 구분 |
| C3 비공개 보호 | 미래 적 배치·사망·비밀 기업/탈출로가 정본에 존재 | 클라라가 미발견 비밀/미래 이벤트를 브리핑하지 않음 |
| C4 흐름/권한 | ON의 마틴 브리핑→클라라 설명→제이든 출격 의사; OFF/현지 세이브 재개 | 신규 강제 화면·구매/장착/동의·지급 없음, OFF/재개에서 본부 브리핑 삽입 없음 |
| C5 기록 | 동일 정식 브리핑을 재표시/복구 | 기존 본부 기록을 중복 발행하지 않음; 실제 DB 검증 실패는 성공으로 표시하지 않음 |

**실행 기준:** 04-setup SCENARIO_BLUEPRINT/COMPATIBILITY_GATE, 05-world WORLD_INITIATIVE_EXECUTION, 06-play SCENE_ELAPSED_TIME_SETTLEMENT/PARALLEL_TIMELINE_SYNC, 07-state STATE_WORKING_CONTEXT/STATE_SCHEMA, 04-setup HQ_FIELD_CONTEXT_BRIEFING. 실제 주사위/서버/본부 기록을 생성하지 않는 정적 기준 테스트와, 권한 있는 환경에서 별도로 수행할 실제 세이브 read-back 테스트를 구분한다.
