## 2. 게임과 본부의 핵심 의미

- 한국어 원작 체험형 생존 공포 TRPG를 바탕으로, 기존 게임 **요원 활성화 OFF는 변화 없이 유지**. ON만 본부·영구 카드/성장/클래스 시스템과 연결한다.
- 게임 속 평행세계의 삶과 죽음은 실제이며 시뮬레이션/리셋이 아니다. 주요 대재난/습격의 **발생 자체는 막을 수 없지만**, 그 뒤 피해·확산·구조·지역 보호·적 격퇴·생존·탈출은 실제 선택으로 바뀌고 성과를 보존한다.
- 본부는 평행우주의 실증 이후 첫 세계 간 경계 간섭 사고를 겪은 지구 국제공동조직. 서로 다른 세계가 침식/간섭할 위험과 가설적 연쇄 붕괴를 막기 위해 활동한다. 현지 기존 인물에 의식을 동기화하는 이유는 간섭을 줄이고 안전성과 연결률을 높이기 위한 것. 모든 원작 공포의 원인이 반드시 경계 침식인 것은 아니다.
- 조직 정식 이름·정확한 연도/지리·내부 비밀은 **아직 미확정**; 도중 임의로 정본으로 고정하지 않는다.
- 본부는 NPC·플레이어 간/사이에서 실제로 보낸 시간·말·약속·식사·다툼·화해·공동 경험·관계 변화를 **영구적으로 이어가는 살아 있는 세계**다. PC의 생각·감정·말·행동·동의를 대신 확정하지 않는다.

## 3. 첫 입단/재진입과 주요 공간

- ON 최초 시작 입력은 참가 인원 1–3과 기존 UUID 기반 영구 닉네임. 첫 신입은 본부 입구에서, 재입단/새 ON 게임의 경력 요원은 동기화실에서. **기존 현지 미완료 임무를 로드하면 본부가 아니라 검증된 현지 세이브에서 그대로 재개**한다.
- 첫 방문 흐름: 제이든 안내 → 마틴의 깊이 있는 첫 면담(세계관/사명/훈련과 실전/동기화 책임) → 몇 시설·실제 NPC와 자유 교류 → 도미닉 기본 카드/장비 교육 → 작전실 원작/규모/인지도 등 임무 세계 선택 → 기존 규칙대로 현지 PC/성장/클래스/장착 확정 → 마틴+클라라 정식 공개 브리핑 → 제이든 동기화.
- 첫 방문 주요 담당: **마틴·제이든·도미닉·클라라(출격 전 작전실 브리핑 참석)**, 동료 요원은 레오/최서린 등 1–2명 정도 자연스러운 등장. 클라라를 '귀환 후 처음 등장'으로 되돌리지 않는다. 사미라/마야 등은 실제 관계와 근무 맥락에 따라 후속 등장.
- 주요 5구역: 작전실(마틴), 동기화실(제이든), 기록·분석실(클라라), 의료·지원/전술·장비 교육(도미닉), 휴게·생활 구역(모두). 남측 출입구↔중앙홀, 북쪽 작전실, 북서 기록실, 북동 동기화실, 남서 의료지원, 남동 휴게실이라는 **운영 구역 지도 v1은 제안**. 정확한 외관/전체 층수/입지/세부 복도는 아직 고정하지 않음.
- 휴게실의 책·커피·공동 생활·유머/갈등은 중요한 경험이고, 숫자 호감도 파밍·무료 보상 장소가 아니다. NPC끼리도 독립적인 삶과 실제로 성립한 관계 변화가 있다.

## 5. 임무와 등급

- **파견 작전**은 원작 평행세계의 대사건 훈련 1회 또는 같은 세계에서 이어지는 연대기 전체. 연대기는 챕터마다 본부 정상 귀환 및 같은 원작 세계 재동기화를 이어갈 수 있다.
- 모든 작전의 공통 **대목표는 '진실을 밝히고 피해를 최소화하라.'** 진실의 완전 증명을 모든 장면/모든 결말의 필수 게이트로 만들지 않는다.
- 사용자가 의도한 **'임무'는 마틴이 사전에 명확하게 부여하는 소목표(구체적 수행 과제)**다. 출격 전 목표별 **상대적 중요도**를 설정한다. 개수/점수 고정 체크리스트 아님.
- **작전 위험 등급 Ⅰ 일반 경계 / Ⅱ 주의 / Ⅲ 고위험 / Ⅳ 극고위험 / Ⅴ 재앙급 / 미산정**: 출격 전 본부 관측에 근거한 예상 위험도; 보스 숫자·HP·추가 보상 승수 아님.
- **종합 수행 평가 S/A/B/C/F:** 사전 소목표의 중요도와 실제 달성/부분 달성/미달성/상황 변화로 수행 불가능을 보존하고, 대목표의 실질적 진실 발견·구조·피해 경감과 추가 성과를 마틴이 **정성적으로 종합 평가**. 단순 과제 완료 개수로 산출하지 않음. 막을 수 없는 첫 재난이나 이미 불가능한 구조를 사후 감점하지 않음. 연대기 최종 실패는 실제 보존한 구조/국지적 성과까지 지우지 않는다.
- **대사건은 훈련**: 훈련 완료하면 연대기 참가 자격. 공식 진급 점수 0, 기존 적격 일반 드래프트/성장 보상은 유지.
- **연대기는 실전**: 팀 전원이 훈련 통과 자격 필요. 첫 연대기 완주로 정식 요원. 공식 실전 평가·상위 진급은 연대기에서만. 구체적인 계급 점수/임계치(S/A/B/F 과거 잠정 산식)는 미확정.
- 연대기 전체 완주 보상은 최종 챕터 일반 보상 **별개**로 영구 훈장 + **A: 미보유 기존 66장 중 전설 제외 일반/희귀/영웅 이하 카드 1장 직접 선택** 또는 **B: 8종 영구 성장 중 Lv.5 미만 1종 +1 확정 상승** 중 정확히 하나. 신규 임의 추가 드래프트 아님. 지급 RPC와 예외는 미구현.

## 6. 사망·재투입과 장기 캠페인

- 대사건: 현지 PC **실제 사망 후**, 비공개 정본에 **사전 등록된 기존 적격 NPC**를 통해 **요원당 최대 1회 재투입**. 현지 사망 취소 아님, 새 NPC의 원래 위치/삶/관계/HP/SAN/소유물 상태 유지. 후보가 없으면 리타이어. 팀 전체 리타이어면 대사건 실패. 전투/교대 절차는 룰북과 검증 필요.
- 연대기: 죽은 후 NPC 재투입 **없음**. 각 요원에게 **연대기 전체에 걸친 1회 사망 직전 생존 특성**, 챕터마다 재충전 안 됨. 기존 전설 생존 카드 우선순위·HP/치명상/지속 위험 처리는 미확정. 실제 최종 사망이 발생하면 연대기 작전 전체 실패. 나머지 현지 PC/NPC의 실제 성과와 이전 챕터 보상 보존.
- 연대기는 같은 세계의 실제 연속성(현지 인물·NPC·물건·관계·세계 변화·경과 시간)을 보존하고 챕터별 보상/본부 귀환 뒤 다시 같은 세계에 들어간다. 기존 카드 장착과 영구 성장 소급 금지 제한 준수.

## 7. 본부 영구 저장과 3일 시간 계약

- **1회 공식 종료+실제 본부 귀환마다 성공/실패와 관계없이 본부 시간 정확히 +3일**. 연대기 정상 종료 챕터마다 각각 +3일. 최종 챕터 귀환과 전체 완주를 이중 계산하지 않는다. 동일 이벤트 재처리 시 +3일 중복 금지.
- 대사건 사망 후 재투입과 연대기 사망 직전 생존 연결은 **임무 귀환이 아니므로 +3일 없음**. 현지 세이브/로드·새 채팅 재개·입력 대기·PC 교대에도 시간 추가 없음.
- 본부에서 식사·대화·휴게 등 **직접 실제 활동으로 걸린 시간은 별도 경과**. 현지 시간과 본부 시간은 서로 독립. 임무 귀환 +3일 동안 NPC들은 자신의 업무·생활·기존 약속을 실제 인과대로 이어가지만, 강제 신규 이벤트/자동 호감도 변화 없음.
- **출격 전** 현재 본부 관계/시간/사건/자격/임무 연결을 검증 저장. **현지**는 별도 체크포인트·비공개 정본. 미완료 임무 로드 시 반드시 현지 마지막 세이브. **귀환** 시에는 최신 본부 상태에 해당 임무의 검증 결과와 +3일을 단 한 번 병합하며 옛 출격 스냅샷으로 덮어쓰지 않는다.
- 저장 구역별 권위는 기존 `trpg_cards`(UUID·보유 카드·성장·장착/보상 원장), 기존 검증된 현지 게임 세이브 및 비공개 세계 정본, 신규 별도 `trpg_hq` (본부 영구 상태·NPC/이력·임무)로 분리. **같은 Supabase 프로젝트 `trpg-state-v2` ID `taoaffdyssqtnjszumpq`**에 신규 스키마를 제안했으나 아직 설치 안 됨.
- 본부 이력은 **현재 스냅샷+중요 사건 로그**: 화자/청취자/시점/장소/약속·거절·농담·다툼·관계 변화 이유·진행 중 사건을 잃지 않게 기록. NPC-NPC 실제 관계도 갱신. 플레이어에게 비공개 정보 누출/전지적 전달 금지.
- 보상 라이프사이클은 현지 종결 검증→본부 복원/귀환→마틴 **승인**→도미닉 **기존 카드 DB에 실제 지급/선택 처리**를 분리. `campaign_id + event_key + player_id` 단위 중복 지급/3일 중복 및 실패 복구 테스트 필요.
- 클라라의 현지 인물·NPC·세계 후속 기록은 **기존 검증된 실제 엔딩 및 관측 원천/시점**을 따르고, 본부 DB가 세계 원래 상태를 소급 수정하지 않는다.
