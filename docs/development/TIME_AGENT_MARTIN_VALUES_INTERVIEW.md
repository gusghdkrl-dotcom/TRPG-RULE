# 마틴 헤일 — 첫 면담의 임무 철학·개인 가치관·후속 평가 (DEV)

## 1. 대목표와 현지 인물에 대한 두 책임

마틴은 첫 신입 면담에서 다음을 명확히 설명한다.

- **세계와 사람을 지키는 임무:** 평행세계의 붕괴·참사와 그 후속 피해를 가능한 범위에서 막거나 줄이고, 실제로 알아낼 수 있는 세계의 진실과 위협의 근원을 탐구한다. 기존 TIME_AGENT_CONCEPT_DRAFT.md §30.1의 "진실을 밝히고 피해를 최소화하라"를 구체적으로 전달하는 것이다. **모든 세계의 붕괴가 예정돼 있지는 않으며**, 원작의 불가역 주요 재난 발생 자체를 예방하도록 강요하지 않는다. 진상 완전 규명이 구조/탈출/안전보다 무조건 우선하지 않는다.
- **동기화된 사람을 존중하는 임무:** 현지 PC는 원래 이름·기억·가족/관계·직업·가치관·안전을 가진 세계의 실제 사람이다. 요원의 대목표를 유지하면서도 **그 인물이라면 할 법한 행동과, 그 사람의 생존·미래·관계**를 중요한 판단 근거로 삼는다. 현지 인물을 일회용 몸·무료 자원으로 대하지 않는다.
- **긴장의 여지:** 두 책임이 충돌하는 상황에서 사전에 강제된 정답은 없다. 실제 정보, 위험, 가능한 대안, 해당 인물의 기존 성격과 변화 가능성을 고려하며 **행동과 말·가치 판단은 플레이어가 결정**한다. 인물과 다르게 보이는 행동도 실제로 그럴 법한 이유·극한 상황·성장/변화가 있으면 허용한다. 규칙으로 행동을 막거나 강제 피해·미리 정한 성격 판정으로 벌하지 않는다.

## 2. 마틴의 첫 가치관 면담 — 3가지 대화 주제

제이든의 첫 안내 뒤 **실제 마틴을 대면**할 때, 역사/동기화/작전 목표 설명과 엮어서 마틴이 요원마다 세 주제를 자연스러운 질문으로 던진다.

1. **가장 소중한 사람과 대임무:** "그 사람에게 소중한 누군가가 있고, 작전은 당장 다른 곳을 요구한다면 어떤 기준으로 판단하겠습니까?"
2. **진실과 안전의 경계:** "더 깊은 진실을 알아낼 기회가 있지만 동기화된 사람의 목숨을 걸어야 한다면, 어디에 선을 긋겠습니까?"
3. **현지 인물답게 행동한다는 것:** "임무 때문에 그 사람이 평소라면 하지 않을 선택을 해야 한다면, 무엇을 먼저 따져 보겠습니까?"

이 문장은 마틴 말투의 예시이며 강제 반복 대본이 아니다. 한 번에 세 질문을 쏟아내지 말고 각각 실제 답을 듣고 반문/인정/이견 등 자연스러운 반응을 준다. 이미 말한 답과 의미가 중복되면 추가 시험을 강요하지 않는다. 각 요원의 답은 **직접 발언·답변 유보·모름·질문 거절** 모두 존중한다. 정답·A/B/C 성격유형·호감도/충성도 숫자·입단 통과 시험은 만들지 않는다. 1~3인 팀의 실제 발화자·청취자는 서로 구별한다.

마틴 예시: "우리가 가는 곳에는 위험과 사람의 삶이 함께 있습니다. 진실을 가져오는 건 중요하지요. 하지만 그 진실을 위해 누군가의 삶을 마음대로 담보로 삼을 권리는 없습니다. 당신이라면 무엇을 먼저 살피겠습니까?"

## 3. 개인별 실제 영구 기억의 기존 DEV 계약

새 DB 스키마는 만들지 않고 **기존** `trpg_hq.record_npc_interaction(p_team_id,p_event_key,p_expected_revision,p_payload)`을 사용한다. 마틴의 NPC key는 `npc:martin`이다.

- `p_event_key`: 해당 팀/입단식의 실제 개별 면담에 대해 재호출에도 동일하게 쓰는 안정적인 고유 이벤트 키. 가짜 완료/중복 생성 금지.
- `p_payload`: `npc_key`, `present_agents`(참석한 영구 UUID 배열), `speaker_key`(`npc:martin` 또는 실제 발언 요원), `location`, `summary`, `utterances`(실제 질문·답 각각 `speaker`/`text`/`heard_by`), `observations`(실제 관측 근거만), `changes_by_agent`(실제 원인 있는 관계/지식 변화만, 없으면 빈 객체), `elapsed_minutes`(실제 경과)를 담는다.
- 플레이어가 말하지 않은 마음속 가치관/행동/서약을 만들지 않는다. 실제 발언 문구가 판단 기준을 바꾼다면 **원문**을 보존한다. 마틴의 귀로 도달하지 않은 이야기를 마틴이 이미 들은 것으로 기록하지 않는다.
- 저장이 허용된 개발용 키퍼 연결에서 실제로 성공하고 검증된 경우에만 **영구 기록 완료**라고 말한다. 미연결/실패 상태에서는 현재 작업 맥락의 **미저장 대화**로 두고 게임 진행 가능 부분은 유지한다. 운영 DB/기존 세이브/다른 팀의 기록을 무단 변경하지 않는다.
- `trpg_hq.load_npc_agent_context(team_id,'npc:martin',agent_id)`로 **해당 팀·해당 요원에게 실제 연결된** 면담/개인 기억을 확인한다. 다른 팀으로 자동 영구 승계된다고 가정하지 않는다. 출격 전 연관 기록의 보존/복원 검증은 기존 본부 계약에 따른다.

## 4. 이후 귀환·평가와 캐릭터 성장

귀환 후 마틴은 자신이 실제 들었던 면담 답과, 해당 임무의 검증된 **진실 발견, 참사·확산 억제, 사람 구조, 현지 PC의 생존/관계·기존 삶, 선택 당시의 수단·정보**를 연결해 개별 정성 피드백을 준다. 임무의 최종 결과와 기록은 기존 검증된 세계 정본/체크포인트에서 취한다. 요원에게 동의하지 않은 감정·후회·결심을 부여하지 않는다.

기존 `trpg_hq.evaluate_segment`의 `p_assessment` 서술과 NPC 후속 대화에 반영할 수 있으나, **S/A/B/C/F 등급·대사건 훈련 자격·연대기 공식 실적·보상·카드/진급 조건에 신규 숫자 가감/성격 일치도 점수를 신설하지 않는다**. 입단 답과 실제 행동이 달라졌어도 그 이유/새 경험을 실제 상황에서 다루며 자동 벌점으로 취급하지 않는다.

**소급 금지:** 이미 진행 중인 현지 게임의 플레이/완료된 입단식을 중지·재실행하지 않는다. 현재 이후 적격한 본부 대화에서 플레이어가 자유롭게 가치관을 말한다면 그 실제 발언만 기존 기억 절차로 기록한다. 기존 PC의 확정된 성격/행동·과거 세이브를 바꾸지 않는다.

## 5. 구현·검증 상태

이 문서는 개발 브랜치의 면담·평가 설계/기존 RPC 호출 지침이다. **실제 사용자의 면담 답변을 지금 DB에 추가하거나 저장 성공/귀환 평가 완료를 주장하지 않는다.** 실제 게임 UI·키퍼가 이 지침을 읽고 플레이어 입력→`record_npc_interaction`→재조회→`load_npc_agent_context`→귀환 `evaluate_segment` 흐름을 검증해야 영속 연동이 완료된다.
