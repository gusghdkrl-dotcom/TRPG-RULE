# 시간요원 본부 고정 NPC 8인 — 승인된 외형 참고 기준

- 구분: 기존 NPC 설정을 보존하고 **2026-11-13 대화에서 직접 확정한 배우 참고·외형 디테일을 보강**한 개발 문서
- 상태: **설정 정리 완료 / 인물별 공식 초상 미승인**. 이미지 제작을 승인 또는 실제 영구 이미지 등록으로 간주하지 않음
- 우선 근거: 기존 `docs/development/TIME_AGENT_CONCEPT_DRAFT.md` §6.3·관련 후속 확정 절, `rules/08-visual.md`의 `CHARACTER_VISUAL_CANON`, `VISUAL_ASSET_PERSISTENCE_BOUNDARY`
- 활용: 배우는 **얼굴·분위기 참고**일 뿐 배우의 실명·영화/드라마 배역·성격·경력을 NPC에게 이식하지 않는다. 아래 인물의 기존 성격·목적·업무·초기 관계는 유지한다.
- 정본 관리: 8명은 최초부터 한꺼번에 강제 소개하지 않는다. 실제 본부 교류/업무/위치/정보에 따라 등장. 이 문서는 **인물 외형/기본 성격의 기준**이지 모든 대화의 정답 대본이나 승인된 이미지 URL이 아니다.

## 공식 초상 제작·사용 게이트

1. **마틴부터 한 명씩**, 위 인물 외형을 바탕으로 일관된 형식의 초상 시안을 제작하고 플레이어가 개별 승인한다.
2. 승인 전 시안·인터넷 인물 사진·단순 배우 참고 사진을 NPC의 '공식 고정 이미지'로 가장하지 않는다.
3. 승인 후 해당 NPC의 위 **고유 ID**에 연결되는 영구 접근 가능한 원본 또는 검증된 asset ref를 따로 등록한다. 임시 대화 이미지 주소·모델의 묘사만으로 같은 사진의 재사용을 보장할 수 없다.
4. 게임에 실제 연결한 경우, 프로필 노출 시 해당 공식 자산을 재사용한다. 로드할 수 없으면 **다른 무관한 얼굴 사진 대신 캐릭터의 실제 외형 설명을 표시**한다.
5. 외형 이외의 미확정 세부(새로운 과거 사건·새 계급·장비 기능·특정 복식 상징·숨겨진 관계 등)는 시안 과정에서 임의로 정본화하지 않는다.
