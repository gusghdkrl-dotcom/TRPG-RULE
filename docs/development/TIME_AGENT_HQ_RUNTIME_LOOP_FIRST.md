# 시간요원 본부 — 실제 플레이 루프 우선 구현 계약 (11차, DEV ONLY)

> 적용 우선순위: **본부 진입 → 입단식 → NPC별 업무 → 원작 게임 출격 → 실제 종결/귀환 → 평가/기록/보상 → 본부 생활 반복.**
> 사용자 최신 결정(2026-11-12): **NPC 8명은 당분간 구조적 역할·서비스·기억 저장 경로만 완성**한다. 세밀한 말투, 대화별 감정/관계 동기화, NPC↔NPC 세부 일상은 루프가 실제 플레이에서 동작한 뒤 별도 개발한다. 기술적 동시 지급 부하 시험도 순차 1명씩 처리하는 실제 플레이를 막지 않는 범위로 후순위 이동.
> 개발 영역은 `dev/time-agent-hq` / `trpg-time-agent-dev`만. 운영 `main`, 운영 Supabase, `START_GAME.md`, `rules/*`, `dist/*`, 실제 세이브에 적용하지 않았다.

## 2. 게임에서 실제 적용할 순서

### 2.1 OFF / ON 첫 설정과 입장
1. 기존 `START_GAME.md`의 게임 시작 입력에서 **이식 후** 라벨만 `요원 활성화 ON/OFF`로 변경. **OFF는 기존 원작/PC/카드OFF 흐름 그대로**; 본부 입단/UUID/보상/동기화도 생성하지 않음.
2. **ON 첫 화면은 1~3인·각 영구 닉네임만** 받고, 원작 인지도·규모·직접 지정/배제 설정은 본부 작전실의 실제 임무 선택까지 연기. 유효한 입력 확정 전에는 `begin_hq_on_visit`를 실행하지 않음.
3. 신입 중 실제 첫 입단 기록/클리어 기록이 없는 요원이 있으면 본부 입구 → 제이든 접촉 → 마틴 첫 입단식·면담. **팀 전원이 함께** 이동하고, 각자 말·의견은 실제 입력만 기록. 최초 행사/면담을 실제로 경험한 뒤에만 `record_hq_induction`과 `record_npc_interaction` 호출.
4. 이미 입단한 경력 요원의 새로운 ON 게임은 동기화실에서. 입단식은 다시 하지 않는다. 팀에 신입/경력 혼합이면 신입의 실제 입단 참여만 새로운 기록으로 만들고 기존 직원과 동료는 기존 기억 유지.
5. **현지 게임 진행 중 V2 세이브 로드는 본부 방문이 아님**. `begin_hq_on_visit`의 `resume_field` 또는 실제 세이브 복원에 따라 현지 위치·시각·열린 대응에서 즉시 재개. 부당한 출격/귀환·보상/본부 시간 재실행 금지.

### 2.2 입단 후 본부와 8명의 NPC
- 작전실: 마틴 — 첫 인사/면담, 임무 세계 선택, 정식 목표·위험 등급 브리핑, 귀환 후 구체적 수행 평가·자격/보상 승인.
- 동기화실·본부 생활: 제이든 — 첫 안내·전송/귀환·사교적 교류. 현지의 평범한 상황에 자유 무전하지 않음. 재투입/치명상 연결은 확정된 별도 조건일 때만.
- 기록·분석실: 클라라 — **출격 전에는 이미 확인된 세계 정보만**, 귀환 후 현지 PC/NPC/공동체의 실제 관측 가능한 삶·변화에 관한 기록/열람·개별 추가 질문. 전지적 미래 조회 불가.
- 의료·지원 구역: 도미닉 — 원래 66장 도감·클래스/4슬롯 장착·영구 성장·훈련/장비, 실제 적격 보상 후보 제시·플레이어 선택 후 원장 지급.
- 사미라 — 자신의 경험/제한적 조언·실제 교류(임의 작전 성공이나 무상 보상 없음).
- 레오 — 동료 교류·생활/물류 경험에 따른 실제 사회적 행동.
- 최서린 — 의료/구조 경험에 따른 조언·대화(현지 HP 무상 회복 자동 부여 금지).
- 마야 — 경험과 기준에 따른 토론·경쟁/협력, 요원과의 개인 관계는 실제 사건 이후에만 변화.
- 네 핵심 담당자(마틴·제이든·도미닉·클라라)는 실제 필요한 장면에 등장하고, 나머지 동료는 자연스럽게 접촉한다. **8명 전원 방문·의무 대화·반복 행사 금지.** 방문은 구매·약속·대사 수락이 아니다. NPC별 개인 기억 데이터/실제 청취자 기록은 기존 5차 구조에만 근거해 갱신; 말투 미세 동기화는 후속.

### 2.3 실제 원작 게임 실행
1. 팀이 작전실에서 인지도·규모·기피/지정 세계관을 선택. 기존 `04-setup` 원작 후보·현지 PC/관계·세계 설계/실제 위험·합당한 적·시대·직업 절차 실행.
2. 영구 UUID를 기존 카드 캠페인에 연결, 전원 본래 현지 PC 생성·실제 원본 특성/성장 스냅샷, 주 클래스·4슬롯 장착을 **플레이어가 직접 확정**.
3. 비공개 세계 정본/원본 SHA·판본/필수 절을 저장·검증. 본부 `prepare_mission`는 이 세션/campaign과 실제 마틴 사전 소목표(중요도 포함)·위험 등급을 링크.
4. 마틴의 정식 브리핑은 **세계·PC/장착/정본 검증 후**. 클라라가 같은 공개 가능한 관측 정보만 보조. `record_martin_formal_briefing`은 실제 발언한 요지와 정본 SHA를 저장.
5. 팀의 **출격 선언** 후 `depart_after_actual_briefing` → 제이든의 실제 동기화 장면 → 원작 현지 위치/시간/위협에서 플레이. 대사건은 훈련, 연대기는 같은 세계의 챕터가 이어지는 실제 작전. 현지에서는 기존 01~09 규칙과 V2 저장/복원을 적용한다.

### 2.4 실제 종료 후의 본부 루프
1. 플레이 중 열린 대사·판정·생존 대응/추격/후일담을 먼저 완료. `06-play ENDING_FINALIZATION_GATE`, `07-state`에 따라 **정당한 CAMPAIGN_TERMINAL / CHAPTER_TERMINAL / CHRONICLE_TERMINAL**을 확정하고 실제 원본의 검증 저장. **종결·검증 전에 임의 귀환/훈장/보상 지급 금지**.
2. 검증된 종료 → 기존 `confirm_segment_terminal` → 실제 가능한 본부 귀환만 `return_segment`: **귀환당 정확히 +4320분**. 연대기 최종 챕터 귀환이 전체 완료와 같은 이벤트면 +3일 추가 없음. 전원 사망·미귀환은 귀환을 꾸미지 않는다.
3. 동기화실 제이든이 귀환·상태를 맞이한 뒤, 마틴은 **사전에 받은 목표와 실제 피해·구조·위험의 결과**를 평가한다. `evaluate_segment`→ 실제 적격 `approve_general_reward`→ 대사건 훈련 성공 시 `certify_training`, 첫 연대기 전체 완료 시 `approve_chronicle_completion` 등 사실 기반.
4. 클라라의 기록 열람은 **관측된 자료만**, 개인 관심 인물에 대한 실제 질문은 각 요원별 기록. **기록실 방문을 보상/다음 임무를 여는 필수 체크리스트로 강제하지 않음**.
5. 도미닉 일반 카드 드래프트/특별 A/B는 **기존 09-cards 실제 후보·Python SystemRandom·사용자의 직접 선택 후에만** `offer_*/resolve_*`. 미선택 보상은 그대로 보존하고 새 임무 또는 재접속이 기존 보상을 소급 지급/취소하지 않는다.
6. 다시 휴게실·일상/다른 본부 업무, 또는 다음 원작 선택·연대기 후속 챕터 준비로 이어간다. 이미 처리한 평가·수여·3일 경과를 반복하지 않는다. 본부의 실제로 확인된 최신 상태를 읽고, 출격 당시 낡은 사본으로 덮어쓰지 않는다.

## 3. 실제 통과한 개발 테스트 (상세는 DEV_ENV_STATUS)

1. **신입 A+B 2인**: 첫 새 ON 방문 `entrance`; NPC 서비스 총8개. 실제 가상 입단 행사 참가자별 1회·행사 시간9분; 같은 entry/행사 재호출 추가 상태/시간0. 두 번째 새 ON 게임 `sync_room`; 현지 segment `field_active`에서 새 채팅 복원 요청은 `resume_field`이고 **새 HQ 방문 이벤트0/시간 증가0**.
2. **A 1인 첫 대사건 전체 루프**: 본부 입구→실제 입단 기록→캠페인/현지 PC/성장 스냅샷/최초 카드 4슬롯→세계 정본→마틴 사전 목표·브리핑→제이든 출격. 브리핑 없는 출격 거부; 실제 V2 `commit/verify` 후 `confirm_segment_terminal`→귀환 +4320분→마틴 평가/보상 승인→도미닉 실제 일반 드래프트 `resolved`→대사건 훈련 자격 인증→본부 자유 활동→다음 새 ON `sync_room`.
3. 진행 안내 오류 수정: **도미닉 미선택 보상이 있는데 마틴 훈련 인증 안내가 먼저 표시되는 결함**을 `phase11c`에서 수정해 보상 미선택 상태를 보존. 재시험 전체 루프 성공.
4. 두 회귀는 모두 **합성 세계/요원/PC/사전 목표/마틴 평가**만 사용하고 성공 후 트랜잭션 롤백. 실제 게임에서 플레이어 행동·공개 지식/고유 말투·공포 사건·재투입을 실행했다는 뜻은 아님.

## 4. 현재 경계: 무엇이 아직 완료가 아닌가

- **실제 ChatGPT 테스트 프로젝트 진입점 미연결**. 이 문서는 ON 개발 전용 루트/DB 함수이며 `main START_GAME`/실제 채팅 첫 화면을 아직 바꾸지 않았다. 별도 테스트 프로젝트가 현재 사용할 GitHub 개발판 스킬/도구가 있는지, 권한 있는 HQ API를 호출할 수 있는지 확인한 뒤 실제 키퍼/채팅/저장/복원 전체 테스트가 필요.
- **정본 최신 main 룰북 회귀 미완**. 현 DEV 분기는 과거 00~09 판본에서 분기했다. 운영 `main`의 새 규칙판, SAN/사망·세이브·카드/장착, 기존 ON/OFF 경로를 덮어쓰지 않고 차이 대조.
- 실제 플레이 **대사건 사망→본부 의식 연결→적격 현지 NPC 재투입 / 연대기 사망 직전 1회 생존 특성** 연동 미완. 원래 02/03과 06/07 판단 및 사용자 확정 예외가 선행되어야 함.
- **특수 맥락**: 합성 세계의 실제 시나리오 생성/원작 체험/후일담5개, 출격 시 현지 저장의 HQ 링크 자동 주입/재개 경계, 클라라가 후일담 이후 실제 관측할 수 있는 장기적 세계 변화, 본부 3일간 NPC 독립 생활은 별도 키퍼 통합 시험 필요.
