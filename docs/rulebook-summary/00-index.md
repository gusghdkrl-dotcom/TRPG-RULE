# rules/00-index.md — 문서별 구조화 요약

> **자료 성격:** GitHub `2447e73` 기준 읽기·감사용 정리본. 게임 실행 정본은 [원래 문서](../../rules/00-index.md)이며, 이 요약은 규칙을 새로 만들거나 우선순위를 변경하지 않는다.

**담당 역할:** 상황→정식 규칙 ID/담당 파일을 찾아가는 라우터. 규칙 본문이 아니므로 신규 판정·게이트를 이 색인만으로 만들지 않음.

**핵심:** 각 상황별 원본 담당 ID와 파일 경로를 빠뜨리지 않기 위해 라우터 표를 보존해 목록화.

**포괄 기준:** 원문의 모든 비어 있지 않은 내용 행을 순서대로 연결하고, 수치·구문이 긴 행은 핵심 조건과 예외를 짧게 압축한다. 각 L번호는 고정 원본으로 바로 연결된다. 요약으로 축약된 세부 조건·수치 판단은 원문을 확인해야 한다.
