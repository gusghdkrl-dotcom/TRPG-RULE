## 규칙을 찾을 때의 실제 순서

1. **상시 판단·첫 시작:** [PROJECT_INSTRUCTIONS](./PROJECT_INSTRUCTIONS.md) → [START_GAME](./START_GAME.md). 신입 ON/기존 요원/OFF와 PC 입력 대기 경계부터 구별한다.
2. **발동 규칙 조회:** [00-index](./00-index.md)에서 현재 상황의 정식 ID를 찾고, 판정·수치/금지/예외가 있는 실제 소유 절(01~09)을 확인한다.
3. **세계 사전 구성:** [04-setup](./04-setup.md)의 원작 출처/PC별 인과, 초기 불가역 G·조건부 E·적 풀·진실/봉쇄·결말을 [07-state](./07-state.md)의 검증되는 10절 정본에 연결한다.
4. **실제 플레이 처리:** [01-core](./01-core.md) 주도권·난수 → [02-checks](./02-checks.md) 판정/HP → [03-danger](./03-danger.md) 전투/SAN → [05-world](./05-world.md) 자율 행동/현장 인과 → [06-play](./06-play.md) 장면/시간/다인/종결 → [07-state](./07-state.md) 현재 상태·저장·재개를 필요할 때 호출한다.
5. **시각·카드 특화:** [08-visual](./08-visual.md) 지도/인물 정본과 [09-cards](./09-cards.md) ON 한정 실물/효과/드래프트·성장을 별도로 확인한다.

## 사용 및 유지보수 경계

- 이 요약은 **충돌을 해결하거나 원본의 중복을 삭제한 패치가 아니다**. 원문 사이 상반된 조건이 있으면 요약 중 어느 문장을 근거로 우회하지 말고 각 담당 규칙의 적용 대상/선행 상태·비소급을 대조한다.
- 링크의 L번호는 위 커밋에서 확인한 원문의 위치다. 정리본을 갱신할 때는 현재 최신 `main`을 새 기준으로 다시 대조하고, 아래 인벤토리의 규칙 ID 180개·원문 행/카드 개수가 맞는지 확인해야 한다.
- 소유자 검증 세이브·비공개 정본/인증정보·운영 DB·카드 원장은 이 공개 요약에 싣지 않는다. 배포 `dist/TRPG-RULE-project.zip`도 변경 대상이 아니다.
