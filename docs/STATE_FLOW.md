# 룰북·세계 정본·현재 상태·파일 세이브

실행 정본은 rules/07-state.md이며 이 문서는 개발·사용 안내다. 실제 캠페인 정보는 포함하지 않는다.

| 필요한 정보 | 확인할 곳 |
|---|---|
| 규칙·기능 선택·판정/위험 절차 | 해당 룰북 ID |
| PC 수치·현재 NPC 반응·상태·입력 대기 | 실제 현재 작업 상태 |
| 불변 진실·세계 법칙·원래 지도 | 정확한 정본 판본의 관련 절 |
| 확정된 비공개 변화 | STATE_PRIVATE_WORK: 변화가 있을 때만 작업 JSON에 기록·재읽기 |
| 현재값 유실·새 채팅 복원 | 사용자가 선택한 FILE_SAVE_V1 전체 파일 |
| 구판 파일 변환 요청 | 사용자가 이미 보유해 제공한 전체 원문·정본 |

일반 턴은 현재 문맥의 확인된 사실에 결과를 반영한다. 공개 진행은 매 턴 파일에 복사하지 않고 비공개 변화만 STATE_PRIVATE_WORK의 실제 작업 파일에 일괄 반영한다. 규칙 검색·정본 조회·저장은 서로 다른 작업이다. 매 턴 전체 직렬화/DB 조회를 하지 않는다. 작업 상태는 별도 숨은 영구 메모리가 아니며 문맥에서 빠질 수 있다. 없는 현재값을 과거 상태나 새 창작으로 메우지 않는다.

신규 정본은 실제 파일로 생성·재읽기한다. 비공개 정본 조회는 등록된 동일 판본 프로젝트 소스를 기본으로 하며, 미등록/접근 불가이면 세이브 내 동일 판본 전문을 사용한다. FILE_SAVE_V1 안에 모든 활성 참조 정본 전문을 포함하므로 다른 프로젝트로 옮겨도 세이브 하나로 복원할 수 있어야 한다. 실제 읽기 도구가 필요하며 파일명·검색 발췌만으로 전체 읽기라 하지 않는다.

정본 재독은 Scene Turn 20/40/60… 안전 경계, 파일 저장과 전체 상태 복기는 시작·Scene Turn 30/60/90… 안전 경계다. 60배수에서 같은 실제 읽은 본문을 재사용한다. 저장은 setup_bootstrap·play_start·전체 캠페인 종료·수동 요청에도 수행한다. 현실 시간 백그라운드 작업은 아니다. 수동 저장은 열린 판정까지 보존하고 저장/로드 자체는 세계 시간·난수·피해를 진행하지 않는다.

파일 저장은 실제 최신 원본 동결 → STATE_RESTORE_CONTRACT의 RESTORE_V1 11영역·전체 경로·입력 대기 등록 → 원본과 payload 대조 → 실제 해시 계산·파일 생성 → 전체 재읽기와 동결 원본/해시/식별/참조/의미 확인 → 다운로드 제공이다. 같은 payload에서 PRIVATE_SOURCE_V1 MD도 생성·재읽기해 두 파일을 전달한다. JSON은 새 방 첨부, MD는 프로젝트 소스 교체용이다. MD의 고정 정본 전문과 현재 비공개 상태를 구별하며 다른 분기/시점의 동적 값은 섞지 않는다. 사용자 기기의 다운로드 완료는 알 수 없으며 링크/실행 공간은 영구 보관이 아니다. 생성·검증·전달 실패를 구별하고 이미 제공한 파일의 상태를 원격 실패 때문에 취소하지 않는다.

NPC 말투·호칭·관계·공동 경험·실제 지식, 상태의 영향·해제·남은 경과, 현재 대화·미결정 선택, 완료 난수/적용 이력까지 보존한다. 이전 출력과 동일한 문장 생성이나 무손실 모델 기억을 보장하지 않는다. 데이터 완전성 검토와 해시 검사는 별개다.

새 채팅은 실제 선택한 파일을 처음 한 번 전체 읽어 검증·복기·현재 상태 구성을 함께 수행하고 해당 분기의 저장 지점부터 이어간다. 이후 확정 변경을 현재 상태에 즉시 반영하고 같은 최신값으로 기존 HUD를 출력한다. 매 턴 파일 재로드/전체 검증을 붙이지 않는다. 실제 유실 시 현재 문맥의 마지막 확인값·이후 변경부터 대조하고 부족한 범위만 복구한다. 부모 파일 없이 독립 복원하되 다른 분기를 자동 합치지 않는다. 공개 수첩이 현재 파일 식별자를 지원하지 않으면 연결만 보류한다. 지원하지 않는 검증 번호를 만들어 보내지 않는다.

게임용 외부 저장·불러오기·백업·재동기화 경로는 제거했다. 기존 서비스의 데이터/권한/스키마는 변경하지 않는다. 계정에서 지원되는 Library/Space의 실제 저장 파일을 재사용할 수 있지만 등록/보관/접근 성공은 확인 없이 주장하지 않는다. 파일 방식도 모든 환경의 도구 실행이나 무차단을 보장하지 않는다.
