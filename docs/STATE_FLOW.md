# 룰북·세계 정본·현재 상태·파일 세이브

실행 정본은 rules/07-state.md이며 이 문서는 개발·사용 안내다. 실제 캠페인 정보는 포함하지 않는다.

| 필요한 정보 | 확인할 곳 |
|---|---|
| 규칙·기능 선택·판정/위험 절차 | 해당 룰북 ID |
| PC 수치·현재 NPC 반응·상태·입력 대기 | 실제 현재 작업 상태 |
| 불변 진실·세계 법칙·원래 지도 | 정확한 정본 판본의 관련 절 |
| 현재값 유실·새 채팅 복원 | 사용자가 선택한 FILE_SAVE_V1 전체 파일 |
| 구판 원격에서 복원하라는 명시 요청 | 실제 권한·계약을 확인한 원격 원문 |

일반 턴은 현재 문맥의 확인된 사실에 결과를 반영한다. 규칙 검색·정본 조회·저장은 서로 다른 작업이다. 매 턴 전체 직렬화/DB 조회를 하지 않는다. 작업 상태는 별도 숨은 영구 메모리가 아니며 문맥에서 빠질 수 있다. 없는 현재값을 과거 상태나 새 창작으로 메우지 않는다.

신규 정본은 실제 파일로 생성·재읽기한다. 프로젝트 소스 업로드는 선택이다. FILE_SAVE_V1 안에 모든 활성 참조 정본 전문을 포함하므로 다른 프로젝트로 옮겨도 세이브 하나로 복원할 수 있어야 한다. 실제 읽기 도구가 필요하며 파일명·검색 발췌만으로 전체 읽기라 하지 않는다.

정본 재독은 Scene Turn 20/40/60… 안전 경계, 파일 저장과 전체 상태 복기는 시작·Scene Turn 30/60/90… 안전 경계다. 60배수에서 같은 실제 읽은 본문을 재사용한다. 저장은 setup_bootstrap·play_start·전체 캠페인 종료·수동 요청에도 수행한다. 현실 시간 백그라운드 작업은 아니다. 수동 저장은 열린 판정까지 보존하고 저장/로드 자체는 세계 시간·난수·피해를 진행하지 않는다.

파일 저장은 현재 state와 정본 전문 구성 → 실제 해시 계산·파일 생성 → 전체 재읽기·해시/식별/참조/의미 확인 → 다운로드 제공이다. 사용자 기기의 다운로드 완료는 알 수 없으며 링크/실행 공간은 영구 보관이 아니다. 생성·검증·전달 실패를 구별하고 이미 제공한 파일의 상태를 원격 실패 때문에 취소하지 않는다.

NPC 말투·호칭·관계·공동 경험·실제 지식, 상태의 영향·해제·남은 경과, 현재 대화·미결정 선택, 완료 난수/적용 이력까지 보존한다. 이전 출력과 동일한 문장 생성이나 무손실 모델 기억을 보장하지 않는다. 데이터 완전성 검토와 해시 검사는 별개다.

새 채팅은 실제 선택한 파일의 전체 내용과 정본/현재값 관계를 검증하고 해당 분기의 저장 지점부터 이어간다. 부모 파일 없이 독립 복원하되 다른 분기를 자동 합치지 않는다. 공개 수첩이 원격 verified 번호만 받으면 연결만 보류한다. 파일 번호를 원격 검증 번호로 위조하지 않는다.

Supabase/GitHub는 기존 구판 복원·명시적으로 선택한 원격 모드에만 사용한다. 운영 DB/권한/스키마는 이번 변경 대상이 아니다. 파일 모드가 원격 차단 원인을 해결했다거나 어떤 환경에서도 도구가 보장된다고 말하지 않는다.
