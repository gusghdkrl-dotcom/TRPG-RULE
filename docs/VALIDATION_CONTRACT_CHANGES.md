# 통합판 검증 계약의 변경 근거

2026-11-09 생성 완성도 보완에서는 기존154개 의미계약·필수/금지/순서 구문을 전부 유지하고, 깊은 원인의 체험 연결·변화 조건/유지 범위·준비가 쓰이는 결정적 대응·실제 안전/탈출 경계·주요 NPC 관계의 행동 효과·정본 본문/ref와 완료 판단·관련 연결만 보완하는 시점을 추가했다. 새 훼손9건은 가능성만으로 설계 완료·원인을 배경으로만 처리·조건 없는 세계 변화·단순 이동을 안전으로 간주·행동에 영향 없는 관계·미완료 설계 통과·매 응답 전체 재검토·제목만 갖춘 정본 완료·고정 보스/전모/근원 소멸 강제를 거부한다. 총72건으로 기존 회귀도 유지한다. 이 보호는 공통 지침의 문서 계약이며, 임의 자연어 캠페인의 품질이나 실제 LLM 장기 준수를 자동 판정하는 검사로 주장하지 않는다. 별도 파일/서버 필드·매 턴 검수·강제 피해를 추가하지 않았다.

2026-11-09 원작 체험 기반 재구성은 기존 필수 구문·금지·순서 계약을 삭제하거나 완화하지 않고, 원작 체험 모델/살아 있는 세계/조건부 상황망·비조사 성과·사람으로서의 NPC·미확정 미래 창작·진상 입증 없는 정당한 종결·현재 경험 보존의 최소 요구를 추가했다. 해당 개편에서 수치/예외·규칙 ID·버튼/상태 패널·현행 저장 수단은 유지했다. 상기 블록의 후속 삭제는 아래 변경 근거를 따른다. 새 고의 훼손8건은 모든 진행의 입증화·원작 이름만 교체·상황망 삭제·NPC 창구화·미래 동결·선택지 조사 편중·종결의 전증거 필수화·저장의 단서 목록 대체를 각각 거부한다. 기존 scene_context 삭제 회귀가 새 설명의 같은 필드명 때문에 통과한 문제는 표의 실제 재개 문맥 정의를 함께 요구하여 수정했다. 기존 실패 사례를 제거하지 않았다. 검사 자체는 실제 재미/장기 AI 준수의 증명이 아니다. 변경 목적과 분기 검토는 EXPERIENCE_FIRST_FOUNDATION/INTEGRATED_SCENARIO_REVIEW를 참조한다.
