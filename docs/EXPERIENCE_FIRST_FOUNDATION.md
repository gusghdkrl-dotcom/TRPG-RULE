# 원작 체험형 생존 공포의 공통 기반

## 진행의 중심

기본 순환은 **당면 목적 → 세계의 변화와 직접 경험 → 행동·관계·수단 선택 → 실제 결과 → 달라진 상황과 다음 목적**이다. 원작의 세계에서 살아가고 목적을 수행하며 위험을 겪는 것이 주 경험이고, 추리·미스터리는 그 경험을 설명하고 대응·신뢰·목표를 바꾸는 층이다.

진상 입증이나 새 증거가 없어도 구조·탈출·준비·관계·생활·성과는 실제 진행이다. 조사 경로는 원작/현재 목적에 필요하거나 플레이어가 원할 때 펼친다. 유효한 추리와 핵심 난관은 보존하며 자동 정답 공개·결론 대필을 추가하지 않는다.

## 세계 생성의 결과

| 구성 | 실제로 준비할 내용 |
|---|---|
| 원작 체험 모델 | 일상/공간·관계·위협·행동/대응·특유의 재미와 호흡이 PC의 직접 경험으로 연결되는 방식 |
| 살아 있는 세계 | 장소의 쓰임/생활·경로·사람들의 자기 목적/관계·실제 접근/협력 수단 |
| 조건부 상황망 | 지금 하려는 일·방해/기회·실제 접촉·서로 다른 행동·차단/실패 뒤 상황·준비/성과의 후속 활용 |
| 숨은 인과 | 원인·행위자·수단/권한·정보/접근 경로·조건·관측 결과·대응/차단. 핵심만 확정하며 전체 행정 절차를 만들지 않음 |
| 종결과 여파 | 실제 위협 제압/차단·구조·목적 성취·철수·불가역 실패. 모든 비밀/증거/법적 책임의 완결은 기본 의무가 아님 |

어떤 원작이든 기관 방문→증언→자료 대조→증거 확정으로만 진행되면 체험 설계 미완료다. 그렇다고 모든 장면에 공격·추격·손실을 할당하지 않는다. 원작의 실제 위험과 관계/유머·준비·안도·성취를 함께 설계하고 확보한 안전을 존중한다.

## 모든 새 캠페인·국면의 완료 기준

가능성의 목록을 완성된 세계로 간주하지 않는다. 원작의 깊은 원인이 실제 현상/공간·난관·관계·대응을 바꾸는 연결과, 중요한 변화의 기존 원인/상태·발동/억제·관측·효과/범위·가능한 대응·차단/실패 뒤 상태를 해당 정본 본문에 확정한다. 실제 이탈은 위험의 접근이 끊기는 경로/목적지·보호/차단 상태로 판단하고 단순한 구역 이동과 구분한다. 필요한 준비·도구·동료·이해가 결정적 대응에 쓰이는 방식도 연결한다.

이 운용성만으로 이야기의 깊이를 대신하지 않는다. 주요 진실의 전후에 무엇이 달라지는지 확인한다. 앞서 겪은 현상·물건·인물 행동의 실제 원인이 드러나 경험의 의미·문제 이해·관계 선택·위험/대응·대가·결말 중 무엇을 바꾸는가? 이 진실을 빼도 모든 경험/선택/결과가 같고 피해 대상 수·작업량·설명만 늘면 심화가 부족하다. 기술적 수치/경로/발동 조건의 충실성과 이야기의 체험/의미/선택을 각각 검토한다.

이번 사건의 내막은 원작의 공포가 실제로 일상·몸/인식·관계/공동체·세계 이해를 흔드는 방식으로 만든다. 우주론 전체는 불가해하게 남겨도 되지만 이번 사건의 의미/결정적 선택을 떠받치는 원인의 역할·주요 소재의 의미/한계는 정본에서 비워 두지 않는다. 인간 호러의 의심/폭력·초자연의 법칙·우주적 공포를 모든 원작에 같은 배신/유물/신격으로 고정하지 않는다.

주요 진실은 실제 행동·도주·구조·대면·위해·현상/인물 반응으로 접촉하고 새로운 대응으로 이어진다. 플레이어에게 공식 해석/감정/신뢰/목표를 대필하지 않고 자료 확인 단계를 자동 추가하지 않는다. 심화된 분기의 절정에서는 앞선 준비·관계·선택·대가와 이해가 해결 방식/생존·손실·여파에 함께 쓰인다. 예상 접점을 건너뛰는 초기 추리/예방과 창의적 해결도 인정하며 미공개 반전을 보여주려고 성과를 취소하거나 새 위협을 추가하지 않는다.

주요 NPC의 개인적 욕구·핵심 관계는 실제 협력·역할 분담·갈등·이탈 조건에 닿아야 한다. 형성하지 않은 PC 친밀감·전원 상세 과거·의무 배신/희생·고정 마지막 보스·근원 전체 소멸·진상 전모 설명은 추가하지 않는다. 원작에 맞는 불가해함과 미확정 장면의 창작은 유지한다.

COMPATIBILITY_GATE는 시작 전에 실제 본문/ref를 한 번 대조하고 새 챕터/중요한 미확정 국면 설계·관련 모순/누락 발견 때 해당 연결만 보완한다. 다른 수단/조기 차단과 실패/철수에서 성과·안전·다음 대응이 유지되는지도 조건부로 살핀다. 매 턴 전수 검토·고정 검토표·추가 검수 모델/도구·서버 필드는 요구하지 않는다. 기존 캠페인의 확정 진실/과거를 덮어쓰지 않으며 정본 개정은07-state의 판본 절차를 따른다.

## 신규 캠페인의 공포 체험과 절정 활용

2026-11-10 보강은 이후 신규 캠페인 생성에 적용한다. 기존 캠페인은 새 채팅으로 옮겨 재개해도 정본/진행을 이 기준으로 재설계하지 않는다. 주요 동기의 복잡화나 목표를 뒤집는 충격적 진실을 새 합격 조건으로 추가하지 않는다.

원작의 핵심 갈등/경험이 어떤 형상·공간·행동으로 나타나고 PC가 어떤 이동/접촉/구조/회피에서 겪고 대응하는지 해당 장소/위협/인물에 구체화한다. 모든 형상을 심리/죄책감의 상징으로 고정하지 않으며 물리·사회·생태·불가해함도 원작에 맞게 다룬다. 발동/차단 절차만 충실하고 공포가 추상적이면 체험 설계가 남아 있다. 상징 해설·정답 고백·선불 SAN 감소로 채우지 않는다.

절정의 활용은 주요 경험/관계/준비가 어떤 조건에서 행동·협력/역할·위험/수단·해결/구조/탈출·대가/여파를 바꾸는지로 설계한다. 실제 형성/선택된 부분만 사용하고 미형성 신뢰·미선언 희생·모든 물품 사용을 가정하지 않는다. 간단한 예방/차단도 유효하며 고정 마지막 전투나 필수 참상을 추가하지 않는다. 기존 담당 절/ref와 현재 작업 상태로 처리하고 매 턴 재검수·새 파일/서버 필드를 만들지 않는다.

## 신규 캠페인의 초기 이탈과 탈출

2026-11-10. 이후 신규 캠페인은 정상 동선의 귀가/우회·관여 축소와 의도적 도주도 생존 국면으로 설계한다. 시작 때 위험권에 들어온 근거와 실제 영향 범위·경로/출구·바깥 안전을 정하고, 각 경로에 닿는 기존 원인의 추적/차단/노출·관측/대응·준비/우회·실패 뒤 상태를 연결한다. 조사/의뢰를 수락해야만 모든 위해가 시작되거나 단순 운항 일정/요금만으로 철수가 완성되는 설계는 보완한다. 어느 특정 원작의 섬/선박/의례/시설을 공통 패턴으로 복제하지 않는다.

PC의 출발 의도가 세계의 새 공격 스위치는 아니다. 인물의 실제 인지/전달·위치/시간·수단, 환경/생물/초자연의 사전 조건으로 접근이 성립해야 한다. 도달한 위해는 기존 판정으로 HP/SAN·부상·광기·소모·사망 가능성까지 적용하고 이탈 실패의 잔존 위치/추격/손실을 보존한다. 상처를 입고 간신히 살아 나가거나 못 나가는 결과도 가능하다. 고정 피해를 지불해야 엔딩을 주거나 우회/예방 성공·이미 확보한 안전을 취소하지 않는다. 위험을 실제로 끊은 빠른 이탈은 유효하다.

## 키퍼의 창작 범위

확정된 과거·위협의 능력/한계·PC 선택·소유/성과는 지킨다. 미확정 후속 상황은 그 인과와 현재 위치/정보에 맞게 창작하고 현재 상태로 남긴다. 사전에 적지 않은 미래 사건은 발생 불가라는 해석이나, 재미를 위해 과거/능력을 소급 변경하는 해석을 모두 거부한다.

NPC는 창구/증언자뿐 아니라 함께 행동하고 갈등·협력·유머·손실을 겪는 사람이다. 직업상 신중함만 Voice로 반복하지 않으며 개인의 생활/욕구·관계·실제 경험이 행동을 바꾸게 한다.

## 유지한 기능과 전환 경계

판정·HP/SAN·성장·행운·실제 Python 난수·플레이어 주도권·UI·상시 진행 원칙·현행 저장 수단/계약은 유지한다. 누적 경험은 기존 story_context/scene_context/ongoing_consequences에 담으며 새 서버 필드를 가정하지 않는다.

기존 캠페인의 진실·인물·위협·플레이 성과를 이 방향으로 소급 덮어쓰지 않는다. 별도 새 캠페인은 다른 정본/식별자로 작성하고 이전 진행과 섞지 않는다. 비공개 설계/세이브는 이 저장소나 배포 ZIP에 넣지 않는다.

## 검토의 실제 한계

자동 검사는 문서 연결·보호 문구·숫자/상태 계약을 확인한다. 시나리오의 플레이 경험은 서로 다른 행동·조기 차단·철수·도움 요청·실패·관계 선택으로 수동 대조한다. 이 대조와 파일 무결성은 실제 ChatGPT 장기 플레이의 재미/준수·도구/저장 왕복·응답 시간 검증을 대신하지 않는다.
