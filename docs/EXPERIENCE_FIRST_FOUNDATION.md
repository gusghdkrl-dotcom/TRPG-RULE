# 원작 체험형 생존 공포의 공통 기반

2026-11-09. 실행 담당은 PROJECT_INSTRUCTIONS와04-setup/05-world/06-play/07-state다. 이 문서는 변경 근거와 수동 검토 기준이며 게임 소스로 올리지 않는다.

## 진행의 중심

기본 순환은 **당면 목적 → 세계의 변화와 직접 경험 → 행동·관계·수단 선택 → 실제 결과 → 달라진 상황과 다음 목적**이다. 원작의 세계에서 살아가고 목적을 수행하며 위험을 겪는 것이 주 경험이고, 추리·미스터리는 그 경험을 설명하고 대응·신뢰·목표를 바꾸는 층이다.

진상 입증이나 새 증거가 없어도 구조·탈출·준비·관계·생활·성과는 실제 진행이다. 조사 경로는 원작/현재 목적에 필요하거나 플레이어가 원할 때 펼친다. 유효한 추리와 핵심 난관은 보존하며 자동 정답 공개·결론 대필을 추가하지 않는다.

## 세계 생성의 결과

| 구성 | 실제로 준비할 내용 |
|---|---|
| 원작 체험 모델 | 일상/공간·관계·위협·행동/대응·특유의 재미와 호흡이 PC의 직접 경험으로 연결되는 방식 |
| 살아 있는 세계 | 장소의 쓰임/생활·경로·사람들의 자기 목적/관계·실제 접근/협력 수단 |
| 조건부 상황망 | 지금 하려는 일·방해/기회·실제 접촉·서로 다른 행동·차단/실패 뒤 상황·준비/성과의 후속 활용 |
| 숨은 인과 | 원인·행위자·수단/권한·정보/접근 경로·조건·관측 결과·대응/차단. 핵심만 확정하며 전체 행정 절차를 만들지 않음 |
| 종결과 여파 | 실제 위협 제압/차단·구조·목적 성취·철수·불가역 실패. 모든 비밀/증거/법적 책임의 완결은 기본 의무가 아님 |

어떤 원작이든 기관 방문→증언→자료 대조→증거 확정으로만 진행되면 체험 설계 미완료다. 그렇다고 모든 장면에 공격·추격·손실을 할당하지 않는다. 원작의 실제 위험과 관계/유머·준비·안도·성취를 함께 설계하고 확보한 안전을 존중한다.

## 키퍼의 창작 범위

확정된 과거·위협의 능력/한계·PC 선택·소유/성과는 지킨다. 미확정 후속 상황은 그 인과와 현재 위치/정보에 맞게 창작하고 현재 상태로 남긴다. 사전에 적지 않은 미래 사건은 발생 불가라는 해석이나, 재미를 위해 과거/능력을 소급 변경하는 해석을 모두 거부한다.

NPC는 창구/증언자뿐 아니라 함께 행동하고 갈등·협력·유머·손실을 겪는 사람이다. 직업상 신중함만 Voice로 반복하지 않으며 개인의 생활/욕구·관계·실제 경험이 행동을 바꾸게 한다.

## 유지한 기능과 전환 경계

판정·HP/SAN·성장·행운·실제 Python 난수·플레이어 주도권·UI·상시 진행 원칙·현행 저장 수단/계약은 유지한다. 누적 경험은 기존 story_context/scene_context/ongoing_consequences에 담으며 새 서버 필드를 가정하지 않는다.

기존 캠페인의 진실·인물·위협·플레이 성과를 이 방향으로 소급 덮어쓰지 않는다. 별도 새 캠페인은 다른 정본/식별자로 작성하고 이전 진행과 섞지 않는다. 비공개 설계/세이브는 이 저장소나 배포 ZIP에 넣지 않는다.

## 검토의 실제 한계

자동 검사는 문서 연결·보호 문구·숫자/상태 계약을 확인한다. 시나리오의 플레이 경험은 서로 다른 행동·조기 차단·철수·도움 요청·실패·관계 선택으로 수동 대조한다. 이 대조와 파일 무결성은 실제 ChatGPT 장기 플레이의 재미/준수·도구/저장 왕복·응답 시간 검증을 대신하지 않는다.
