# 게임 운영 방식 결정

현행 세이브는 [FILE_SAVE_V1](FILE_SAVE.md)이며 외부 저장·불러오기 연동은 없다. [Library/Space 등 대안 조사](SAVE_ALTERNATIVES.md)를 참고한다. 전용 게임 앱·서버를 개발하거나 게시하지 않는다.

결정일: 2026-10-30. 사용자는 전용 게임 서버·상주 메모리 시스템 방안을 폐기하고 현재 프로젝트 방식을 유지하기로 했다. 새 서버·전용 채팅 화면·추가 상태 API를 이번 작업의 후속 계획으로 두지 않는다.

## 채택: 프로젝트 지침·분야별 룰북·독립 파일 세이브

일반 턴은 필요한 규칙 ID와 현재 작업 상태를 사용한다. 세이브는 정본 전문과 전체 현재 상태를 담은 검증 파일이며 직접 첨부/다운로드 또는 실제 지원되는 Library 파일 선택으로 전달한다. 게임 시작과 Scene Turn 30/60/90… 저장 경계에서 같은 파일의 재읽기와 STATE_CHECKPOINT_RECAP을 결합한다. 파일의 원문·상태·NPC·난수·대기 범위를 보존하고 별도 외부 저장·조회는 실행하지 않는다.

## 장면 운영

공개 장면과 단서는 P1~P3의 공통 지식이며 실제 위치·자원·행동권은 구분한다. NPC가 새 답변이나 수락을 요구하면 플레이어에게 선택을 돌린다. 플레이어가 직접 말했거나 질문/설명/일감 문의를 선언한 부분은 직접화법으로 보여준다. 단순 이동에 새 PC 대사를 만들거나 목적 단위 압축으로 협상·계약까지 대신 끝내지 않는다.

방문·탐색·교류는 선택할 기회를 여는 선언이고, 품목·가격·범위가 확정된 구매/수리는 결과를 맡긴 실행이다. CINEMATIC_ELLIPSIS가 이 경계를 담당한다. 새로운 UI나 자동 구매 기능을 만들지 않으며 같은 입력 폼/채팅에서 실제 선택을 받는다. 일반 판정은 목적과 성패 범위를 먼저 고정하고, 중요한 결과 뒤 성장은 SKILL_IMPROVEMENT를 따른다. 성장 선택 대기는 일반 진행/엔딩을 막지 않는다.

## 실제 한계와 측정

문서만으로 무손실 기억·정확한 실행·응답 시간을 보장할 수는 없다. 전체 복기는 기존 저장 시점에 정확한 데이터를 다시 확인하는 절차이며 영구 비밀 메모리를 추가하는 기능이 아니다. 저장 사이에 실제 정보가 유실되면 한정 복구하고, 미저장 변경분을 재구성할 근거가 없으면 그 영향을 받는 결과만 보류한다.

일반 턴과 시작/30턴 저장의 응답 시간을 구분해 측정한다. 실제 도구 로그에서 동일 규칙·동일 version의 반복 조회를 먼저 확인한다. 상세 데이터 흐름은 [STATE_FLOW.md](STATE_FLOW.md), 측정 방법은 [RESPONSE_TIME.md](RESPONSE_TIME.md)를 따른다.

## 생성 입력 UI의 지원 조건

게임 실행 대상은 일반 ChatGPT 프로젝트 채팅이다. 이 저장소는 Markdown 룰북과 ZIP 생성 도구이며 채팅 클라이언트의 입력 컴포넌트를 구현하지 않는다. 코드 블록·Markdown 표·HTML 코드 출력은 제출 가능한 폼이 아니다.

현재 게임 채팅에 실제 입력 UI 도구가 제공되면 SETUP_UI_FIXED_CONTRACT에 따라 사용한다. 지원 여부는 해당 채팅의 호출 가능한 도구와 실제 렌더링·제출로 확인해야 한다. Codex의 질문 도구가 작동했다는 사실은 일반 ChatGPT 프로젝트의 지원 증거가 아니다. UI 도구가 없으면 문서 수정만으로 폼을 활성화할 수 없으며, 사용자 선택으로 채팅 입력을 사용한다. 별도 웹앱/서버 도입은 이 수정에 포함하지 않는다.

비공개 정본은 실제 생성/재읽기하고 독립 세이브에 전문을 포함한다. 프로젝트 소스 업로드는 선택이다. 현재값·누적 변화·새 사실·사망/취소·완료 난수·입력 대기를 정확히 보존하며 구판 변환은 사용자가 실제 제공한 원문 범위에 한정한다.

세이브 실패는 시작·첫 장면·일반 진행·인계·엔딩을 막지 않는다(STATE_SAVE_FAILURE_CONTINUE). 현재 작업 상태로 계속하며 저장 성공은 실제 검증 때만 표시한다. 실패한 원문은 동결하고 이후 진행과 구분해 다음 저장 경계/수동 저장/연결 복구 때 최신 상태를 저장한다. 미저장 진행이 새 채팅에서도 복원된다고 보장하지 않으며, 실제 데이터 유실은 필요한 범위를 복구한다.

- 2026-10-31: PRIVATE_CANON_PERIODIC_REVIEW로 20턴마다 활성 정본 전체를 실제 소스에서 재독한다. 30턴 저장 복기와 별개이며 60턴에는 읽기를 공유한다. 안전 경계 지연·동적 변경 대조·조회 미완료 처리를 유지하고 중간의 상황별 조회를 대체하지 않는다.
