# 전체 경험·판정·성장 개편 설계

설계일: 2026-11-02. 개발·검토용 설명이며 게임 실행 정본은 아래 연결한 `rules/`의 각 담당 절이다. 실제 캠페인 자료나 플레이 테스트 로그가 아니다. 새 앱·서버·운영 DB 변경은 포함하지 않는다.

## 게임의 중심과 담당 규칙

CoC 기반의 취약함·공포와 판정, 언틸던에서 가져온 나비효과, 발더스 게이트에서 가져온 선택에 따른 전개를 결합한다. 관심에서 자발적 목표가 생기고, 행동과 선택의 결과가 세계·관계·능력을 바꾸며, 그 변화가 다음 플레이를 만드는 흐름이다. 조사만 수행하는 게임이나 피해량을 채우는 게임으로 운영하지 않는다.

## 세부 결정과 이유

- 전문성은 높은 성공률뿐 아니라 시도 자격과 가능한 성과를 바꾼다. 다른 인물에게 같은 성과의 대안을 보장하지 않지만 전체 게임을 단 한 사람의 단 한 판정에 잠그지 않는다. 기회는 세계 확정 전에 설계하고 확정 후 성공 편의로 약점·과거를 바꾸지 않는다.
- 정보를 얻는 것, 사람과 관계를 맺는 것, 시설·위협에 개입하는 것은 서로 다른 성과다. 모두가 실제 세계 변화로 이어질 수 있어야 한다. 개인 목표와 즐거운 생활 경험을 전부 메인 단서나 비극으로 바꾸지 않는다.
- 일반 판정은 목적 단위로 남은 불확실성을 해결한다. 치명적인 결과는 높은 난이도를 자동 의미하지 않는다. 준비 효과는 접근/자격, 무판정, 작업 변경, 유불리, 실패 완화 중 실제 효과로 먼저 반영한다. 같은 원인의 이중 보정은 금지한다.
- 기능 성장은 의미 있는 사용·학습과 중요한 결과의 경계에 연결한다. 우연한 극단값에 따른 즉시 성장에서 벗어나고, 정상 플레이에서 준비를 잘해 판정을 없앤 경우도 인정한다. 낮은 기능과 높은 기능의 증가 폭을 구분하고 상한·선택 개수·중복 방지를 둔다. 수치의 단일 정본은 SKILL_IMPROVEMENT다.
- 별도 경험치·레벨·피해 보상·성장 주사위를 추가하지 않는다. 장비·응용법·협력자·권한도 실제 획득과 사용 가능 범위로 남긴다. 일반 사건에서 전문 분야 슬롯을 무제한 추가하지 않으며 연대기의 기존 전문성 발전 경계는 유지한다.
- 방문은 다음 선택을 열려는 행동이다. 구매 품목·수량·가격 동의·대화·퇴장까지 자동 위임되지 않는다. 반대로 범위가 구체적인 구매/수리 선언은 통상 공정을 묶어 충분히 진행한다. 플레이어가 세부 경험을 원하면 그 범위를 펼친다.
- 결과를 기록하는 것은 모든 관계·복선을 완결하라는 요구가 아니다. 실패·미완성·갑작스러운 죽음도 보존하며 PC의 감정·교훈·도덕적 성장을 키퍼가 대신 결론 내리지 않는다.

## 합성 상황으로 대조한 처리 흐름

### 상점에서 개인 목표와 전문 행동으로 이어짐

1. `상점에 간다`: 공간·주인·실제 대표 상품/가격과 대화할 표면까지 보여준다. 현금·물품 소유는 아직 바뀌지 않는다.
2. 플레이어가 수리할 만한 도구에 관심을 보인다: 현재 확인 가능한 상태·거래 조건을 펼친다. 구매·감정·소식 질문을 대신 쓰지 않는다.
3. 플레이어가 가격을 흥정한다: 상대의 실제 거래 여지와 저항이 있을 때만 사회 판정을 검토한다. 성공 범위와 실패 결과를 먼저 정한다. 성공해도 숨겨진 희귀품을 새로 생성하지 않는다.
4. 물건을 구해 수리하겠다고 선언한다: 해당 전문 자격·도구·실제 결함을 기준으로 판정 여부를 정하고 종속 공정은 묶는다. 새 교체 비용/비가역 개조 선택이 생기면 그 지점에서 멈춘다.
5. 수리 성과로 새로운 작업이나 접근이 가능해진다: 물건의 실제 상태와 사용 범위를 보존한다. 단순 구매마다 성장하지 않고 중요한 개인적 도전의 일단락과 학습 근거가 성립할 때 성장 규칙을 적용한다.

### 준비가 구조와 위험의 결과를 바꿈

1. 세계 설계에 발전기·독립 전원·의료실·위협의 탐지 수단이 실제로 연결되어 있다.
2. 정비사에게는 회로 분리, 적격 의료인에게는 환자 이송 가능성 확보 같은 고유 행동이 있을 수 있다. 실제 자격·도구·접근이 필요하며 무조건 성공하지 않는다.
3. 다른 PC는 배터리 확보·경로 개척·협상·대피 등 가능한 목적을 선택한다. 모든 사람이 같은 기능 한 번으로 같은 결과를 내지는 않는다.
4. 준비로 의료실을 유지하며 위협을 차단했다면 그 성과를 인정한다. 필수 희생을 만들려고 새 고장이나 추적 능력을 추가하지 않는다.
5. 실패해 실제 공격·환경 위해·SAN 노출이 닿았다면 담당 규칙을 실행한다. 성공/실패를 임의 보정하거나 자동 구조하지 않는다.
6. 변화한 시설·인물·경로가 다음 선택을 바꾼다. 원인이 해소됐으면 나비효과를 강제로 발동시키지 않고, 인과가 남았으면 후속 행동을 실행한다.

## 구판과 실행 범위

기존 기능 수치·성공·관계·안전 퇴로는 보존한다. 이미 열린 구판 판정은 그 판정의 성장 처리까지 한 번 마친 후 새 기준으로 전환하며 과거 사건을 재생해 추가 성장하지 않는다. 성장 대기·처리 event·전후 값, 자발적 목표의 변경, 상점의 미결정 구매/답변은 기존 동적 상태에 보존한다. 저장 실패 때문에 진행을 막거나 정본 기준선으로 성장치를 초기화하지 않는다.

기존 비공개 정본 개정은 PRIVATE_CANON_DOCUMENT를 따른다. 이 패치에서 실제 캠페인 정본을 제공받거나 개정하지 않았다. 운영 저장 서버의 필드 수용·왕복은 실행 검증하지 않았다.

## 검증의 의미

문서의 조건·예외·참조와 합성 사례는 [REVIEW_CASES.md](REVIEW_CASES.md)에서 대조한다. 자동 검사는 링크/규칙 ID·문자수·문자열 계약을 확인하며 AI 플레이의 재미·균형·기억·규칙 준수율을 보장하지 않는다. 성장 속도, 장면 길이, 직업별 활약의 체감은 실제 프로젝트 플레이에서 별도로 확인해야 한다.
