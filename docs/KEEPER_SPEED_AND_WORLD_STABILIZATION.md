# 일반 턴 속도·공동 출발·메인 무대와 최종 보스 안정화

기준: main `76c47c0`, 2026-11-17. 사용자가 승인한 일반 턴 속도 개선, 새 다인 현지 PC의 친분/공동 시작, 원작 메인 무대의 필연 진입, 배경 고유 적과 실제 최종 보스, 후속 생성의 잔존 문제를 반영한다. 비공개 시나리오·상태·PC 자료는 수정/커밋하지 않았다. 이 문서는 개발 변경 기록이며 게임 중 새 검토표나 매 턴 조회 대상이 아니다.

## 실행 방식

- **일반 턴:** 현재 단계/관련 상태와 실제 확보한 담당 규칙의 조건·예외를 재사용한다. 실제 난수·정기 재독/저장·복원/이미지 경계가 없고 원문/사실이 확보됐다면 검색/Python/DB 호출 없이 장면으로 응답한다. 매 응답 숙지 계획·전 세계 재구성·전수 검수를 하지 않는다.
- **판정 턴:** 지금 조건이 확정된 독립 난수/필요 계산을 한 Python 호출로 처리한다. 앞 결과가 다음 판정의 발생/조건을 바꾸면 그 경계에서 멈춘다. PC d100은 플레이어가 굴린다. 미래 난수 큐·재굴림은 금지한다.
- **상태:** 실제 경과/변경 ref의 영향을 받는 개체/과정만 현재 작업 문맥에서 갱신한다. 화면 밖 독립 진행과 도달한 공격은 누락하지 않고, 유실된 규칙/과거 경험을 가상의 영구 기억으로 대신하지 않는다.
- **무거운 경계:** 20턴 정본 전체 재독, 40턴 저장, 새 채팅 복원과 이미지 처리는 담당 절을 유지한다. save commit→verify→정확한 동일 버전 read-back은 그대로다.

첫 출력30초는 운영 목표다. 모델/도구의 실제 지연을 프롬프트로 보장하거나 HIGH 설정을 자동 변경하는 기능을 만든 것은 아니다. 먼저 짧은 안내만 내보내거나 가짜 백그라운드 저장으로 시간을 감추지 않는다. 중요 서술·전체 인벤토리/HUD·실제 난수·필수 원문·저장 검증을 줄이지 않는다. 실제 모델/도구별 시간 측정과 장기 플레이는 미실행이다.

## 신규 생성의 기본 배치

2~3인 현지 PC는 서로 아는 사이이고 같은 정확한 장소에서 함께 시작한다. 사전 관계/공동 과거·서로 아는 신원 범위·현재 동행 이유와 각자의 목적을 함께 준비한다. 별도 관계 폼·만남 퀘스트는 없다. 하나의 씬을 기본으로 이어가되 개인 행동권·감각/비밀/소유는 구별한다. 실제 분리 선택과 기존 저장 위치는 보존한다. 새 채팅 로드는 새 생성이 아니다.

메인 공간 안/연결된 진입 현장에서 시작하고 외부 도입도 지형/운송/이미 시작한 재난·봉쇄로 실제 진입을 성립시킨다. 메인 무대에 들어가기 전 안전 귀가 노선은 없다. 필연적 외부 작용과 PC의 자발적 선택을 구별하며 안에서의 접근·구조/장비 보존·탐험/협력·국지 피난은 플레이한다. 사후 새 장벽/자동 침몰·강제 재합류로 성과를 취소하지 않는다.

최종 보스는 배경의 대표 상위 적대 실체로 시작 정본에 실제 준비한다. 같은 세계관에 있는 대표 적을 선택 단편 밖 각색으로 사용할 수 있다. 인스머스/심해인 세력이 중심인 각색은 딥원을 상위 위협·최종 보스로 연결한다. 출처/각색을 구별하며 모든 다른 배경에 같은 신격을 붙이지 않는다. 초기 위치/목적·정보/감지·접근·실제 HP/공격·패턴/한계·학습/대응·퇴각과 최종 봉쇄를 준비한다. 보스 처치만의 해법·필수 희생·고정 페이즈를 강제하지 않고, 정당한 조기 격퇴 뒤 부활/대체 보스를 추가하지 않는다.

## 충돌·상반·중복 정리

1. ‘중심 거점 방문을 요구하지 않는다’를 메인 무대 필연 진입과 내부 선택의 구별로 바꿨다. 필연 진입과 체험 누락 뒤의 사후 강제 이동을 분리해 기존 보호 문구를 한정했다.
2. 사전 관계 입력을 강제하지 않는 기존 조항은 자동 친분 생성과 양립하게 연결했다. 프로필 열람이 만남을 만든다는 뜻 대신, 생성에서 이미 확정한 친분/공동 장소와 그 밖의 비밀을 구별했다.
3. ‘필수 보스전 없음/고정 보스전 없음’을 실제 보스 준비와 처치 외 유효 대응의 구별로 고쳤다. 풀 밖 사후 보스 금지와 생존·사살 성과는 유지한다.
4. SOURCE→BLUEPRINT/FINAL→GATE→START/상시 지침→05/06 실행→07 상태의 호출을 연결했다. 설계·실행·저장 담당을 새 Override로 중복 정의하지 않는다.
5. START_GAME의 중복 첫 화면/초상·본부 안내를 같은 담당 계약에 통합했다. 외부 입력 대기→실제 입장→음악 듣는 제이든/직접 응답, 입단식 첫 공식 초상·실패 대체, 실제 마틴 입단/시설/출격 순서는 보존했다.
6. 변경한 두 업로드 인스트럭션을 각각7,800자 이내로 맞추고 START 길이도 기존 구조 검사에 포함했다. 축약된 PI 문구에 묶인 의미 앵커14개/직접 변이4개를 현재 표현으로 이관하고 유효 기존 검사는 유지했다.

기존 검증 정본/세이브에 친분·공동 위치·딥원/보스·새 봉쇄를 소급 추가하지 않는다. 기존 비공개 자료, DB 스키마/RPC/권한, 카드66장·성장8종, 난수/HP/SAN·보상 수치·저장 주기·이미지 자산은 변경하지 않는다. 지적 항목을 생성 본문에 반영한 것은 실제 AI가 모든 원작에서 올바르게 생성/진행함을 보증하는 것과 다르다.

## 검증 범위

기존 문서 구조/의미 검사와 문서 부정 회귀, 기존 유한 합성 경로를 사용한다. 변경 경계의 문서 부정 변이15개와 공동 출발/메인 우회/실제 보스 부재의 소수 지도 반례만 추가했다. 유한 검사는 공개 합성 부분 세계이며 전체 캠페인/운영 세이브 스키마가 아니다. 실행 결과와 배포 정합성은 같은 변경의 DEVLOG에 기록한다. 실제 AI 생성·장기 플레이·응답 속도·운영 DB는 미검증이다.
