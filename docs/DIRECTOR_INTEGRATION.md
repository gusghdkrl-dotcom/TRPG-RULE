## 기존 지침 원문 이동

기준은 커밋 `8a833530774fb8a4b38e313c0030d057a766ef8b`의 PROJECT_INSTRUCTIONS다. 제목을 제외한 본문 32개 블록을 전부 추적했다. 8개는 인스트럭션에 그대로 남겼고 24개, 합계 4,899자는 담당 룰북의 기존 절로 원문 그대로 옮겼다. 기존 요약을 새로운 판정 수치나 버전별 Override로 만들지 않았다.

| 게임 목표·주도권·공개 지식·조회 재사용 | 01-core의 CORE_ZERO_HOMAGE_EXPERIENCE_GATE / CORE_AGENCY / CORE_VISIBILITY / ACTIVE_PLAY_ROUTING_FIREWALL |
| 시작 입력·생성 순서·APP/직업·원작 구현·정본 | 04-setup의 START_SETTINGS_GATE / CAMPAIGN_SETUP_PIPELINE / PC_APPEARANCE_FROM_APP / HOMAGE_SIGNATURE_FREEZE / GENERATION_FREEZE |

최초 이관 시점의 각 블록 원본 순번·길이·SHA-256·목적지 및 첨부 원문 hash는 [이관 기록](instruction-relocation-2026-10-30.json)에 있다. 이번 반영에서 각 블록이 목적지 본문에 정확히 일치하고, 전체 첨부가 지정한 형식 정리 외에는 바뀌지 않았음을 검사했다.

## 사건 진행·HUD 후속 보강 (2026-10-30)

연출 13개 항목과 최종 원칙은 변경하지 않았다. 사건 진행의 상세 규칙은 유지됐지만 인스트럭션의 초반·정체 기준이 약해진 점을 보완했다. 첫 생활 목표 뒤 사건 접점, 전체 30턴 이내 구체적 이상·대응 이유·접근 경로, 완결 장면 2개 정체 또는 할 일 없음의 안전 경계 점검을 다시 상시 지침에 명시했다. 실제 경과 구간의 화면 밖 사건은 작업 상태로 확인해 한 번 처리하며 저장/복기까지 미루지 않는다. 턴 수로 사건을 강제하거나 정본·PC 선택을 바꾸지는 않는다.

HUD의 시각·위치·현금·상태 및 메인·파우치는 고정 아이콘을 가진 독립 문단으로 명시했다. 빈 줄로 분리하며 짧아도 합치지 않는다. 실제 별도 직업품/키템도 같은 형식이다. 문서 검사는 이 사건 진행·HUD 지침이 인스트럭션에 직접 남아 있는지도 확인한다.

공간 확보를 위해 상황별 라우팅의 중복 링크 주소와 설명을 파일·ID 표기로 축약했다. 기존 충돌 판단 문단 127자는 `01348c0`의 인스트럭션에서 [색인의 조회 순서](../rules/00-index.md)로 원문 그대로 옮기고 인스트럭션에는 판단 순서와 충돌 보류 원칙을 짧게 남겼다. 위 JSON은 최초 이관 당시 감사 기록이며 후속 수정본의 문자 수/라우팅 형식을 나타내지 않는다.
