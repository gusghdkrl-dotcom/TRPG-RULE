# 규칙 대응과 구판 보존

현행 통합 경량판은154개실행ID를사용한다. 이번부모판361개ID의유지/통합/삭제·새담당은[rule-reorganization.json](rule-reorganization.json)에전부대응한다. 최초403개원문블록의source hash/이력은[rule-migration.json](rule-migration.json)에유지하고이동한담당을현재ID로갱신했다. 삭제는명시합의사유를기록한다.

대응표의행수가맞는다는사실은의미가모두보존됐다는증명이아니다. [의미계약](validation-contract.json)·[대표대조](REVIEW_CASES.md)와함께확인한다. 실제게임의원작체험·연속성·속도는별도플레이검증이다.

신규는시드/후보/태그/성장/교대/UI/수첩의승인된변경을적용한다. 기존verified원문·과거규칙판·이미적용한수치/생사/합의/난수는유지한다. 구판열린판정·메뉴·동의를현재형식으로몰래재해석하지않으며전환은STATE_COMPATIBILITY를따른다. 운영스키마가삭제필드를요구하면호환문제로보고하며가짜필드로검사를우회하지않는다.

공개수첩문서/동기화/감시기/미디어기능은실행자료에서삭제했다. 외부앱·데이터·DB를삭제/배포한것은아니다.
