# PC별 시작 정보와 한 화면 순번 열람

각 플레이어는 자기 PC가 원래 알고 있는 사실을 받고, 동료에게도 별도의 개인 자료가 있다는 것만 안 채 공동 장면을 시작한다. 담당 규칙은 [INVESTIGATOR_DEPTH_PROTOCOL](../rules/04-setup.md#investigator_depth_protocol)·[FINAL_INVESTIGATOR_PROFILE_OUTPUT_CONTRACT](../rules/04-setup.md#final_investigator_profile_output_contract), 공개 범위는 [CORE_VISIBILITY](../rules/01-core.md#core_visibility)다.

## 한 화면·한 계정에서 받는 순서

1. 키퍼는 공용 프로필/공통 상황과 별도로 PC별 브리핑 파일을 실제 생성한다. 파일명은 `PC_BRIEF_<campaign>_P1_r1.md`처럼 슬롯/판본만 알리고 내용의 단서를 드러내지 않는다. 실제 이름/identity·기억과 지식의 내용/출처는 본인 파일에서 확인한다.
2. 공용 채팅에는 개인 자료의 존재와 열람 순서만 안내한다. 내용·비밀 요약·서로 무엇을 아는지 묻는 교환 메뉴를 올리지 않는다.
3. P1만 자기 파일을 열고 다른 사람은 화면을 보지 않는다. 읽은 뒤 닫고 다음 사람이 자기 파일을 같은 방법으로 읽는다. 키퍼 정본/전체 세이브·전체 스토리 파일은 개인 자료로 배부하지 않는다.
4. 전원이 받았다는 실제 확인을 한 번 알려준다. 예를 들어 `각자 자기 파일 읽었어`라고 입력할 수 있다. 파일을 만들거나 링크를 보인 것과 수령/열람 확인은 구별한다. 없는 자동 읽음 감지를 주장하지 않는다.
5. 준비/열람은 극중0시간이다. OFF는 공통 오프닝 전, ON은 실제 동기화 뒤 첫 현지 선택 전 본인 정보를 받고 공동 장면을 진행한다. 성격·감정·목표·공유 여부는 플레이어가 정한다.

같은 계정이면 모든 파일/대화에 접근할 수 있다. 이 방식은 **자기 자료만 읽는 합의**이며 비밀번호/별도 접근권이 아니다. 실제 비공개 분리가 필요하면 별도 기기/개인 전달 수단을 선택해야 한다. 지원하지 않는 DM/접기·자동 삭제 기능을 있는 것처럼 사용하지 않는다. 생성 도구/열람이 안 되면 그 자료는 미전달로 남기고 실제 가능한 방법을 먼저 확인한다.

## 정보가 플레이를 바꾸는 방식

개인 자료에는 본인이 이미 아는 구체 사실·관계/업무·문서 내용/이름/약속과 불확실한 점이 들어간다. 본인도 모르는 진상·다른 PC의 개인 내용은 빠진다. 단순히 '수상한 연락을 받았다'는 제목만 주고, 이미 알고 있는 내용은 다시 조사하게 만들지 않는다.

실제 인물과 만나거나 이름/물건·현상을 관측했을 때 개인 정보의 의미가 드러날 기회를 둔다. 개인 정보가 현재 관심·가설/접근을 다르게 할 수 있지만 특정 선택/감정·배신/비밀 유지 의무를 강요하지 않는다. 시작부터 `각자 비밀을 말하세요`라고 재촉하지 않는다.

플레이어가 곧장 전부 말하겠다고 해도 허용한다. 공유 지연·원문 낭독·벌점/판정을 강제하지 않는다. 처음부터 모두 공유해도 현장 판단/탐사·대응이 남도록 작성하며, 끝까지 개인 정보를 말하지 않아도 필수 진실에 도달할 다른 경로가 있어야 한다. 실제로 대화/제시·공동 관측한 청자/범위를 기록하고 다른 PC의 공개 선택을 대신하지 않는다.

공용 HUD/지문은 실제 공개 활동과 관측을 표시하고 개인 정보 때문에 그런 행동을 한다는 이유를 자동 해설하지 않는다. 문서 실물은 실제 이름/수량·점유를 표시하되 비공개 본문/관계 정보를 끼워 누출하지 않는다. 브리핑 파일을 받았다는 이유로 극중 편지/봉투를 새로 지급하지 않는다.

## 저장·재개

[STATE_EXPERIENCE_CONTINUITY](../rules/07-state.md#state_experience_continuity)는 PC가 아는 사실·플레이어에게 실제 전달한 범위·다른 PC에게 극중 공유된 범위를 따로 보존한다. 같은 계정이라는 이유로 모두 알게 되거나, 새 채팅이라 이미 받은 기억을 잊게 하지 않는다. 구판의 전달 누락은 남은 실제 원문에서 본인에게 보완하며 과거 행동/새 기억은 만들지 않는다.

이 문서는 사용 안내이며 실제 PC 자료/비공개 전달 기능을 생성한 것이 아니다. 공통 배포 ZIP의 템플릿을 채우는 것과 실제 개인 파일 생성·전달/수령 확인도 별개다.
