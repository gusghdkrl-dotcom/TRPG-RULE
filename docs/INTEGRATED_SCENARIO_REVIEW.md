# 통합판 시나리오·분기 검토

현행 지침/룰북을 적용해 작성한 **합성 설계와 수동 분기 대조**다. 실제 ChatGPT 프로젝트에서 플레이한 기록, 본편의 새 웹검증, 운영 세이브 결과가 아니다. 아래 두 원작은 직접 지정한 조건의 검토다. 새 인물·물건·사건은 검토용 각색이며 어떤 실제 캠페인에도 자동 적용하지 않는다. 특정 사건을 모든 원작의 생성표로 만들지 않는다.

2026-11-09 기반 재설계에서는 [원작 체험형 공통 기반](EXPERIENCE_FIRST_FOUNDATION.md)을 우선한다. 아래 표의 기록/증언은 대응 수단의 일부이며 필수 수사 동선이 아니다. 먼저 PC의 당면 목적·실제 접촉·행동/관계 선택·준비/성과·다음 상황이 연결되는지 대조한다.

## 원작과 경험 구조를 바꾼 두 설계

| 설계 내용 | The Thing(1982) 기반의 새 사건 | Dracula(1897) 기반의 새 사건 |
|---|---|---|
| 원작 문법 | 고립·동화/모방·생존자의 불신·제한된 수단. 수송/후속망 사건은 이번 각색 | 흡혈귀·인간 사회/매혹·은신처와 유입 경로·협력과 추적. 장례시설 사건은 이번 각색 |
| 평범한 출발 | 해빙 전에 관측소의 송전/통신을 복구하러 온 기술자 | 장례시설의 실종된 직원을 찾아달라는 의뢰를 받은 인물 |
| 중심 원인·파급 | 구조수송 준비 중 생물 시료/장비 이동망이 동화체의 외부 탈출 기회가 됨. 기지 생존과 외부 유입 차단이 함께 걸림 | 여러 구역의 은신처/운송/인간 협력망이 기존 실종과 새 피해를 이어감. 한 건의 시신 분실로 끝나지 않음 |
| 첫 직접 충돌 | 동료의 실제 위치/행동 모순이 장비 손상과 격리 갈등으로 이어져 복구 업무와 안전이 동시에 변함 | 수사 접근을 막는 실제 인물과 피해자가 나타나고 은신처 이동 때문에 의뢰의 구조 가능성이 바뀜 |
| 생존 속 발견 | 손상 구간 우회·격리·검사/소각 수단 확보·수송 경로 대면에서 누가 무엇을 알았는지와 실제 위험을 좁힘 | 피해자 보호·추적·은신처 진입·협력자 설득 속에서 위협의 범위/이동 방식과 대응 조건을 알아감 |
| 주요 소재의 중요성 | 운송목록/열원/통신기록은 시료 인계·실제 통신·격리/구조/차단을 바꾼다. 모든 것을 기계 하나 수리로 끝내지 않음 | 은신처 물품·운송기록·증언은 거점/연결과 실제 보호·추적·제압 경로를 연다. 장식 유물로 남기지 않음 |
| 최종 위험·해결 | 누구/무엇이 출발 가능한가라는 실제 확인과 구조/격리/차단 수단. 생존자 확보와 외부 차단을 준비로 함께 지킬 수 있음 | 분산된 거점/인간 행동/피해 조건을 바꿔 제압·방어·구조·철수할 수 있음. 최후의 방에서 단순 보스전으로 초기화하지 않음 |
| PC의 전문성 | 시설 분리/전력·보호 장비/통신·의료 접근이 실제 다른 성과. 한 기능 한 번 실패로 전체 봉쇄하지 않음 | 기록·언어·사회 접근·의료·추적 등으로 실제 다른 수단/협력을 얻음. 모두에게 동일한 성과를 주지 않음 |
| 위해·환기 | 실제 노출/공격/추위의 조건과 처치를 사전 설계. 실패를 강제하지 않고 동료 행동/상황의 짧은 어긋남이 환기 | 실제 공격/정신적 침해/추격을 조건대로 처리. 인물의 생활·관계·짧은 행동 유머가 인물성을 살림 |

여기서 끝내는 것은 표 채우기가 아니다. 실제 생성에서는 NPC별 목적/Voice/수단/숫자·관련 법칙/위해의 조건/효과·지도/경로·자료 원문·실제 종료 경계를 확정해야 한다. 예컨대 『드라큘라』에 현대 대중물의 햇빛 즉사 규칙을 확인 없이 섞거나, 『괴물』에 동일한 감염/검사 능력을 임의 추가하면 원작 적합성 검토에서 거부한다.

## 같은 설계에 다른 선택을 적용한 수동 대조

| 선택/상태 변화 | 유지해야 하는 반응 |
|---|---|
| 서류를 읽지 않고 구조/도주/준비/관계 행동을 선택 | 현재 세계의 실제 수단/위험/관계로 진행. 새 증거 제출이나 다음 기관 문의를 필수로 붙이지 않음 |
| 중요한 진실을 모른 채 실제 안전/목적을 확보 | 성과와 해당 종결 경계 인정. 모든 비밀/범인 신원/증거 완전성을 자동 필수로 만들지 않음 |
| 이름/미학만 다른 두 원작이 같은 자료 수사로 수렴 | 체험 설계 미완료로 재구성. 실제 행동·위협의 작동/제약·관계와 생활·준비의 활용이 원작별로 달라져야 함 |
| 일찍 운송/은신처 연결을 알아내 차단 | 기존 위협이 실제 제한되고 조기 해결/우회가 유효. 아직 나올 예정이었던 장면을 위해 차단 취소하지 않음 |
| PC가 구조보다 탈출 우선 | 실제 경로/수단/남은 위험으로 처리. 도덕 벌점·새 봉쇄를 만들지 않고 남는 세계 결과를 구분 |
| 핵심 전문 PC가 부재/실패 | 그 고유 성과가 닫힐 수 있으나 실제 대가/도움/다른 목표/철수 등 진행이 남음. INT/Luck으로 모두 같은 성과를 주지 않음 |
| NPC의 손실·자원/정보가 바뀜 | 현재 목적·협력 경계·다음 행동이 이유와 함께 바뀜. 자동 동의/배신/추적 정보 전지화 없음 |
| 준비로 실제 위해를 예방 | 피해 없이 안전을 얻음. 서바이벌 분위기 유지를 위한 강제 부상/감염 없음 |
| 실제 위해/심각한 공포가 도달 | 정상 판정과 결과·부상/상태/처치·SAN 누적을 적용. 암시로 물리지 않음 |
| 이미 확인한 이해/합의 뒤 저장 | 이야기의 연결·태도 이유·지식/발화 차이·마지막 질문/준비를 함께 재개. 제목만 저장해 처음부터 되묻지 않음 |
| 최종 원인 해결 | 남은 선택으로 결과를 바꿀 수 있는지 확인 후 실제 결말·다섯 후일담. 추가 군단/보스 자동 생성 없음 |

## 서로 다른 가상 세계의 완료 기준

아래는 특정 작품/실제 캠페인에서 가져온 설정이 아닌 개발용 합성 상황이다. 실제 새 캠페인은 선택한 원작에 맞는 원인/법칙/수단으로 구성한다. 통과 예는 해당 연결의 충분성을 설명하며 완성된 전체 시나리오나 플레이 기록이 아니다.

| 가상 세계/빈 연결 | 구체화할 연결과 조건부 분기 | 수용/거부 |
|---|---|---|
| 과학 재난: ‘오염이 퍼질 수 있고 통신 복구 후 안전해짐’ | 손상된 배기관이 오염 구역과 대피실을 연결한 상태에서 팬을 재가동하면 유입. 압력계/밸브·관측 증상으로 범위 파악, 구역 분리/보호 장비/다른 통로 사용 가능. 통신 복구와 별개로 오염 유입이 끊긴 대피실/외부 수송로 확보를 판단. 먼저 배기관을 분리하면 해당 유입 예방, 실패하면 현재 노출/구조·우회로 진행 | 장비 복구 자체로 전원 안전 선언은 거부. 원작에 없는 감염/탐지 능력을 추가하지 않고 실제 법칙/수치로 확정해야 함 |
| 초자연 영역: ‘변형할 때 길이 변하고 다리를 넘으면 탈출’ | 이 가상 설정은 소멸한 경계 표식의 영향권만 겹침. 표시가 사라지는 현상·범위·남는 출입구를 먼저 확정하고 경계 보전/우회/보호 구역 확보로 대응. 다리 반대편도 영향권이면 이동 성공과 전체 이탈을 구분. 실제 영향권 밖으로 이어진 길과 그 보호 조건을 확보하면 근원의 소멸/전모 설명 없이 철수 인정 | 모든 초자연 원작에 이 법칙 강제 금지. 적당한 때 모든 출구를 바꾸는 운영과 실제 안전 뒤 새 봉쇄는 거부 |
| 인간 추격: ‘추격자가 필요할 때 나타나고 운전하면 끝남’ | 추격자의 실제 위치·가시/전달 정보·현재 이동 수단과 남은 접근 경로를 고정. 차량/동료의 경고·우회/길 차단이 접근을 바꿈. 감시/추적 연결을 끊고 실제 도달할 수 없는 구역에 이르면 이탈. 조기 제압/신고로 안전을 확보하면 추가 추격자 없이 종결 가능 | 미공개 PC 계획을 적이 아는 처리·항상 빠른 순간이동·이탈을 무효로 할 공범 추가는 거부 |
| 관계: ‘운송 담당자가 도울 수도 갈등할 수도 있음’ | 맡은 사람의 구조와 자기 차량/동료의 안전을 함께 지키려는 이유, 이미 전달된 구조 정보와 감수할 위험을 정함. 실제 경로 확보/동료 부상/새 약속에 따라 동행·역할 분담·조건부 도움·이탈이 달라짐. PC의 수락/감정은 미확정 | 직업 기능/명령 대기만으로 인물 완료·전원 희생/배신·없는 PC 과거 친밀감은 거부 |

이 연결을 생성 때 정본의 기존 절/entity/ref로 보존하고 새 주요 국면·관련 누락/모순에서 해당 부분만 보완한다. 주 경로를 택하지 않거나 일찍 차단한 분기에서 기존 성과를 취소하는 설계, 원인/결말을 영원히 비워 즉흥으로 채우는 설계는 미완료다. 새로 제안된 창의적 대응은 기존 능력/인과에 맞으면 인정하며 열거한 해법만 허용하는 목록으로 쓰지 않는다. 게임마다 이 표를 출력/검사하거나 파일을 추가할 필요는 없다.

## 주요 진실 전후의 경험·선택 대조

아래는 앞 표와 별개의 개발용 가상 상황이며 실제 캠페인이나 특정 원작의 설정을 옮긴 것이 아니다. 사전 원인과 관측 경로를 준비한 경우의 분기 대조이며 모든 게임의 반전 양식으로 쓰지 않는다.

| 대조 | 사전 인과와 직접 경험 | 드러난 뒤의 차이와 분기 |
|---|---|---|
| 가상 우주 공포의 보호 설비 | 방벽은 실제 외부 공격을 막지만 존재의 감각 기관으로도 사용된다. 그 한계는 처음부터 확정. 관측된 흔적의 분포·접촉 반응·생존 행동에서 그 역할을 알아갈 수 있음 | 기존 보호 성과 유지. 유지/우회·감각 연결 차단·다른 수단 확보의 이익/위험이 달라지고 준비/이해가 실제 돌파/철수에 쓰임. 우주론 전모 설명·추가 보스·강제 손실은 없음 |
| 가상 인간 추격의 조력자 | 산장 관리인이 협박받는 가족을 지키려고 특정 연락을 숨겼고, 그가 건넨 일부 정보로 추격이 가능해짐. 정보 전달 경로·알려진 범위와 실제 도움은 사전 확정. 현장 언행·연락의 결과로 접촉 | PC가 믿음/협력 범위를 선택. 이전 구조 성공은 유지하면서 연락 경로·역할 분담·구조/철수의 우선순위를 다시 판단할 수 있음. 전지적 추격·동료 전원 배신·없는 PC 과거는 추가하지 않음 |
| 초기 추리/예방·다른 해법 | 플레이어가 적은 사실로 원인을 정확히 이해하거나 실제 접근을 차단. 준비한 진실 접점을 거치지 않을 수 있음 | 차단 성과와 얻은 안전 인정, 짧은 결말도 실제로 지킨 사람·일상·관계/여파로 마무리. 새 반전이나 숨은 공범으로 초기 성공을 무효로 하지 않음 |
| 운용성만 높은 설계 | 위치·수치·회로/문·탈출 경계는 정확하지만 주요 진실을 제거해도 경험/선택/결말이 같고 할 작업과 피해 대상 수만 달라짐 | 조건 검사 통과와 서사 깊이를 구분. 주된 전개에서 원작의 공포·겪은 일의 의미·현재 대응/관계/대가·절정 회수를 연결해 보완. 서류/반전 수·강제 피해를 늘려 대체하지 않음 |

이 표는 사전 능력/원인을 지키며 가능한 다른 행동과 결과를 대조한다. 예시의 보호 설비/협박/관계 비밀을 실제 원작에 무조건 넣지 않으며 인간적인 호의·유머·책임도 중요한 원인과 여파가 될 수 있다. 진실의 드러남 자체로 정답/PC 감정을 선언하거나 SAN을 자동 차감하지 않는다. 서사 질을 평가하는 단일 점수·필수 반전 수·플레이어 고통 할당량은 없다.

## 신규 캠페인의 형상/공간 체험과 절정 활용 대조

2026-11-10. 아래는 실제 첨부 캠페인/원작을 옮기지 않은 개발용 합성 대조다. 장면 실행·난수 추첨·PC 선택은 수행하지 않는다. 이후 신규 생성 기준이며 기존 캠페인의 재개/정본 개정 지시가 아니다.

| 대조 | 원작에 맞춰 구체화할 경험 | 누적 경험이 쓰이는 대응과 경계 |
|---|---|---|
| 가상 생물 공포 | 살아 있는 터널의 벽이 먹이의 진동에 수축한다는 원인/한계를 사전 확정. 관측된 수축·바닥의 압박·이동/운반 중 접촉으로 무엇을 피하고 시도할지 파악 가능 | 실제 관측/준비와 동행자의 역할 분담이 이동·구조·철수 방법을 바꿈. 밸브 종료만 상세하고 몸으로 겪는 현상이 비면 보완. 심리적 죄의 상징·특정 PC 과거·필수 포식은 추가하지 않음 |
| 가상 인간 추격 | 선박의 승무원 출입 구조와 살인자의 실제 접근/시야/이동 제약이 익숙한 일터를 위협으로 만듦. 철문/발소리·선제 행동·피할 공간이 현장 접촉으로 확인됨 | 앞서 실제 익힌 경로·협력 약속·맡긴 장비가 동행/구조·차단·이탈 방법에 쓰임. 없는 배신/전지적 추격을 만들지 않고 신뢰하지 않은 PC에게도 다른 수단이 있음 |
| 동기가 소박함·간단한 예방 성공 | 인물의 욕구를 복잡하게 만들거나 새로운 충격적 진실을 붙이지 않아도 형상/행동과 실제 체험이 원작의 핵심을 구현할 수 있음 | 조기 차단과 얻은 안전을 인정하고 실제로 지킨 사람/일상·잔존 여파로 종결. 정해 둔 절정/회상을 위해 해결을 무효로 하지 않음 |
| 새 채팅 재개·미형성 관계·쓰지 않은 도구 | 기존 정본과 현재 맥락을 유지. 신규 생성 기준을 이유로 장면/과거를 다시 쓰거나 미발견 비밀을 누출하지 않음 | 실제 관계/준비만 적용. 모든 인물/물품의 의무 사용·고정 보스/희생·새 퍼즐·장면 전수 출력은 거부 |

설계에서 관측 가능한 현상과 행동/결과가 연결됐는지 살핀다. 설명 듣기·상징 해석·SAN 지불을 대응의 추가 관문으로 만들지 않고 후일담의 회상만으로 실제 절정 활용을 대체하지 않는다. 이 표를 모든 캠페인의 대본/필수 장면 목록으로 복제하지 않는다.

## 아직 필요한 실제 검증

새 채팅에 정확한 정본+저장본만 주고 이어 쓰는 실험, 여러 실제 선택을 받는 장기 플레이, 원작별 일관성/스토리의 크기·속도·위해 실행·유머/몰입의 평가는 미실행이다. 위 분기 표는 실제 플레이의 성공률이나 응답시간 측정이 아니다. 문서·수치·JSON 왕복 검사는 이 설계가 LLM에 의해 항상 구현됨을 증명하지 않는다.
