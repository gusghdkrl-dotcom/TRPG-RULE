# 통합판 시나리오·분기 검토

현행 지침/룰북을 적용해 작성한 **합성 설계와 수동 분기 대조**다. 실제 ChatGPT 프로젝트에서 플레이한 기록, 본편의 새 웹검증, 운영 세이브 결과가 아니다. 아래 두 원작은 직접 지정한 조건의 검토다. 새 인물·물건·사건은 검토용 각색이며 어떤 실제 캠페인에도 자동 적용하지 않는다. 특정 사건을 모든 원작의 생성표로 만들지 않는다.

2026-11-09 기반 재설계에서는 [원작 체험형 공통 기반](EXPERIENCE_FIRST_FOUNDATION.md)을 우선한다. 아래 표의 기록/증언은 대응 수단의 일부이며 필수 수사 동선이 아니다. 먼저 PC의 당면 목적·실제 접촉·행동/관계 선택·준비/성과·다음 상황이 연결되는지 대조한다.

## 원작과 경험 구조를 바꾼 두 설계

| 설계 내용 | The Thing(1982) 기반의 새 사건 | Dracula(1897) 기반의 새 사건 |
|---|---|---|
| 원작 문법 | 고립·동화/모방·생존자의 불신·제한된 수단. 수송/후속망 사건은 이번 각색 | 흡혈귀·인간 사회/매혹·은신처와 유입 경로·협력과 추적. 장례시설 사건은 이번 각색 |
| 평범한 출발 | 해빙 전에 관측소의 송전/통신을 복구하러 온 기술자 | 장례시설의 실종된 직원을 찾아달라는 의뢰를 받은 인물 |
| 중심 원인·파급 | 구조수송 준비 중 생물 시료/장비 이동망이 동화체의 외부 탈출 기회가 됨. 기지 생존과 외부 유입 차단이 함께 걸림 | 여러 구역의 은신처/운송/인간 협력망이 기존 실종과 새 피해를 이어감. 한 건의 시신 분실로 끝나지 않음 |
| 첫 직접 충돌 | 동료의 실제 위치/행동 모순이 장비 손상과 격리 갈등으로 이어져 복구 업무와 안전이 동시에 변함 | 수사 접근을 막는 실제 인물과 피해자가 나타나고 은신처 이동 때문에 의뢰의 구조 가능성이 바뀜 |
| 생존 속 발견 | 손상 구간 우회·격리·검사/소각 수단 확보·수송 경로 대면에서 누가 무엇을 알았는지와 실제 위험을 좁힘 | 피해자 보호·추적·은신처 진입·협력자 설득 속에서 위협의 범위/이동 방식과 대응 조건을 알아감 |
| 주요 소재의 중요성 | 운송목록/열원/통신기록은 시료 인계·실제 통신·격리/구조/차단을 바꾼다. 모든 것을 기계 하나 수리로 끝내지 않음 | 은신처 물품·운송기록·증언은 거점/연결과 실제 보호·추적·제압 경로를 연다. 장식 유물로 남기지 않음 |
| 최종 위험·해결 | 누구/무엇이 출발 가능한가라는 실제 확인과 구조/격리/차단 수단. 생존자 확보와 외부 차단을 준비로 함께 지킬 수 있음 | 분산된 거점/인간 행동/피해 조건을 바꿔 제압·방어·구조·철수할 수 있음. 최후의 방에서 단순 보스전으로 초기화하지 않음 |
| PC의 전문성 | 시설 분리/전력·보호 장비/통신·의료 접근이 실제 다른 성과. 한 기능 한 번 실패로 전체 봉쇄하지 않음 | 기록·언어·사회 접근·의료·추적 등으로 실제 다른 수단/협력을 얻음. 모두에게 동일한 성과를 주지 않음 |
| 위해·환기 | 실제 노출/공격/추위의 조건과 처치를 사전 설계. 실패를 강제하지 않고 동료 행동/상황의 짧은 어긋남이 환기 | 실제 공격/정신적 침해/추격을 조건대로 처리. 인물의 생활·관계·짧은 행동 유머가 인물성을 살림 |

여기서 끝내는 것은 표 채우기가 아니다. 실제 생성에서는 NPC별 목적/Voice/수단/숫자·관련 법칙/위해의 조건/효과·지도/경로·자료 원문·실제 종료 경계를 확정해야 한다. 예컨대 『드라큘라』에 현대 대중물의 햇빛 즉사 규칙을 확인 없이 섞거나, 『괴물』에 동일한 감염/검사 능력을 임의 추가하면 원작 적합성 검토에서 거부한다.

## 같은 설계에 다른 선택을 적용한 수동 대조

| 선택/상태 변화 | 유지해야 하는 반응 |
|---|---|
| 서류를 읽지 않고 구조/도주/준비/관계 행동을 선택 | 현재 세계의 실제 수단/위험/관계로 진행. 새 증거 제출이나 다음 기관 문의를 필수로 붙이지 않음 |
| 중요한 진실을 모른 채 실제 안전/목적을 확보 | 성과와 해당 종결 경계 인정. 모든 비밀/범인 신원/증거 완전성을 자동 필수로 만들지 않음 |
| 이름/미학만 다른 두 원작이 같은 자료 수사로 수렴 | 체험 설계 미완료로 재구성. 실제 행동·위협의 작동/제약·관계와 생활·준비의 활용이 원작별로 달라져야 함 |
| 일찍 운송/은신처 연결을 알아내 차단 | 기존 위협이 실제 제한되고 조기 해결/우회가 유효. 아직 나올 예정이었던 장면을 위해 차단 취소하지 않음 |
| PC가 구조보다 탈출 우선 | 실제 경로/수단/남은 위험으로 처리. 도덕 벌점·새 봉쇄를 만들지 않고 남는 세계 결과를 구분 |
| 핵심 전문 PC가 부재/실패 | 그 고유 성과가 닫힐 수 있으나 실제 대가/도움/다른 목표/철수 등 진행이 남음. INT/Luck으로 모두 같은 성과를 주지 않음 |
| NPC의 손실·자원/정보가 바뀜 | 현재 목적·협력 경계·다음 행동이 이유와 함께 바뀜. 자동 동의/배신/추적 정보 전지화 없음 |
| 준비로 실제 위해를 예방 | 피해 없이 안전을 얻음. 서바이벌 분위기 유지를 위한 강제 부상/감염 없음 |
| 실제 위해/심각한 공포가 도달 | 정상 판정과 결과·부상/상태/처치·SAN 누적을 적용. 암시로 물리지 않음 |
| 이미 확인한 이해/합의 뒤 저장 | 이야기의 연결·태도 이유·지식/발화 차이·마지막 질문/준비를 함께 재개. 제목만 저장해 처음부터 되묻지 않음 |
| 최종 원인 해결 | 남은 선택으로 결과를 바꿀 수 있는지 확인 후 실제 결말·다섯 후일담. 추가 군단/보스 자동 생성 없음 |

## 아직 필요한 실제 검증

새 채팅에 정확한 정본+저장본만 주고 이어 쓰는 실험, 여러 실제 선택을 받는 장기 플레이, 원작별 일관성/스토리의 크기·속도·위해 실행·유머/몰입의 평가는 미실행이다. 위 분기 표는 실제 플레이의 성공률이나 응답시간 측정이 아니다. 문서·수치·JSON 왕복 검사는 이 설계가 LLM에 의해 항상 구현됨을 증명하지 않는다.
