# (개발중) 플레이어 영구 카드 성장·드래프트 시스템

> **상태: 개발중 / 설계 보관용 / 현재 룰북에 미적용**
>
> 작성 기준: 2026-11-10까지의 사용자–키퍼 설계 대화. **2026-11-10 생존자 확정 카드 10장 및 신비주의자→기회주의자 교체 반영.**
>
> 이 파일은 나중에 정식 룰북에 통합할 설계를 **별도 보관**하기 위한 문서다. 지금은 실행 규칙, 프로젝트 지침, 현재 캠페인 상태, 데이터베이스 스키마를 변경하지 않는다. 현행 게임은 기존 `rules/` 원문을 따른다.
>
> 표기: **[확정]** = 사용자와 합의한 체계·방침 / **[카드 초안]** = 제안된 기본 카드의 이름·효과·난이도·위험, 추후 조정 가능 / **[후속 작업]** = 아직 고정하지 않은 부분.

## 1. 시스템 목적 및 귀속 [확정]

- 아컴호러 카드게임의 **클래스·카드 수집·덱 조합의 재미**를 참고하되, CoC 기반 원작 체험형 생존 공포 TRPG에 맞춘 별개의 **영구 장착 카드 시스템**이다. 아컴호러 카드 텍스트/효과를 그대로 이식하지 않는다.
- 카드 컬렉션의 영구 소유자는 **PC가 아닌 플레이어 아이디**다. PC가 사망하거나 새 캠페인·새 PC로 전환해도 컬렉션은 유지된다. 전 PC의 기억·인맥·물건·비밀·성과가 새 PC에게 자동 이전되는 것은 아니다.
- **수평 성장**이 목적이다. 새 카드를 수집할수록 빌드 선택지가 늘지만 기본 HP, SAN, 능력치, 공격력, 장착 슬롯 수 등을 영구적으로 상향하지 않는다. 카드가 제공하는 효과를 무효화하려고 적의 난이도를 자동 상향하지도 않는다.
- 카드가 없는 PC도 원래 CoC 기능·행동·직업·전문 지식으로 조사·전투·설득·도주·구조할 수 있다. 카드는 기존 행동의 허가증이나 직업권한을 독점하지 않고, 특별한 수단/결과를 추가한다.
- 원작의 시대·기술·초자연 법칙, 실제 소지·관계·위험·사망 가능성을 그대로 존중한다.

## 2. 클래스와 장착 [확정]

### 클래스

1. **수호자 (Guardian)** — 보호, 위험에 개입, 구조·저지
2. **탐구자 (Seeker)** — 관찰, 기록, 분석을 실제 대응으로 연결
3. **무법자 (Rogue)** — 기동, 잠입, 순간적 빈틈 활용
4. **기회주의자 (Wildcard, 작업명)** — 고위험 승부수, 실제 손실을 감수한 극적인 역전. 기존 신비주의자 대체 [클래스 교체 확정]
5. **생존자 (Survivor)** — 원작 생존자의 실패 속 성과·임기응변·폐품 활용·끈질긴 생존 [콘셉트 및 카드 10장 확정]
6. **중립 (Neutral)** — 어느 클래스든 장착할 수 있는 범용 카드

- **캠페인 시작 때 주 클래스 하나 선택**, 해당 캠페인 전체에서 고정한다. 다음 캠페인에서는 변경 가능. 서브클래스는 이번 설계 범위에서 사용하지 않으며 미래 검토 사항이다.
- 해당 캠페인에서 **현재 주 클래스 카드 + 중립 카드만 장착**할 수 있다. 타 클래스 카드는 영구 소유·수집은 가능하지만 그 캠페인에서 장착하지 않는다.
- 클래스는 PC 직업·성격·배경을 제한하지 않는다(예: 군인이 탐구자를 선택해도 된다).

### 슬롯 구성

| 슬롯 | 수 | 허용 카드 |
|---|---:|---|
| 자산 전용 | 1 | 자산 |
| 이벤트 전용 | 1 | 이벤트 |
| 자유 | 2 | 자산 또는 이벤트 |
| **합계** | **4** | **항상 고정** |

- 가능한 구성: **자산 3·이벤트 1 / 자산 2·이벤트 2 / 자산 1·이벤트 3**.
- 장착 수는 영구 수집량·플레이 경력에 따라 증가하지 않는다.
- **대사건**: 장착 구성과 카드를 캠페인 내내 고정.
- **연대기**: **이벤트 카드만 챕터 사이에서 교체 가능**. 자산 카드의 장착 선택은 연대기 전체에서 고정. 자유 슬롯에 자산을 넣었다면 그 슬롯을 중간에 이벤트용으로 바꾸거나 새로운 자산을 중도 투입하지 않는다. 자유 슬롯에 이벤트를 넣었다면 챕터 사이 이벤트 카드는 바꿀 수 있지만 해당 슬롯을 중도에 자산으로 바꾸지는 않는다.
- 이미 발생한 PC·장비·세계·관계의 결과는 장착 변경으로 지워지지 않는다.

## 3. 카드 유형과 적용 성격 [확정]

**유형은 자산(Asset), 이벤트(Event) 두 가지뿐**이다. 별도의 기능(Skill) 카드·배경(Background) 카드 분류는 도입하지 않는다. 인간 동료를 영구 카드로 지급하는 자산도 도입하지 않는다.

### 자산 (Asset)

- 캠페인 **시작 시** 실제로 가지는 장비·도구·소모품 또는 동물 동료 등. 일반적인 무료 시작 장비는 최소한으로 두고 선택한 자산에 시작 장비의 의미를 집중시킨다.
- 물리 자산은 기존 소지품 규칙(기본 메인 5칸, 파우치 3칸 등)에 포함된다. 인벤토리를 우회해 무료로 들고 다니는 장비로 처리하지 않는다.
- 사용·소모·파손·분실·버림·타인에게 넘김 등 현실의 결과가 적용되며 자동 재생성되지 않는다. 반려 동물 자산은 의지와 위험을 가진 생명체로서 부상·사망 가능성이 있고, 소환수처럼 재지급되지 않는다.
- 시대·세계에 존재하지 않는 기술·초자연 능력을 강제로 지급하지 않는다. 기능과 등가인 시대별 물품으로 구체화할 수 있는지 해당 원작에 맞게 판단한다.
- 자산의 캠페인 중 교체는 불가하며, 특히 연대기의 자산은 챕터를 넘어 고정한다.

### 이벤트 (Event)

- 실제 발동 기회에서 플레이어가 선언하는 **특별 행동**. 장착만으로 자동 발생하거나 평범한 판정을 대신하지 않는다.
- **사용 횟수 무제한**이지만, **동일한 실제 발동 기회에서는 딱 한 번만 시도** 가능하다. 새로운 실제 기회가 생겨야 다시 사용할 수 있다. 성공할 때까지 반복 굴리지 않는다.
- 이벤트마다 **발동 조건 / 요구 기능·특성 / 판정 난이도(어려움 또는 극단적) / 성공 효과 / 실패 위험**을 기재한다.
- **어려운 성공**: 기능/특성값의 1/2 이하(버림); **극단적 성공**: 기능/특성값의 1/5 이하(버림). **보통 성공만으로 이벤트 발동 불가**.
- 이벤트 전용 d100은 **플레이어가 직접 굴리는 원시 판정값**을 사용하며, **행운 소모·강행·보너스/패널티 주사위·다른 특별 카드의 판정 보정은 전부 금지**.
- 실패 위험은 실제 장면·수단과 인과적으로 연결된 **실질적인 위험**이며, **판정 전에** 알린다. 카드 때문에 임의의 고정 HP/SAN 소모를 찍어내거나, 이미 막아낸 피해를 되살리지 않는다.
- 이미 확정된 성공·예방·도주·안전 및 실제 원작 법칙과 PC 주도권을 보호한다.
- 이벤트 카드 교체는 연대기 챕터 사이에만 가능하다. 대사건 중에는 불가.

## 4. 아이디 생성 시 동일 지급하는 기본 카드 [확정]

**플레이어 아이디 최초 생성 시 모두 동일한 기본 카드 18장을 한 번에 영구 지급**한다.

| 소속 | 자산 | 이벤트 | 계 |
|---|---:|---:|---:|
| 중립 · 일반 | 4 | 4 | 8 |
| 수호자 · 희귀 | 1 | 1 | 2 |
| 탐구자 · 희귀 | 1 | 1 | 2 |
| 무법자 · 희귀 | 1 | 1 | 2 |
| 기회주의자 · 희귀 | 1 | 1 | 2 |
| 생존자 · 희귀 | 1 | 1 | 2 |
| **합계** | **9** | **9** | **18** |

- **기본 카드 18장은 모든 계정에 동일**, 랜덤 지급이 아니다. **가챠/드래프트 후보 풀에는 절대 포함하지 않는다.**
- 클래스 최초 선택 시 추가 지급 없음. 다섯 클래스 기본 카드는 아이디 생성 때 이미 전부 소유한다.
- 첫 캠페인에서 장착 가능한 기본 카드 후보는 **중립 8 + 선택 클래스 2 = 10장**이며, 이 중 4장 장착. 클래스 카드를 반드시 넣어야 하는 것은 아니다.
- **기본/해금**은 획득 경로이고, **일반·희귀·영웅·전설**은 희귀도다. 같은 일반 등급이라도 중립 기본 카드와 가챠 전용 카드가 따로 존재할 수 있다.

## 5. 영구 해금·드래프트·희귀도 [확정]

### 보상 발생

- **대사건**: 캠페인의 실제 종결 시 1회.
- **연대기**: 실제 **각 챕터 종결 시 1회**. 마지막 챕터의 종결 보상과 연대기 전체 종결 보상을 이중 지급하지 않는다.
- 실제로 달성한 구조·탈출·안전 확보·유효한 철수 등 종결을 인정하며, 반드시 괴물 처치나 모든 진상 규명을 강요하지 않는다.
- **PC가 사망해도 플레이어의 종결 보상 자격은 유지**한다. PC 사망 그 자체로 즉시 드래프트를 추가 지급하지 않으며, 실제 해당 종결 보상 시점에 지급한다.
- 보상 1회당 **드래프트 한 번 → 새 카드 정확히 한 장 획득**(획득 가능 카드가 있는 경우).
- 연대기에서 종결 보상으로 해금한 **이벤트**는 다음 챕터 시작 전 교체 시 장착 가능. **자산**은 다음 캠페인부터 장착 가능.

### 후보 3장 드래프트

1. 보상권이 생기면 후보 **최대 3장**을 실제 무작위로 정한다.
2. **첫 후보**: 현재 캠페인 클래스 또는 중립의 **미보유 해금 카드** 풀에서 선정.
3. **둘째·셋째 후보**: **모든 클래스+중립의 미보유 해금 카드** 풀에서 선정.
4. 기본 지급 18장, 기존 보유 카드, **동일 드래프트의 앞선 후보**는 추첨에서 제외한다.
5. 플레이어가 공개된 후보 중 **한 장을 직접 선택**하여 플레이어 아이디 컬렉션에 영구 해금한다. 선택하지 않은 후보는 소유하지 않으며 다음 보상 후보로 다시 등장할 수 있다.
6. 현재 클래스+중립 풀이 전부 소진되었다면 **첫 후보도 전체 미보유 해금 풀**로 전환한다.
7. 미보유 해금 카드가 2장이면 2장을, 1장이면 1장을 전부 제시하고 1장 선택/획득한다.
8. 전체 미보유 해금 카드가 **0장**이면 추가 보상 없음. **이월 보상권 없음**, 추후 신규 카드 추가 시 지난 종결 보상을 소급 지급하지 않는다.
9. **재추첨·천장·실패 누적 확률 보정 없음**. 드래프트 결과는 한 번 확정하여 동일 보상에서 반복 굴리지 않는다.

### 희귀도/등장 확률

| 등급 | 색상 | 카드 소속 | 기본 확률 |
|---|---|---|---:|
| **일반(Common)** | 회색 | **중립만** | **50%** |
| **희귀(Rare)** | 초록 | **클래스 전용** | **30%** |
| **영웅(Epic)** | 보라 | **클래스 전용** | **15%** |
| **전설(Legendary)** | 주황 | **클래스 전용** | **5%** |

- 추첨은 **Python 실제 난수**로 수행. PC의 이벤트 d100은 플레이어가 직접 굴리므로 혼동하지 않는다.
- 후보별로 **허용 클래스 풀 → 기본·보유·이번 후보 제외 → 남은 희귀도만 가중치 비례 재분배 → 등급 추첨 → 해당 등급에서 카드 추첨** 순서로 처리한다.
- 예: 일반 풀이 모두 소진되면 기존 희귀:영웅:전설 = 30:15:5를 정규화해 **희귀 60% / 영웅 30% / 전설 10%**. 이는 천장이 아니라 추첨 가능한 풀이 줄어든 결과다. 첫 후보와 전체 후보는 허용 풀에 따라 적용 확률이 다를 수 있다.
- 색상/희귀도는 **획득의 희소성·효과의 독특함**을 나타낸다. 전설이 일반·희귀 효과의 필연적 상위 호환이거나 자동 성공·단순 피해량 상향인 구조로 만들지 않는다.
- 개별 추첨 결과 및 보상 중복 방지 기록은 이후 구현 시 설계한다. 아직 DB·운영 로직은 변경하지 않았다.

## 6. 기본 카드 18장 [카드 초안 — 카드별 최종 효과 미확정]

이 절은 **기본 카드 18장 구성의 보존본**이다. 생존자 기본 2장은 **§8의 확정 효과**를 따르며, 그 외 기본 카드의 구체 명칭·발동 조건·요구 기능·난이도·효과는 추가 검토 가능한 초안이다.

### 6-1. 중립 자산 4장 (일반)

| 카드명 | 기본 기능 | 물리적 제약·주의 |
|---|---|---|

## 7. 확정된 설계의 핵심 경계와 남은 작업

### 확정된 금지/구분

- **기능 카드·배경 카드 신설 없음**. 직업·전문성·관계·권한·생활 기반을 영구 카드로 자동 부여하지 않음.
- 인간 동료 영구 자산 없음. 동물 동료 자산은 향후 추가 가능하지만 생명/위험을 존중.

- 행운·강행·보정·보너스/패널티로 이벤트 특수 성공의 난이도를 변형하지 않음.

- 클래스 선택·카드 장착으로 PC의 통상 행동을 금지하지 않음.
- 신규 카드를 얻었다고 연대기 도중 새로운 시작 자산을 지급하지 않음.

## 8. 생존자 원작 개성 재정립 및 카드 10장 [사용자 확정 · 2026-11-10]

> **이 절이 생존자 카드의 최신 확정 기준이며, 위의 구형 생존자 명칭이나 이전 생존자 가챠 초안보다 우선한다.** 정식 게임 룰북 적용은 아직 승인되지 않았으며, 이 문서는 개발중 보관본이다.

### 8-1. 클래스 정체성 [확정]

- **생존자(Survivor)**: “빈손이어도 싸우고, 실패해도 건지고, 쓰러져도 끝까지 살아남는다.”
- 원작 아컴호러 생존자의 감각을 참고한 **실패 속 성과 / 임기응변과 잡동사니 활용 / 소박한 자산과 회수·재활용 / 궁지의 끈질긴 생존**.
- **기회주의자는 위험한 승부를 미리 선택해 큰 성과를 노리고, 생존자는 이미 발생한 실패·손실·불리한 결과 속에서 다음 가능성을 찾는다.**
- **실패 결과는 취소하지 않는다.** 원래 실패한 기능 판정을 같은 기회에 재굴림하지 않고, 실패로 실제로 생긴 물건·공간·기회가 있을 때 **별도 이벤트**를 선언하여 어려움/극단적 판정으로 새로운 행동을 시도한다.
- 원작의 판정값 보정·재굴림·마법 같은 아이템 재생성은 채택하지 않는다. 물품·동물·피해·사망은 실제 상태로 유지한다.

### 8-3. 자산 5장 [확정]

1. **기워 입은 가죽 외투 / 기본 희귀**: 캠페인 시작 시 두꺼운 낡은 외투 보유. 비바람·가벼운 마찰로부터 실제 보호 가능한 부위를 보호하며 위험한 물건을 덮거나 다른 사람에게 건네어 활용 가능. 찢어짐·손상·분실 지속. 칼날·총탄·강력한 공격에 대한 무적 방호 아님.
2. **잡동사니 보따리 / 가챠 희귀**: 처음부터 내용이 정해진 철사·천 조각·짧은 끈·금속 조각 등 **소량의 실제 부품** 보유. 묶기·막기·연결하기 등 즉석 활용. 내용물은 실제 소모; 추가 재료를 얻으려면 직접 찾아야 함. 무한 도구 생성·인벤토리 슬롯 증가 아님.
3. **녹슨 삽 한 자루 / 가챠 희귀**: 실제 낡은 삽. 땅 파기·물건 받치기·지렛대·비상 근접 무기 등 현장에 맞게 다용도로 사용. 전문 장비 상위 호환 아님; 무게·파손 위험과 기존 공격/행동 규칙 적용.
4. **끝까지 쓸모 있는 소화기 / 가챠 영웅**: 캠페인 시작 시 시대에 맞는 실제 휴대용 소화기 한 개. (a) 소화약제의 종류·양에 따라 화재 진압 또는 확산 지연, (b) 분말 등 **실제로 시야를 가리는 소화제**로 일시적 시야 방해, (c) 약제 소진 후에도 실물 용기·부품을 다른 용도로 활용 가능. 소화약제는 유한하며 자동 재충전되지 않음. 적의 추격 포기를 강제하지 않으며 사용자에게도 시야·호흡 불리, 화재·분사·무게 위험이 도달할 수 있음.
5. **끝까지 따라온 녀석 / 가챠 전설**: 캠페인 시작 시 세계에 실제 존재하는 **동물 동료**(기본 이미지: 떠돌이 개)와 동행. 소리·냄새·이동·소형 물건 회수 등 실제 동물이 할 수 있는 행동을 보조. 동물은 독립 의지·두려움·한계·위치가 있으며 명령에 자동 복종하지 않고 부상·도주·사망 가능. 죽어도 같은 캠페인에서 자동 재소환·재지급 없음. 원작 세계에 없는 동물이나 능력을 강제로 등장시키지 않음.

### 8-4. 이벤트 5장 [확정]

1. **헛수고는 아니야! / 기본 희귀 — 관찰·어려움**
   - **발동**: 탐색·작업이 실제로 실패했지만 현장에 노출·남겨진 **다른 유용한 물건/대응 수단**이 존재함.
   - **성공**: 원래 실패 유지; 실제 현장에서 다른 물건이나 작은 대응 기회 하나를 찾아 확보.
   - **실패 위험**: 추가 탐색 시간 손실·위험 노출. 없는 단서·물건 발명 불가.
2. **부러졌다고 끝이냐? / 가챠 희귀 — 기계 수리·어려움**
   - **발동**: 장비가 실제 파손되었고 아직 사용할 수 있는 부분·부품이 남음.
   - **성공**: 남은 부분을 떼거나 형태를 바꿔 **원래와 다른 임시 도구 한 가지**로 활용.
   - **실패 위험**: 남은 부분 추가 손상/손실 또는 작업 중 부상. 장비 원상복구 아님.
3. **넘어져서 살았다 / 가챠 희귀 — DEX·어려움**
   - **발동**: 실제 넘어짐·충돌로 바닥에 쓰러졌고 낮은 자세에서 닿을 수 있는 틈/엄폐물 존재.
   - **성공**: 쓰러진 위치에서 그 틈을 통과하거나 가까운 엄폐물 뒤로 이동.
   - **실패 위험**: 이탈 지연·끼임·추가 위해 노출. 기존 넘어짐/부상 결과 취소 아님.
4. **아직 움직일 수 있어 / 가챠 영웅 — CON·어려움**
   - **발동**: 실제 부상·강한 충격을 입었으나 의식과 행동 능력이 남아 있고 닿을 수 있는 보호 위치가 존재.
   - **성공**: 부상을 유지한 채 기어가거나 지지물을 붙잡는 **한 번의 긴급 이탈 행동**으로 보호 위치에 도달할 기회 확보.
   - **실패 위험**: 움직임으로 인한 부상 악화·추가 위해 노출. 행동 불능·사망 무효화나 자동 회복 불가.
5. **다 끝난 줄 알았지? / 가챠 전설 — INT·극단적**
   - **발동**: 중요한 계획·행동이 실제 실패해 원래 경로를 잃었지만, **실패로 드러난 물건·공간·구조·상대의 움직임**에 실제 활용 가능한 대안 존재.
   - **성공**: 실패 결과를 이용해 **다른 방법으로 현재의 긴급 목적 하나를 달성할 행동**을 수행.
   - **실패 위험**: 마지막 대응 수단 소모·위험 재노출. 원래 실패 취소, 물건/탈출구 창조, 비물리적 즉시 해결 불가.

### 8-5. 확정 범위와 후속 확인

- **기본 2장 + 가챠 희귀 4장 + 가챠 영웅 2장 + 가챠 전설 2장 = 10장**의 구성·카드명·효과 방향을 사용자 채택. 이전 제안의 **고물 손수레는 폐기**, **끝까지 쓸모 있는 소화기**로 교체 확정.
- 기존 생존자 초안의 **수선 도구 묶음·있는 것으로 버틴다·작업 장갑·회수용 집게·화로·임시 거처·고장 난 채로 한 번 더·폐허에서 길을 만들다 등**은 최신 카드 구성에 포함하지 않는다.
- 자산의 **크기·인벤토리 칸·구체적인 시대별 사양**, 실제 판정 상황의 위험과 대항 절차는 정식 적용 단계에서 현재 CoC/TRPG 원문과 대조해 정리한다. 확정 카드가 기존 규칙을 우회하지 않는다.
- 생존자 이외의 수호자·탐구자·무법자는 **원작 정체성 재검토 대상**이며, 사용자가 요청한 다음 작업은 수호자부터 시작하는 것이다.
