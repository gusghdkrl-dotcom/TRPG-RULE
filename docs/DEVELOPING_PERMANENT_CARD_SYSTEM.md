# (개발중) 플레이어 영구 카드·강화·성장·4장 드래프트 시스템

> **상태: 개발중 / 66장 자산·강화 설계 채택 / Supabase 영구 카드 백엔드 및 게임 시작·종결 연결 규칙 반영 / 개별 카드 효과 검증·정식 운영 통합 진행 중**
>
> **최종 재정리: 2026-11-10 (자산 33종·강화 33종 및 Supabase 영구 카드 백엔드)** — 자산 33종은 클래스 정체성·세계관별 실물 가변·실제 행동의 유용성을 기준으로 전면 재설계하여 채택. 강화 33종은 기존 1차 채택 상세안을 보존. 성장 8종과 4후보 드래프트 유지. 인간 관계형 조력자 2종은 정식 카드와 별도로 후보 보관.
>
> 이 문서는 대화에서 합의된 **카드 설계의 보관본**이다. **영구 카드 DB와 게임 시작·판정·종결·ID 연결 지침은 별도 승인에 따라 실제 구축/반영**되었다. 다만 개별 카드 효과 66장의 상세 인과·전투·의료 정합성 검증과 장면별 구현이 자동 완료된 것은 아니다. **현재 운영 룰북이 실제 판정의 정본**이며, 게임 상태·비공개 정본/기존 체크포인트 데이터는 소급 변경하지 않는다.
>
> **표기**: [확정] 사용자 승인한 시스템 골격 / [자산 채택] 사용자 승인한 자산명·역할·효과 방향(원작별 실물 사양은 캠페인마다 확정) / [강화 1차 채택] 구체 조건·효과 방향의 초안 승인 / [후보] 카드 풀 미포함, 장차 교체 검토 / [미정] 실행 전 추가 결정 필요. 아래 채택 내용은 **정식 룰북에 아직 반영되지 않은 개발 문서**다.

## 1. 이번 설계의 핵심 결론 [확정]

1. 카드의 기본 유형은 **자산(Asset)**과 **강화(Enhancement)**다. **이벤트(Event)라는 카드 유형은 폐기**한다. 기존 이벤트 카드의 발동·판정·효과를 현행 확정 효과로 사용하지 않는다. 이름과 콘셉트는 새 강화 제작에 참고 가능하다.
2. 별도 **성장(Growth)** 셀렉션을 추가한다. 이는 **클래스도 중립도 아니며**, 장착 카드 유형인 자산·강화와도 별개다.
3. 자산은 실제로 보유하는 시작 장비·도구·소모품 또는 **독립적인 동행 동물**이다. **33장 전부 재설계한 사용자 채택 목록**을 제9절에 적는다. 희귀도는 일률적인 공격력·방어력 상승이 아니라 **상황에 따른 유연성·새 대응 경로·플레이 방식의 확장**을 의미한다.
4. 강화는 플레이어에게 특정 행동을 하라고 지시하지 않는다. PC가 자유롭게 행동하고, **현재 상황과 판정의 성공 단계가 장착한 강화의 조건을 만족하면 자동 발동**하는 것이 기본이다. 카드 전용 추가 d100 굴림 없음.
5. **강화 카드가 제공하는 특수 보너스 주사위**는 해당 카드당 **캠페인 전체 1회**, **굴리기 전에 선택**한다. 일반 판정은 낮은 주사위값, 그 특수 보너스와 결부된 강화 발동 판정은 높은 주사위값을 본다. 준비·환경 등에서 얻는 **일반 보너스 주사위**는 낮은 값으로 일반 판정과 강화 조건을 함께 판단한다.
6. 플레이어가 **자발적으로 추가 위험/손실을 선택**한 경우에만 위험·보상 강화의 추가 실패 대가를 부과한다. 카드를 소지·장착했다는 이유만으로 일반 실패가 더 나빠지지 않는다.
7. 성장 카드는 **STR, CON, SIZ, DEX, APP, INT, POW, EDU**, 총 8종. 같은 종류를 순차적으로 최대 **5단계**, 해당 기본 특성 **+1~+5포인트**로 성장시킨다. 기능(관찰·격투·잠행 등)은 대상이 아니다.
8. 성장 카드 **첫 획득은 Lv.1(+1) 확정**. 이후 같은 성장을 선택할 때마다 Python 실제 난수로 **Lv.2 80% / Lv.3 50% / Lv.4 25% / Lv.5 10%** 강화 시도. 실패하면 단계는 유지하되 **그 종결 보상 1회는 완전히 소비**한다.
9. 보상 드래프트는 **최대 4후보 중 정확히 1개 선택**. 순서는 **① 현재 클래스 전용 카드 ② 전체 5개 클래스 중 랜덤 카드(성장·중립 제외) ③ 성장 카드 ④ 중립 카드**로 고정한다.
10. 플레이어 ID 영구 컬렉션, 원작/세계 인과, PC 주도권, 실제 물품 소모·손상, 캠페인 종료 보상 구조는 유지한다.

## 2. 클래스 및 플레이어 귀속 [확정]

| 분류 | 방향 |
|---|---|
| **수호자 / Guardian** | 정면 전투, 동료 보호, 피해 감수, 구호 지원. 강적을 직접 상대할 수단과 방어의 선택 |
| **탐구자 / Seeker** | 실제 관찰·분석·기록·정보 활용. 단순 단서 획득뿐 아니라 대응에 도움 |
| **무법자 / Rogue** | 잠입, 교섭, 기동, 상대의 빈틈·위치·시간차 활용 |
| **기회주의자 / Wildcard (작업명)** | 도박·확률·위험을 걸고 더 큰 성과를 노리는 하이리스크/하이리턴. **기존 신비주의자를 대체** |
| **생존자 / Survivor** | 원작 감각: 실패 속 성과, 잡동사니 임기응변, 재활용, 부상·궁지에서의 끈질김 |
| **중립 / Neutral** | 모든 클래스가 장착할 수 있는 범용 자산·강화 |
| **성장 / Growth** | **클래스/중립 소속이 아닌 독립 셀렉션**. 8대 기본 특성별 단계 성장 |

- 소유·해금·성장 단계는 **플레이어 ID**에 귀속된다. PC가 사망해도 컬렉션/성장 단계는 사라지지 않는다.
- 새 PC에게 이전 PC의 기억·비밀·개인 인맥·실물 장비가 자동 전달되지 않는다.
- 캠페인 시작 때 **주 클래스 하나**를 선택해 그 캠페인에 고정한다. 그 캠페인에는 **해당 클래스 + 중립**의 장착 카드만 사용한다. 다른 클래스 카드도 컬렉션에는 소유 가능하며 다음 캠페인에 클래스를 바꿀 수 있다.
- 클래스 선택은 PC 직업·성격·일반 CoC 기능·행동 가능 범위를 제한하지 않는다.
- 인위적인 적 난이도 자동 상향·성과 무효화 없음.
- **성장만 제한적인 영구 수치 상승의 명시적 예외**다. 원래의 순수 수평 성장 원칙은 자산·강화 카드 선택에 적용되며, 성장 때문에 최대 HP·SAN·소지 슬롯을 직접 영구 증가시키는 설계를 자동으로 허용하는 것은 아니다.

## 3. 카드 수량 및 풀 구성 [확정된 골격]

### 3-1. 플레이어 ID 생성 시 기본 18장 즉시 지급

| 소속 | 기본 자산 | 기본 강화 | 합계 |
|---|---:|---:|---:|
| 중립 일반 | 4 | 4 | 8 |
| 수호자 희귀 | 1 | 1 | 2 |
| 탐구자 희귀 | 1 | 1 | 2 |
| 무법자 희귀 | 1 | 1 | 2 |
| 기회주의자 희귀 | 1 | 1 | 2 |
| 생존자 희귀 | 1 | 1 | 2 |
| **합계** | **9** | **9** | **18** |

- 모든 신규 플레이어 ID에 **동일한 기본 18장**을 처음 한 번 영구 지급한다. 클래스 선택에 따른 추가 지급은 없다.
- **기본 18장은 무작위 해금 풀에서 제외**한다. 현재 주 클래스 기준 처음 장착 가능한 기본 후보는 중립 8장 + 클래스 2장 = 10장.
- 기본 지급 카드 가운데 기존 이벤트로 설계했던 **기본 강화 9장의 최종 효과는 전부 재설계 대상**이다.

### 3-2. 신규 해금 전용 풀 48장

| 소속 | 희귀도 | 자산 | 강화 | 합계 |
|---|---|---:|---:|---:|
| 중립 | 일반 8장 | 4 | 4 | 8 |
| 수호자 | 희귀 4 / 영웅 2 / 전설 2 | 4 | 4 | 8 |
| 탐구자 | 희귀 4 / 영웅 2 / 전설 2 | 4 | 4 | 8 |
| 무법자 | 희귀 4 / 영웅 2 / 전설 2 | 4 | 4 | 8 |
| 기회주의자 | 희귀 4 / 영웅 2 / 전설 2 | 4 | 4 | 8 |
| 생존자 | 희귀 4 / 영웅 2 / 전설 2 | 4 | 4 | 8 |
| **합계** | | **24** | **24** | **48** |

- 각 클래스 해금 풀의 분포: **희귀 자산 2·강화 2 / 영웅 자산 1·강화 1 / 전설 자산 1·강화 1**.
- 기본 18장 + 해금 전용 48장 = **자산·강화 66종**(자산 33종 + 강화 33종).
- 성장 독립 셀렉션 **8종 추가 → 전체 고유 카드/셀렉션 명칭 74종**. 성장 카드 8종은 단계 강화를 위해 중복 등장할 수 있으며 별도의 신규 해금 48장에 포함되지 않는다.
- **자산 33종은 제9절의 최신 채택안이 정본**이며, 과거 물품 초안은 대체됐다. **강화 33종은 제10절의 1차 채택안**을 보존한다. 성장 8종 및 해금·장착 수량 골격은 유지한다.

## 4. 장착 및 캠페인 경계 [확정 골격]

| 슬롯 | 수 | 허용 |
|---|---:|---|
| 자산 전용 | 1 | 자산 |
| 강화 전용 | 1 | 강화 |
| 자유 | 2 | 자산 또는 강화 |
| **합계** | **4** | **1자산+1강화 필수** |

- 가능한 장착 구성: **자산 3·강화 1 / 자산 2·강화 2 / 자산 1·강화 3**. 슬롯 수 증가 없음.
- **대사건**: 캠페인 내 장착 카드/구성 고정.
- **연대기**: **강화 카드만 챕터 사이에 교체**. 자산 및 자유 슬롯의 유형(자산 또는 강화)은 연대기 전체에서 고정한다. 자산용 자유 슬롯을 강화용으로 바꾸거나 반대 변경도 불가.
- 캠페인 중 새로 해금한 강화는 다음 **연대기 챕터 경계**에서만 장착 가능; 새 자산은 다음 캠페인부터 시작 지급 가능.
- **성장은 장착 슬롯을 차지하지 않는다 [확정]**. 영구 UUID와 신규 PC identity를 연결하는 순간 저장된 성장 레벨을 기본 특성에 반영하고 스냅샷을 확정한다. 같은 PC의 재연결·이후 성장으로 소급 변경하지 않는다. 파생값은 기존 PC 생성 규칙으로 산출한다.

## 5. 자산: 세계관별 실제 수단과 동행 동물 [채택된 설계 기준]

1. **카드 정체성과 실제 구현을 분리한다.** 카드명·클래스 역할·새로 열리는 대응 방식은 유지하되, 캠페인을 시작할 때 **해당 원작의 시대·기술·문화·장소·세계 법칙 안에 실제 존재하는** 물품/동물로 구현한다. 모습만 바꾸고 현대 장비의 기능·효과를 옛 시대의 물건에 억지로 복사하지 않는다. 해당 원작에서 성립하지 않는 원격 장치·의료 기술·생물·물품을 발명해 지급하지 않는다.
2. **실제 장착 가치 우선.** 자산은 단순 공격력·피해 경감·기본 능력치 상승 카드가 아니라, 보호·구조·조사·실험·잠입·교란·임기응변·협상 등 **다른 방식으로 문제에 개입할 수 있는 물리적 수단**을 제공한다. 기본 자산도 끝까지 유용할 수 있으며, 영웅·전설은 더 높은 숫자가 아니라 **새로운 전략과 상황 대응의 폭**을 연다.
3. 자산은 해당 캠페인 **시작 시 한 번** 실물·소모품·동행 동물로 지급한다. 이후 실제 위치·사용·소진·손상·파손·인계·분실·사망이 계속 유지되며, 장착 카드가 남았다고 자동 복구·재지급되지 않는다. 같은 성능의 물품을 세계 안에서 구한 다른 PC도 실제로 사용할 수 있다. 카드는 행동 자체를 독점하지 않는다.
4. **새 무게·하중 수치, 하중 계산, 별도 장비 용량 시스템을 도입하지 않는다.** 소지는 현행 룰북의 **메인 5칸·파우치 3칸과 실제 소지/운반 상태**로 관리한다. 기존 룰북에 이미 명시된 특정 무기·목표물의 슬롯 취급은 기존 절차에 따른다. 자산 카드별 임의 무게 페널티나 정격 하중 수치를 신설하지 않는다. 물리적 가능 여부는 장면의 실물 구조와 기존 판정으로 판단한다.
5. **동행 동물은 독립적인 NPC적 존재**다. 훈련·감각·습성·관계에 따라 실제 행동하고, 무조건 명령에 따르지 않는다. 위치·공포·부상·이탈·죽음이 실제로 남는다. PC가 지시하지 않은 행동을 명령으로 만들어내지 않으며, 사망 후 카드로 다시 소환하지 않는다. 동물 세 종류의 클래스 역할은 **수호자: 호위·대피 / 기회주의자: 속임수·돌발 기회 / 생존자: 감각·생존 동행**으로 구분하되 가능한 행동을 독점시키지 않는다.
6. **인간 협력 관계는 아직 정식 자산이 아니다.** 탐구자의 연구 협력자·무법자의 뒷세계 연결책은 제9-8절의 **예비 후보**로만 보관한다. NPC가 자동 지급·종속되거나 원격 도움을 무제한 제공하지 않는다. 시대별 연락 방식·실제 접근성·인물의 자유와 계약·거절·관계 변화를 향후 검토한다.
7. **자산과 강화의 역할 분리.** 자산은 손에 잡히는 수단과 동행 존재를 확보한다. 강화는 자유 선언된 행동의 실제 조건과 판정 성공 단계가 맞을 때 별도 카드 전용 주사위 없이 추가 결과를 제공한다. 장비만 갖췄다는 이유로 자동 성공·숨은 정보 전지적 공개·NPC 자동 동의를 허용하지 않는다.

> **시대별 실물 결정 경계**: 아래 자산별 예시는 '모든 원작에 반드시 등장하는 장비' 목록이 아니다. 캠페인마다 구체 물건·내용물·횟수·연료·훈련·기능·한계·소지 위치를 시작 전에 정하고, 실제 세계 결과로 유지한다. 실물이 존재하지 않아 카드의 핵심 역할을 구현할 수 없다면 없는 능력을 꾸며내지 말고 해당 충돌을 정식 적용 전에 해결한다.

## 6. 강화: 자유 행동의 조건부 혜택 [확정 골격]

### 6-1. 보통 강화의 처리

1. 플레이어가 카드와 무관하게 **자유롭게 행동·대화·탐험·전투·치료·수리 등을 선언**한다.
2. 키퍼가 실제 상황/도구/상대 반응에 맞춰 **기존 CoC 판정 또는 무판정 결과**를 처리한다.
3. 장착 강화의 **장면 조건 + 요구 성공 단계(어려움 또는 극단적)**가 맞으면 **해당 강화의 이익이 자동 적용**된다.
4. 일반 행동과 강화는 가능한 한 **한 번의 기존 판정으로 처리**한다. 기존 이벤트 방식의 **별도 카드 전용 d100**, 사용 선언, 반복 시도 판정을 만들지 않는다.
5. 보통 성공만 충족하고 강화의 어려운 성공을 못 얻었더라도 **원래 행동 성공은 유지**한다. 강화 미발동이 이미 얻은 성공이나 안전을 지우지 않는다.
6. 강화가 전제하는 자원/시간/물리적 조건이 없으면 억지로 부가 이익을 만들어내지 않는다. 비밀·NPC 의지·물리 법칙·상대의 대응권 보호.

### 6-2. 강화 효과의 허용 방향

- **조건부 성과 확대**: 기존 성공 후 가능한 추가 효과를 얻음. 정상 행동만으로 가능한 결과를 금지하거나 카드에 독점시키지 않음.
- **물건·자원·회복 효율**: 실제 회복/소모 조건이 성립하는 경우 한정. 자동 HP/SAN 복구나 무한 자원 창조 아님.
- **시작 시 적용하는 강화**: 시작 현금 등은 별도 판정을 강제로 만들지 않고 캠페인 시작 시 적용한다. 예: 중립 「비상금」의 실제 시작 현금 **+10%**는 제10-6절 채택안. 원작 경제에 실제 화폐가 없으면 허구 보상으로 대체하지 않는다.
- **실패 결과 활용**: 원래 실패와 피해를 취소하지 않고, 실제 남은 부산물·상황에서 가능한 성과를 부여. 카드가 실패를 성공으로 소급 변경하지 않음.
- **위험·보상**: 평소보다 큰 성과를 위해 추가 손실·노출을 자발적으로 거는 방식. **플레이어의 선택과 사전 고지**가 있어야 추가 실패 대가를 부과. 카드 장착만으로 불리한 손실 자동 발생 금지.
- **강력한 판정 보정**: 카드가 제공하는 특수 보너스 주사위는 다음 절을 따름. 전설이라고 무조건 상시 수치가 더 큰 카드로 만들지 않음.

### 6-3. 일반 보너스 주사위 vs 특수 강화 보너스 주사위 [확정]

| 판정 방식 | 본 행동 성패 | 강화 발동 성공 단계 |
|---|---|---|
| 추가 보너스 없음 | 일반 d100 결과 | 같은 결과 |
| **환경·장비·준비 등의 일반 보너스** | 유리한 **낮은 결과값** | **낮은 결과값** |
| **장착 강화 카드가 제공한 특수 보너스** | 유리한 **낮은 결과값** | 같은 특수 보너스와 관련된 강화의 경우 **높은 결과값** |

- **특수 보너스는 해당 강화 카드당 캠페인 전체에서 1회**, 판정 **전에 사용을 선택**한다. 결과를 본 뒤에 사용·소급 적용 불가.
- 일반 행동의 성공률과 강화 발동은 구분한다. 특수 보너스에서 낮은 값으로 본 행동은 성공해도 높은 값이 어려움/극단적 요구치에 미달하면 **추가 강화 효과는 미발동**한다.
- 예: 기능값 50, 강화 어려운 성공 기준 25. 공유 일의 자리가 1인 후보값이 **21 / 41**이라면, 일반 행동은 **21로 성공**, 특수 보너스와 결부된 강화 효과는 **41로 미발동**. 단, 같은 후보가 **21 / 21**이면 양쪽 모두 충족한다.
- **일반 보너스의 낮은 값을 쓰는 것은 준비를 잘했기 때문에 오히려 강화를 잃는 역전 현상을 막기 위함**이다.
- 실제 CoC 보너스 주사위는 십의 자리 굴림을 추가하고 일의 자리를 공유한다. 기존 보너스/패널티 상쇄·최대 적용 수 등 담당 룰북의 일반 판정 절차를 유지한다.
- **일반 보너스 주사위와 강화 특수 보너스 주사위는 같은 판정에서 함께 사용할 수 없다 [확정]**. 혼합·중첩 높은/낮은 값 계산 자체가 없다. 일반 패널티 등 기존 판정 규칙은 그대로 따른다.

### 6-4. 유의할 균형

- 일반 보너스 주사위 1개는 기능값 50의 보통 성공을 대략 **50% → 75%**로 높일 만큼 강력하다. 상시 지급하지 않고 **특수 보너스는 캠페인 1회**로 제한한다.
- 강화 카드는 플레이어가 선택한 자유 행동에 **실제 의미 있는 차이**를 줘야 한다. 일반 행동을 허가해 주는 효과, 같은 행동을 이름만 바꾼 효과는 재설계한다.
- 소유/장착한 강화만큼 기본 스탯·최대 HP/SAN·인벤토리·피해량이 자동 누적 상승하는 구조는 피한다. **정해진 성장 +5 상한만 별도 허용**한다.

## 7. 캠페인 보상과 4후보 드래프트 [확정]

### 7-1. 보상 발생

- **대사건**: 캠페인 실제 종결 시 **1회**.
- **연대기**: 실제 **각 챕터 종결마다 1회**. 마지막 챕터 보상과 연대기 전체 완료 보상을 이중 지급하지 않는다.
- 유효한 탈출·구조·안전 확보·철수 등 실제 종결을 인정한다. 특정 진상 규명이나 괴물 처치를 강요하지 않는다.
- PC가 죽어도 플레이어의 종결 보상 자격은 남으며, **사망 순간 추가 드래프트를 주는 것은 아님**. 실제 종결 시점에 보상 지급.
- 보상당 드래프트 하나, **선택 한 번**. 신규 일반 카드 해금 또는 성장 획득/강화 시도를 선택한다.

### 7-2. 슬롯 순서와 정확한 후보 풀

| 후보 | 반드시 속할 풀 | 성장 포함? | 중립 포함? |
|---|---|---|---|
| **1번: 현재 클래스** | 캠페인에서 선택한 **주 클래스 전용 자산·강화** | 아니오 | 아니오 |
| **2번: 전체 클래스 랜덤** | **다섯 클래스 전체**의 자산·강화 (현 클래스 포함 가능) | **아니오** | **아니오** |
| **3번: 성장** | 독립 성장 카드 **8종** 중 Lv.5 미달 성장 | **이 슬롯만** | 아니오 |
| **4번: 중립** | **중립** 자산·강화 | 아니오 | **이 슬롯만** |

**예: 수호자 캠페인** → 1번 수호자 / 2번 수호자·탐구자·무법자·기회주의자·생존자 가운데 랜덤 / 3번 성장 / 4번 중립.

- 1·2·4번은 **해금 전용 48장**에서만 뽑으며, **기본 지급 18장은 후보에 나오지 않는다**.
- **일반 자산·강화의 이미 보유한 카드**는 후보에서 제외한다. 한 번의 드래프트에서 1번과 2번이 같은 카드가 되는 중복도 금지한다.
- 3번 성장 후보는 **Lv.5에 도달하지 않은 8개 성장**에서 실제 무작위로 하나를 뽑는다. **이미 가진 Lv.1~4 성장도 다시 후보로 나올 수 있다.** 이것만 소유 중복 제한의 예외다.
- **실제 나타난 후보 중 정확히 한 장만 선택**하며 나머지는 획득하지 않는다. **4장 전부 비었다면 선택 없이 보상 종료**한다. 나머지 후보는 다음 적격 보상에서 다시 등장할 수 있다.
- 1·2·4번을 선택하면 해당 자산/강화를 **플레이어 ID에 확정 영구 해금**한다.
- 3번을 선택하면 **첫 획득은 Lv.1 확정, 기존 Lv.1~4는 다음 레벨 강화 도전**. 성공/실패와 무관하게 **보상권은 소비**된다.
- **후보 풀이 소진되면 해당 슬롯은 비운다 [확정]**. 다른 범주로 대체하지 않는다. 네 슬롯 전부 소진되면 해당 종결 보상은 0개로 종료하고, 새로운 카드 추가 뒤에도 이전 보상을 소급 지급하지 않는다.

### 7-3. 희귀도와 추첨 가중치

| 희귀도 | 색 | 소속 | 기존 기본 가중치 |
|---|---|---|---:|
| 일반(Common) | 회색 | 중립 카드만 | 50 |
| 희귀(Rare) | 초록 | 클래스 전용 카드 | 30 |
| 영웅(Epic) | 보라 | 클래스 전용 카드 | 15 |
| 전설(Legendary) | 주황 | 클래스 전용 카드 | 5 |
| 성장(Growth) | **독립 셀렉션** | 8대 기본 특성 | **클래스 희귀도와 별개** |

- 새 드래프트는 **후보 슬롯별 허용 풀이 고정**되어 있으므로 기존 50/30/15/5를 네 후보 전체에 무조건 적용하는 방식이 아니다.
- 1번과 2번은 클래스 전용 카드만 있으므로 남은 희귀:영웅:전설 가중치를 **30:15:5 → 60%:30%:10%**로 정규화하여 등급을 뽑고, 해당 등급의 허용 미보유 카드 중 무작위 선택한다.
- 4번은 **중립 일반 카드 중 무작위**이며, 3번은 **성장 중 무작위**이다. 성장의 등장 여부 자체는 3번에서 보장되므로 기존 희귀도 확률과 경쟁하지 않는다.
- 특정 희귀도·카드 풀이 소진되면 **남은 허용 후보에 한해서만 가중치 비례 재분배**한다. 등급과 개별 카드 후보는 Python 실제 난수를 사용한다.
- 재추첨·천장·보유 중복 화폐·실패 보정은 없다. 전설 카드가 자동 성공이나 단순 상위 성능이라는 뜻은 아니다.

## 8. 성장 셀렉션과 Python 순차 강화 [확정]

### 8-1. 성장 카드 8종

| 카드 | 대상 기본 특성 | 최대 누적 |
|---|---|---:|
| 근력 성장 | STR | +5 |
| 체력 성장 | CON | +5 |
| 체격 성장 | SIZ | +5 |
| 민첩 성장 | DEX | +5 |
| 외모 성장 | APP | +5 |
| 지능 성장 | INT | +5 |
| 정신력 성장 | POW | +5 |
| 교육 성장 | EDU | +5 |

- **기능(Skill)이 아닌 기본 특성(Attribute/Characteristic)**에 적용한다. +1%는 기존 0~100 척도에서 기본 **특성값 +1포인트**로 해석한다. 예: STR 60에 Lv.3 적용 → STR 63.
- 성장 단계는 **플레이어 ID에 귀속**되며 현재 주 클래스와 무관하다. 슬롯 장착이나 카드 소모 후 재지급 대상이 아니다.
- 각 종류별 최대 **Lv.5(+5)**, 8종 전부 최대 달성 시 전체 특성에 걸친 누적 상한은 **40포인트**다. 같은 성장 5단계 이후 그 성장은 3번 후보에서 제외한다.

### 8-2. 획득 및 도전 확률

| 선택 당시 상태 | 결과를 위한 난수 | 성공 확률 | 성공 시 누적 효과 |
|---|---|---:|---:|
| **미보유 → Lv.1** | 최초 획득 확정 | **100%** | 해당 특성 +1 |
| **Lv.1 → Lv.2** | Python 1~100 | **80%** | +2 |
| **Lv.2 → Lv.3** | Python 1~100 | **50%** | +3 |
| **Lv.3 → Lv.4** | Python 1~100 | **25%** | +4 |
| **Lv.4 → Lv.5** | Python 1~100 | **10%** | +5 |

- 실제 해당 성장 후보를 **드래프트에서 선택한 후** Python으로 한 번 굴린다. 결과가 성공 범위에 들면 즉시 다음 단계 +1, 아니면 기존 단계 유지. **단계 건너뛰기 없음**.
- **강화 실패 시 단계 하락 없음, 보상은 반드시 소모**. 대체 카드 지급, 재추첨, 무료 재도전, 실패 누적 확률 보정 없음. 다음 도전에는 실제 새 종결 보상이 필요하다.
- 성장 강화의 Python 난수는 **PC가 직접 굴리는 CoC d100**과 별개다.
- **성장 적용 시점 [확정]**: 영구 플레이어 UUID와 새 PC identity를 **연결하는 순간**, 그때까지 소유한 성장 레벨(+0~+5)을 해당 PC의 8대 기본 특성에 반영하고 스냅샷으로 고정한다. 같은 PC의 재연결 시 이전 스냅샷을 유지하고 추후 성장 보상을 소급 적용하지 않으며, 다음 새 PC 연결 때 최신 성장을 반영한다. 파생값은 성장 반영된 기본 특성으로 현행 캐릭터 생성 규칙에 따라 산출한다.

## 9. 자산 카드 최신 채택 목록 [33종 확정: 기본 9 + 해금 24]

2. **맹렬한 일격 / 가챠 희귀 / 공격 / 어려운 성공**

   - **조건**: 실제로 막을 수 있는 통로·좁은 접근 지점에서 다수에게 닿을 위협을 저지.
   - **효과**: 성공한 방어를 통해 **위협의 접근을 물리적으로 막고, 원래 위협이 가로막던 통로/퇴로를 여러 사람이 실제 이용할 수 있는 상태**로 만든다.
   - **한계**: 장소 폭·적의 힘·거리·차폐 성능·행동 선택 등 세계의 실제 제약 적용. 무조건적인 집단 탈출/무적 아님.

### 10-3. 무법자 Rogue [5장 / 1차 채택]

   - **효과**: 그들에게 **같은 잘못된 방향으로 주의를 돌리도록 하는 유효한 기만 성과**를 얻고, 실제 비워진 동선/감시 범위를 이용할 수 있다.

### 10-4. 기회주의자 Wildcard [5장 / 위험·보상 3차안 채택]

**참고한 원작 감각**: Double or Nothing(큰 위험·큰 효과), High Roller(자원 걸기), Watch This!(배당), All In(큰 성공 보상), 21 or Bust(멈춤/승부의 선택). **이 클래스 자체는 원작 공식 클래스가 아니다.**

**기회주의자 공통 약속**
- 장착만으로 손해를 추가하지 않는다. **판정 전 플레이어가 도박 참여 여부와 실제 판돈·위험한 방법을 선택**해야 한다.
- **강화 요구치 달성**: 본래 결과 + 명시된 보상. **일반 행동만 성공**: 본래 성공 유지, 특수 보상 없음, 이미 건 판돈은 손실. **본래 행동도 실패**: 정상 실패 + 실제 건 판돈 손실.
- 물건·현금·HP·엄폐/경로처럼 실제 상태가 변해야 하며, 원래 세계에 없는 피해/자원/물품은 만들지 않는다. 자동 성공/실패의 복제, 강행 재굴림 대체 금지.

1. **아슬아슬한 한 수 / 기본 희귀 / 회피·도주 / 어려운 성공**
   - **조건**: 감시·공격·추적을 피해 도주할 때 안전한 엄폐/퇴로를 버리고 실제 노출 위험이 있는 경로를 선택.
   - **판돈**: **보유 중인 안전한 위치 또는 퇴로**를 포기.
   - **성공 보상**: 원래 회피·도주에 성공하고 **실제로 닿는 엄폐 위치를 확보하거나 추적자의 현재 접근 경로 하나를 물리적으로 끊음**.
   - **미달 대가**: 보통 성공이면 이탈은 성공하되 포기한 엄폐/퇴로는 사라짐; 기본 실패면 노출된 위치에서 실제 추적·공격 대응에 직면. 단, 자동 피격/추가 HP 강제 손실 아님.
2. **승리의 배당 / 가챠 희귀 / 돈·협상 / 어려운 성공**
   - **조건**: 상대방이 실제로 판돈 및 배당을 제시/동의한 금전·물품 내기나 거래.
   - **판돈**: 실제 소유 현금 또는 물건 하나. 상대의 지급 가능한 배당 사전 확정.
   - **성공 보상**: 원래 거래의 효과 외에 **자기 판돈을 지키고 최대 자기 판돈의 2배 가치인 상대 합의 배당**을 획득.
   - **미달 대가**: 본래 거래 자체의 성패는 기존대로 유지하되, **건 현금/물품은 상대에게 넘어감**.
   - **한계**: 상대 동의·재산·지급능력을 강제로 만들지 않는다. 실제 배당이 더 적게 합의됐다면 그 액수만 받음.
3. **몸으로 밀어붙인다 / 가챠 희귀 / 공격·위험 / 어려운 성공**
   - **조건**: 근접 공격/육체적 돌파에서 실제 부상 위험이 있는 방법으로 안전한 자세·보호를 포기.
   - **판돈**: 물리적 접촉·충돌로 발생 가능한 **HP 1의 부상 위험**.
   - **성공 보상**: 실제 명중/유효한 돌파라면 **공격 피해 +2** 또는 같은 방향의 **두 번째 물리적 장애물까지 연속 돌파**.
   - **미달 대가**: **실제로 미리 정한 위험 접촉이 성립하면 HP 1 손실**, 그리고 원래 행동의 성패·적 대응을 정상 처리.
   - **한계**: 허공에서 자동 HP 감소 만들지 않음; 전투 피해와 중복 적용/방호는 정식 규칙과 조화 필요.
4. **모든 것을 건 순간 / 가챠 영웅 / 실제 물건·판정 / 캠페인 1회 특수 보너스**
   - **조건**: 장비/소모품을 무리하게 사용하면 중요한 행동의 성공 가능성을 높일 수 있는 실제 상황.
   - **판돈**: **무리한 사용으로 소모·파손될 수 있는 소유 실물 하나**를 판정 전에 지정.
   - **효과**: 해당 강화 카드당 캠페인 전체 1회 특수 보너스 주사위 1개. **낮은 값**은 본 행동; **높은 값**도 어려운 성공이면 본래 행동 성공 + **건 물건의 기능 보존**.
   - **강화 미달**: 낮은 값으로 행동 성공 가능하지만 **건 물건은 사전 합의한 실제 방식으로 소모·파손**. 기본 실패라면 행동 실패 및 물건 소실.
   - **한계**: 실제로 물건을 걸지 않으면 사용 불가. 보너스 없는 물건 소모를 강제하지 않는다.
5. **모 아니면 도 / 가챠 전설 / 실제 물건·공격·도주·돌파 / 극단적 성공**
   - **조건**: 실제 동일한 작용/인과로 복수의 목표에 영향을 줄 수 있는 중대한 행동.
   - **판돈**: 플레이어가 실제로 갖고 쓰고 있는 **중요 장비·물리적 수단 하나**를 잃을 수 있는 위험한 방법 선택.
   - **성공 보상**: **원래 목표 + 실제로 연결된 추가 물리적 목표 두 가지 달성**, 걸었던 수단 **보존**.
   - **미달 대가**: 일반 행동 성공이면 원래 목표 하나만 달성, **건 수단 상실**. 기본 실패면 기본 행동 실패 + **건 수단 상실**.
   - **한계**: 추가 목표는 판정 전에 실제로 가능하고 같은 인과에 연결된 것으로 정한다. 독립 판정 세 개/상대 방어를 임의 자동 성공 처리하지 않는다.

### 10-5. 생존자 Survivor [5장 / 전설 교체안 채택]

**참고한 원작 감각**: Look what I found!(실패 활용), Scavenging·Resourceful(재활용), Survival Instinct(탈출), Act of Desperation·Eucatastrophe(마지막 역전), Devil's Luck(치명 위협에서의 생존).

1. **헛수고는 아니야! / 기본 희귀 / 수색·실패 활용 / 근소 실패**
   - **조건**: 실제 물품·재료 수색/회수 판정에서 **보통 성공 기준으로부터 10포인트 이내의 실패**.
   - **자동 효과**: 찾던 대상 확보는 **실패 그대로**. 같은 수색 범위에 **실제로 존재하고 직접 확인 가능한 별도의 유용한 물건·부품 하나를 발견**.
   - **한계**: 대상/부산물이 없으면 발동할 실물 없음. 원래 찾던 아이템을 성공 처리하거나 허공에서 새 물품 창조 금지.
2. **부러졌다고 끝이냐? / 가챠 희귀 / 물건·수리·재활용 / 어려운 성공**
   - **조건**: 실제 남은 부품으로 고장 장비를 임시 작동시키는 수리·개조 판정.
   - **효과**: 당장의 임시 작동에 더해 **같은 기능을 추가로 1회 실제 사용할 수 있는 상태**로 남김.
   - **한계**: 연료·전력·핵심 부품이 없거나 기계 구조상 불가능하면 적용 불가. 횟수 없는 작업의 효과는 정식 적용 때 검토.
3. **넘어져서 살았다 / 가챠 희귀 / 회피·HP·실패 활용 / 근소 실패**
   - **조건**: 실제 충격/물리적 공격의 회피 판정에서 **보통 성공 기준으로부터 10포인트 이내 실패**, 실제로 넘어지거나 몸을 낮춰 충격 일부를 흘릴 가능성이 있을 때.
   - **자동 효과**: 원래 회피는 **실패 그대로** 두되 **해당 HP 피해 2점 경감**(최소 0).
   - **한계**: 실제 일부 분산 불가능한 질식/독성/폭발의 해당 부분에는 적용하지 않는다. 원래 성공·예방 판정을 소급 변경하지 않음.
4. **아직 움직일 수 있어 / 가챠 영웅 / 부상·도주 / 캠페인 1회 특수 보너스**
   - **조건**: **의식이 있고 HP가 최대치의 절반 이하**일 때 눈앞의 물리적 위험에서 돌파·이탈을 선언.
   - **사용**: 판정 전 특수 보너스 주사위 1개. 낮은 값으로 본 행동, 높은 값도 어려운 성공이면 추가 강화 성공.
   - **추가 효과**: 본래 이탈에 성공하면서 **동일 움직임의 실제 경로에 있는 두 번째 물리적 방해 하나도 벗어남**.
   - **한계**: 별개 공격/대항 자동 성공 없음, HP 회복 아님. 기존 부상 제약 유지.
5. **다 끝난 줄 알았지? / 가챠 전설 / 개인 생존·치명상 / 캠페인 1회 자동**
   - **조건**: 실제 한 번의 **물리적 공격/사고**로 현재 HP가 **0 이하가 될 만큼** 치명적인 피해를 받게 되는 순간, **세계의 물리 조건상 살아남을 가능성**이 있을 때.
   - **자동 효과**: 해당 피해를 **HP 1이 남는 수준으로 경감**한다. **별도 선언이나 추가 d100 없음. 캠페인 전체에서 한 번만 발동**.
   - **한계**: 본래 부상·중상·출혈·의식 상태 등은 담당 규칙의 허용 범위에서 실제 반영. 이미 확정된 사망 소급 취소, 다음 공격 자동 방어, 현장 탈출, 물리적으로 생존 불가능한 완전 파괴/장시간 질식 등 불가. 정식 통합 전에 HP·사망 처리 순서 대조 필수.
   - **변경 기록**: 기존 초안의 '부서진 문짝으로 위협 차단' 전설 효과는 폐기하고, 사용자가 채택한 **개인 생존/HP 1 효과**로 교체.

### 10-6. 중립 Neutral [8장 / 1차 채택]

**참고한 원작 감각**: Unexpected Courage(범용), Overpower·Manual Dexterity(성공 시 실익), Emergency Cache(자원), Fine Clothes(교섭), Backpack(물품). **중립은 전체 일반 등급**이며, 클래스 전용 카드에 비해 작은 범용 혜택 중심.

**기본 일반 강화 4장**
1. **손에 잡히는 대로 / 기본 일반 / 임시 무기·공격 / 어려운 성공** — 실제 주변 생활용품이나 임시 도구를 무기로 사용한 근접 공격에서 **추가 피해 +1**. 정식 무기에는 적용하지 않는다. 실제 도구의 파손·대상 방호 적용.
2. **충격을 흘린다 / 기본 일반 / 방어·HP / 어려운 성공** — 실제 충돌·물리 공격을 막거나 피하는 판정에서 어려운 성공을 거두었음에도 일부 피해가 남는다면 **남은 HP 피해 1점 경감**(최소 0). 이미 피해가 없거나 독성/질식 등 단순 충격 분산 불가능한 피해에는 적용 안 함.
3. **온전하게 건진다 / 기본 일반 / 물건·회수 / 어려운 성공** — 손상 위험이 있는 실물을 꺼내거나 회수할 때, 본래 회수 성공에 더해 **회수물의 사용 가능한 부분 하나를 추가 손상 없이 보존**. 기존 파손 복구·없던 부품 생성 아님.
4. **값을 깎는 요령 / 기본 일반 / 협상·돈 / 어려운 성공** — 실제 흥정 가능한 구매 거래에서 **기존 합의 가능한 가격에서 추가 10% 할인**. 고정가·상대가 가격 권한 없음·합의 불가 상황에는 강제 할인 없음.

**해금 일반 강화 4장**
5. **손에 익은 응급처치 / 가챠 일반 / 치료·HP / 어려운 성공** — 실제 의료 도구·재료를 사용해 회복 가능한 부상을 치료하며 기존 치료 성공으로 회복되는 HP에 **+1 HP 추가**(최대 HP 이내). 같은 부상에 무한 반복 적용 불가; 원래 치료할 수 없는 치명상 자동 회복 아님. 기존 치료 규칙과 최종 대조 필요.
6. **문은 닫고 간다 / 가챠 일반 / 도주·방어 / 어려운 성공** — 추적을 피해 실제 출입구를 통과하는 도주 판정 성공 시 **같은 움직임으로 닿는 문/차단문을 뒤에서 닫고 실제 손에 닿는 잠금/걸쇠가 있으면 잠금**. 문의 물리적 무게/구조 적용, 닫힌 문은 적이 다시 열거나 파괴할 수 있음.
7. **여분을 남긴다 / 가챠 일반 / 물건·소모품 / 어려운 성공** — 재료·소모품을 나누어 쓰는 실제 작업에서 같은 정상 작업 결과를 유지하며 **소모품 1단위 절약**. 최소 필수 약물 용량, 탄환 1발, 이미 소모된 연료처럼 줄일 수 없는 것은 절약 불가.
8. **비상금 / 가챠 일반 / 돈·캠페인 시작 / 판정 없음** — 해당 캠페인 시작 시 초기 현금 산출값에 **+10% 현금**을 지급. 실제 세계의 통용 화폐와 출처에 맞춤. 현금이 없는 원작 세계에서는 임의로 물건을 만들어 대체하지 않는다.

### 10-7. 초안 채택과 남은 검토의 경계

- **33종의 이름·조건·추가 성과 방향은 초기안으로 채택**. 클래스별 원작 감각과 실제 게임 인과를 유지하되, 세부 밸런스·담당 룰북 충돌은 정식 도입 전 별도 검토한다.
- **시간을 카드 자원/보상/판돈으로 쓰는 이전 표현 모두 폐기**. 일부 카드의 '위치 확보·엄폐·차단'은 시간을 주는 것이 아니라 **물리적 위치와 접근 상태의 변화**다.
- 높은 판정 기준이 원래 판정의 요구 난이도를 떨어뜨리거나 기존 명중·부상·대항 결과를 취소하는 구조는 아니다.
- 생존자 두 근소 실패 카드의 '10포인트 이내', 기회주의자 '+2 피해 및 HP1 위험', 중립 치료 '+1 HP' 등은 **초기 승인 수치**이며 룰북 본문과의 정합성/밸런스 검증은 아직 안 됐다.

## 11. 아직 확정하지 않은 세부 사항 [미정]

1. [확정/구현] **후보 풀 소진**: 해당 후보 null, 모두 소진이면 보상 0개로 종료. 다른 풀 대체·과거 보상 소급 없음.
2. [확정] **일반 보너스와 강화 특수 보너스 동시 사용 금지**. 혼합 계산 없음. 기존 패널티는 기존 판정 규칙 따름.
3. [확정/통합 대조 예정] **플레이어 ID와 신규 PC 연결 순간 성장 적용**. 연결 당시 스냅샷만 해당 PC에 사용; 파생값은 현행 PC 생성 규칙으로 산출. 실제 PC 생성 절차 통합 검증 필요.
4. 초기 채택된 강화 33장의 **밸런스·기존 피해/치료/HP/대항 규칙과의 충돌·동시 적용·현장 인과 해석** 검증. 특히 생존자 전설 HP 1 처리와 중립 응급처치.
5. 자산 33종의 **원작별 구체 실물 사양·내용물·시작 수량·소지 슬롯·동행 동물의 훈련/행동 조건**. 새 무게·하중 수치나 독립 운반 계산 규칙은 도입하지 않음. 자산 카드는 현행 룰북에 미적용.
6. [백엔드 구현 완료/게임 연동 점검 중] Supabase `trpg-state-v2`의 비공개 `trpg_cards`에 **영구 UUID·닉네임·카드 66종·소유·성장·캠페인·PC 연결·장착·드래프트 저장을 구현**. 닉네임은 신원 인증이 아닌 조회 키. 승인된 GM 연결과 Python RNG로 운영. [운영 계약](CARD_SYSTEM_RUNTIME.md).
7. [확정/구현] 카드 풀 부분 소진도 해당 슬롯 null, 전체 소진 보상 소멸. 새 카드 업데이트는 이후 보상에만 적용. `issue_draft`가 미보유 풀로 후보 유효성 검증.
