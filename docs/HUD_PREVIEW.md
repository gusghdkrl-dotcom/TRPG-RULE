# 현행 행동 선택·HUD 예시

아래는 가상 수치의 서식 예시이며 특정 캠페인의 정본이 아니다. 실제 버튼/패널 UI가 지원되면 동일한 번호·라벨·정보 구조로 우선 사용한다. 크기 지정 지원 시 HUD 본문 18px·자원 24px를 기준으로 구분한다. 아래는 Markdown 대체 예시로 HUD는3/4단계 제목을 쓴다. 고정 아이콘·자원 구역·메인/파우치 분리를 유지하며 실제 크기·테두리는 클라이언트에 따른다.

### 🎯 행동 선택

**[1] 🚪 배수문 — 열쇠로 문을 열어 본다.**

**[2] 🔦 통로 — 안쪽의 수위와 장애물을 살핀다.**

번호 또는 원하는 행동·대사를 직접 입력할 수 있습니다.

상태효과는 이 가상 세계에서 이미 확정된 것으로 가정했다. 모든 젖음의 공통 벌점 규칙이 아니다. 위 예시의 판정 전Luck은33이며 체크 동의 뒤4소모했다. 실제일반응답은 인벤토리목록/점유량을유지하며현금은거래/변경/요청시에표시한다. 별도씬요약·연출의도·생활버프·고정4번자유행동안내는없다. 완료한공개대항은 실제상대값도1~2줄내표시하고비공개판정은누출하지않는다.

키퍼 원칙·숙지 문구·준수 보고는 게임 응답에 반복 출력하지 않는다. 원작 체험·세계 반응·페이싱·규칙 적용은 프로젝트 지침 본문에서 유지한다. 이 문서의 구분선과 예시 설명은 실제 HUD의 일부가 아니다.
