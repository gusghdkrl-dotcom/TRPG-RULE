# 현행 행동 선택·바텀 HUD 예시 (요약형 2열)

실제 게임 출력의 정본은 [BOTTOM_HUD_CONTRACT](../rules/06-play.md#bottom_hud_contract)다. 이 문서는 가상 상태를 사용한 UI 참고이며, 실제 PC/캠페인/비밀 정본 또는 새로운 카드·회복 효과를 부여하지 않는다. 실제 지원되는 한 장의 둥근 상태 카드·3열 HP/SAN/Luck 자원 행·그 아래 **동일 너비 2열, 각 열 내용 중앙 정렬**을 우선한다. 좌우 여백·열 간격·행 간격은 충분히 둔다. 중앙 배치선은 출력하지 않는다.

## 행동 선택
- 사용 가능한 경우 가로 전체 너비의 세로 알약형 버튼을 사용하고, 클릭/동작 지원이 없다면 번호와 행동 intent를 독립된 문단으로 제공한다.
- 자유 선언은 동등하게 유지하며 실제 선택을 대신하지 않는다.

## 바텀 HUD 배치 — 게임용 그리드 기준

**P1 · 가상 조사자**　　🎬 18턴

🔵 수호자 · 현장 수사관　👥 P2, 토머스

| ❤️ HP | 🧠 SAN | 🍀 Luck |
|:---:|:---:|:---:|
| **7/10** | **60/64** | **27** |

| **왼쪽 열 (50%) · 중앙 정렬** | **오른쪽 열 (50%) · 중앙 정렬** |
|:---:|:---:|
| **🌍 환경** | **✦ 상태·효과** |
| 🕒 4/12 · 20:35 | 🟢 방한 · 20분 남음 (가상 지속 효과) |
| 📍 등대 오두막 | 🔴 발목 부상 · 달리기 불리 (가상 상태) |
| 🌧️ 비·강풍 · 외부 최근 관측 | 위험한 긴급 대응이 도달할 때만 🔴 긴급 표시 |
| 💵 $18.50 | 상태 없는 경우 ‘없음’ |
| **⚔️ 장착 장비** | **🎒 소지품** |
| 오른손 · 랜턴 | **메인 4/5** |
| 왼손 · 차폐구 | 랜턴 · 차폐구 · 외투 · 권총 |
| 착용 · 방수 외투 | **파우치 1/3** |
| 빠른 접근 · 권총 4/6발 | 붕대 ×2 |
|  | 🔑 배수문 열쇠 |
| **🃏 장착 카드 ①·③** | **🃏 장착 카드 ②·④** |
| ① 🛡️ 호위용 차폐구 | ② 🛡️ 내가 막는다 |
| 엄폐·호위 · 자산 실물 | 동료 보호 · 어려운 성공 |
| ③ 🔦 휴대 광원 | ④ ⚔️ 선두에 서다 |
| 조명·빛 신호 · 자산 실물 | 전투 저지 · 특수 보너스 · 어려운 성공 / 1회 가능 |

*표는 이 문서에서만 두 열을 설명하는 용도다. 실제 게임은 표 셀보다 **지원되는 패널/그리드 UI**를 사용한다. 환경↔상태, 장착↔소지품, 카드①③↔②④의 구역별 간격은 유지하고 각 항목마다 중첩 테두리를 만들지 않는다. 좁은 화면에서는 단일 열로 자연스럽게 내려놓는다.*

### 매 장면 달라지는 것
- 수치 변화량은 그 결과가 적용된 응답에만: 예시 `❤️ 7/10 (-3)`, `🧠 60/64 (+2)`. 실제로 변경된 수치만 표시.
- 부상·광기·진행성 위해/위급 상황은 해당 PC가 실제 맞닥뜨렸을 때만 빨간색. 유효한 지속 버프는 초록색, 유효 종료 시각/조건이 있을 때만 부기.
- 실제 식사/수면/휴식으로 확정된 효과만 표시한다. **휴식에 의한 1회 SAN 회복은 지속 버프가 아니다.** 단순 식사만으로 공통 강화 효과를 만들지 않는다.
- 장비명 옆에 남은 탄약·의료품·연료/전지·파손 등 확인된 상태만 짧게 표시. 장착과 소지의 중복 표기는 실물 복제를 의미하지 않으며 실제 메인/파우치 점유를 유지.
- 강화 카드에는 사용/발동 상황·정확한 요구 성공 단계·명시적 1회 한도 여부를 축약하고, 자산에는 없는 판정 단계를 부여하지 않는다. 전체 카드 효과는 09-cards 원문을 따른다. 카드 OFF이면 카드 영역 전체를 생략.
- 공개 판정 완료값은 HUD 끝에 1~2줄만 요약한다. 상대의 미실시/비공개 값은 발명하거나 누출하지 않는다.
- 실제 UI 미지원 시 읽기 쉬운 Markdown 상태 카드로 대체한다. 클릭 가능한 척하는 HTML/CSS/가짜 링크는 만들지 않는다. 저장 검증 없이 저장 완료를 표시하지 않는다.
