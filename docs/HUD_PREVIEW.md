# 채팅 HUD 미리보기

모두 임의로 만든 표시 예시이며 실제 캠페인·저장 상태가 아니다. 게임에서는 현재 PC의 확인된 공개 값만 사용한다. 출력 정본은 [HUD_VISUAL_STYLE](../rules/06-play.md#hud_visual_style)이다. 시각·위치·현금·상태와 가방 분류는 각각 빈 줄로 분리한 독립 문단이다. 값이 짧아도 합치지 않으며 단일 개행에 의존하지 않는다. 색상·폰트·표 너비는 채팅 앱의 렌더러에 따라 달라진다.

## HUD 맨 마지막 실제 판정 내역

아래는 서로 다른 가상 판정의 표시 예시다. 실제 캠페인 기록/Python 실행이 아니다. 게임에서는 하나의 응답 전체 판정 표시를 1~2줄 일반 텍스트로 제한하고 표·제목·항목별 목록·빈 셀·각주·자동 해설을 붙이지 않는다. 씬 연출 의도는 기존대로 판정 뒤 한 문장이다.

고정 목표치 예시:

🎲 판정: 보통≤60(기계수리60) · PC 24·어려운 성공 / 내부 미실시 → 성공.

대항 예시:

🎲 판정: PC 설득60 대 상대 POW50 · PC 32·보통 / Python 41·보통 → 동단계·기능 우위로 PC 승리.

보너스 원값을 구분하는 별도 가상 사례:

🎲 판정: 보통≤70 · PC 보너스1·99/98→99·실패 / 내부 미실시 → 실패.

필요한 자원 변화만 둘째 줄에 붙이는 예시:

🎲 판정: 보통≤45 · PC 54→45·보통 / 내부 미실시 → 성공.
🍀 행운 −9 · 잔여44.

대기/누락은 같은 줄의 해당 값에 `입력 대기`/`실행 대기`/`확인 불가`라고 적고 실제 미실시와 구분한다. 내부 피해라면 실제 식/원값/합계를 짧게 담는다. 무변화 HP/SAN·행운 미사용·펌블 아님·쌍방 실패 규칙 해설을 자동으로 덧붙이지 않는다. 원래 raw·후보·기준·적용 여부는 기존 판정 상태에 보존한다. 상세 요청이 있을 때만 별도로 펼친다.
