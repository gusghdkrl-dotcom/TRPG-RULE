# 현행 행동 선택·HUD 예시

사용자가 승인한 화면을 다음 공통 서식으로 고정한다. 아래 값/물품은 기존 개발용 가상 예시이며 실제 캠페인의 시트·사진·비공개 정본은 포함하지 않는다. 게임 담당은06-play이며 이 문서를 별도 게임 소스로 등록하지 않는다.

- 선택: `🎯 행동 선택` 아래 전체 너비·얇은 회색선·알약형 둥근 버튼을 한 열로 세로 배치. 아이콘/라벨은 보라색·가운데 정렬, 간격 일정. 라벨은 `아이콘 번호 · 대상 — 할 일`. 성립하는 선택만 표시하며5개 고정이나 자리 채우기를 하지 않는다. 마지막에 자유 입력 안내 한 번.
- 상태: 구분선 뒤 단일 둥근 카드, 얇은 회색선·대화 폭·충분한 안쪽 여백. 어두운 테마는 어두운 카드. 맨 위 PC슬롯/이름, 다음 줄 직업·Scene Turn. HP/SAN/Luck은 같은 너비3열, 아이콘/라벨 위·굵은 실제 수치 아래.
- 상세: 시각→위치→현금→존재하는 상태→구분선→메인→파우치→실제 중요 물품→필요한 차량/특수장비→있는 공개 판정1~2줄. 현금은 상시이며 미지급 대금은 잔액과 구분. 물품의 실제 소지 위치/수량/점유량을 보존.
- 실제 지원되는 버튼/패널·스타일만 사용한다. 글자 크기 지정이 가능하면 HUD 본문18px/자원24px. 미지원 시 같은 라벨·순서·분류의 아래 Markdown 대체를 사용하며 가짜 HTML/클릭 링크·지원되지 않는 숨김/폰트 제어는 만들지 않는다. 좁은 화면에서는 긴 글을 줄바꿈하고 자원을 독립 행으로 배치할 수 있다.

아래는 Markdown 대체 예시다. 실제 카드 UI가 지원되는 경우 아래 상태 전체를 하나의 카드 안에 넣는다. 예시 뒤 개발 설명은 게임 응답에 복사하지 않는다.

### 🎯 행동 선택

**🚪 1 · 배수문 — 열쇠로 문을 열어 본다.**

**🔦 2 · 통로 — 안쪽의 수위와 장애물을 살핀다.**

번호를 선택하거나 원하는 행동과 대사를 자유롭게 입력할 수 있습니다.

---

### 👤 P1 · 가상 조사자

#### 시설 점검원 · 🎬 Scene Turn 18

### ❤️ HP **10/12** · 🧠 SAN **41/60** · 🍀 Luck **29**

#### 🕒 **시각** · 저녁 무렵

#### 📍 **위치** · 발전소 서쪽 통로

#### 💵 **현금** · $24 · 작업비 $12 미지급

#### 🩹 **상태** · 젖은 외투 — 현재 방한 효과 약화, 건조/교체 필요

---

#### 🎒 **메인 2/5** · 손전등 · 구급상자

#### 👝 **파우치 1/3** · 건전지 2개

#### 🔑 **중요 물품** · 배수문 열쇠(0칸)

#### 🎲 보통≤60 · PC64 실패→행운4 사용·잔여29·Regular 성공.

---

상태효과는 이 가상 세계에서 이미 확정된 것으로 가정했다. 모든 젖음의 공통 벌점 규칙이 아니다. 위 예시의 판정 전Luck은33이며 체크 동의 뒤4소모했다. 현금24와 미지급12는 별개이며 소지금36으로 합산하지 않는다. 실제 일반 응답은 현금과 인벤토리 목록/점유량을 유지한다. 별도 씬요약·연출의도·생활버프·고정4번 자유행동 안내는 없다. 완료한 공개 대항은 실제 상대값도1~2줄 내 표시하고 비공개 판정은 누출하지 않는다.

저장 알림은 실제 저장/검증 경계가 있을 때만 카드 밖 아래 한 줄로 표시한다. 이 예시는 실제 저장을 실행한 기록이 아니므로 저장 성공 표시는 없다. 과거의 성공을 현재 저장처럼 표시하거나 서식을 채우기 위해 저장 도구를 호출하지 않는다. 차량/특수장비·직업품/중요 물품은 실제 존재·소지/점유를 보존하고 예시 물품/부재 안내를 강제하지 않는다.

키퍼 원칙·숙지 문구·준수 보고는 게임 응답에 반복 출력하지 않는다. 원작 체험·세계 반응·페이싱·규칙 적용은 프로젝트 지침 본문에서 유지한다. 예시 뒤 개발 설명은 실제 HUD의 일부가 아니다.
