# 현행 행동 선택·바텀 HUD 예시

실행 정본은 [GUIDED_ACTION_RETURN](../rules/06-play.md#guided_action_return)·[BOTTOM_HUD_CONTRACT](../rules/06-play.md#bottom_hud_contract)다. 아래는 **실제 캠페인과 무관한 가상 예시**이며 수치·지명·효과/자산을 고정하거나 지급하지 않는다. 이미지와 같은 순서의 실제 패널 UI를 우선하고, 지원하지 않으면 같은 정보/행 순서의 Markdown으로 대체한다.

## 🎯 행동 선택 · P2 가상 조사자

비바람 속 오두막에 있다. 동료가 밖을 살피는 동안 현재 관측 가능한 선택을 한다.

1. 🔦 오두막 입구 — 문밖의 발자국을 살핀다
2. 🧥 실내 — 젖은 외투를 말리며 숨을 고른다
3. 🗣️ 동료 — 다음 이동 경로를 상의한다

번호를 선택하거나 원하는 행동과 대사를 자유롭게 입력할 수 있습니다.

일반 선택지는 **세로 한 열, 정확히 3개**, 가능한 실제 행동만 제시한다. 입력을 하나만 요구하는 본부 첫 출입·열린 판정/전투/반응 등 전용 게이트에는 3개를 억지로 붙이지 않는다. 버튼을 지원하면 둥근 테두리 알약형 3개를 쓰고, 미지원 시 독립 문단·번호로 대체하며 가짜 HTML/링크 버튼은 만들지 않는다. 자유 선언은 동등하다.

HUD는 구분선 아래 **한 카드**이며 상단 정보/HP·SAN·Luck → 목표·현재 상황 → 구분선 → 위치/시각/날씨·동행/현금·장착/메인/파우치 → 구분선 → 실제 상태/위험 순이다. 조건부 이번 판정·이번 변화·검증된 저장 알림은 관련 이벤트가 있을 때만 아래에 덧붙인다. **수치·시간·PC·목표·실물명/수량·날씨·위험은 정본에 따라 모두 가변**이다.

장착 실물은 가방 점유에 포함하며 장착/소지 표시는 같은 물건이다. 총 칸을 두 번 더하지 않는다. 상시 카드 4슬롯은 표시하지 않는다. 판정 전 카드 선택과 발동 안내·명시적 카드 상세 열람은 유지한다. 변화량은 해당 결과 응답에 한 번만, 부정 변화 빨강/긍정 변화 초록을 사용한다. 비공개 E/S ID·다른 PC 지식·저장 미검증 성공을 HUD에 넣지 않는다.
