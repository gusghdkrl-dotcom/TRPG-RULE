# 현행 행동 선택·바텀 HUD 예시

실행 정본은 [BOTTOM_HUD_CONTRACT](../rules/06-play.md#bottom_hud_contract)다. 아래는 가상 예시이며 실제 효과/자산을 추가하지 않는다. 지원되는 패널 UI를 우선하고, 미지원이면 같은 정보·순서의 Markdown으로 대체한다.
