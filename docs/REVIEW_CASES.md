2026-11-09. 현행 담당 본문과 합의의 문서 대조다. 실제 ChatGPT 게임 실행/운영 저장 결과가 아니다. 자동 검사와 실제 이어쓰기 평가는 구분한다. 구판 검토 이력은 Git 기록에 보존되어 있다.

## 인스트럭션의 적용 조건·우선순위

| 상황 | 수용할 결과 / 거부할 결과 | 담당 |
|---|---|---|
| 연출 목표가 PC 선택/성과/비공개 사실과 충돌 | 최우선 기준의 주도권·공개·확정 사실 보호→담당 조건/예외 순서 적용. 재미/속도를 이유로 상위 기준 취소는 거부 | 지침: 최우선 기준 |

기능 보존 대조: 직전 지침의 역할은 서두, 주도권/공개/규칙 우선순위는 최우선 기준, 세계/시나리오/원작은 설계 절, 사건/생존은 진행 절, NPC/말투/추리 판단 보호는 인물 절로 연결했다. 묘사/공포/문장 호흡/유머는 서술 절, 압축/새 선택/교대는 장면 절, 축적/종결/재현 맥락은 연속성·종결 절, 상황별 조회는 진행 순서와 9개 파일 라우팅으로 이어진다. 반복 상기 블록은 삭제하고 원작 체험·세계 반응·호흡·규칙 적용은 각 상시 본문에 유지한다. 주도권/연속성 본문과 필요한 UI 정보도 보존한다. 이는 문서 대조이며 실제 플레이 준수율의 검증은 아니다.
