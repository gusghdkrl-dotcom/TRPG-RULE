# 시간요원 본부 — 운영 DB 설치 기록 및 통합판 관리
2026-11-13 KST 기준 · 현재 운영 대상 `trpg-state-v2`.

## 현재 확인된 사실

- **운영 DB 설치 완료:** 기존 Supabase 운영 프로젝트 `taoaffdyssqtnjszumpq`에 본부 전용 마이그레이션 **21개**를 순서대로 적용. 전체 마이그레이션은 기존 9개 + 신규 21개 = **30개**. DEV의 기본 DB 초기화 5개와 카드 bootstrap은 **적용하지 않음**.
- **백업 생략:** 사용자가 이번 작업에 대해 명시적으로 독립 백업 생략을 요청함. 따라서 독립 백업 파일도 격리 복원 시험도 **없음**. 운영 복구 가능성이 검증됐다고 말해서는 안 된다.
- **구조 감사:** 본부 테이블 **20**, 함수 **43**, NPC 서비스 **8**. 테이블 RLS 미적용 **0**, `anon` 및 `authenticated` 본부 함수 실행 권한 **0**.
- **기존 게임 데이터 불변:** 설치 직전/직후 `hq_readonly_preflight.sql`의 **12개 보호 테이블** 행 수와 내용 지문이 모두 일치. 세이브 **3건**, 비공개 정본 **9건**, 복구 아카이브 **38건**, 카드 카탈로그 **66장** 유지. 기존 카드·저장·정본 함수 **25개**와 정본 불변성 트리거 유지. 지문값/원문은 공개 저장소에 기록하지 않음.
- **실제 운영 SQL 함수 시험:** `BEGIN…ROLLBACK` 내부에서 신규 요원 입단, 중복 입단 요청의 멱등 처리, 첫 입단 경로, NPC 서비스 8개 로드, 입단 이벤트와 후속 경로, 중복 입단 거절을 시험. 종료 후 테스트 계정/팀/입단 기록 **0건**. **실제 ChatGPT 원작 플레이의 종결·보상 전체 연동은 아직 미검증**.
- **보안 어드바이저:** 본부 테이블 20개의 RLS 정책 없음은 비공개 Keeper 접근 구조에 따른 정보 안내. 공용 `public.card_*`의 익명 SECURITY DEFINER 실행 경고 8개는 **기존 이슈**로 별도 추적. 본부 EXECUTE 권한을 익명으로 열지 않음.

## 운영 안전 경계

일반 플레이의 정본·카드·세이브 데이터를 덮어쓰지 말 것. HQ ON의 입단/기억/보상은 실제 운영 DB의 성공 응답을 검증한 뒤만 확정할 것. PC의 행동·발언·기억을 검증용 SQL로 실제 저장하지 말 것.

백업 생략은 이번 운영 설치 시점의 사용자 선택이다. 향후 파괴적인 수정이나 데이터 정리까지 자동 승인받은 것으로 해석하지 말 것. **향후 정리 전 독립 백업과 복원 확인이 필요**할 수 있다.

## 아직 확보되지 않은 증거

실제 ChatGPT에서 일반 게임 OFF의 처음부터 종결까지, 본부 ON의 첫 입단부터 현지 대사건·검증 종결·귀환·마틴 평가·클라라/도미닉 보상·새 대화 복구까지 **플레이어 주도 실제 전 과정**을 실행한 검증 기록은 없음. 데이터베이스 스모크 시험과 정적 CI 테스트를 그 대신이라고 주장하지 말 것.
