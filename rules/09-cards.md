# 정식 영구 카드 규칙 — 자산·강화·성장

키퍼가 장착한 카드의 효과를 처리할 때 쓰는 **정식 카드 룰북**이다. 개별 카드명·발동 조건·수치·한계는 이 본문을 따른다. 카드 외 기존 판정·치료·공격·부상·대항은 02-checks/03-danger, 소지 및 실물은 05-world, 시작/종결은 04-setup/06-play, 검증된 세계·저장 상태는 07-state가 담당한다. 아래 카드는 실제 인과·PC 주도권·정보 공개 범위를 변경하지 않는다.

## CARD_SYSTEM_SCOPE

- 카드 유형은 **자산(Asset) 33장**·**강화(Enhancement) 33장**이다. 기존 이벤트 카드는 폐기. **성장(Growth) 8종**은 이 둘과 구별되는 별도 셀렉션이며 장착 카드가 아니다.
- **주 클래스 5종**: 수호자(GU), 탐구자(SE), 무법자(RO), 기회주의자(WI), 생존자(SU). 캠페인 시작 때 하나를 고정하고 해당 클래스+중립(NE)만 장착한다. 다른 클래스 카드도 영구 소유할 수 있으나 다른 주 클래스 캠페인에서 장착한다. 직업·기능·일반 행동은 카드로 독점하지 않는다.
- **등급**: 중립은 일반(Common)만; 클래스 전용은 희귀(Rare)·영웅(Epic)·전설(Legendary). 희귀도가 곧 단순 피해/방호/HP 자동 상위호환은 아니고, 상황별 대응·새 플레이 수단을 구별한다.
- **총량**: 클래스별 자산5+강화5, 중립 자산8+강화8 = 수집 카드66종. 플레이어 UUID 최초 생성에 기본 **자산9+강화9=18장**, 해금 가능 **자산24+강화24=48장**. 성장8종은 별개이며 전체 고유 명칭74종. 각 카드 옆 **`[GU-A-0]`** 등 ID는 Supabase `card_catalog.card_id`와 1:1 일치한다.
- **인물 자산 후보**: 탐구자의 「연구 협력자」와 무법자의 「뒷세계 연결책」은 **정식 카드에 미포함**. 현재 66장을 대체하거나 NPC를 영구 지급하지 않는다.

## CARD_EQUIP_AND_ASSET

- **장착 4슬롯**: 자산 전용1, 강화 전용1, 자유2. 자유에는 자산 또는 강화만 허용, 가능 조합은 **3자산+1강화 / 2자산+2강화 / 1자산+3강화**. 성장은 장착 슬롯을 쓰지 않는다. **대사건 캠페인 동안 장착 고정**. **연대기는 챕터 경계에서 강화만 교체**하고 자산 및 각 자유 슬롯의 유형(자산/강화)은 고정한다. 새 해금 자산의 **실물 재지급은 다음 캠페인 시작**부터; 새 강화는 적격 챕터 경계나 다음 캠페인에 장착해야 사용한다.
- **실물 지급**: 04-setup 직업 필수 시작물품 1개와 **별도로**, 장착한 자산 카드의 실물·소모품·동물은 **캠페인 시작에 한 번만** 지급한다. 실제 획득·위치·내용물·수량·메인5/파우치3 점유를 확정하고 이후 소모·분실·파손·인계·죽음을 반영한다. 장착 카드가 남아도 같은 캠페인에서 자동 복원/추가 지급하지 않는다. 시작 장비를 0칸 무료 물품으로 취급하거나 새 무게·하중 규칙을 발명하지 않는다.
- **원작별 실물**: 원작 시대·기술·생활·공간의 실존 가능한 물품과 동물로 구현한다. 모습만 바꾸고 해당 시대에 없는 기능(무전·분사·현대식 진단·인공 지능 등)을 복사하지 않는다. 시작 전 원작에 맞는 장비 종류·내용물·훈련·작동 조건·한계를 확정한다. 실제 불가능한 기능은 적용하지 않으며, 기능 자체가 성립하지 않는 세계에서는 억지로 발명하지 않고 충돌을 정식 적용 전에 해소한다.
- **동물 동행**: 수호자는 호위·구조, 기회주의자는 작은 소동과 속임수, 생존자는 감각·생존을 주된 동행 활용으로 한다. 실제 종·훈련·개체 성격·위치·공포·부상·이탈·죽음이 존재한다. 자동 명령 복종·모르는 비밀 감지·사망 즉시 재소환 없음. 다른 클래스의 PC도 그 상황에 원래 가능한 동물 활용 행동을 시도할 수 있다.

## CARD_ENHANCEMENT_TRIGGER

- PC가 먼저 자유롭게 행동을 선언하고 02-checks/03-danger가 요구하는 기존 판정·대항·무판정 여부를 결정한다. **장착 강화의 실제 장면 조건과 성공 단계**를 만족할 때만 카드의 **명시된 추가 효과**를 한 번 처리한다. 기본은 **어려운 성공**; 개별 카드가 **극단적 성공, 근소 실패, 판정 없는 시작 효과, 사전 선택 위험·보상, 캠페인 1회 자동 생존**을 지정하면 그 원문이 우선한다. **카드 전용 d100은 별도로 만들지 않는다.** 본 행동이 성공했으나 강화 요구치에 못 미쳤다면 원래 성공을 유지한다.
- 환경·장비·준비의 **일반 보너스**를 쓰면 **낮은 판정 후보값**으로 본 행동과 조건부 강화를 모두 판단한다. 영웅 등 명시된 **특수 보너스**는 **그 카드당 전체 캠페인 1회** 판정 전에 선택하며, **낮은 값**은 본 행동, **높은 값**은 해당 특수 보너스와 연결된 강화의 요구 단계에 적용한다. **일반 보너스와 카드 특수 보너스는 같은 판정에 함께 사용 불가**. PC d100은 플레이어 입력; 다른 실제 난수는 Python 담당.
- **기회주의자 위험·보상**은 플레이어가 **판정 전에 실제 판돈/손실 위험을 선택**할 때만 적용한다. 추가 강화 미달 시 판돈 손실과 원래 행동의 성공·실패 관계는 카드 원문대로. 미선언 HP·물품·퇴로 비용을 자동 부과하지 않는다.
- **시간**을 카드 보상·판돈으로 환산하거나 무료 행동/턴을 지급하지 않는다. 대신 실제 위치·통로·방해·소모·확보한 물건만 적용. 임의 단서·존재하지 않는 자원 생성이나 NPC 자동 동의, 이미 해결한 위험의 복귀 불가.
- **수치 카드의 명시적 예외**: 카드에 쓰인 추가 공격 피해·실제 남은 피해 경감·치료 HP 증가만 해당 발동 조건에 적용하며, 일반 Hard/Extreme 성공만으로 일괄 추가 피해를 지급하지 않는다. 기존 명중/방호/의료·중상·빈사 절차는 유지한다. 생존자 전설 「다 끝난 줄 알았지?」는 적격 물리 피해로 HP가 0 이하에 도달하기 **직전**, 물리적으로 생존 가능한 조건에서 해당 피해를 **HP 1이 남도록 1회 경감**한다. 이미 확정된 사망 소급 취소, 의식·중상·출혈·잔존 위험 무효화는 아니다.

## CARD_ASSET_GU

**클래스 감각: 다른 사람과 위험 사이에 서고, 구호·제압·현장 방어를 조직한다.**

1. **호위용 차폐구 / 기본 희귀 / 보호·호위** `[GU-A-0]`
   - **실물/효과**: 자신의 몸이나 주변 동료와 위협 사이에 실제 차폐물을 놓아 공격선·접근선을 가리거나, 접근하는 대상을 물리적으로 막는 수단. 동료와 함께 이동하면서 가릴 수도 있다.
   - **시대별 예시**: 목재·금속 방패, 진압 방패, 해당 세계의 실제 휴대 차폐 장비.
   - **한계**: 방패가 닿는 위치·방향·구조만 보호한다. 자동 피해 경감 수치나 무조건적 공격 무효화 없음. 필요한 방어·저지·이동 판정과 상대 대응 유지.
2. **제압용 결속구 / 해금 희귀 / 비살상 제압·통제** `[GU-A-1]`
   - **실물/효과**: 이미 적절히 제압한 인물이나 협조하는 대상을 결박·고정하고, 도주·위험한 움직임을 제한하거나 단순 구조물을 묶어 둘 수 있는 장치.
   - **시대별 예시**: 결박끈·족쇄·수갑·결속 장치.
   - **한계**: 상대를 제압해야 하고, 실제 신체·결속 구조에 맞아야 한다. 모든 적·괴물을 자동 포박하거나 생존자/다른 PC의 포박 행동을 금지하지 않음.
3. **야전 구호 세트 / 해금 희귀 / 구호·치료·이송 준비** `[GU-A-2]`
   - **실물/효과**: 실제 전문 구급상자에 해당하는 처치 재료로 지혈·고정·응급 안정화·이송 준비를 수행한다. 해당 세계에서 전문 구급상자로 성립한다면 **의료 물자 3회분**, 기존 의료 규칙에 따른 치료 성공 **HP 1d6**, 빈사 안정화와 중상 해제의 기존 조건 적용.
   - **시대별 예시**: 해당 시대의 붕대·부목·처치 도구, 현장 구급상자, 원작에 실재하는 전문 의료 세트.
   - **한계**: 치료·중상 해제는 현행 판정·자원 소모·필요 기술대로 처리. 시기에 없는 치료 효과는 자동 생성하지 않음.
4. **함께 지키는 전우 / 해금 영웅 / 동행 동물·구조·호위** `[GU-A-3]` — **기존 현장 인양 장치 대체 [채택]**
   - **실물/효과**: 시작부터 PC와 함께 생활·훈련한 **독립적인 실제 동행 동물 하나**. 익숙한 신호에 따라 호위·경계·사람 안내·대피 보조를 시도한다. 동물의 종과 실제 장구가 허용하면 부상자 이동 보조나 기승 이동도 가능하다.
   - **시대별 예시**: 말·작업 동물·훈련된 구조견 등, 원작의 장소와 실제 동물 행동에 맞는 한 종류.
   - **한계**: 구조견에게 사람을 태우는 등 종에 맞지 않는 기능을 부여하지 않는다. 독립 의지·두려움·이동·부상·죽음·훈련 한계 유지. 현장에 없는 동물이 자동 출현하지 않음.
5. **방어 거점 구축 세트 / 해금 전설 / 공간 통제·집단 보호** `[GU-A-4]`
   - **실물/효과**: 실제 공간에 조립·고정 가능한 방호물·지지대·차폐 도구로 임시 엄폐·출입구 봉쇄·보호 구역·접근 경로 제한을 시도해, **싸우는 위치와 방어 방식 자체를 바꾼다**.
   - **시대별 예시**: 목재 방책·방호틀, 야전 방호 설치품, 해당 원작에 실재하는 임시 방벽 장구.
   - **한계**: 실제 설치·고정·공간이 필요하고 파손·우회·침입이 가능하다. 추상적 안전 지대, 자동 진입 금지, 무료 시간 보상은 없음.

## CARD_ASSET_SE

**클래스 감각: 관찰·측정·실험·원격 접근·복수 지점 관측을 통해 위험에 대응한다.**

1. **현장 감식함 / 기본 희귀 / 물증·측정·대조** `[SE-A-0]`
   - **실물/효과**: 실제 보이는 미세 흔적·파손·자국을 확대·측정하고 기록하여 다른 장소와 대조할 수 있는 감식품.
   - **시대별 예시**: 확대경·자·표식·기록 용품, 가능한 시대의 정밀 계측 도구.
   - **한계**: 숨은 사실 자동 생성/발견 금지. 실제 시야·접근·기술 판정 필요.
2. **휴대 반응 시험함 / 해금 희귀 / 표본 실험·성질 확인** `[SE-A-1]`
   - **실물/효과**: 실제 접근·채취한 액체·분말·표면 잔류물을 시대에 가능한 시험으로 조사하는 **시험 재료 3회분**. 실제 도구가 확인할 수 있는 물질 반응이나 특성을 알아볼 수 있다.
   - **시대별 예시**: 전근대의 가능한 간이 시험재료부터 근현대의 간이 분석 세트까지.
   - **한계**: 초자연적 물질/미지 독성의 만능 식별기 아님. 위험한 화학 반응·오염·시험 물자 소모 보존.
3. **굴절 관찰기 / 해금 희귀 / 엄폐 관찰·좁은 틈 확인** `[SE-A-2]`
   - **실물/효과**: 거울·렌즈·관측관 등 실제 빛의 경로를 이용해 모퉁이 뒤나 좁은 틈의 일부 공간을 몸 전체를 노출하지 않고 살핀다.
   - **시대별 예시**: 손거울·관측관·해당 시대 광학 도구.
   - **한계**: 투시 아님. 어둠·반사각·장비 노출·실제 관측 범위 적용.
4. **원격 탐사 장치 / 해금 영웅 / 거리 둔 물리 조작·회수** `[SE-A-3]`
   - **실물/효과**: 직접 들어가지 않고 실제 도달 가능한 위험 구역의 작은 물건을 집거나 끌고, 단순 기계장치를 건드리거나 틈 안쪽을 탐사하는 장치.
   - **시대별 예시**: 연장봉·집게·견인줄·원작에 실재하는 소형 탐사 기구.

| 전설(Legendary) | 주황 | 클래스 전용 카드 | 5 |
| 성장(Growth) | **독립 셀렉션** | 8대 기본 특성 | **클래스 희귀도와 별개** |

- 새 드래프트는 **후보 슬롯별 허용 풀이 고정**되어 있으므로 기존 50/30/15/5를 네 후보 전체에 무조건 적용하는 방식이 아니다.
- 1번과 2번은 클래스 전용 카드만 있으므로 남은 희귀:영웅:전설 가중치를 **30:15:5 → 60%:30%:10%**로 정규화하여 등급을 뽑고, 해당 등급의 허용 미보유 카드 중 무작위 선택한다.
- 4번은 **중립 일반 카드 중 무작위**이며, 3번은 **성장 중 무작위**이다. 성장의 등장 여부 자체는 3번에서 보장되므로 기존 희귀도 확률과 경쟁하지 않는다.
- 특정 희귀도·카드 풀이 소진되면 **남은 허용 후보에 한해서만 가중치 비례 재분배**한다. 등급과 개별 카드 후보는 Python 실제 난수를 사용한다.
- 재추첨·천장·보유 중복 화폐·실패 보정은 없다. 전설 카드가 자동 성공이나 단순 상위 성능이라는 뜻은 아니다.

## CARD_PERMANENT_GROWTH

### 8-1. 성장 카드 8종

| 카드 | 대상 기본 특성 | 최대 누적 |
|---|---|---:|
| 근력 성장 | STR | +5 |
| 체력 성장 | CON | +5 |
| 체격 성장 | SIZ | +5 |
| 민첩 성장 | DEX | +5 |
| 외모 성장 | APP | +5 |
| 지능 성장 | INT | +5 |
| 정신력 성장 | POW | +5 |
| 교육 성장 | EDU | +5 |

- **기능(Skill)이 아닌 기본 특성(Attribute/Characteristic)**에 적용한다. +1%는 기존 0~100 척도에서 기본 **특성값 +1포인트**로 해석한다. 예: STR 60에 Lv.3 적용 → STR 63.
- 성장 단계는 **플레이어 ID에 귀속**되며 현재 주 클래스와 무관하다. 슬롯 장착이나 카드 소모 후 재지급 대상이 아니다.
- 각 종류별 최대 **Lv.5(+5)**, 8종 전부 최대 달성 시 전체 특성에 걸친 누적 상한은 **40포인트**다. 같은 성장 5단계 이후 그 성장은 3번 후보에서 제외한다.

### 8-2. 획득 및 도전 확률

| 선택 당시 상태 | 결과를 위한 난수 | 성공 확률 | 성공 시 누적 효과 |
|---|---|---:|---:|
| **미보유 → Lv.1** | 최초 획득 확정 | **100%** | 해당 특성 +1 |
| **Lv.1 → Lv.2** | Python 1~100 | **80%** | +2 |
| **Lv.2 → Lv.3** | Python 1~100 | **50%** | +3 |
| **Lv.3 → Lv.4** | Python 1~100 | **25%** | +4 |
| **Lv.4 → Lv.5** | Python 1~100 | **10%** | +5 |

- 실제 해당 성장 후보를 **드래프트에서 선택한 후** Python으로 한 번 굴린다. 결과가 성공 범위에 들면 즉시 다음 단계 +1, 아니면 기존 단계 유지. **단계 건너뛰기 없음**.
- **강화 실패 시 단계 하락 없음, 보상은 반드시 소모**. 대체 카드 지급, 재추첨, 무료 재도전, 실패 누적 확률 보정 없음. 다음 도전에는 실제 새 종결 보상이 필요하다.
- 성장 강화의 Python 난수는 **PC가 직접 굴리는 CoC d100**과 별개다.
- **성장 적용 시점 [확정]**: 영구 플레이어 UUID와 새 PC identity를 **연결하는 순간**, 그때까지 소유한 성장 레벨(+0~+5)을 해당 PC의 8대 기본 특성에 반영하고 스냅샷으로 고정한다. 같은 PC의 재연결 시 이전 스냅샷을 유지하고 추후 성장 보상을 소급 적용하지 않으며, 다음 새 PC 연결 때 최신 성장을 반영한다. 파생값은 성장 반영된 기본 특성으로 현행 캐릭터 생성 규칙에 따라 산출한다.

## CARD_PLAYER_STORAGE

- **닉네임 연결**: 2~3명 소규모 운영에서 2~24자 고유 닉네임을 입력해 Supabase 플레이어 UUID를 연결한다. 신규 UUID에 기본 카드18장을 자동 지급하고, 기존 닉네임은 그 UUID·컬렉션·성장을 그대로 조회한다. 로그인·비밀번호 요구 없음. 닉네임을 아는 다른 사람도 접속해 장착/보상 선택을 대신할 수 있음을 사용자 요청에 따라 허용한다.
- **영구 vs 캠페인**: UUID 소유 카드·성장 단계·드래프트는 영구 컬렉션, PC의 위치·HP·SAN·현금·물품·동물 상태는 기존 07-state 검증 게임 상태에 기록한다. 저장 실패 시 성공을 가장하지 않는다.
- **성장 적용**: 신규 PC의 **8대 원본 기본 특성**을 확정하고 플레이어 UUID와 해당 **PC identity를 연결하는 그 순간** 보유 성장 레벨(+0~+5)을 더해 스냅샷으로 확정한다. 같은 PC를 재개해 성장치를 중복 적용하거나 연결 후 새로 얻은 성장을 소급 적용하지 않는다. 새 PC에게는 새 연결 시 최신 성장 수준을 적용하며 PC의 사적 기억/아이템/관계는 상속하지 않는다.
- **종결·지급**: 06-play에서 실제 종결 조건 및 `finalization_event_id`를 먼저 확인한다. Python 실제 난수로 적법한 4후보를 뽑아 최초 후보를 저장, 플레이어 선택 뒤 **정확히 하나만** DB에 확정한다. 이전에 발행한 후보를 임의 재추첨하지 않고 이중 지급·과거 보상 소급 없음. 풀이 비면 후보 null, 모든 풀이 비면 보상 없음.
- **실제 도구 계약**: 공개 `public.card_login`, `public.card_join`, `public.card_link_pc`, `public.card_equip`, `public.card_rewards`, `public.card_pick_reward`는 연결이 실제 지원되는 경우에만 호출한다. 키퍼는 적격 종결 검증·서버 후보 발행·Python 성장 난수를 담당한다. 접근 불가 시 UUID나 소유 결과를 발명하지 않는다. 공개 카드 API가 기존 비공개 게임 정본/세이브 접근권을 개방하지는 않는다.
