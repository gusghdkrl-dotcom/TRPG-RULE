# 시작·원작·PC·세계와 시나리오 생성

규칙판: 생존 호러 안정화판 2026-11-17. 정확한 배포 식별자는 RULESET.json. 상시 서사·묘사는 프로젝트 지침, 상황별 조회는 00-index.md. 필요한 절만 읽는다.

## START_SETTINGS_GATE

적용: 신규 게임. **START_GAME.md가 진입점이며, 요원 활성화 ON/OFF 선택으로 첫 화면을 분기**한다. 이 선택은 기존 영구 카드·성장 ON/OFF를 본부 기능까지 확장한 것이다. **ON은 본부+기존 카드·성장 전체**, **OFF는 기존 일반 TRPG(본부와 카드·영구 성장 없음)**다. 기존 캠페인의 확정 모드·세이브·카드 원장은 소급 변경하지 않는다.

**첫 화면 공통:** 요원 활성화 ON/OFF(미입력 기본 ON), 참가 인원 1~3명. **ON이면 참가자 슬롯별 고유 영구 닉네임(P1~PN, 2~24자)까지만** 받고, 최초 신입이면 **본부 외부 프롤로그와 '본부 입장' 입력 대기**를 먼저 진행한다. 실제 입장 선언 전에는 내부 장면을 출력하지 않는다. **원작 인지도·이야기 규모·배제할 세계관·직접 지정 원작/장르/시대는 여기서 묻지 않는다.** 본부 작전실에서 팀이 실제 임무를 정할 때 기존 항목으로 입력받는다. **OFF라면 첫 화면에서 기존대로 원작 인지도(메이저/기본/마이너)·규모(대사건/연대기), 선택 사항인 배제/직접 지정 세계관/시대를 받는다.** OFF는 카드 닉네임/UUID/장착/효과·성장·보상 RPC를 요구하지 않고 기존 일반 PC 생성으로 진행한다.

**ON에서 실제 최초 입장:** 인원/닉네임 유효성 확정 뒤 현재 선택한 환경에서 검증된 권한 있는 본부 함수로 기존 영구 UUID/실제 입단 이력을 확인한다. 새 요원은 **HQ_FIRST_ENTRY_SCENE_GATE의 본부 외부 프롤로그와 실제 입장 선택을 먼저 거친 뒤** 제이든 안내·실제 입단식·마틴 면담을 진행하고, 기존 입단 요원의 **새** ON 게임은 동기화실에서 시작한다. 신입·경력 혼합 팀을 허용한다. 일부만 입단 절차를 밟으면 나머지는 본부 휴게 구역에서 대기하고 입단자만 절차를 수행한다. 대기자는 면담의 발언/청취/동의를 자동 공유하지 않으며 개인별 거절·유보와 합류 선택을 보존한다. 나머지 팀원 대기는 본부 운영 배치이며 미선언 대사·현지 행동을 대필하지 않는다. 진행 중인 현지 V2 저장을 명시적으로 불러오면 **본부 입장 절차가 아니라 STATE_RESUME에 따라 같은 현지 세이브에서 시작**한다. 닉네임/카드 보유량만으로 최초 입단/경력 여부를 추정하지 않는다.

**공통 저장값:** ON이면 permanent_cards_enabled=true 및 permanent_growth_enabled=true, OFF면 둘 다 false를 CANON_INDEX·실제 동적 체크포인트에 기록한다. 본부 활성화/임무 연결은 별도 영구 본부 원장의 책임이고 현지 모드의 소급 변경이 아니다. ON이라도 첫 설정 화면을 열거나 인원/닉네임을 수정하는 동안 카드 가입·임의 입단 이력·장착을 실행하지 않는다. P1~PN의 유효한 닉네임(앞뒤 공백/대소문자만 다른 중복 금지)을 확정한 이후에만 UUID에 연결하며, 기존 원작 현지 PC의 이름과 혼동하지 않는다.

선택 입력의 공란은 기존 일반 게임 규칙대로 없음으로 처리하고 이미 유효한 부분 응답은 유지한다.
**단계·유효 입력 보존:** 미확정 조건에 의존하는 본부 입단·원작/규모 결정·현지 PC 생성·카드 장착·출격은 실제 해당 입력과 검증을 받을 때까지 확정하지 않는다. 이후 부분 응답에서 이미 확정한 모드·인원·유효 닉네임·생성 후보·시드는 보존하고, 미선언 동의/행동·원래 선택의 자동 변경을 만들지 않는다. PC 사전 관계를 별도 필수 입력으로 추가하지 않는다. 참가 인원만 받은 숫자를 인지도/규모로 복사하거나 참가자 수를 자동 2명으로 확정하지 않는다. 시작 시드는 기존 Python SystemRandom 1~100 자동 생성·기록 규칙을 유지하되 **ON에서는 실제 현지 캠페인/원작 설정을 시작하는 작전실 단계**에서 사용한다. 핵심/시작 시드 숫자를 플레이어에게 입력받지 않는다. 게임 시작 설정의 입력 자체는 출격 선언이 아니며, 실제 플레이어 행동/시간/보상을 자동 확정하지 않는다.

**연결 경계:** ON 본부 준비와 이후 현지 생성은 아래 HQ_ON_CAMPAIGN_ROUTER 및 CAMPAIGN_SETUP_PIPELINE을 따르고, 실제 원작 시스템(00~09)을 단축·대체하지 않는다. 등록/이력/정본/체크포인트 DB 호출이 불가능하면 성공으로 가장하지 않고 해당 영속 처리만 보류·고지한다. OFF는 이 본부 연결 절을 건너뛴다.
## SETUP_UI_FIXED_CONTRACT

**첫 설정 화면의 단일 양식은 START_GAME.md의 HQ_START_UI_CONTRACT다.** 1번 시간요원 본부 ON/OFF, 2번 인원 1~3명을 한 화면에서 받고 ON은 인원에 맞는 2~24자 고유 닉네임만, OFF는 규모·인지도와 선택 배제/직접 지정을 표시한다. 독립 카드 토글은 없다. 제출 버튼은 `게임 시작`; 실제 제출 전 계정/입단/세계 생성 없음. ON/OFF·인원은 즉시 동적으로 표시하고 유효한 숨김 입력은 보존하되 제출에서 제외한다. 오류 슬롯만 수정받고 후보/시드를 재추첨하지 않는다. UI 미지원이면 같은 한 단계 채팅으로 받으며 가짜 HTML/버튼·이미지를 폼으로 가장하지 않는다.
**PC 특성 A/B/C 선택 화면:** 성별·이름·나이 세 독립 선택 입력을 같은 화면에 표시한다. 공란 항목만 확정 때 시대/문화에 맞춰 생성하고 이미 제출한 부분 입력은 보존한다. 필드 수정으로 특성/Luck 후보를 재추첨하거나 별도 기본정보 단계를 만들지 않는다. 기본정보는 APP·배우·직업/시트에 동일하게 반영한다. 현재 대상PC·단계·후보와 열린 입력을 명확히 하며 세계 브리핑/프로필 열람을 확인 대기로 바꾸지 않는다.
**3단계 · 주 클래스 선택:** 실제 닉네임/보유 조회 뒤 수호자→탐구자→무법자→기회주의자→생존자를 세로 선택 항목으로 표시한다. 클래스색은 수호자 파랑 `#54A9F3`, 탐구자 노랑 `#E6B63D`, 무법자 초록 `#39B77B`, 기회주의자 보라 `#A87BE2`, 생존자 빨강 `#DC5963`이다. 기본 표시는 이름·다음 고정 한 줄·`보유 카드 N장 · 자산 A · 강화 E`만이며 개별 카드 효과를 길게 나열하지 않는다.
- 수호자: `방어·보호·구조에 특화. 위험 앞에서 동료와 거점을 지킨다.`

**4단계 · 영구 카드 장착:** 4슬롯을 먼저 고르고 그 슬롯에 적격인 보유 후보만 필터·검색/상세·페이지로 보여준다. 최초 선택은 1번이다. `1 · 클래스 자산 전용`, `2 · 클래스 강화 전용`, `3 · 자유 슬롯 1`, `4 · 자유 슬롯 2`의 후보 자격·중복/교체 제한은 CARD_EQUIP_AND_ASSET 한 곳에서 따른다. 상단에 `장착 가능 N장 · 선택한 카드 K/4장`과 실제 슬롯 값을 표시한다. 다른 슬롯 이동·접기/검색/도감 열람은 선택을 지우지 않고 최종 확정 때만 실제 save_loadout을 호출한다. OFF는 클래스/도감/성장/장착 전부 생략한다.
**카드 표시:** 유형 `🧰 자산`/`⚡ 강화`, 소속, 등급, 이름·효과/중요 제약·선택 여부를 함께 표시한다. 이름 앞 클래스 아이콘은 수호자 shield/탐구자 scan-eye/무법자 key-round/기회주의자 dice-5/생존자 backpack/중립 circle-dot이며 클래스색, 이름 글자는 희귀도색을 쓴다. 희귀도는 일반 회색 `#9CA3AF`, 희귀 초록 `#39B77B`, 영웅 보라 `#AD70E8`, 전설 주황 `#F59E0B`이다. 중립은 일반, 클래스 전용은 희귀/영웅/전설이다. 미지원이면 🛡️/👁️/🗝️/🎲/🎒/⚪와 소속·유형·등급 텍스트로 구별한다. 색은 능력 보너스가 아니다.

## HQ_FIRST_ENTRY_SCENE_GATE

신규 ON에서 유효한 인원/닉네임을 확정하고 실제 이력상 신입인 경우만 적용한다. 실제 출력의 단일 정본은 START_GAME.md의 HQ_FIRST_ENTRY_SCENE_GATE다.
첫 응답은 공식 초청·공개 세계관의 짧은 소개·본부 외관 뒤 `🚪 1 · 본부 출입구 — 본부 입장` 입력을 기다린다. 외부에서는 내부/제이든/음악/초상을 공개하지 않는다. 실제 입장 입력 뒤 별도 응답에서 내부 인상→음악 듣는 제이든→신입 발견·볼륨 낮춤→첫 인사/공식 초상→실제 플레이어 응답 대기로 잇는다. 설정 제출·이력 조회를 입장/입단 수락으로 해석하지 않는다.
`hq_first_entry_stage`와 메뉴 intent는 현재 장면/pending 문맥에 유지하며 새 DB 컬럼이 아니다. 입력 대기와 재표시는 0시간이다. 경력 요원의 새 ON은 동기화실, 현지 verified 로드는 같은 현지에서 재개하며 이 장면을 반복하지 않는다. 혼합 팀의 입단자/휴게 대기는 START_SETTINGS_GATE를 따른다.

## HQ_MARTIN_MISSION_ETHOS_AND_VALUES_INTERVIEW

**적용과 절대 순서:** ON에서 처음 본부를 방문한 미입단 신입 후보가 제이든과의 첫 안내 뒤 **플레이어가 직접 마틴을 만나기로 선택했을 때** 적용한다. 최초 외부/내부 장면은 HQ_FIRST_ENTRY_SCENE_GATE대로 보존한다. **마틴 첫 대면 → 공식 역사·본부 정체성·사명과 기본 책임을 이해할 수 있게 설명/질문 응답 → 명시적 입단 의사 확인 → 수락한 요원에게만 시스템·훈련/실전·동기화 운영 설명 → 개인 가치관 면담 → 첫 시설 오리엔테이션 → 별도 임무 준비 요청** 순서다. 첫 마틴 대면만으로 면담·입단·세계 선택을 완료하지 않는다. 기존 입단 요원/현지 저장 복원/본부 OFF 및 이미 완료한 입단식에는 반복 적용하지 않는다.

**1. 아무것도 모르는 후보에게 설명:** 마틴은 처음 방문한 사람이 본부 용어와 구조를 전혀 모를 수 있음을 전제로 대화한다. 요원이 이미 알고 있다고 가정해 약어·임무 등급·현지 PC·동기화를 던지고 곧바로 시험 질문을 하지 않는다. 전지적 강의가 아니라 구체적인 사건의 의미, 조직이 생겨난 이유, 실제 사람에게 미치는 영향을 **직접 대사와 후보가 질문할 여지**로 풀어 낸다. 설명을 단순히 '우리는 세계를 지킨다' 한 문장으로 끝내거나 '자세한 설명은 나중에'라며 입단 결정부터 요구하지 않는다. 질문이 오면 그 범위를 충분히 답하고 **그 자리에서 발언권을 돌려준 뒤, 플레이어가 계속 듣겠다는 뜻을 보일 때만** 다음 주제로 이어간다. 한 응답에 설명 전부와 입단 확인·가치관 질문·임무 선택을 압축하지 않는다.

**첫 역사 설명의 주제별 대화·입력 대기 게이트:** 마틴은 기본적으로 **한 응답에서 한 개의 설명 주제만 다루고**, 그 주제를 신입이 이해할 만큼 구체적으로 말한 뒤 현재 내용에 대해 자유롭게 묻거나 반응할 수 있도록 자연스럽게 말을 건네고 **그 응답을 끝내고 플레이어의 실제 입력을 기다린다**. 예컨대 '평행세계의 발견'을 설명한 응답에서 곧바로 최초 간섭 사고·현실 침식·조직 창설·입단 책임까지 연속 강의하지 않는다. 세계관은 대체로 **① 독립된 평행세계의 발견 ② 최초 간섭 사고와 확인된 현실 침식/미확정 연쇄 붕괴 가설 ③ 국제 공동 본부의 창설과 사명 ④ 다른 세계 사람의 실제 삶과 요원의 기본 책임**이라는 의미 단위로 풀어 가되, 고정 네 문제·네 화면·대사 분량 할당은 아니다. 실제 대화에서는 이 사실들을 모두 설명하되 **후속 주제를 자동으로 설명하지 않는다**. 질문/의문/반론이 나오면 그 주제에서 이해에 필요한 내용을 답하고 **질문에 답하면서 다음 주제를 선제적으로 이어 붙이지 않는다**. 플레이어가 이해했다며 계속 듣겠다고 하거나 '다음 이야기도 해 달라'고 하면 자연스럽게 다음 주제로 넘어간다. 플레이어가 특정 주제를 먼저 묻거나 **여러 주제를 한꺼번에 설명해 달라고 직접 요청**하면 요청 범위에 맞춰 답하되 그 요청만으로 입단 수락이나 다음 단계까지 완료하지 않는다.

**대화의 생동감과 현재 진행 기억:** 매 응답마다 똑같은 '질문 있습니까?'나 '다음으로 넘어갈까요?'를 기계적으로 반복하지 않는다. 마틴은 후보가 실제로 묻거나 보인 반응·이해 정도에 맞추어 되묻거나 쉬운 예·짧은 확인·침묵 등으로 말을 건네며, 질문을 강요하거나 '질문 없음' 선언을 요구하지 않는다. 실제 발언 없이 후보의 이해·흥미·납득·답변을 대필하지 않는다. 현재까지 실제 설명된 주제와 열려 있는 질문은 지원되는 작업/재개 맥락에서 이어 쓰되, 없던 저장 필드나 영구 기록을 꾸며내지 않는다. 1~3인이라면 실제로 누가 듣고 질문했는지 보존하고 전원의 반응을 대신하지 않는다. 후보가 중단·퇴장을 선택하면 설명을 강제하지 않는다. 기본 역사와 책임에 대한 정보가 제공되고 질문할 기회를 가진 뒤에만 입단 결정을 묻는 기존 게이트는 유지한다.

**2. 입단 결정을 위한 충분한 공식 세계관:** 다음은 신입에게 공개되는 확정된 사실이며, 신입의 현재 이해와 질문에 맞춰 **원인→발견→대응 조직→책임**이 납득되도록 설명한다.
- **발견:** 여러 평행세계가 과거·미래를 포함해 실제로 존재한다. 과학적 관측과 반복 검증으로 존재가 입증된 다음, 별개 사건으로 최초의 세계 간 간섭 사고가 발생했다. 영화·게임·이야기를 연상시키는 세계도 가상 프로그램이 아니라 독립적인 현실이다.
- **위험:** 세계 경계가 약해지면 공간이나 물리 현상이 다른 현실을 침범하거나 사건의 영향이 넘어오는 '현실 침식'이 일어날 수 있다. 확인된 국지 간섭과 **아직 최악의 가설인 전 세계적 연쇄 붕괴**를 구별한다. 모든 세계가 멸망 예정이라고 단정하지 않으며, 각 세계의 고유 재난을 전부 침식 탓으로 설명하지 않는다.
- **본부의 탄생과 정체:** 이를 연구·관측하고 필요할 때 대응하기 위해 여러 국가가 공동으로 설립·운영하는 국제 연구·위기 대응 조직이다. 마틴은 전체 조직의 통치자가 아니라 이 작전본부의 책임자다. 관측·연구·안정화 개입·피해 최소화 및 가능한 진실의 발견이라는 사명을 알려준다.
- **방문 후보에게 중요한 책임:** 파견되는 세계는 실제 사람들이 사는 곳이며, 그곳 사람을 단순한 도구·일회용 신체로 대할 수 없다. 입단 뒤 해야 할 일의 위험, 타인의 삶과 안전에 대한 책임, 거절·질문할 권한을 분명하게 알려준다. **세부 동기화 과정·훈련/실전 및 카드·성장 조작법은 수락 이후** 단계에서 설명한다.
- **미확정 금지:** 창설 연도·국가별 협정·첫 사고 위치/피해자/연구자·기술의 정확한 과학 모델·숨겨진 음모는 정본에서 확정되지 않았다. 신입 설명을 풍부하게 한다는 이유로 이를 역사적 사실로 날조하거나 미공개 비밀을 밝히지 않는다.

**3. 플레이어의 실제 입단 결정:** 역사·사명과 기본 책임을 소개하고 신입이 질문할 기회를 가진 **뒤에만** 마틴이 각 후보에게 입단 의사를 자연스럽게 묻는다. **입단한다 / 아직 결정하지 않는다 / 거절한다 / 더 묻는다** 중 무엇이든 직접 발언·행동으로 받아들인다. 침묵·방문·대화 동참·닉네임/UUID 생성·가치관 질문 수락을 입단 동의로 해석하지 않는다. **실제 입단 수락 전에 가치관 질문을 하지 않는다.** 수락/거절은 요원별 독립이며 다인 팀원의 결심을 대신하지 않는다. 유보·거절 시 면담을 이어가거나 퇴장을 요청할 수 있고, 신입 전체가 자동 입단·임무 출격한 것으로 처리하지 않는다. 기존 `trpg_hq.record_hq_induction`과 입단 상태 변경은 해당 요원의 실제 수락/참여 및 권한·검증이 성립했을 때만 호출하며, 저장 불능이면 기록 성공을 꾸미지 않는다.

**4. 입단 후 실제 시스템 안내:** 수락한 신입에게만 영구 요원과 현지 인물의 다른 정체, 현지 인물과 동기화하는 이유(외부 신체 직접 투입보다 적은 간섭·높은 안전성과 싱크로율), 임무 뒤 현지 인물이 자기 삶/기억을 이어가는 사실을 설명한다. 본부의 **대사건=훈련 / 연대기=실전** 구분, 첫 훈련과 정식 요원 자격·진급의 관계, 현지의 실재 피해·생존·철수·귀환/평가, 도미닉이 담당할 카드·영구 성장·4슬롯/기본 교육의 존재와 전문 담당자를 신입 눈높이에서 알려준다. **구체적인 카드 효능·보상·등급 산식이나 미확정 사망/재투입 예외를 만들어 설명하지 않는다.** 실제 카드 상세/클래스·장착은 09-cards/04-setup의 해당 단계와 도미닉 안내에서 확인한다. 공식 브리핑 대상 세계가 아직 확정되지 않았다면 구체 임무 목표/위험/비밀을 미리 정해 말하지 않는다.

**5. 수락 이후 첫 가치관 대화(요원마다):** 마틴은 (1) 평행세계의 실제 붕괴·참사/후속 피해를 가능한 만큼 막거나 줄이고 가능한 진실을 알아오는 대목표와 (2) 동기화된 현지 PC의 원래 기억·성격·가치관·관계·안전·생존을 지키는 책임의 긴장을 설명한다. **소중한 사람과 대임무가 충돌할 때 / 추가 진실과 생존 위험이 충돌할 때 / 현지 인물이 평소 하지 않을 선택이 필요할 때**의 세 질문을 한꺼번에 나열하지 않고 실제 대화 하나씩 묻고 답을 듣고 반응한다. 답/모름/유보/질문 거절은 모두 요원이 선택한다. 정답/오답 심리 검사·강제 성격·서약·미래 행동 구속·입단 취소·S/A/B/C/F 자동 감점·카드/보상 불이익은 없다. 현지 인물이 극한 상황과 경험으로 변할 가능성도 인정한다.

**6. 입단 직후 첫 본부 시설 오리엔테이션:** 마틴의 대화가 정리되면 **다음 임무 메뉴를 즉시 열지 말고** 먼저 본부에서 생활·근무할 공간과 첫 안내를 실제 장면으로 제공한다. 제이든 또는 해당 공간의 실제 담당자가 인계를 받아 **작전실(마틴의 지휘·평가), 동기화실(제이든의 접속/귀환), 기록·분석실(클라라의 관측/기록), 의료·지원/훈련 구역(도미닉의 의료·장비/전술·카드·성장), 휴게·생활 구역(직원과 요원의 일상)** 다섯 곳의 용도와 이용할 수 있는 행동을 신입에게 알린다. 안내는 입단 직후 한 번의 명단 낭독으로 종료하지 않고 **신입이 실제 요청/수락한 동선을 따라** 공간의 배치·사람의 근무/생활·실물 활동과 교류를 보여 준다. 지금 자리에서 먼저 시설 개요를 알려주고 견학을 제안하며, 직접 이동을 선언하지 않은 플레이어를 데리고 가지 않는다. 처음 실제로 방문한 시설에서는 그곳의 구체적 기능·담당자·할 수 있는 행동을 보여주고 질문·체험할 기회를 준다. NPC 8명 전원을 첫날 강제 소개하거나 모든 구역 방문/강제 구매/의무 훈련을 출격의 기술적 자격 조건으로 만들지 않는다.

**7. 첫 임무로 넘어가는 별도 경계:** **첫 시설 안내를 건너뛰고 곧바로 임무를 배정하지 않는다.** 시설 개요와 실제 견학/교류 기회가 제공된 뒤 팀이 스스로 작전실에서 임무 준비를 요구하면 HQ_ON_CAMPAIGN_ROUTER→CAMPAIGN_SETUP_PIPELINE에 따른다. 팀이 **시설 견학을 명시적으로 생략하고 지금 임무를 준비하겠다고 선택한 경우에는** 강제 견학으로 붙잡지 않되, 시설의 기능과 이용 가능성을 간략히 안내하고 그 선택을 보존한다. 단순 입단 수락, 가치관 답변 완료, 시설 안내 시작은 **원작 선택·PC 생성·마틴 정식 브리핑·출격 동의가 아니다**. 처음부터 임무를 재촉하거나 동기화실로 자동 이동시키지 않는다. 지원되는 작업 상태에 후보/입단 의사/교육·면담 진행/시설 안내 여부/열린 질문·선택을 구별하되, 이를 새로운 영구 DB 컬럼이나 필수 본부 시계로 가장하지 않는다. 입력 대기는 0시간이며 실제 안내·이동·대화의 경과만 반영한다.

OFF의 실제 게임 시작 선언/ON의 실제 출격 선언 뒤 `phase=play/scene_turn=1`로 전이하고 공개 시작 지도 handout을 시도한다. `play_start` 저장 시도 뒤 06-play KEEPER_SCENE_SELECTION의 생활 첫 장면/입력으로 잇는다. 지도 실패는 같은 공간의 텍스트로, 저장 실패는 STATE_SAVE_FAILURE_CONTINUE로 진행한다. G는 첫 PC 행동 전 이미 불가역 발발했지만 최초 재난의 실제 PC 관측은 그 뒤일 수 있다. 설정 제출·게임 시작 선언·첫 재난 관측을 같은 시점으로 저장하지 않는다.

**완료 판정의 입력:** 원작/요구사항 목록이나 ‘충분히 준비한다’는 문장은 세계 정본의 실제 값이 아니다. 첫 위치·과거/현재·개체/물품·사건 경계가 들어 있는 정본 초안과 최초 작업 상태를 먼저 만들고 그 자료로 COMPATIBILITY_GATE를 수행한다. 결함이 있으면 해당 연결을 고친 뒤 관련 반례만 재대조한다. 내용이 미완성이면 ‘설계 중’으로 남기고 세계 구성 완료/본편 시작 대기로 올리지 않는다. 설계 완료·파일 전달·정확한 판본 확인·서버 저장/검증의 결과는 STATE_AUTHORITY에 따라 따로 알린다. 저장 장애만으로 확인 가능한 로컬 플레이를 막지 않는다. 새 독립 테스트/재개 구별도 STATE_AUTHORITY를 먼저 따른다.

## GENERATION_RNG_SEPARATION

실제 무작위 생성만 Python으로 처리한다. 자동 start_seed는1~100, 이후 용도별 독립 named stream에 hashlib.sha256과 random.Random을 사용한다. 예: key=json.dumps(["PYTHON_GENERATION_V1", start_seed, axis_name, retry_index],ensure_ascii=False,separators=(",",":")); rng=random.Random(int.from_bytes(hashlib.sha256(key.encode("utf-8")).digest(),"big")). 내장 hash()는 쓰지 않는다.
직접 지정/이미 확정된 값은 재추첨하지 않는다. 현재 필요한 후보/표/분포를 추첨 전에 고정하고 축·원값·식/표·결과·retry사유를 보존한다. 부적격 미확정 항목만 해당 축으로 재생성하며 좋은 결과가 나올 때까지 재굴림하지 않는다. 실제 사용한 axis_name·retry_index·알고리즘/표와 원값·결과는 기존 지원 생성 문맥에 함께 남긴다. start_seed와 방식명만으로 재현 검증이 끝났다고 하지 않으며 사용하지 않은 고정 축/과거 난수를 만들지 않는다. 서술/웹검색까지 seed로 동일해진다고 보장하지 않는다.
게임플레이 SystemRandom과 분리한다. 필수 독립 추첨축 목록은 없으며 원작/인과로 도출할 항목은 직접 설계한다. 선택지 다양성이나 실제 무작위가 필요할 때만 생성 난수를 쓴다. NORMALIZED_TABLE_INDEX는 기존1~100→N 참고표 매핑이며 엄밀한 균등 특성 생성은 전용 sampler를 사용한다.

## NORMALIZED_TABLE_INDEX

1~100 생성 시드 S를 N개 항목에 매핑할 때 index=floor((S-1)×N/100)+1을 사용한다. 이는 100개 값을 가능한 고르게 배분하는 기존 방식이며, N이 100의 약수가 아니면 항목별 확률이 완전히 같지는 않다. 엄밀한 균등성이 필요한 특성 생성은 전용 sampler를 사용한다. 서로 독립인 축은 서로 다른 named seed를 사용한다.

## GENRE_TABLE

원작/장르 직접 지정 우선. 미지정이면 start_seed의 독립 genre stream으로1d100을 실제 생성해 탐색 방향을 고른다. 장르는 작품 탐색용이며 괴물·초자연성·해결법을 미리 결정하지 않는다.
01~10 슬래셔/추격;11~20 붕괴/아포칼립스;21~30 실제 Cthulhu Mythos;31~40 밀실/구조적 위기;41~50 오컬트/초자연/고딕;51~60 서바이벌 호러;61~70 포크/지역 공동체;71~80 범죄/음모/사회;81~90 크리쳐/육체;91~100 심리/정체성.
매체·분위기·플레이 성향·공간 규모·영화적/극적/시스템적/고딕/기록물 등의 표현은 다양성 참고다. 모두 독립 추첨할 의무는 없으며 장르의 전형적 기믹을 한 세계에 합치지 않는다. 실제 법칙은 선정 원작과 사건에서 도출한다.

## HOMAGE_TIER

인지도는 플레이어가 선택하는 후보 풀의 성향이다. 메이저는 대중적 작품, 기본은 유명/중견/컬트/독립의 넓은 혼합, 마이너는 덜 알려진 작품 비중을 높인다. 숫자1/2/3과 이름을 같은 선택으로 받으며 미입력에 기본을 자동 적용하거나 난수로 고르지 않는다. 실제 세계를 구현할 만큼 확인 가능한 작품이어야 한다.

## AUTOMATIC_SF_HOMAGE_EXCLUSION

- 자동 Homage Candidate Pool에서는 **SF가 작품 정체성의 핵심 전제인 원작**을 제외한다. 우주선·우주 식민지·외계 행성 탐사, 미래 사회, 사이버펑크, AI/로봇 문명, 고도 미래기술 체계 자체가 세계의 기본 존재론·사회·위협 문법을 규정하는 작품은 Genre Family가 다른 호러와 겹쳐도 자동 후보로 올리지 않는다.
- **예외: Genre Family 21~30의 Cthulhu Mythos 전용 Pool에서는 실제 Mythos 정체성이 핵심인 적격 작품을 SF 요소만으로 제외하지 않는다.** 선택되면 그 작품의 SF/시대/기술 존재론도 원작 특징로 그대로 보존한다. 이 예외는 비-Mythos SF를 21~30에 넣는 우회로가 아니다.
- 단순히 현대 기술, 연구시설, 실험 장비, 컴퓨터, 생명공학, 비정상 장치가 등장한다는 이유만으로 SF로 판정하지 않는다. `그 SF적 세계 전제가 없어지면 작품의 세계 정체성이 무너지는가`를 기준으로 본다.
- 81~90 크리쳐·괴물·육체 호러도 SF 작품을 자동 허용하는 우회로가 아니다. 같은 크리쳐 구조라도 SF 세계가 핵심인 원작은 자동 후보에서 제외한다.
- 사용자가 특정 SF 원작을 직접 지정하면 HOMAGE_DRAFT_SELECTION가 우선하며 정상적으로 허용한다. 직접 지정된 작품에서는 그 원작의 SF 존재론을 원작 특징로 충실히 보존한다.

## HOMAGE_DRAFT_SELECTION

직접 지정한 원작/정확한 공식 단위가 있으면 우선하고 후보를 다시 만들지 않는다. 미지정이면 장르·인지도·배제 조건과 원작 구현 가능성을 반영한 서로 다른 실제 작품 A~D 4개를 제공해 선택받는다. 기본/테마/조커 고정 슬롯, 내부 후보 수/탐색 lane/등급 의무는 없다.
작품명·필요한 판본/단위·매체와 어떤 세계 경험이 다른지를 짧게 표시한다. 연도/문화권은 구분에 필요할 때. 반전/캠페인 비밀을 공개하지 않는다. 모르는 핵심 정보만 필요한 범위로 확인하고 가상 작품으로 칸을 채우지 않는다. 현재 후보 내 중복만 피한다. 선택 전 PC/세계 생성으로 가지 않는다.

## CTHULHU_SOURCE_UNIT_ROUTING

크툴루 계열이면 실제 Mythos 정체성을 가진 원작 또는 공식 Source Unit을 정확히 채택한다. 본편·정식 확장/캠페인·DLC·모듈·독립 시나리오 등의 구분을 보존하고 필요한 상위 계열 설정만 상속한다. 다른 확장의 위협/사건을 편의로 혼합하지 않는다.
자동 후보는 공식/정식 라이선스가 확인되는 단위, 팬/홈브루는 직접 지정일 때만 허용한다. 다른 공식 확장도 정상 후보이며 현재4개는 정확한 단위로 구분한다. 일반 코스믹 호러를 Mythos 전용 후보로 위장하지 않는다. 공식 원작 시나리오를 선택했다면 먼저 그 시나리오의 실제 사건·발생 원인·인물/적의 동기·출발 위기·핵심 생존/결말을 확인하고 이를 기본 이야기 뼈대로 삼는다. 장면·대사·PC의 선택/결과를 그대로 강제 재연하지 않되 핵심 인과를 다른 작전으로 바꾸지 않는다. 크툴루 신화 세계관·원작 진실은 보존하지만 신규 PC의 수치형 신화 기능은 만들지 않는다. 실제 발견·지식은 [MYTHOS_KNOWLEDGE_FACTS](03-danger.md#mythos_knowledge_facts)를 따른다.

## INVESTIGATOR_DEPTH_PROTOCOL

플레이어의 기본정보/직업/외형 지정은 우선한다. **성별·이름·나이는 각기 선택 입력이며, 특성 A/B/C 선택과 같은 단계에서 제출한 값만 우선하고 공란인 필드만 그 단계 확정 때 생성한다.** 미지정 정보는 시대·문화·생활에 맞게 생성하고 이름은 현재 등장 인물과 혼동되지 않게 한다. 입력한 항목을 자동 생성값으로 덮어쓰거나 이미 확정된 PC의 세 항목을 재설정하지 않는다. 최소 이름 후보 수나 과거 이름 이력 추적은 없다.
공개 과거·현재 목적·실제 지위/책임·일상 관계로 그 세계에서 살아온 인물을 만든다. 신규 현지 PC마다 **원래의 인물상**으로 기존 생활에서 관찰된 말투·대인 태도/행동 습관 1~2가지, 중요한 관계·책임 또는 소중히 다룬 일 하나, 이를 뒷받침하는 짧은 과거 실제 사례를 준비한다. 플레이어가 정한 성격/과거가 있으면 우선하고, 제삼자의 평가와 본인이 아는 기억을 구별한다. 이 정보는 동기화 요원이 그 사람의 이전 삶을 이해하는 참고 자료이지 동기화 뒤의 감정·신념·판단/선택·말투를 강제하는 성격표가 아니다. 필수 과거 상처/민감 자극·캐릭터 태그 카탈로그·사건 공명 후보는 만들지 않는다. PC가 실제 아는 과거는 공개하고 모르는 외부 비밀은 구분한다. PC의 감정/도덕/장기 결심을 자동 확정하지 않는다. 선언된 경력·권한·소유는 선택에 필요한 구체성을 갖춘다.

PC의 그 과거/관계 때문에 실제로 아는 것·접근 가능한 사람/장소·현재 선택/책임과 최종 대응 수단 중 무엇이 달라지는지 같은 ref로 연결한다. 직업명과 죽은 동료 이름만 다른 조난자로 바꾸어도 모든 접근/갈등/결과가 같으면 연결을 보완한다. 새 감정·사명·가족사/트라우마를 강제로 만들거나 직업 때문에 그 선택을 하도록 정하지 않는다.

## STAT_DRAFT_GENERATION

- 각 A/B/C 안은 STR/CON/SIZ/DEX/APP/INT/POW/EDU 8개, 합계 400, 개별 30~80, 5단위다. 세 안을 같은 숫자 묶음의 재배열로 만들지 않는다.
- 각 안의 Luck은 별도 생성 난수로 20~80 정수 하나를 정한다. 400 합계·5단위 제약에 포함하지 않는다.
- 8특성의 모든 적격 순서 배열을 표본공간으로 하는 균등 bounded-composition sampler를 사용한다. 각 안과 Luck에 독립 generation seed/sub-seed를 사용한다. 직업·사건·게임플레이 난수를 입력으로 쓰지 않는다.
- 생성 후 개수·합계·범위·5단위·Luck 범위를 실제 검산한다. 8특성 배열이 다른 안과 같으면 해당 안만 독립 retry seed로 재생성한다. 수동 교환·직업 최적화로 수치를 조정하지 않는다.
- **A/B/C 능력치·Luck 후보를 보여주는 같은 선택 단계에 성별·이름·나이 3개 독립 선택 입력란**을 둔다. 이름·성별은 플레이어의 자유 기입값을 보존하고, 나이는 시대·인물의 실제 숫자 나이로 입력받되 적절한 범위가 모호하거나 형식이 잘못된 경우 해당 항목만 확인한다. 미입력/빈칸은 자동 생성 요청이며 각 항목을 다른 필드와 독립해 처리한다. A/B/C 선택·기본정보 동시 제출 전에는 생성 후보와 입력값을 보존하고, 확정 순간 미지정 필드만 원작·시대·문화에 맞게 자동 생성한다. 특성·Luck 후보 재추첨, 별도 이름/나이 선택 단계, 성별·이름·나이 때문에 추가 대기를 만들지 않는다.
- 플레이어가 한 안의 특성과 Luck을 함께 선택한다. A 특성+B Luck 혼합과 키퍼의 자동 선택은 불가하다.
- 선택이 확정된 뒤 직업 후보를 생성하고 [PC_DERIVED_STATS](04-setup.md#pc_derived_stats)로 파생값을 계산한다. Luck 20은 플레이 중 소비 하한이 아니다.


실제 Python에서 사용할 수 있는 균등 표본 함수다. 각 안의 독립 seeded rng를 인수로 주고 Luck은 별도 stream으로 생성한다.

```python
from functools import cache

@cache
def ways(n, total):
    if n == 0:
        return int(total == 0)
    if total < 0 or total > 10 * n:
        return 0
    return sum(ways(n - 1, total - x) for x in range(11))

def sample_stats(rng):
    total, values = 32, []  # 8*30 + 5*32 = 400
    for n in range(8, 0, -1):
        ticket = rng.randrange(ways(n, total))
        for x in range(11):
            count = ways(n - 1, total - x)
            if ticket < count:
                values.append(30 + 5*x)
                total -= x
                break
            ticket -= count
    return values
```

## PC_DERIVED_STATS

확정된 8특성에서 계산한다. 생성 뒤 파생값의 공식으로 기존 특성을 바꾸지 않는다.
- **신규 생성 PC의 시작/현재/최대 HP** = floor((최종 CON+최종 SIZ)/10)+2. 영구 카드·성장 ON에서는 실제 확정된 적용 CON/SIZ를 사용하고, PC 최초 생성에 단 한 번 반영한다. 기존 확정 PC·NPC·적·동물에는 소급 적용하지 않는다. 실제 피해·중상·치료·사망은 [HP_AND_DEATH](02-checks.md#hp_and_death)를 따른다.
- initial/current/base max SAN은 [SAN_CORE](03-danger.md#san_core)의 **신규 PC 산식** `max(50,min(99,floor(60+0.4×(최종 POW−50))))`을 적용한다. 이 SAN 산식 자체는 POW/DB/Build/MOV를 변경하지 않으며, 신규 PC HP +2는 위 HP 산식에서만 따로 처리한다. 구판 확정 PC는 비소급이다.
- DB/Build는 [DAMAGE_BONUS_AND_BUILD](02-checks.md#damage_bonus_and_build) 표를 사용한다.
- MOV=8. DEX≥70이면 9, DEX≤40이면 7. 이 MOV는 기존 하우스룰이다.
- Luck은 선택한 특성 안에 붙은 20~80 생성값이다.
- 시작 기능은 [PC_SKILL_START_VALUES](04-setup.md#pc_skill_start_values)를 적용한다. 신규 PC에는 수치형 크툴루 신화 기능 자체를 생성하지 않는다.

## PC_APPEARANCE_FROM_APP

선택한 APP와 **같은 특성 선택 단계에서 확정한 성별·이름·나이**, 지정 외형·문화·직업·시대를 반영해 구체 외형을 확정한다. 배우 레퍼런스 1명은 필수이며 직접 지정이 없으면 알맞게 선정한다. 별도 배우 추첨축과 APP 구간별 상세 묘사표는 없다.
자동 외형/배우는 APP가 확정된 뒤 정한다. 외형을 맞추려고 특성을 재굴리거나 지정된 핵심 인종/성별/나이 등을 바꾸지 않는다. 배우의 성격/배역을 PC 성격으로 복사하지 않는다. APP는 첫인상의 근거이지 자동 호감/도덕성/설득 성공이 아니다. 이후 그림은 같은 외형과 실제 변화만 유지한다.

## PROFESSION_DRAFT

특성/기본정보 동일 단계 확정 뒤 원작 시대·문화에 실제 성립하는 직업 A~F 6개를 만든다. A/B는 원작 테마 맞춤 2개로 각각 원작 대표 기관/사건과 또 다른 생활·사회/산업 측면을 경험하게 한다. C 전투·방어 1개, D 조사/분석 1개, E 범죄/잠입·비공식 거래 1개, F 의외지만 실제 활용 가치가 있는 조커 1개로 구성한다. 조커가 반드시 무능하거나 우스꽝스러운 직업일 필요는 없다.
 각 후보의 직업명·배경/실제 업무·직업 기능7개/배정 수치(**60 / 55 / 50 / 45 / 40 / 35 / 30**)·대표 강점·원작 세계에서 가능한 활동과 접근 기회를 선택 전에 공개한다. 핵심 역할을 차별화하되 직업상 자연스러운 전투·조사·사회 기능의 중복은 허용하고 모든 후보에 같은 시작 기능 총량을 적용한다. 숨겨진 진실·보장되지 않은 인맥이나 무료 물품을 후보 설명에 추가하지 않는다.
 플레이어가 직업을 직접 지정하면 우선한다. 기존 확정 직업은 보존한다. 산업/세부업무/지위/근무환경/경력은 필요할 때 참고하며 다단계 의무 추첨하지 않는다. 특성이 직업명을 자동 결정하지 않는다. 별도 전문 분야는 부활시키지 않고 직업 확정 뒤 STARTING_EQUIPMENT_MINIMAL의 필수 물품 정확히1개를 정한다.

## PC_SKILL_START_VALUES

**신규 생성 또는 미확정 PC만:** 실제 업무·책임·훈련에서 서로 다른 직업 기능7개를 도출하고**60 / 55 / 50 / 45 / 40 / 35 / 30**을 한 번씩 배치한다. 6개 직업 후보 모두 이 수치 기준을 사용하며 선택 전에 각 기능의 실제 배정값을 공개한다. 기존 확정 PC의 직업/기능·성장 스냅샷과 세이브에는 하향 수치를 소급 적용하지 않는다. 업무 축 개수나 선택 전 수치 비공개는 강제하지 않는다.
겹치지 않는 일반 취미 기능1개를 직업 확정 뒤 고르고**30**으로 배정한다. 기존 확정 취미 기능 40 및 현재/영구 성장값은 소급 변경하지 않는다. 그 외 일반 기본20, 회피는 floor(DEX/2), 모국어는 EDU이며 별도 전문 분야 슬롯은 생성하지 않는다. 회피가 직업/취미면 max(해당 배정값,floor(DEX/2)). 관찰·듣기·회피·격투·사격을 공통 표시한다.
직업 기능 7개·취미 기능 1개, 그 외 일반 기본20, 회피 floor(DEX/2), 모국어 EDU, 회피 및 타 기능의 기존 max 예외는 그대로 유지한다. 위 60/55/50/45/40/35/30과 취미30은 **새 PC 시작 기능 배정값**이며 직업 후보의 강점이나 이미 학습한 기능을 지우는 규칙이 아니다.
외국어는 구체 언어를 명시한 일반 기능이다. 크툴루 신화는 세계관·발견 사실로만 기록하고 신규 PC 기능 목록·직업/취미 후보·성장 목록에 수치를 만들지 않는다. 이미 이해한 약점/진실은 원천·공개 범위와 함께 보존한다. 포괄적인 직감/통찰/위험감지/대인관계 등 새 만능 기능을 만들지 않는다. NPC 범위를 PC에게 적용하지 않는다.

## STARTING_EQUIPMENT_MINIMAL

신규 PC는 실제 시대·직업·담당 업무를 수행하는 데 필요한 **직업 관련 필수 물품 정확히 1개**만 **직업 기본 지급분으로** 시작 인벤토리에 가진다. 선택해 장착한 영구 카드 **자산은 이 직업 기본 지급분과 다른 별도 캠페인 시작 1회 실물 지급**이며 CARD_EQUIP_AND_ASSET에 따라 소지 상태에 기록한다. 장비의 명칭·통상 기능·실제 소지 이유·소유자·사용 조건·메인/파우치 점유를 확정한다. 생존에 유리한 만능 물품보다 해당 직업에서 실제로 당장 사용할 수 있는 물품을 우선한다. 필요하면 직업 선택 뒤 이 1개를 구체화하되 무작위 장비 꾸러미는 만들지 않는다.
한 개는 물리적으로 하나인 물품이며, 별개로 사용할 수 있는 여러 도구가 든 키트·세트·추가 파우치 묶음이나 공짜 보조 무기/탄약/의약품/통신기/서류를 끼워 넣지 않는다. 일체형 구조와 실제 장착된 최소 작동 요소만 그 물품에 포함하고, 소모성 자원은 실제 수량을 기록하며 예비품은 주지 않는다. 통상 복식·이미 가진 직업 지식·법적 지위를 별도 무료 장비로 둔갑시키지 않는다. 물품이 메인/파우치에 들어가면 INVENTORY의 일반 점유 규칙을 적용하고, 빈 슬롯에 가상 기본 물품을 채우지 않는다.
나머지 장비는 게임 내 발견·파밍·탐색·구매·거래·대여·수리·제작·타인과 협력하는 등의 실제 행동과 소유/위치/대가를 통해 정상적인 획득으로 확보한다. 시나리오는 쓸 만한 도구의 실제 원래 용도·소유자/장소·접근 경로와 유용함을 준비하되 특정 장비를 무료 지급하거나 단일 필수 아이템 파밍으로 생존/해결을 잠그지 않는다. 장비 없이 시도할 수 있는 우회·도움·철수도 유지한다.
전문 분야 A/B/C 선택과 별도 전문성 성장·상시 보너스는 신규 PC에 만들지 않는다. 직업 업무와 전문 자격·상식의 범위는 실제 경력·훈련·직업 기능·접근/장비에서 판단하고 불확실한 수행은 FICTION_FIRST_ROLL_TRIGGER_GATE로 처리한다. 기존 캠페인의 이미 확정된 직업·물품·전문성 및 저장 원문은 소급 삭제/재배치하지 않는다.

## FINAL_INVESTIGATOR_PROFILE_OUTPUT_CONTRACT

확정 프로필은 PC identity·이름/나이/성별/문화·직업/실제 지위·공개 과거/목적·원래의 말투/생활 습관·관계와 근거 사례·APP 반영 외형과 배우 레퍼런스·8특성·모든 확정 기능/취미·HP/SAN/Luck/MOV/DB/Build·현금·실제 시작 장비/슬롯을 포함한다. PC가 아는 과거를 비밀로 숨기지 않는다. 미확정 감정·관계·사건 해법은 넣지 않는다.
서식/순서/코드블록/문장 수는 강제하지 않고 보관 가능한 읽기 자료로 제공한다. 전원 공개 프로필은 플레이어가 열람할 자료이며 극중 PC의 자동 지식 공유·물리적 만남·우정·동행을 만들지 않는다. 신규 직업 기본 지급분은 STARTING_EQUIPMENT_MINIMAL의 1개이며 ON의 별도 장착 카드 자산을 포함한 실제 시작 소지품·점유도 빠짐없이 기록한다. 무료0칸 직업 소품을 추가하지 않는다. 프로필 이미지의 수치 오자는 확정 텍스트를 바꾸지 않는다.

프로필의 Luck은 실제 현재값만 표시한다. 현재값/가짜 최대값 표기를 만들지 않고 공개 프로필·소지품·첫 위치는 STATE_CANON_SAVE_BINDING의 동일 최초 작업 상태에서 투영한다.

## STORY_SCALE

신규 선택은 MAJOR_INCIDENT(대사건) / CHRONICLE(연대기)다. 명시적으로 선택받고 미입력을 작은 사건으로 채우지 않는다.
대사건: 연결된 사람·장소·기관/세력·공동체에 중대한 영향을 미치는 하나의 중심 갈등과 결정적 해결/탈출. 연대기: 지속 세계와 현재 챕터를 만들고 앞 챕터의 실제 결과가 다음 챕터의 세력·관계·지역·위협 조건을 바꾼다. 전체 회차/턴 상한은 없다.
스케일은 영향권·적의 실행력·파급·숨은 진실·실패 손실·해결의 무게로 구현한다. 장소·왕복·문서·군단·분 단위 시한을 늘리는 방식으로 대신하지 않는다. 평범한 PC도 큰 사건의 당사자가 될 수 있다. 기존 INCIDENT 세이브는 구판 범위로 보존하고 숫자/enum을 조용히 재해석하지 않는다.

## FULL_DIVE_CROSS_ANALYSIS

원작의 존재론·핵심 갈등·시대/생활·공간/미학·인물/사회·위협 작동·발견/대응/실패의 문법을 파악한다. 선택된 정확한 원작 단위의 공식 시나리오 본문·공식 설정·신뢰할 출처를 세계 생성 전에 실제로 확인한다. 작품 제목·장르·기억·요약 인상만으로 원작을 안다고 간주하지 않는다. 우선 공식 원문/배포사 자료, 그다음 확인 가능한 신뢰 출처를 대조하고, 핵심 서사가 확인되지 않으면 추측한 독립 사건으로 대체하거나 정본 확정을 완료 처리하지 않는다. 원작 사실·추가 각색·접근 불가/미확인 사실을 구분한다. 특징 개수나 세계 법칙 최소 개수는 없다.
산출물은 원작 요소→이번 세계의 실제 인물/공간/위협/물건→PC의 접촉/선택→결과/후속 국면으로 연결한다. 모든 요소를 설명문에만 두거나 같은 범용 창고/문서 조사로 번역하지 않는다. 다른 원작에 일률적인 교단/신격을 덧씌우지 않는다. 원작의 주요 사건·발생 이유·적의 목적·핵심 참극/위험·출발 상황과 생존 갈등은 기본 뼈대로 보존하되, 신규 G·필수 진실·최종 봉쇄에 필요한 제한적 변주는 기조와 상징적 체험을 유지하는 범위에서 허용한다. 원작의 정수와 테마에서 실제 필요한 세계 법칙을 도출한다. 기술·사회·환경·초자연 모두 가능하며 고정 개수는 없다. 법칙별 적용 조건·효과·한계/예외·감지 가능한 현상·차단·회피/대응을 정한다. 플레이어는 현상과 단서·실험·실패 결과로 체득한다. 이미 확정·검증한 법칙을 난이도 조절을 위해 바꾸지 않는다.
중요한 변화는 어떤 기존 상태/원인이 성립하면 어느 범위의 공간·접근·위해·사람/정보 전달이 달라지고 무엇은 유지되는지 정한다. ‘전환될 때 전환한다’처럼 조건을 되풀이하거나 필요할 때 길/능력을 바꾸는 설명은 운영 기준이 아니다. 원작의 설명 불가능한 공포는 남길 수 있지만 키퍼가 적용할 조건/범위·관측·대응은 일관돼야 한다. 모든 초자연 현상을 인공 스위치·정밀 시간표·해독 문제로 바꾸지 않는다.

## WORLD_PC_INPUT

**PC-원작 연결의 실질 인과(신규 세계·미확정 챕터):** P1~PN 각자의 확정 직업·생활·과거/현재 관계·책임/실물 중 실제 존재하는 출발 사실을 원작의 **특정 중심 원인·대표 적/인물·사건·장소/물건 ref**와 연결한다. 각 PC에게 적어도 하나의 고유한 인과선을 마련한다: 누가/무엇이 이미 그 PC의 생활·보호 대상·책임·현장 수단과 충돌하는가 → 어떤 NPC/현상/전조가 실제 위치·지식·수단으로 접촉하는가 → 관측 전 숨은 관계와 PC가 원래 아는 사실은 어떻게 다른가 → 발견·회피·교섭·구조·차단·철수에서 **그 PC의 관계/책임 때문에 상대의 행동·선택 가능한 수단·안전/손실/결말이 어떻게 달라지는가**. 직업 기능이 단서 판정에 유리하거나 출발 장소에 우연히 있었다는 설명만으로 개인 인과선이 완성되지 않는다. 원작 세계 사건은 PC 수락 없이도 독립 진행한다.
**숨은 연결과 발견의 작동:** 숨은 인과는 시작 전 HIDDEN_TRUTH/PC_CONNECTIONS의 실제 ref로 선확정하고 NPC_BASELINES/LOCATION_BASELINES/DRIVER_BASELINES의 관측자·지식 출처·접촉 경로·변할 결과에 연결한다. 모든 PC에게 필수 비밀 혈연·죄·계약·기억상실을 부여할 필요는 없다. 숨은 의미가 과거가 아니라 **현재 원작 인물·물건·위험과 이미 가진 관계/책임의 새로운 해석**이어도 된다. 발견이 실제 신뢰·전술·사람의 안전·대응·결말에 차이를 만들어야 하며 미발견 비밀은 PC/NPC에게 자동 공개하지 않는다.
**PC-원작 연결의 대체 가능성 반례:** 같은 위치·장비만 가진 무관한 여행자로 PC를 바꾸어도 원작 적/NPC의 접근·관계/대응·사건 결과와 할 수 있는 판단이 사실상 같고 **직업 기능·이름·발견 대사만 달라진다면 생성 실패**다. 본인의 기존 책임·관계·실물 자원·원작 인물과의 이해충돌처럼 원작 특유의 인과를 사용하되 플레이어에게 새 과거를 강제하지 않는다. 첫 위기 예방/거절/우회 뒤의 접점도 기존 세계 원인/전달 경로에서 성립하거나 정당한 안전·종결이어야 한다. 사후 추적/강제 사고로 빈틈을 메우지 않는다.
**주도권·다인·비소급:** 플레이어가 정한 설정·기억·행동·감정·호감·수락과 과거의 미선언 행위는 덮어쓰지 않는다. 아직 형성되지 않은 관계를 억지로 소중한 사람으로 만들거나 남을 도덕적 의무를 부과하지 않는다. 2~3인 PC는 서로 다른 개인 인과·정보·출발을 가지되 같은 중심 위기에 영향을 줄 현실적 연결을 두고 **물리적 합류·신뢰를 강요하지 않는다**. 자동 정보 공유도 금지한다. 기존 검증 정본/세이브는 비소급이다.

## ORGANIC_SKILL_INTEGRATION

세계 확정 전 각 PC의 직업 기능·취미·실제 경력이 고유한 행동·성과를 만들 실제 기회를 장소/시설/인물/경로/위협과 연결한다. 필요한 자격·도구·가능한 작업·바꿀 결과·실패/부재 때의 다른 진행을 고려한다. 시작 장비 1개 외의 도구를 실제 장소·사람·자원에서 얻을 선택과 우회를 연결하되 무료 장비를 보충하지 않는다. 판정 수치만 높게 쓰는 같은 조사로 끝내지 않는다.

이미 확정된 세계에서는 타당한 새 활용을 인정하되 성공시키려고 과거/약점/전용 도구를 소급 발명하지 않는다. 성공으로 바뀐 접근·시설·구조·안전·협력은 유지한다.

## HARM_ECOLOGY

신규 위협의 외형·위치·등급만으로 설계를 마치지 않는다. 원작에 맞는 실제 생존/공포 대응을 초기 생활·이동/교류·탐험/구조·중간 E·최종 대응/탈출에 준비한다. 각 위협 ref에는 원래 원인/개체·목표/위치·감지/접근/노출 경로·관측 전조·방어/우회/협력/퇴각·공격/피해식·SAN 적격 내용/Tier·상태/치료·발동/차단·실패/미개입 여파를 연결한다. 실제 HP/SAN·중상·PC 구조형 HP0/게임 오버·비PC 사망은 02/03 담당 수치를 그대로 사용한다. 원작 적의 성공 단계 조건부 고유 능력은 일반 Hard/Extreme 추가 피해와 구별해 능력 ref·발동/피해식·지속/해제·실제 대응과 공통 전투 규칙의 관계를 사전 확정한다. ‘충돌 시 담당 규칙 우선’이라고만 쓰고 실제 효과를 미정으로 남기지 않으며 기존 01/100 서술 재량·자동 추가 피해 금지를 유지한 프로필로 대조한다.
**소수 적의 장기적 능동 압박:** 살아 있는 소수 적도 원래 목표·경유/감지/정보·시간/수단으로 수색/추적·퇴로 압박을 한다. 정당한 은폐·감지 단절·사살/포획은 인정한다. 부족한 압박은 시작 전 초기 전력/사전 적 풀·예비 인과로 준비하고 풀 조건 없는 증원·텔레파시 재탐지·부활을 금지한다. 소수라는 표현은 전력 상한이 아니다. SCENARIO_BLUEPRINT의 추적·경비·배회 전 기능과 지속 압박이 부족하면 추가 인간/생물 등 원작에 맞는 적 전력을 시작 전에 보강한다. 전원이 함께 있어도 실효 위협이 있고 1인도 관측/대응 가능한 경로가 있어야 한다.
주요 E 위기의 발생 보장과 개별 피해는 다르다. 실제 공격·환경 위해·참극/변형·신체 침해·비정상 현실/진실의 적격 노출이 닿으면 판정/대응을 받고 결과를 적용한다. 경고만 반복하거나 최종전까지 SAN을 미루지 않고, 단순 긴장·같은 노출 반복·출구 통행료 같은 고정 HP/SAN 차감은 없다. 피해·광기·감염·사망을 대상/횟수로 할당하지 않는다.
부상·정신 상태·물품/퇴로·NPC 사상과 협력이 이후 행동을 바꾸고 실제 치료/구조·안식·국지 안전의 수단/한계가 있어야 한다. 조기 적 격퇴/피해 0은 유지하지만 전체 종결은 모든 E 뒤 최종 대응과 탈출 조건을 따른다. 최종 대응 전에 무료 전체 철수가 가능한 배치는 불합격이다.

**위해와 생존 수단의 같은 수준 구체화:** 경로를 좌우하는 해상/낙상·화재/접안 등 위해는 실제 노출→대응 가능한 수단/판정→성공/실패 시 피해식·상태/장비 손실→중단/구조 조건을 확정한다. 02/03의 공통식이 정확히 해당하면 그 ref와 실제 노출 조건을 쓰고, ‘위험함/상황에 따라 관련 규칙’만으로 피해/손실을 비워 두지 않는다. 이동·수리/연락·구조자의 출발/접근에는 실제 거리/수단/조건·물리 소요의 근거를 둔다. 고정 E 개시 시간표와 구별하며 장면 분량 때문에 구조를 미루거나 시간을 정지하지 않는다.
선택한 PC의 실제 수치·탄약/방호·노출/독 저항과 의료품·안전 장소·비전투 치료/중상 해제·우회/차단·NPC 도움의 접근을 함께 대조한다. 의료품은 종류/수량·소유/위치·획득/사용 조건으로 준비하고 희소/접근 곤란이면 그 사실과 실제 다른 대응을 둔다. 치료를 무조건 지급하거나 모든 위협을 정면전으로 이길 수 있게 하라는 뜻이 아니다. 필요한 수단이 전혀 없는 필연 사망/단일 극단 성공 의존을 보완하며, 사후 PC 재추첨·몰래 적 약화/부활·자동 NPC 구조로 덮지 않는다. 1인 HP0와 SAN0 뒤 가능한 계속 진행은 DEATH_AND_INHERITANCE를 먼저 판정한다.

## CAUSAL_ENDGAME_PRECOMMIT

G의 최초 불가역 원인·피해는 PC 첫 행동 전에 확정한다. 이후 주요 E 위기는 시작 정본의 실제 독립 원인·유한 예비 경로로 발생을 보장하되 개별 공격/손실은 방어·구조로 0까지 줄일 수 있다. 사후 새 원인·불사 보스·피해 복구로 필연성을 만들지 않는다.
모든 E를 참가 PC 전원이 현장에서 직접 체험한 뒤 최종 국면으로 이어지는 경로·필수 선행 인과를 처음부터 완성한다. 조기 종결은 없다. 최종 대응자가 이해해야 할 핵심 HIDDEN_TRUTH·복수 발견 경로·그 정보로 사용할 자원/봉쇄 해제·탈출 위험과 안전 경계를 ENDING_CONDITIONS에 연결한다. 국지 피난/안전과 전체 위험권 탈출은 다르다. 기존 verified 종결·안전·정본에는 소급하지 않는다.

## COMPATIBILITY_GATE

신규 캠페인/미확정 챕터 확정 전 한 번, 관련 실제 결함 발견 때 해당 연결만 대조한다. 아래는 SCENARIO_BLUEPRINT의 생성 조건을 반복 작성하는 별도 정본이 아니라 실제 ref로 확인할 실패 반례다. 미래 PC 선택/주사위·가상 사망자를 미리 실행하거나 매 턴 검수표/DB 전수조회·새 검사 엔진을 만들지 않는다.
1. **원작 출처·중심 인과 역검증:** 공식 Source Unit의 중심 원인·적 목적·공포/생활·실제 조우와 추가 전력·방/자원·기록 내용이 정본에 보존됐는가. 이름/괴물 외형만 남은 범용 수사·시설 수리, 조우 권고 2개체를 세계 총량으로 오해한 축약은 실패다. 각색/미확인을 공식 사실로 꾸미지 않는다.
2. **불가역 G·필연 E·최종 순서:** 첫 입력 전 G의 되돌릴 수 없는 인과, 모든 E의 실제 위기 발생·예비 실행 조건, 참가 PC 전원 현장 직접 체험 뒤에만 최종 국면이 성립하는가. 한 번의 경고/사살로 G와 후속 E를 전부 취소하거나 조기 종결, 최종 국면 중 미체험 E 잔존, 원격 지원/뉴스를 E 체험으로 계산하면 실패다.
3. **PC별 깊은 원작 연결:** 확정 생활·관계/보호 대상·책임·생존→원작 중심 위험→서로 다른 관측/진실 발견→대응/결말이 같은 ref로 이어지는가. 이름/직업 기능·동료 사망 한 줄만 바꾸어도 같은 사건이면 WORLD_PC_INPUT의 대체 가능성 반례에서 실패다. 새 가족사·감정/조사 수락을 강제하지 않는다.
4. **주요 E의 실제 깊이:** E를 제거/합병해도 갈등·보호 대상·위험·상태 전이·후속 대응/최종 결산이 같으면 하위 작업/배경으로 분류한다. 수리/서류 한 단계·동일 전투 반복·사후 결산으로 E/S 수를 채우지 않는다. 고정 E/S 수량·적 5종·첫 E 턴 제한은 없다.
5. **결과별 경로·상태 실행 증명:** 정상 업무·집중 탐험·구조·귀가/우회·조사 거절·분리/도움 요청·빠른 격퇴의 대표 경로에서 현재 실제 정보/위치/소유→인지자/목적→전달/이동 매체·통로/장애/소요→관측/현장 대응→다음 상태를 추적한다. 죽은 발신자·고장 수신기·단일 물건 이중 위치·미등록 ref·PC 자동 정보 공유/합류·미선언 방문을 운반자로 쓰면 실패다. 별칭은 LOCATION에 정식 ID로 연결한다.
6. **전원 현장 체험과 주도권:** 실제 위치·접근/이동·위기 지속과 관측/대응 기회로 모든 참가 PC가 각 E를 직접 겪을 수 있는가. 타 PC가 오기 전에 세계 사건이 소진되는 배치, 무관한 방문 순례·강제 이동/수락·상대 위치 텔레파시로 체험을 채우면 실패다. 실제 세계 진행/이미 얻은 안전·사살을 멈추거나 취소하지 않는다. 인계 뒤 새 PC에게 과거 경험을 복제하지 않는다.
7. **1~3인 실효 위협·NPC 자율성:** 확정 HP/SAN·기능·장비/탄약·의료품/엄폐·자율 NPC의 동의로 전원 결집/단독/PC+NPC 분리·전투 없는 회피를 대조한다. 적이 PC 방문 전에는 움직이지 않음, 1인 무조건 처형, 결집하면 모든 위협 소멸, 분리 뒤 자동 증원/페널티·전원 배신/무조건 명령 복종이면 실패다. NPC의 실제 거절·합의 이행·독립 구조와 실제 사망/1회 인계를 따른다.
8. **원작 적/풀의 실행:** 원래 감지/위치·수색 실패/정보 획득·부상/퇴각 뒤 다음 행동·추적 포기와 대응이 구체적인가. 사전 풀의 근원/수량/시간/발동/차단 없이 생성, 사후 예비 실행자·새 능력, 죽은 적 복귀·자동 도주는 실패다. 필연 E를 보장할 인과는 시작 전에만 준비한다.
9. **생활·독립 S와 물리 시간:** 정상 경로에서 짧은 생활과 깊은 독립 S가 실제 접촉·거절/미개입·자율 결과/다른 재회로 열리는가. 같은 의뢰 재포장, 화면 밖 목록만 있음, S가 E/필수 보상의 유일 관문, 기관 도착 대기만 남음, 정상 탐험으로 모든 유효 경험이 소진되면 실패다. 새 E 시간표·전 사건 종료+유예와 실제 시작된 이동/작업/침수 속도를 구별한다.
10. **공포·진실·최종 행동의 의미:** 앞선 현상/관계·핵심 진실의 발견 전후 실제 판단·대응/위험·대가가 달라지고 쌓은 준비·관계가 최종 현장에서 쓰이는가. 기술 절차와 끝의 설명만 상세함·전문가 단독 해결·한 굴림 결산·필수 반전/희생은 실패다. 실제 최종 대응자가 진실을 이해하고 실행하면 충분하며 PC 감정을 대필하지 않는다.
11. **정본·판본·저장:** 같은 정식 entity/ref·규칙 배포 식별자·원문 SHA·누적 상태/실제 검증과 공개 범위가 연결되는가. 원격 확인 없이 pending을 저장 완료로 표시하거나 새 서버 컬럼/권한으로 우회하면 실패다. 실제 저장 실패·AI 서사 적용/재개 품질은 정적 대조 합격과 별개로 보고한다.
기존 캠페인/verified 세이브는 신규 생성이 아니다. 이미 확정한 규칙판·정본·손실/안전·구판 시계/종결을 이 검토로 덮거나 확장하지 않는다. 원작 체험의 깊이와 운용 가능한 조건을 함께 대조하되 무한 분기·고정 플레이 길이·의무 체크리스트를 요구하지 않는다.

**대조 대상과 통과 근거:** 실제 작성된 정본 초안·최초 작업 상태의 위치/값·정식 ref를 읽고 위 반례에 답한다. ‘전원 체험한다·경비를 둔다·치료 수단을 준비한다·진실이 필요하다’는 지시/자기 평가만 있고 해당 개체/장소/수단/상태가 없으면 미완료다. 준비 원칙을 다른 절에 복사해서 빈 사실을 채운 것으로 보지 않는다.
정상 생활/탐험, 수사 거부·즉시 이탈, 초기 적/실행자 전부 조기 제압, 주요 수리/통신 실패, 동행 NPC 거절/이탈·PC 종료/인계의 대표 경로를 기존 인과에서 추적한다. 각 경로는 현재 실제 위치/정보/소유→선택 가능한 시도→성공/실패의 다른 상태→도달 가능한 다음 접점/실제 실패를 보여야 한다. 미래 PC 선택·난수/피해·인계 수락을 확정하지 않는다. 첫 위치의 파일 간 상충, 추적/경비/배회 중 이름만 있는 역할·모두 같은 1개체, 핵심 자원 이중 위치/미확정 수량, 위협만 있고 실제 대응/회복 접근이 없음, 마지막 E=최종의 중복 행동, 모든 적 제거 뒤 근거 없는 진실 정답 요구, 인계 전 전멸 확정이면 관련 본문을 보완한 뒤 해당 경로를 다시 대조한다. 숨겨야 할 정본/검토표를 일반 플레이에 출력하거나 매 응답 전수 검수하지 않는다.
