## START_SETTINGS_GATE

적용: 신규 게임. **START_GAME.md가 진입점이며, 요원 활성화 ON/OFF 선택으로 첫 화면을 분기**한다. 이 선택은 기존 영구 카드·성장 ON/OFF를 본부 기능까지 확장한 것이다. **ON은 본부+기존 카드·성장 전체**, **OFF는 기존 일반 TRPG(본부와 카드·영구 성장 없음)**다. 기존 캠페인의 확정 모드·세이브·카드 원장은 소급 변경하지 않는다.

**첫 화면 공통:** 요원 활성화 ON/OFF(미입력 기본 ON), 참가 인원 1~3명. **ON이면 참가자 슬롯별 고유 영구 닉네임(P1~PN, 2~24자)까지만** 받고, 최초 신입이면 **본부 외부 프롤로그와 '본부 입장' 입력 대기**를 먼저 진행한다. 실제 입장 선언 전에는 내부 장면을 출력하지 않는다. **원작 인지도·이야기 규모·배제할 세계관·직접 지정 원작/장르/시대는 여기서 묻지 않는다.** 본부 작전실에서 팀이 실제 임무를 정할 때 기존 항목으로 입력받는다. **OFF라면 첫 화면에서 기존대로 원작 인지도(메이저/기본/마이너)·규모(대사건/연대기), 선택 사항인 배제/직접 지정 세계관/시대를 받는다.** OFF는 카드 닉네임/UUID/장착/효과·성장·보상 RPC를 요구하지 않고 기존 일반 PC 생성으로 진행한다.

**ON에서 실제 최초 입장:** 인원/닉네임 유효성 확정 뒤 현재 선택한 환경에서 검증된 권한 있는 본부 함수로 기존 영구 UUID/실제 입단 이력을 확인한다. 새 요원은 **HQ_FIRST_ENTRY_SCENE_GATE의 본부 외부 프롤로그와 실제 입장 선택을 먼저 거친 뒤** 제이든 안내·실제 입단식·마틴 면담을 진행하고, 기존 입단 요원의 **새** ON 게임은 동기화실에서 시작한다. 본부에서는 파티 전원이 함께 이동하되 각자의 발언/선택/관계는 독립이다. 진행 중인 현지 V2 저장을 명시적으로 불러오면 **본부 입장 절차가 아니라 STATE_RESUME에 따라 같은 현지 세이브에서 시작**한다. 닉네임/카드 보유량만으로 최초 입단/경력 여부를 추정하지 않는다.

**공통 저장값:** ON이면 permanent_cards_enabled=true 및 permanent_growth_enabled=true, OFF면 둘 다 false를 CANON_INDEX·실제 동적 체크포인트에 기록한다. 본부 활성화/임무 연결은 별도 영구 본부 원장의 책임이고 현지 모드의 소급 변경이 아니다. ON이라도 첫 설정 화면을 열거나 인원/닉네임을 수정하는 동안 카드 가입·임의 입단 이력·장착을 실행하지 않는다. P1~PN의 유효한 닉네임(앞뒤 공백/대소문자만 다른 중복 금지)을 확정한 이후에만 UUID에 연결하며, 기존 원작 현지 PC의 이름과 혼동하지 않는다.

선택 입력의 공란은 기존 일반 게임 규칙대로 없음으로 처리하고 이미 유효한 부분 응답은 유지한다.
**단계·유효 입력 보존:** 미확정 조건에 의존하는 본부 입단·원작/규모 결정·현지 PC 생성·카드 장착·출격은 실제 해당 입력과 검증을 받을 때까지 확정하지 않는다. 이후 부분 응답에서 이미 확정한 모드·인원·유효 닉네임·생성 후보·시드는 보존하고, 미선언 동의/행동·원래 선택의 자동 변경을 만들지 않는다. PC 사전 관계를 별도 필수 입력으로 추가하지 않는다. 참가 인원만 받은 숫자를 인지도/규모로 복사하거나 참가자 수를 자동 2명으로 확정하지 않는다. 시작 시드는 기존 Python SystemRandom 1~100 자동 생성·기록 규칙을 유지하되 **ON에서는 실제 현지 캠페인/원작 설정을 시작하는 작전실 단계**에서 사용한다. 핵심/시작 시드 숫자를 플레이어에게 입력받지 않는다. 게임 시작 설정의 입력 자체는 출격 선언이 아니며, 실제 플레이어 행동/시간/보상을 자동 확정하지 않는다.

**연결 경계:** ON 본부 준비와 이후 현지 생성은 아래 HQ_ON_CAMPAIGN_ROUTER 및 CAMPAIGN_SETUP_PIPELINE을 따르고, 실제 원작 시스템(00~09)을 단축·대체하지 않는다. 등록/이력/정본/체크포인트 DB 호출이 불가능하면 성공으로 가장하지 않고 해당 영속 처리만 보류·고지한다. OFF는 이 본부 연결 절을 건너뛴다.
## SETUP_UI_FIXED_CONTRACT

**신규 최초 설정 UI의 단일 정본:** 아래의 첫 설정 화면 고정 UX를 기존 카드 UI나 과거 게임 시작 화면보다 먼저 적용한다. START_GAME.md의 HQ_START_UI_CONTRACT와 동일한 입력 구조를 사용하며, 본부 OFF가 기존 일반 게임을 의미한다. 화면에 `영구 카드 및 성장 시스템 ON/OFF`라는 독립 항목을 표시하거나 ON인데 규모/인지도를 함께 묻지 않는다.

실제 입력 도구가 있으면 사용하고 없거나 실패하면 동일 항목을 일반 채팅으로 받는다. 별도 전환 승인이나 기능 설명을 매번 요구하지 않는다. 코드/그림/HTML을 입력 위젯으로 가장하지 않는다.
**첫 설정 화면 고정 UX — 기존 영구 카드 토글 화면 폐기:** `게임 시작`을 입력하면 **한 화면에서 동적 입력**을 제공한다. 게임 시작 화면의 **1번 필드는 반드시 `시간요원 본부`의 `ON / OFF`**로 표시한다. 예전 `영구 카드 및 성장 시스템 ON/OFF` 필드를 **보이지 않게 하고 별도 토글로 추가하지 않는다**. 내부적으로만 ON=본부+기존 영구 카드·성장, OFF=본부도 카드·성장도 없는 기존 일반 TRPG로 매핑한다. `2. 플레이어 인원`은 두 모드에서 모두 1명/2명/3명 중 선택하는 한 화면의 세그먼트/라디오다. **ON이면 `3. 플레이어 닉네임` 아래 P1~PN(현재 선택 인원과 동일한 개수)의 독립된 닉네임 입력칸을 즉시 열고, 여기서 화면이 끝난다.** 예컨대 ON+1명은 P1만, ON+2명은 P1/P2, ON+3명은 P1/P2/P3를 표시한다. **ON일 때 캠페인 규모·원작 인지도·배제/지정 세계관은 첫 설정 화면에 절대 표시하지 않는다; 최초 방문/입단 후 본부 작전실에서 선택한다.** **OFF이면 닉네임 입력칸을 숨기고 `3. 캠페인 규모`(대사건/연대기)·`4. 원작 인지도`(메이저/기본/마이너) 및 기존 선택형 배제 세계관·직접 지정 원작/장르/시대를 표시**한다. OFF에서는 별도 영구 카드 토글·가입/장착·본부/영구 닉네임 입력이 없다. **두 모드의 화면 최하단 제출 버튼 라벨은 정확히 `게임 시작`**이다(`설정 확정하고 다음 단계로`·`영구 카드 ON` 등 과거 라벨 폐기). 이 버튼을 누를 때만 유효성 검증과 모드별 다음 단계로 진행한다. 기존 스크린샷과 같이 하나의 카드/폼 안에서 번호별 섹션·라디오/세그먼트·입력칸·최하단 버튼을 제공하며, 가능한 경우 클라이언트의 실제 상호작용하는 동적 폼을 사용한다. **ON/OFF·인원 변경은 제출 이전에도 동일 화면에서 즉시 UI가 변해야** 하며, 별도 메시지·닉네임 수집 단계·상태 안내문으로 대체하지 않는다. UI 불가 환경에서는 같은 항목을 한 번의 채팅으로 수집하지만 가짜 작동 버튼을 만들지 않는다.
**닉네임 검증:** ON의 현재 P1~PN 각각 직접 입력한 닉네임은 2~24자·빈칸 불가이며, 앞뒤 공백을 제외하고 대소문자를 구별하지 않는 동일 이름(서버 `lower(btrim(nickname))`)은 참가자 사이에 중복 금지다. 중복/누락·길이 오류가 있으면 잘못된 슬롯만 수정 요청하며 ON의 설정 확정을 완료하지 않는다. 임의 닉네임 생성·P1 값 복사·PC 캐릭터 이름으로 대체하지 않는다. OFF에는 닉네임 검증을 적용하지 않는다.
**조건부 입력값·게임 시작 제출:** `hq_mode` ON/OFF와 `party_size` 1~3을 현재 폼 상태로 유지한다. ON일 때에만 P1~PN 닉네임이 필수(2~24자·중복 금지), OFF일 때에만 원작 인지도·캠페인 규모가 필수다. 인원을 줄이면 범위 밖의 P슬롯을 숨기고 제출에서 제외하며 다시 늘리면 수정하지 않은 값은 가능한 한 유지한다. ON→OFF 전환 시 닉네임 값을 숨기되 **서버에 전달/가입/재조회하지 않는다**; OFF→ON으로 돌리면 활성 슬롯의 기존 작성값을 보존할 수 있다. OFF의 캠페인 규모와 인지도/선택 입력은 ON에서 일시 숨겨도 다시 OFF로 돌아오면 가능한 한 보존한다. **최하단 `게임 시작`의 실제 제출 이전에는 DB 조회·계정 생성·입단·세계 생성/현지 플레이를 하지 않는다.** 제출 시 ON은 활성 P1~PN 닉네임만 검증해 영구 UUID/본부 신입 판별로 연결한 뒤 신입이면 **외부 프롤로그→`본부 입장` 버튼 대기**로, 경력이라면 동기화실로 연결한다. OFF는 본부/카드 작업 없이 기존 일반 원작 캠페인 설정·PC 생성으로 연결한다. 제출 라벨 `게임 시작`은 **설정 접수 의사 표시일 뿐** 곧바로 본부 출입문 통과, 현지 PC 행동/시간 진행, 현지 `play_start`를 뜻하지 않는다. 부분 입력이 유효하면 유지하고 오류 슬롯만 수정받는다. 실제 동적 UI를 쓸 수 없으면 동일한 **한 설정 단계**의 채팅으로 대응하며, 버튼/폼이 있는 척하는 정적 그림·HTML을 사용하지 않는다.
**PC 특성 A/B/C 선택 화면:** 해당 PC의 **성별·이름·나이**를 각각 자유 입력 가능한 선택 항목으로 특성 A/B/C·해당 Luck 후보와 **동일한 화면/단계**에 표시한다. 세 항목은 모두 선택이며 공란이면 **확정 시 해당 항목만** 현재 확정 원작·시대·문화·PC 설정에 맞춰 자동 생성한다. 성별만 지정하거나 이름만 지정하는 등 부분 입력도 그대로 보존하고 나머지만 채운다. 기존 확정 정보·카드 계정 닉네임을 기본정보로 오인하거나 덮어쓰지 않는다. 입력 필드 수정/공란/화면 열람만으로 A/B/C의 8특성·Luck을 재추첨/재배열하지 않는다. 하나의 선택 응답에서 특성안 선택과 기본정보 입력을 받아 유효 항목을 확정한다. 지원되는 실제 폼이 없으면 후보와 선택 기본정보 항목을 같은 채팅 단계에 보여준다. 이미 받은 유효 이름·성별·나이/특성 선택을 재질문하지 않으며, 필드 오류가 있어도 다른 정보·난수를 유지한다. 현재 PC의 이름·성별·나이는 APP 외형·배우 선택·직업 후보/공개 시작 시트에 동일하게 반영한다.
현재 대상PC·단계·후보 문자/값·필수 정보와 입력 의미는 보존한다. 제목·항목 순서·문장/행 수는 상황에 맞게 표시한다. 선택 대기는 하나의 현재 단계로 명확히 하고 무관한 플레이 메뉴/HUD를 섞지 않는다. 자동 처리는 다음 실제 선택까지 이어갈 수 있다.
잘못된 항목만 수정받고 이미 받은 값·생성 후보·수치를 다시 뽑지 않는다. 세계 브리핑/확정 프로필은 읽기 자료이며 표시를 위해 확인 질문을 만들지 않는다. 이미지 제공은08-visual을 따른다.

각 항목은 **클래스 이름 + 다음 한 줄 요약 + 클래스별 실제 보유 수치 한 줄**만 기본 표시하며, 개별 자산/강화 카드 이름·능력 설명·기본 지급 카드명/희귀도 목록은 이 화면에서 반복 나열하지 않는다. 요약 문구는 다음과 같이 고정한다.
- 수호자: `방어·보호·구조에 특화. 위험 앞에서 동료와 거점을 지킨다.`
- 탐구자: `관찰·분석·기록에 특화. 단서와 환경 정보를 빠르게 읽는다.`
- 무법자: `잠입·우회·이탈에 특화. 봉쇄와 추적을 비껴간다.`
- 기회주의자: `위험 감수·거래·변칙에 특화. 불리한 판을 뒤집는 데 능하다.`
- 생존자: `환경 적응·버티기·재활용에 특화. 실패 속에서도 다음 수를 만든다.`
수치 표시 형식은 `보유 카드 N장 · 자산 A · 강화 E`로 고정한다. **N=A+E**이고 A/E는 현재 입력 플레이어의 실제 검증된 영구 컬렉션에서 **해당 클래스 전용** 소유 카드 ID를 중복 없이 유형별로 센 값이다. **중립(NE) 카드는 어느 클래스 수에도 합산하지 않는다.** 새 계정의 클래스별 기본 1자산+1강화가 실제 지급·조회됐다면 `보유 카드 2장 · 자산 1 · 강화 1`로 표시할 수 있지만, 새/기존 계정의 소유를 확인하지 않고 2/1/1을 고정 숫자로 복사하지 않는다. 조회 불가/불완전이면 해당 수치에 `미확인`을 표시하고 확인된 소유를 조작하지 않는다. `보유`와 `장착`은 별개이며 비선택 클래스 소유도 정상 표시한다.
실제로 동작하는 선택 UI라면 각 카드/버튼의 선택 이벤트를 해당 클래스의 고정 ID(GU/SE/RO/WI/SU)에 연결하고 캠페인 가입/클래스 확정의 실제 기존 절차로 전달한다. 선택 클릭만으로 카드 장착·물품 지급·서버 성공을 가장하지 않는다. 실제 카드 UI가 없으면 동일 항목을 색상 표시 가능한 채팅 옵션으로 보여주고 문자/이름으로 입력받는다. 선택 대기를 다섯 번 쪼개거나 상세 카드 설명 단계를 강제하지 않는다.

**`permanent_cards_enabled=true`인 ON 캠페인에서만 카드 클래스/도감/장착/성장 UI를 보여준다. OFF 캠페인에서는 해당 단계 전체를 숨기고 일반 PC 설정으로 진행한다.**
**ON에서는 카드 시스템을 `전체 카드 도감`과 `4단계 · 영구 카드 장착` 두 화면으로 나눈다.** 도감은 전체 카드·효과·소유 현황을 열람하는 곳이며 장착 화면은 보유 카드로 4슬롯을 구성하는 곳이다. 도감은 클래스 선택 전·장착 도중·플레이 중 요청 시 열 수 있고, 열람/검색/효과 확인은 게임 시간·위험·PC 행동·카드 소유/장착/보상을 변경하지 않는다.

**전체 카드 도감:** 기존 정식 자산33장+강화33장 **전체 66장**을 모두 보여준다. **보유·미보유** 카드를 함께 열람하고 미보유 카드도 정확한 효과를 볼 수 있지만 장착할 수 없다. 실제 조회된 소유만 `보유 N/66`에 반영한다. **클래스 5종/중립·자산/강화·일반/희귀/영웅/전설·전체/보유/미보유 필터, 카드명 검색, 결과 수, 더 보기/페이지 이동**을 지원한다. 전량을 한 화면에 출력하지 않고 필터 결과만 페이지별로 보여준다. **영구 성장8종은 별도 `성장` 탭**에서 CARD_PERMANENT_GROWTH대로 실제 Lv.0~5·대상 특성·증가값·다음 단계 성공률을 표시한다. 성장8종은 66장 수집 카드나 4슬롯 장착 후보에 합산하지 않는다.

도감 카드 행은 클래스 아이콘·희귀도 이름색·카드 종류/소속/등급·실제 보유 상태·짧은 효과 설명을 보여주며, **`상세 보기`에서는 원래 발동 시점·전제 행동/성공 조건·효과 수치·한계·시대/실물 제한을 모두** 읽는다. 효과는 **`09-cards.md`의 동일 카드 ID 원문**을 사용한다. 운영 `card_catalog`에는 ID/제목/소속/유형/희귀도/기본 여부/순서만 있고 **효과 원문 칼럼은 없다**. 메타데이터와 소유는 기존 조회에, 카드 효과는 원문에 연결하며 효과를 추정/발명하지 않는다. 원문을 확인할 수 없으면 `상세 효과 확인 불가`, 소유를 검증하지 못하면 `보유 상태 미확인`으로 표시한다.

**4단계 · 영구 카드 장착은 4개의 슬롯을 먼저 선택**하게 한다. 상단에 `장착 가능 N장 · 선택한 카드 K/4장`과 슬롯 현재 선택/빈 상태를 표시한다. **`1 · 클래스 자산 전용`, `2 · 클래스 강화 전용`, `3 · 자유 슬롯 1`, `4 · 자유 슬롯 2`** 중 하나를 고르면 **그 슬롯에 장착 가능한 실제 보유 카드만** 아래 후보 목록에 표시한다. 최초에는 1번 슬롯을 선택한다. 1번은 주 클래스 소유 자산, 2번은 주 클래스 소유 강화, 3·4번은 주 클래스/중립 자산·강화만 허용하고 타 클래스/미보유·다른 슬롯에서 선택된 중복 카드는 제외한다. 후보에도 카드명 검색·자산/강화·주 클래스/중립·등급 필터·결과 수·더 보기/페이지 이동을 제공하며, 부적합 필터는 비활성이다. 26장까지 장착 가능 카드가 늘어도 전량 장문으로 펼치지 않는다. 상세 효과는 도감과 같은 카드 ID 원문을 사용한다.

이전 자산/강화의 **자산 펼침/강화 접힘** 고정 기본 화면 대신 종류별 표시를 슬롯 후보/도감의 선택형 필터로 통합한다. 필터·검색·접기·상세/도감 열람은 **선택·장착·소유 상태를 바꾸지 않으며** 다른 슬롯으로 이동해도 최종 확정 전 선택 4장을 유지한다. 플레이어가 4장 최종 확정을 명시하고 기존 장착 제약을 통과했을 때만 `save_loadout`으로 저장하며 그 전에는 확정 성공으로 표시하지 않는다. 실제 UI 컨트롤을 지원하면 슬롯·검색·필터·페이지·상세의 동작을 연결하고 미지원이면 `도감/카드 ID 상세/클래스·종류·등급·소유 필터/카드명 검색/슬롯1~4/더 보기` 요청으로 필요한 범위만 채팅에 표시한다. 정적 이미지·가짜 버튼으로 인터랙션을 가장하지 않는다.
카드 한 장의 기본 정보는 **`[카드 유형] [클래스/중립] [등급] 카드명` + 실제 효과/중요 제약 + 현재 선택 여부**를 명확히 표시한다. 유형은 `🧰 자산`/`⚡ 강화`, 소속은 **주 클래스 5색(3단계의 동일 색상), 중립은 회색 `#9CA3AF`**, 등급은 **일반 회색 `#9CA3AF` · 희귀 청록 `#28B8D8` · 영웅 보라 `#AD70E8` · 전설 금색 `#E9B949`**으로 구분한다. **이름 바로 앞에는 색상 있는 클래스 고유 아이콘**, **카드 이름 글자색에는 실제 희귀도 색상**을 지정한다. 클래스 아이콘은 **수호자 파란 방패(`shield`)**, **탐구자 노란 눈(`scan-eye`)**, **무법자 초록 열쇠(`key-round`)**, **기회주의자 보라 주사위(`dice-5`)**, **생존자 빨간 배낭(`backpack`)**, **중립 회색 원형(`circle-dot`)**으로 고정한다. 아이콘은 3단계와 같은 클래스 색, 이름은 위에서 정한 등급별 일반 회색·희귀 청록·영웅 보라·전설 금색을 사용한다. 각각 다른 의미이므로 카드 전체에 클래스/등급색을 한꺼번에 칠해 혼동시키지 않는다. 소속은 아이콘+클래스명, 등급은 이름색+등급명, 카드 종류는 자산/강화 라벨로 구분한다. 스타일·아이콘 미지원 시 🛡️/👁️/🗝️/🎲/🎒/⚪와 소속·등급·유형 텍스트로 대체하고 색만으로 구별하도록 만들지 않는다. 등급/소속은 실제 카드 카탈로그의 ID/원문을 쓰고 `[초록 열쇠] 우회 공구함(이름색 희귀 청록) · 무법자 · 희귀 · 자산`, `[회색 원형] 충격을 흘린다(이름색 일반 회색) · 중립 · 일반 · 강화`처럼 구별한다(표현 예시는 실제 카드의 소속/등급/유형에 맞을 때만 사용). 다른 클래스의 미소유/장착 불가 카드를 장착 후보로 표시하지 않는다.
클래스별 색은 정체성 표시, 등급별 색은 희귀도 표시이지 카드 능력의 추가 보너스가 아니다. **중립은 일반 등급이고 클래스 전용은 희귀·영웅·전설**이라는 기존 분류를 보존하며, 보유/선택/장착을 혼동하지 않는다. 슬롯 이름과 후보는 **`1 · 클래스 자산 전용`(선택한 주 클래스 자산만)**, **`2 · 클래스 강화 전용`(같은 주 클래스 강화만)**, **`3 · 자유 슬롯 1`/`4 · 자유 슬롯 2`(주 클래스/중립 자산·강화)**로 고정한다. 1·2번 드롭다운에는 중립 카드를 제외하고 3·4번에도 미소유·다른 클래스 카드를 넣지 않는다. 선택/해제는 해당 고유 카드 ID와 4슬롯의 실제 제약·중복/소유 확인에 연결한다. 접힘/펼침·정보 열람만으로 선택을 바꾸거나 `save_loadout`을 호출하지 않는다. 최종 장착 확정은 기존 승인/실제 검증 절차 이후에만 표시한다.

## HQ_MARTIN_MISSION_ETHOS_AND_VALUES_INTERVIEW

**적용과 절대 순서:** ON에서 처음 본부를 방문한 미입단 신입 후보가 제이든과의 첫 안내 뒤 **플레이어가 직접 마틴을 만나기로 선택했을 때** 적용한다. 최초 외부/내부 장면은 HQ_FIRST_ENTRY_SCENE_GATE대로 보존한다. **마틴 첫 대면 → 공식 역사·본부 정체성·사명과 기본 책임을 이해할 수 있게 설명/질문 응답 → 명시적 입단 의사 확인 → 수락한 요원에게만 시스템·훈련/실전·동기화 운영 설명 → 개인 가치관 면담 → 첫 시설 오리엔테이션 → 별도 임무 준비 요청** 순서다. 첫 마틴 대면만으로 면담·입단·세계 선택을 완료하지 않는다. 기존 입단 요원/현지 저장 복원/본부 OFF 및 이미 완료한 입단식에는 반복 적용하지 않는다.

**1. 아무것도 모르는 후보에게 설명:** 마틴은 처음 방문한 사람이 본부 용어와 구조를 전혀 모를 수 있음을 전제로 대화한다. 요원이 이미 알고 있다고 가정해 약어·임무 등급·현지 PC·동기화를 던지고 곧바로 시험 질문을 하지 않는다. 전지적 강의가 아니라 구체적인 사건의 의미, 조직이 생겨난 이유, 실제 사람에게 미치는 영향을 **직접 대사와 후보가 질문할 여지**로 풀어 낸다. 설명을 단순히 '우리는 세계를 지킨다' 한 문장으로 끝내거나 '자세한 설명은 나중에'라며 입단 결정부터 요구하지 않는다. 질문이 오면 그 범위를 충분히 답하고 **그 자리에서 발언권을 돌려준 뒤, 플레이어가 계속 듣겠다는 뜻을 보일 때만** 다음 주제로 이어간다. 한 응답에 설명 전부와 입단 확인·가치관 질문·임무 선택을 압축하지 않는다.

**첫 역사 설명의 주제별 대화·입력 대기 게이트:** 마틴은 기본적으로 **한 응답에서 한 개의 설명 주제만 다루고**, 그 주제를 신입이 이해할 만큼 구체적으로 말한 뒤 현재 내용에 대해 자유롭게 묻거나 반응할 수 있도록 자연스럽게 말을 건네고 **그 응답을 끝내고 플레이어의 실제 입력을 기다린다**. 예컨대 '평행세계의 발견'을 설명한 응답에서 곧바로 최초 간섭 사고·현실 침식·조직 창설·입단 책임까지 연속 강의하지 않는다. 세계관은 대체로 **① 독립된 평행세계의 발견 ② 최초 간섭 사고와 확인된 현실 침식/미확정 연쇄 붕괴 가설 ③ 국제 공동 본부의 창설과 사명 ④ 다른 세계 사람의 실제 삶과 요원의 기본 책임**이라는 의미 단위로 풀어 가되, 고정 네 문제·네 화면·대사 분량 할당은 아니다. 실제 대화에서는 이 사실들을 모두 설명하되 **후속 주제를 자동으로 설명하지 않는다**. 질문/의문/반론이 나오면 그 주제에서 이해에 필요한 내용을 답하고 **질문에 답하면서 다음 주제를 선제적으로 이어 붙이지 않는다**. 플레이어가 이해했다며 계속 듣겠다고 하거나 '다음 이야기도 해 달라'고 하면 자연스럽게 다음 주제로 넘어간다. 플레이어가 특정 주제를 먼저 묻거나 **여러 주제를 한꺼번에 설명해 달라고 직접 요청**하면 요청 범위에 맞춰 답하되 그 요청만으로 입단 수락이나 다음 단계까지 완료하지 않는다.

**대화의 생동감과 현재 진행 기억:** 매 응답마다 똑같은 '질문 있습니까?'나 '다음으로 넘어갈까요?'를 기계적으로 반복하지 않는다. 마틴은 후보가 실제로 묻거나 보인 반응·이해 정도에 맞추어 되묻거나 쉬운 예·짧은 확인·침묵 등으로 말을 건네며, 질문을 강요하거나 '질문 없음' 선언을 요구하지 않는다. 실제 발언 없이 후보의 이해·흥미·납득·답변을 대필하지 않는다. 현재까지 실제 설명된 주제와 열려 있는 질문은 지원되는 작업/재개 맥락에서 이어 쓰되, 없던 저장 필드나 영구 기록을 꾸며내지 않는다. 1~3인이라면 실제로 누가 듣고 질문했는지 보존하고 전원의 반응을 대신하지 않는다. 후보가 중단·퇴장을 선택하면 설명을 강제하지 않는다. 기본 역사와 책임에 대한 정보가 제공되고 질문할 기회를 가진 뒤에만 입단 결정을 묻는 기존 게이트는 유지한다.

**2. 입단 결정을 위한 충분한 공식 세계관:** 다음은 신입에게 공개되는 확정된 사실이며, 신입의 현재 이해와 질문에 맞춰 **원인→발견→대응 조직→책임**이 납득되도록 설명한다.
- **발견:** 여러 평행세계가 과거·미래를 포함해 실제로 존재한다. 과학적 관측과 반복 검증으로 존재가 입증된 다음, 별개 사건으로 최초의 세계 간 간섭 사고가 발생했다. 영화·게임·이야기를 연상시키는 세계도 가상 프로그램이 아니라 독립적인 현실이다.
- **위험:** 세계 경계가 약해지면 공간이나 물리 현상이 다른 현실을 침범하거나 사건의 영향이 넘어오는 '현실 침식'이 일어날 수 있다. 확인된 국지 간섭과 **아직 최악의 가설인 전 세계적 연쇄 붕괴**를 구별한다. 모든 세계가 멸망 예정이라고 단정하지 않으며, 각 세계의 고유 재난을 전부 침식 탓으로 설명하지 않는다.
- **본부의 탄생과 정체:** 이를 연구·관측하고 필요할 때 대응하기 위해 여러 국가가 공동으로 설립·운영하는 국제 연구·위기 대응 조직이다. 마틴은 전체 조직의 통치자가 아니라 이 작전본부의 책임자다. 관측·연구·안정화 개입·피해 최소화 및 가능한 진실의 발견이라는 사명을 알려준다.
- **방문 후보에게 중요한 책임:** 파견되는 세계는 실제 사람들이 사는 곳이며, 그곳 사람을 단순한 도구·일회용 신체로 대할 수 없다. 입단 뒤 해야 할 일의 위험, 타인의 삶과 안전에 대한 책임, 거절·질문할 권한을 분명하게 알려준다. **세부 동기화 과정·훈련/실전 및 카드·성장 조작법은 수락 이후** 단계에서 설명한다.
- **미확정 금지:** 창설 연도·국가별 협정·첫 사고 위치/피해자/연구자·기술의 정확한 과학 모델·숨겨진 음모는 정본에서 확정되지 않았다. 신입 설명을 풍부하게 한다는 이유로 이를 역사적 사실로 날조하거나 미공개 비밀을 밝히지 않는다.

**3. 플레이어의 실제 입단 결정:** 역사·사명과 기본 책임을 소개하고 신입이 질문할 기회를 가진 **뒤에만** 마틴이 각 후보에게 입단 의사를 자연스럽게 묻는다. **입단한다 / 아직 결정하지 않는다 / 거절한다 / 더 묻는다** 중 무엇이든 직접 발언·행동으로 받아들인다. 침묵·방문·대화 동참·닉네임/UUID 생성·가치관 질문 수락을 입단 동의로 해석하지 않는다. **실제 입단 수락 전에 가치관 질문을 하지 않는다.** 수락/거절은 요원별 독립이며 다인 팀원의 결심을 대신하지 않는다. 유보·거절 시 면담을 이어가거나 퇴장을 요청할 수 있고, 신입 전체가 자동 입단·임무 출격한 것으로 처리하지 않는다. 기존 `trpg_hq.record_hq_induction`과 입단 상태 변경은 해당 요원의 실제 수락/참여 및 권한·검증이 성립했을 때만 호출하며, 저장 불능이면 기록 성공을 꾸미지 않는다.

**4. 입단 후 실제 시스템 안내:** 수락한 신입에게만 영구 요원과 현지 인물의 다른 정체, 현지 인물과 동기화하는 이유(외부 신체 직접 투입보다 적은 간섭·높은 안전성과 싱크로율), 임무 뒤 현지 인물이 자기 삶/기억을 이어가는 사실을 설명한다. 본부의 **대사건=훈련 / 연대기=실전** 구분, 첫 훈련과 정식 요원 자격·진급의 관계, 현지의 실재 피해·생존·철수·귀환/평가, 도미닉이 담당할 카드·영구 성장·4슬롯/기본 교육의 존재와 전문 담당자를 신입 눈높이에서 알려준다. **구체적인 카드 효능·보상·등급 산식이나 미확정 사망/재투입 예외를 만들어 설명하지 않는다.** 실제 카드 상세/클래스·장착은 09-cards/04-setup의 해당 단계와 도미닉 안내에서 확인한다. 공식 브리핑 대상 세계가 아직 확정되지 않았다면 구체 임무 목표/위험/비밀을 미리 정해 말하지 않는다.

**5. 수락 이후 첫 가치관 대화(요원마다):** 마틴은 (1) 평행세계의 실제 붕괴·참사/후속 피해를 가능한 만큼 막거나 줄이고 가능한 진실을 알아오는 대목표와 (2) 동기화된 현지 PC의 원래 기억·성격·가치관·관계·안전·생존을 지키는 책임의 긴장을 설명한다. **소중한 사람과 대임무가 충돌할 때 / 추가 진실과 생존 위험이 충돌할 때 / 현지 인물이 평소 하지 않을 선택이 필요할 때**의 세 질문을 한꺼번에 나열하지 않고 실제 대화 하나씩 묻고 답을 듣고 반응한다. 답/모름/유보/질문 거절은 모두 요원이 선택한다. 정답/오답 심리 검사·강제 성격·서약·미래 행동 구속·입단 취소·S/A/B/C/F 자동 감점·카드/보상 불이익은 없다. 현지 인물이 극한 상황과 경험으로 변할 가능성도 인정한다.

**6. 입단 직후 첫 본부 시설 오리엔테이션:** 마틴의 대화가 정리되면 **다음 임무 메뉴를 즉시 열지 말고** 먼저 본부에서 생활·근무할 공간과 첫 안내를 실제 장면으로 제공한다. 제이든 또는 해당 공간의 실제 담당자가 인계를 받아 **작전실(마틴의 지휘·평가), 동기화실(제이든의 접속/귀환), 기록·분석실(클라라의 관측/기록), 의료·지원/훈련 구역(도미닉의 의료·장비/전술·카드·성장), 휴게·생활 구역(직원과 요원의 일상)** 다섯 곳의 용도와 이용할 수 있는 행동을 신입에게 알린다. 안내는 입단 직후 한 번의 명단 낭독으로 종료하지 않고 **신입이 실제 요청/수락한 동선을 따라** 공간의 배치·사람의 근무/생활·실물 활동과 교류를 보여 준다. 지금 자리에서 먼저 시설 개요를 알려주고 견학을 제안하며, 직접 이동을 선언하지 않은 플레이어를 데리고 가지 않는다. 처음 실제로 방문한 시설에서는 그곳의 구체적 기능·담당자·할 수 있는 행동을 보여주고 질문·체험할 기회를 준다. NPC 8명 전원을 첫날 강제 소개하거나 모든 구역 방문/강제 구매/의무 훈련을 출격의 기술적 자격 조건으로 만들지 않는다.

**7. 첫 임무로 넘어가는 별도 경계:** **첫 시설 안내를 건너뛰고 곧바로 임무를 배정하지 않는다.** 시설 개요와 실제 견학/교류 기회가 제공된 뒤 팀이 스스로 작전실에서 임무 준비를 요구하면 HQ_ON_CAMPAIGN_ROUTER→CAMPAIGN_SETUP_PIPELINE에 따른다. 팀이 **시설 견학을 명시적으로 생략하고 지금 임무를 준비하겠다고 선택한 경우에는** 강제 견학으로 붙잡지 않되, 시설의 기능과 이용 가능성을 간략히 안내하고 그 선택을 보존한다. 단순 입단 수락, 가치관 답변 완료, 시설 안내 시작은 **원작 선택·PC 생성·마틴 정식 브리핑·출격 동의가 아니다**. 처음부터 임무를 재촉하거나 동기화실로 자동 이동시키지 않는다. 지원되는 작업 상태에 후보/입단 의사/교육·면담 진행/시설 안내 여부/열린 질문·선택을 구별하되, 이를 새로운 영구 DB 컬럼이나 필수 본부 시계로 가장하지 않는다. 입력 대기는 0시간이며 실제 안내·이동·대화의 경과만 반영한다.

**기존 기억·평가·비소급:** 실제 발언/청취자·요원 UUID·경과만 기존 `trpg_hq.record_npc_interaction`(`npc:martin`)으로 기록하고, 검증된 저장 뒤에만 영구 기억이라 한다. 실제 `load_npc_agent_context`와 현지 검증 결과로 귀환 후 정성 평가를 이어가며, 규칙상의 S/A/B/C/F·보상·진급·입단 조건을 변경하지 않는다. 이미 진행 중인 현지 게임·완료한 첫 입단식·기존 verified 세이브에 이 순서를 소급 재실행하지 않는다. 상세 대화/기억 원문: `docs/development/TIME_AGENT_MARTIN_VALUES_INTERVIEW.md`.

## HQ_FIELD_CONTEXT_BRIEFING

**ON 출격 전 클라라의 현지 실무 브리핑(#5):** 본부 작전실에서 원작·시대/지역·현지 PC·확정 비공개 정본/공개 임무 범위가 갖춰지고 마틴의 정식 임무 목표·위험도 설명이 이루어지는 자리에서 **클라라가 관측·공개 자료로 아는 생활 상식**을 자연스럽게 덧붙인다. 마틴 브리핑과 같은 장면에서 필요 부분만 제공하며 새 필수 확인 화면·강제 강의·출격 동의 단계를 만들지 않는다. 기존 장착/검증 및 제이든 실제 동기화 선후 관계를 유지한다.

- **화폐/구매력:** 현지 통화·단위, 소지금으로 가능한 일반 식사·숙박·생활 물품 등 꼭 필요한 대표적 가격 감각을 간결하게. 확실하지 않은 과거 시세·환율은 근사치/미확인으로 밝히고 실제 통용 가격이나 환전 보증을 발명하지 않는다.

**현지 인물의 동기화 직전 상황·출발 목적 브리핑(PC별):** ON 새 출격에서 마틴의 실제 정식 임무 설명과 같은 장면에 각 P1~PN 현지 인물이 바로 직전 무엇을 하던 중이었는지, 어디에 왜 있었고 무슨 업무·약속·생존 목적을 어떤 상대·물건·장소와 수행하려 했는지, 무엇이 아직 미완료이고 지금 무엇부터 할 수 있는지 설명한다. 현재 정본 PC_CONNECTIONS/LOCATION_BASELINES와 일치하는 공개 가능 사실만 쓴다. 본부 임무와 각 현지인의 원래 목적을 구별한다. 일반 직업만 소개하거나 '일하다가 동기화'라는 추상적 설명으로 대체하지 않는다. 두 명 이상이면 각 슬롯을 누락하지 않고 각자의 장소·지식·관계/책임을 섞지 않는다. ## HQ_ON_CAMPAIGN_ROUTER

**요원 활성화 ON에서만** START_SETTINGS_GATE가 확정한 닉네임/영구 UUID를 가지고 **본부 입구(신입) 또는 동기화실(기존 요원)**로 이어간다. **신입은 HQ_MARTIN_MISSION_ETHOS_AND_VALUES_INTERVIEW의 세계관 설명→입단 의사 확인→수락 후 교육·가치관 대화→시설 오리엔테이션→명시적 임무 요청 경계를 반드시 지킨다.** **신입의 첫 장면은 HQ_FIRST_ENTRY_SCENE_GATE에 따라 반드시 외부 프롤로그에서 '본부 입장' 버튼을 제시하고 그 실제 선택을 받은 뒤 내부 제이든 장면으로 전환한다.** 외부 프롤로그에서는 본부로부터 '신입 요원 후보 초청'을 받고 방문했다는 경위를 먼저 알려, 플레이어가 왜 이곳에 왔는지 이해하게 한다.** 이유 없는 본부 앞 순간 등장/이미 입단을 승인한 상태로 진행하지 않는다. 초청 후보 선정 기준이나 개인의 과거 행적·특별한 능력·감정·입단 서약/수락은 임의 확정하지 않는다. 본부의 역사·설립 경위·임무·동기화에 관한 **자세한 설명은 마틴의 입단식과 실제 질문·면담**에 맡기고, 첫 도입은 짧게 끝낸다. 그 뒤 제이든이 기존 캐릭터대로 재치 있고 사교적인 첫 안내를 한다. 마틴은 신입을 기존 요원처럼 대하지 않고 공식 역사/사명부터 설명하며, 입단 수락 전 가치관 질문이나 시스템 교육을 강행하지 않는다. 수락 후 교육·면담과 실제 시설 안내를 거친 뒤 플레이어가 선택한 본부 시설/NPC 자유 활동으로 이어진다. 실제로 발생한 입단 행사만 개인 영구 원장에 쓰고 미선언 답변·서약·이동·선택을 생성하지 않는다. 본부 NPC 8명은 우선 담당 기능·필요 위치·개별 기억 저장 경로를 제공하며 의무 소개/세밀한 대사 동기화는 요구하지 않는다.

## GENERATION_RNG_SEPARATION

실제 무작위 생성만 Python으로 처리한다. 자동 start_seed는1~100, 이후 용도별 독립 named stream에 hashlib.sha256과 random.Random을 사용한다. 예: key=json.dumps(["PYTHON_GENERATION_V1", start_seed, axis_name, retry_index],ensure_ascii=False,separators=(",",":")); rng=random.Random(int.from_bytes(hashlib.sha256(key.encode("utf-8")).digest(),"big")). 내장 hash()는 쓰지 않는다.
직접 지정/이미 확정된 값은 재추첨하지 않는다. 현재 필요한 후보/표/분포를 추첨 전에 고정하고 축·원값·식/표·결과·retry사유를 보존한다. 부적격 미확정 항목만 해당 축으로 재생성하며 좋은 결과가 나올 때까지 재굴림하지 않는다. 서술/웹검색까지 seed로 동일해진다고 보장하지 않는다.
게임플레이 SystemRandom과 분리한다. 필수 독립 추첨축 목록은 없으며 원작/인과로 도출할 항목은 직접 설계한다. 선택지 다양성이나 실제 무작위가 필요할 때만 생성 난수를 쓴다. NORMALIZED_TABLE_INDEX는 기존1~100→N 참고표 매핑이며 엄밀한 균등 특성 생성은 전용 sampler를 사용한다.

## NORMALIZED_TABLE_INDEX

1~100 생성 시드 S를 N개 항목에 매핑할 때 index=floor((S-1)×N/100)+1을 사용한다. 이는 100개 값을 가능한 고르게 배분하는 기존 방식이며, N이 100의 약수가 아니면 항목별 확률이 완전히 같지는 않다. 엄밀한 균등성이 필요한 특성 생성은 전용 sampler를 사용한다. 서로 독립인 축은 서로 다른 named seed를 사용한다.

## AUTOMATIC_SF_HOMAGE_EXCLUSION

- 자동 Homage Candidate Pool에서는 **SF가 작품 정체성의 핵심 전제인 원작**을 제외한다. 우주선·우주 식민지·외계 행성 탐사, 미래 사회, 사이버펑크, AI/로봇 문명, 고도 미래기술 체계 자체가 세계의 기본 존재론·사회·위협 문법을 규정하는 작품은 Genre Family가 다른 호러와 겹쳐도 자동 후보로 올리지 않는다.
- **예외: Genre Family 21~30의 Cthulhu Mythos 전용 Pool에서는 실제 Mythos 정체성이 핵심인 적격 작품을 SF 요소만으로 제외하지 않는다.** 선택되면 그 작품의 SF/시대/기술 존재론도 원작 특징로 그대로 보존한다. 이 예외는 비-Mythos SF를 21~30에 넣는 우회로가 아니다.
- 단순히 현대 기술, 연구시설, 실험 장비, 컴퓨터, 생명공학, 비정상 장치가 등장한다는 이유만으로 SF로 판정하지 않는다. `그 SF적 세계 전제가 없어지면 작품의 세계 정체성이 무너지는가`를 기준으로 본다.
- 81~90 크리쳐·괴물·육체 호러도 SF 작품을 자동 허용하는 우회로가 아니다. 같은 크리쳐 구조라도 SF 세계가 핵심인 원작은 자동 후보에서 제외한다.
- 사용자가 특정 SF 원작을 직접 지정하면 HOMAGE_DRAFT_SELECTION가 우선하며 정상적으로 허용한다. 직접 지정된 작품에서는 그 원작의 SF 존재론을 원작 특징로 충실히 보존한다.

## HOMAGE_DRAFT_SELECTION

직접 지정한 원작/정확한 공식 단위가 있으면 우선하고 후보를 다시 만들지 않는다. 미지정이면 장르·인지도·배제 조건과 원작 구현 가능성을 반영한 서로 다른 실제 작품 A~D 4개를 제공해 선택받는다. 기본/테마/조커 고정 슬롯, 내부 후보 수/탐색 lane/등급 의무는 없다.
작품명·필요한 판본/단위·매체와 어떤 세계 경험이 다른지를 짧게 표시한다. 연도/문화권은 구분에 필요할 때. 반전/캠페인 비밀을 공개하지 않는다. 모르는 핵심 정보만 필요한 범위로 확인하고 가상 작품으로 칸을 채우지 않는다. 현재 후보 내 중복만 피한다. 선택 전 PC/세계 생성으로 가지 않는다.

## CTHULHU_SOURCE_UNIT_ROUTING

크툴루 계열이면 실제 Mythos 정체성을 가진 원작 또는 공식 Source Unit을 정확히 채택한다. 본편·정식 확장/캠페인·DLC·모듈·독립 시나리오 등의 구분을 보존하고 필요한 상위 계열 설정만 상속한다. 다른 확장의 위협/사건을 편의로 혼합하지 않는다.
자동 후보는 공식/정식 라이선스가 확인되는 단위, 팬/홈브루는 직접 지정일 때만 허용한다. 다른 공식 확장도 정상 후보이며 현재4개는 정확한 단위로 구분한다. 일반 코스믹 호러를 Mythos 전용 후보로 위장하지 않는다. 공식 원작 시나리오를 선택했다면 먼저 그 시나리오의 실제 사건·발생 원인·인물/적의 동기·출발 위기·핵심 생존/결말을 확인하고 이를 기본 이야기 뼈대로 삼는다. 장면·대사·PC의 선택/결과를 그대로 강제 재연하지 않되 핵심 인과를 다른 작전으로 바꾸지 않는다. 크툴루 신화 세계관·원작 진실은 보존하지만 신규 PC의 수치형 신화 기능은 만들지 않는다. 실제 발견·지식은 [MYTHOS_KNOWLEDGE_FACTS](03-danger.md#mythos_knowledge_facts)를 따른다.

## INVESTIGATOR_DEPTH_PROTOCOL

플레이어의 기본정보/직업/외형 지정은 우선한다. **성별·이름·나이는 각기 선택 입력이며, 특성 A/B/C 선택과 같은 단계에서 제출한 값만 우선하고 공란인 필드만 그 단계 확정 때 생성한다.** 미지정 정보는 시대·문화·생활에 맞게 생성하고 이름은 현재 등장 인물과 혼동되지 않게 한다. 입력한 항목을 자동 생성값으로 덮어쓰거나 이미 확정된 PC의 세 항목을 재설정하지 않는다. 최소 이름 후보 수나 과거 이름 이력 추적은 없다.
공개 과거·현재 목적·실제 지위/책임·일상 관계로 그 세계에서 살아온 인물을 만든다. 필수 과거 상처/민감 자극·캐릭터 태그 카탈로그·사건 공명 후보는 만들지 않는다. PC가 실제 아는 과거는 공개하고 모르는 외부 비밀은 구분한다. PC의 감정/도덕/장기 결심을 자동 확정하지 않는다. 선언된 경력·권한·소유는 선택에 필요한 구체성을 갖춘다.

## STAT_DRAFT_GENERATION

- 각 A/B/C 안은 STR/CON/SIZ/DEX/APP/INT/POW/EDU 8개, 합계 400, 개별 30~80, 5단위다. 세 안을 같은 숫자 묶음의 재배열로 만들지 않는다.
- 각 안의 Luck은 별도 생성 난수로 20~80 정수 하나를 정한다. 400 합계·5단위 제약에 포함하지 않는다.
- 8특성의 모든 적격 순서 배열을 표본공간으로 하는 균등 bounded-composition sampler를 사용한다. 각 안과 Luck에 독립 generation seed/sub-seed를 사용한다. 직업·사건·게임플레이 난수를 입력으로 쓰지 않는다.
- 생성 후 개수·합계·범위·5단위·Luck 범위를 실제 검산한다. 8특성 배열이 다른 안과 같으면 해당 안만 독립 retry seed로 재생성한다. 수동 교환·직업 최적화로 수치를 조정하지 않는다.
- **A/B/C 능력치·Luck 후보를 보여주는 같은 선택 단계에 성별·이름·나이 3개 독립 선택 입력란**을 둔다. 이름·성별은 플레이어의 자유 기입값을 보존하고, 나이는 시대·인물의 실제 숫자 나이로 입력받되 적절한 범위가 모호하거나 형식이 잘못된 경우 해당 항목만 확인한다. 미입력/빈칸은 자동 생성 요청이며 각 항목을 다른 필드와 독립해 처리한다. A/B/C 선택·기본정보 동시 제출 전에는 생성 후보와 입력값을 보존하고, 확정 순간 미지정 필드만 원작·시대·문화에 맞게 자동 생성한다. 특성·Luck 후보 재추첨, 별도 이름/나이 선택 단계, 성별·이름·나이 때문에 추가 대기를 만들지 않는다.
- 플레이어가 한 안의 특성과 Luck을 함께 선택한다. A 특성+B Luck 혼합과 키퍼의 자동 선택은 불가하다.
- 선택이 확정된 뒤 직업 후보를 생성하고 [PC_DERIVED_STATS](04-setup.md#pc_derived_stats)로 파생값을 계산한다. Luck 20은 플레이 중 소비 하한이 아니다.


실제 Python에서 사용할 수 있는 균등 표본 함수다. 각 안의 독립 seeded rng를 인수로 주고 Luck은 별도 stream으로 생성한다.

```python
from functools import cache

@cache
def ways(n, total):
    if n == 0:
        return int(total == 0)
    if total < 0 or total > 10 * n:
        return 0
    return sum(ways(n - 1, total - x) for x in range(11))

def sample_stats(rng):
    total, values = 32, []  # 8*30 + 5*32 = 400
    for n in range(8, 0, -1):
        ticket = rng.randrange(ways(n, total))
        for x in range(11):
            count = ways(n - 1, total - x)
            if ticket < count:
                values.append(30 + 5*x)
                total -= x
                break
            ticket -= count
    return values
```

## PC_DERIVED_STATS

확정된 8특성에서 계산한다. 생성 뒤 파생값의 공식으로 기존 특성을 바꾸지 않는다.
- **신규 생성 PC의 시작/현재/최대 HP** = floor((최종 CON+최종 SIZ)/10)+1. 영구 카드·성장 ON에서는 실제 확정된 적용 CON/SIZ를 사용하고, PC 최초 생성에 단 한 번 반영한다. 기존 확정 PC·NPC·적·동물에는 소급 적용하지 않는다. 실제 피해·중상·치료·사망은 [HP_AND_DEATH](02-checks.md#hp_and_death)를 따른다.
- initial/current/base max SAN은 [SAN_CORE](03-danger.md#san_core)의 **신규 PC 산식** `max(50,min(99,floor(60+0.4×(최종 POW−50))))`을 적용한다. 이 SAN 산식 자체는 POW/DB/Build/MOV를 변경하지 않으며, 신규 PC HP +1은 위 HP 산식에서만 따로 처리한다. 구판 확정 PC는 비소급이다.
- DB/Build는 [DAMAGE_BONUS_AND_BUILD](02-checks.md#damage_bonus_and_build) 표를 사용한다.
- MOV=8. DEX≥70이면 9, DEX≤40이면 7. 이 MOV는 기존 하우스룰이다.
- Luck은 선택한 특성 안에 붙은 20~80 생성값이다.
- 시작 기능은 [PC_SKILL_START_VALUES](04-setup.md#pc_skill_start_values)를 적용한다. 신규 PC에는 수치형 크툴루 신화 기능 자체를 생성하지 않는다.

## PC_APPEARANCE_FROM_APP

선택한 APP와 **같은 특성 선택 단계에서 확정한 성별·이름·나이**, 지정 외형·문화·직업·시대를 반영해 구체 외형을 확정한다. 배우 레퍼런스 1명은 필수이며 직접 지정이 없으면 알맞게 선정한다. 별도 배우 추첨축과 APP 구간별 상세 묘사표는 없다.
자동 외형/배우는 APP가 확정된 뒤 정한다. 외형을 맞추려고 특성을 재굴리거나 지정된 핵심 인종/성별/나이 등을 바꾸지 않는다. 배우의 성격/배역을 PC 성격으로 복사하지 않는다. APP는 첫인상의 근거이지 자동 호감/도덕성/설득 성공이 아니다. 이후 그림은 같은 외형과 실제 변화만 유지한다.

## PROFESSION_DRAFT

특성/기본정보 동일 단계 확정 뒤 원작 시대·문화에 실제 성립하는 직업 A~F 6개를 만든다. A/B는 원작 테마 맞춤 2개로 각각 원작 대표 기관/사건과 또 다른 생활·사회/산업 측면을 경험하게 한다. C 전투·방어 1개, D 조사/분석 1개, E 범죄/잠입·비공식 거래 1개, F 의외지만 실제 활용 가치가 있는 조커 1개로 구성한다. 조커가 반드시 무능하거나 우스꽝스러운 직업일 필요는 없다.
 각 후보의 직업명·배경/실제 업무·직업 기능7개/배정 수치(**60 / 55 / 50 / 45 / 40 / 35 / 30**)·대표 강점·원작 세계에서 가능한 활동과 접근 기회를 선택 전에 공개한다. 핵심 역할을 차별화하되 직업상 자연스러운 전투·조사·사회 기능의 중복은 허용하고 모든 후보에 같은 시작 기능 총량을 적용한다. 숨겨진 진실·보장되지 않은 인맥이나 무료 물품을 후보 설명에 추가하지 않는다.
 플레이어가 직업을 직접 지정하면 우선한다. 기존 확정 직업은 보존한다. 산업/세부업무/지위/근무환경/경력은 필요할 때 참고하며 다단계 의무 추첨하지 않는다. 특성이 직업명을 자동 결정하지 않는다. 별도 전문 분야는 부활시키지 않고 직업 확정 뒤 STARTING_EQUIPMENT_MINIMAL의 필수 물품 정확히1개를 정한다.

## PC_SKILL_START_VALUES

**신규 생성 또는 미확정 PC만:** 실제 업무·책임·훈련에서 서로 다른 직업 기능7개를 도출하고**60 / 55 / 50 / 45 / 40 / 35 / 30**을 한 번씩 배치한다. 6개 직업 후보 모두 이 수치 기준을 사용하며 선택 전에 각 기능의 실제 배정값을 공개한다. 기존 확정 PC의 직업/기능·성장 스냅샷과 세이브에는 하향 수치를 소급 적용하지 않는다. 업무 축 개수나 선택 전 수치 비공개는 강제하지 않는다.
겹치지 않는 일반 취미 기능1개를 직업 확정 뒤 고르고**30**으로 배정한다. 기존 확정 취미 기능 40 및 현재/영구 성장값은 소급 변경하지 않는다. 그 외 일반 기본20, 회피는 floor(DEX/2), 모국어는 EDU이며 별도 전문 분야 슬롯은 생성하지 않는다. 회피가 직업/취미면 max(해당 배정값,floor(DEX/2)). 관찰·듣기·회피·격투·사격을 공통 표시한다.
직업 기능 7개·취미 기능 1개, 그 외 일반 기본20, 회피 floor(DEX/2), 모국어 EDU, 회피 및 타 기능의 기존 max 예외는 그대로 유지한다. 위 60/55/50/45/40/35/30과 취미30은 **새 PC 시작 기능 배정값**이며 직업 후보의 강점이나 이미 학습한 기능을 지우는 규칙이 아니다.
외국어는 구체 언어를 명시한 일반 기능이다. 크툴루 신화는 세계관·발견 사실로만 기록하고 신규 PC 기능 목록·직업/취미 후보·성장 목록에 수치를 만들지 않는다. 이미 이해한 약점/진실은 원천·공개 범위와 함께 보존한다. 포괄적인 직감/통찰/위험감지/대인관계 등 새 만능 기능을 만들지 않는다. NPC 범위를 PC에게 적용하지 않는다.

**중대 사건의 필연성과 손실·주도권의 분리:** 정상적으로 중심 이야기를 추적하는 완주 경로에서는 정본에 명시한 필수 기점을 관통하도록 구성한다. 핵심 세계 변화·대면/발견·위협의 성립과 구체적인 전투·개체 생존·시설 파괴·PC 피해는 별개다. 이미 진행된 불가역 변화·독립 원인·유한한 복수 수단을 시작 전에 준비해 전체 서사가 실행자 한 명의 생존에 매이지 않게 한다. 큰 세계 손실은 사전에 성립한 불가역 손실과 실제로 위태로운 사람·생활/지역·안전·자원, 앞으로 발생 가능한 중대한 파급을 구별해 적는다. 이미 잃은 것은 사실대로 남고 새 피해·구조·손실 규모는 실제 대응과 판정으로 달라진다. 무조건 추가 피해량을 부과하거나 특정 NPC 사망·PC HP/SAN 손실을 예약하지 않는다. 중요한 실행자의 미노출·거리·경호·퇴로도 사전 사실과 실제 판정의 한계를 따른다. 조기 제압한 실행자의 능력·실제로 막은 공격·방어/구조로 보존한 사람/시설·획득한 안전은 유지한다. 적 수장/실행 수단 전체가 사전에 진짜 차단될 수 있다면 해당 국지 위협의 조기 해결을 인정하고 독립해서 남는 원인만 진행한다. 뼈대는 남은 본질적 문제의 사전 대응/재해석 경로나 정당한 종결로 처리한다. 전원 사망·완전 철수·실제 해결은 완주 보장의 종료 경계다. 뒤늦게 적을 소환하거나 사건을 무적화하지 않는다.
**사전 콘텐츠 수량은 '실제로 놀 수 있는 사건'으로 계산:** 대사건/연대기에서는 **플레이 가능한 독립 주요 사건 8~12개와 개별 서사를 가진 사이드 18~30개**를 생성 목표로 삼는다. **사전 종결된 원인·동일 현장의 기술 작업/소모품/단서 한 번 보기·주요 사건의 세부 선택지는 개수에 포함하지 않는다.** 주요 국면은 처음/중간/후반의 다른 종류의 위기·발견/대면·환경/관계/공동체 변화, 그 이전 선택과 준비가 나중에 다른 결과를 만드는 **실제 상승·회수**를 갖는다. 사이드는 짧은 일상 만남부터 여러 만남/상태 변화를 거치는 관계·생활·원작형 괴이 이야기까지 **분량과 유형을 다양하게** 준비하며 한 줄짜리 발견/수리만 대량 복제해 18~30개로 세지 않는다. 인물/보조 NPC·원작 적(유한 전력)·장소/방·실물 도구/정보·생활사를 이 은행의 실제 선택에 맞춰 확충하고 한 재료가 여러 사건에서 다르게 쓰이게 한다. 원작의 실제 규모상 목표 수량이 불합리하면 무관한 조직/적·빈 구역으로 채우지 말고 **부족한 이유와 실제 대체되는 플레이 분량/경로별 사건 밀도**를 정본에 설명한다. 단순 숫자/메타 설명이 아니라 각 주요 경로에서 실행 가능한 사건으로 충분함을 확인한다.
**풀·물의 상시 작동과 접촉:** NPC의 생업·욕구·관계·자기 시간과 S의 독립 원인/자율 결과는 PC 수락·메인 정체와 무관하게 진행한다. 시작·기점 사이·이동 여정·휴식처의 정상 경로마다 실제 관측/교류 가능한 생활·탐험·휴게 접점을 분산 준비한다. 중심/외곽/안전 지대·교통과 연결하고 한 S가 닫혀도 다른 생활 경험을 선택할 여지를 남긴다. 화면 밖 S 목록만 있거나 메인이 명확하다는 이유로 접점을 생략하면 미완성이다. 모든 S 동시 발동·매 전투 행동의 팝업·휴식 중 강제 사건은 요구하지 않는다. 본래 목적은 원작 세계의 생활감·관계·안도·몰입이다. 실제 인과에 따른 작은 도움/정보·관계·장비 효과는 가능하지만 S 수락/완료만이 필수 사건·핵심 단서·주요 보상/성장을 얻는 유일한 길이어서는 안 된다. 관련 도움이 있으면 별도의 메인 접근 경로를 준비하고 기존 보상 수치를 바꾸지 않는다. 거절한 S의 자율 결과와 실제 소진을 유지하며 이름만 바꿔 재권유하지 않는다.
**사이드 사건·현장 소품·메인 하위 과제를 분류:** 독립 S로 집계하려면 **독자적인 사람/상황의 욕구·갈등/문제·플레이어가 개입/거절할 실제 선택·개입 전후 바뀌는 생활/관계/자원/안전의 결과·PC 없는 자율 경과**가 있어야 한다. 메인 문제를 해결하는 '핀 수리·SOS 연결·장부 회수'만 따로 떼어 동일 E를 다시 세거나, 그림 한 번 보기·정적인 방의 흔적을 독립 완결 사이드로 부풀리지 않는다. 이런 요소도 탐험/분위기·중간 과제로 보존하되 **사이드 분량을 대신하지 않는다**. 사전 S 은행에는 **짧고 선명한 독립 경험과 여러 접촉·인물 관계 변화가 쌓이는 중형 에피소드**가 고르게 있어야 한다. 각 S에는 최초 실행 NPC의 실제 지식/위치·독립 행동, 고유한 첫 접근 장면/갈등·적어도 하나 이상의 구체적인 분기/이후 반응과 **정상 PC 경로에서 만날 수 있는 원인/전달자/장소/이동·연락 조건**을 준비한다. '다른 루트에서는 누군가가 전할 수 있다'라는 공통 복붙은 노출 경로로 인정하지 않는다. 한 사건 거절 뒤 **다른 S를 현실적으로 접촉**시키되 강제 수락·이전 거절 반복/무한 의뢰를 금한다. 즉흥적인 작은 생활 사건은 허용하지만 사전 사건 부족을 메우는 주요 원인·핵심 전력의 사후 생성은 금지한다.


**신규 시나리오의 서사는 시계가 아니라 목표·세계 상태로 진행:** 대명제/필수 국면의 연결은 SCENARIO_BLUEPRINT와 기존 정본 `DRIVER_BASELINES/PC_CONNECTIONS`의 **실제 조건·관계·인과적 목표망**을 따른다. LINKED_MAJOR_DISASTER_TIMERS는 이름을 유지하는 구판 호환 ID이지만 **신규 정본에서 메인 사건 예약 시각표를 작성하는 규칙이 아니다.** 기존 검증 정본에 기록된 고정·상대 타이머는 비소급으로만 보존한다.

세계 생성의 필수 결과는 원작 체험을 진행할 조건부 진행 설계도다. 대표 원작 경험은 SOURCE_EXPERIENCE_CONTRACT로, 주요 사건의 PC 체험 연결은 PC_REACHED_EVENT_CONTRACT로 설계하고 COMPATIBILITY_GATE로 확인한다.
**출발점·지식별 접근:** 일상/업무에서 우연히 연루된 PC와 이미 위험을 알고 직접 대응하는 PC를 모두 지원한다. **PC별 출발 사실:** P1~PN 각각의 직전 행동·현재 위치 이유·개인적 당면 일/약속/수행 대상·접촉 인물·목적지·첫 행동 수단과 공개 범위를 기존 정본에 확정한다. 한 PC의 개인 목적/정보를 다른 PC가 동기화로 자동 아는 것으로 만들지 않는다. 혼합 팀은 PC별 목적·인지·위치·동행 동의를 구분하고 아는 사실을 의무 재조사시키지 않는다. 확정된 첫 목적에서 첫 기점까지 최소 두 상이한 정상 접근 경로를 검토하고 원작/공간상 불가능하면 이유와 가능한 대응을 남긴다. 이는 퀘스트 개수가 아니다. 시작부터 생활/S가 작동하며 첫 목적·주요 목적지·정보 운반자·필요 장비·실제 통로는 사전 정본에 존재해야 한다. 긴 여정에도 기존 사람·시설·휴게/원작 접점이 있고 이동은 실제 수단·거리/소요를 따른다. 모든 대사/일상 반응을 미리 쓰지는 않지만 핵심 재료와 접근 경로를 플레이 중 새로 발명해 목표 공백을 메우지 않는다.
**기존 목적을 살리는 열린 사건망:** 신규 정본은 PC의 평범한 업무·생활·책임이 원작 고유의 위험과 접촉하게 설계하되, 첫 위협을 격퇴·회피·차단한 뒤 **기존 목적이 유효하면 정상적으로 계속할 경로·사람·시설·도착지의 세계 상태**를 연결한다. 그 목적을 이어가는 대표 경로, 다른 방향으로 우회하는 경로, 실패·포기·철수한 경로에서 각각 실제로 닿을 수 있는 원작다운 상황·선택·안전/종결을 대조한다. 단서/특정 방문·강제 재난·미리 배정한 다음 퀘스트에만 의존해 진행을 보장하지 않는다. 주요 사건의 독립 원인·유한 적/핵심 자원·필연 발생은 기존대로 사전 확정하며, 모든 대화·NPC의 반응·사소한 후속 갈등을 대본으로 고정하지 않는다. 그 미확정 부분은 기존 인물의 목적·지식·위치·수단과 플레이어 결과에서 생길 가능성으로 열어 둔다. 주요 사건을 많이 준비했더라도 PC의 위협·목적·관계·수단·인식에 끝내 아무 영향도 없는 사건은 핵심 플레이 사건으로 세지 말고 접촉 인과를 보완하거나 배경으로 축소한다.

**PC별 메인 당근과 독립 풀·물의 분류:** 신규 정본은 P1~PN **각각**에게 현지 출발 목적→원작 중심 사건의 실제 접촉→인지하고 추구할 수 있는 중대 E 방향 또는 원작 대명제와 인과적으로 연결된 작은 목표를 준비한다. 각 PC의 첫 사건 도달/대응 경로·정보 소지/전달·자율 NPC·접근 수단·마지막 당근이 닫힐 때의 기존 다른 메인 방향을 각각 정본 ref로 검증한다. P1에게 E가 닿거나 파티 공통 목표가 있다는 이유만으로 P2/P3의 메인 당근도 존재한다고 처리하지 않는다. 동일한 원작 재난에 서로 다른 현장/방식으로 연결돼도 되지만 합류·동시 목격·정보 공유나 개인의 선택은 강제하지 않는다. **풀·물 및 독립 S는 개인 생활·휴식·교류·탐험·사이드 목적**이며 유용한 보상·정보·장비/관계를 얻었다는 이유만으로 메인 작은 당근으로 재분류하지 않는다. 같은 장면에 양쪽이 존재해도 독립 S와 메인 E/작은 목표의 원인·ref를 따로 둔다. **P1만 사건을 겪고 P2는 S 세 개만 수행하는 경로**는 P2의 메인 목표 공백이므로 신규 세계 설계 실패다. 정당한 철수·완전 해결·사망/종결 이후에는 새 메인 목표를 강제하지 않는다.

**전체 당근 시야와 작은 목표의 자유:** 작은 목표의 성공·실패·우회 뒤 먼저 이미 보이는 중대 기점의 방향이나 다른 유효한 작은 목표를 확인한다. 기존 당근이 남으면 직접 후속 없음도 합격이며 새 단서/의뢰를 억지로 발행하지 않는다. 마지막 메인 당근이 닫히는 비종결 결과에서만 준비된 다음 방향이 지금 인지·추구 가능하도록 잇는다. 다음 기점의 정체가 비공개여도 어디서 무엇을 왜 시도할지 현재 PC가 이해할 수 있어야 한다. 작은 목표는 경험·준비·관계·갈등·발견 자체로 사람/수단/안전 등을 바꾸며 전부 필수 단서나 해금 과제가 될 필요는 없다. 각 목표의 ref·현재 구간/역할·관측 표지·행동 가능한 이유·NPC/장소/물건·이동/전달 소요·선택 수단·성공/부분 성공/실패/포기 결과·남는 활성 목표 또는 마지막 목표의 후속 경로·비공개 범위·정당한 종료를 기존 정본에 연결한다. `next_goal_ref`를 모든 작은 목표에 의무화하지 않는다. 구간당 작은 목표의 완료 개수·체험 횟수·시간 상한은 없으며, 8~12 E/18~30 S는 사전 준비 목표일 뿐 작은 목표/체험의 상한이나 기점 해금 조건이 아니다. 무제한은 유한한 풍부한 재료와 실제 상태 변화의 결합으로 다양한 경로를 지원한다는 뜻이다. 소진된 심부름·보상 농장·없는 핵심 적/중요 인물의 무한 생성으로 채우지 않는다. **새로운 주요 국면을 일으키기 위한 고정 시각/유예·시간 간격은 제작하지 않는다.**
**정상 체험을 벌주지 않는 사건 구조:** PC가 준비된 장소를 살펴보고 사람과 관계를 맺고 실물을 손보며 보급하는 통상적인 체험을 실제 시간만큼 수행했다고 해서 **주요 목표 전체가 자동 실패하거나 핵심 인물·대응 기회가 일괄 소멸하도록** 사건들을 배치하지 않는다. 이는 시간을 무료로 주거나 현실의 시계를 정지한다는 뜻이 아니다. 이미 도달한 화재·침수·공격·개별 구조 시한과 플레이어가 실제로 방치한 특정 위험의 결과는 유지하되, 그 국지적 손실과 세계 전체의 메인 사건 실패를 구별한다. 독립 세력의 준비·경계·작업·이동, 사건의 단계적 파급과 사후 남은 사람·시설·문제를 원래 인과로 준비하여 **일상/준비를 즐긴 경로에도 지금 직접 대응할 유효한 중심 경험**이 남게 한다. PC가 신속하게 해결·차단하거나 안전하게 이탈하면 이미 확보한 성과를 존중하고 강제 체류·추가 재난을 만들지 않는다.
**절차적 조사 중심 전개의 배제:** 정보는 행동·위험·신뢰·경로·해결 수단을 변화시키는 재료이지 다음 장면을 열기 위해 제출할 검증 단계가 아니다. 문서 발견→진위 확인→증인 방문→추가 자료 신청의 반복이나 단서 수집량/진상 입증을 메인 진행의 기본 엔진으로 설계하지 않는다. 중요한 사실은 현장 현상·적/NPC 행동·도구 활용·구조/대면·생활 속에서 접촉 가능하게 하고, 발견 직후 현재의 대응·협력·준비·돌파·여파로 이어지게 한다. 플레이어가 스스로 선택한 깊은 조사/추리는 충분히 허용하되 의무적인 절차적 검증과 창구 순례는 만들지 않는다.
**동일한 적의 상황별 체험 차별화:** 유형/개체 수를 늘리는 것으로 위협의 다양성을 대신하지 않는다. 주요 조우/위험 접점마다 기존 유한 개체의 실제 목적·정보와 **지형/거리·수직 동선·엄폐/시야·날씨/시설·지킬 사람/물건·가능한 퇴로·PC가 확보한 도구**가 달라지면 관측·회피·유인·방어·구조·격퇴의 문제가 어떻게 달라지는지 장소/사건 ref에 연결한다. 같은 적의 기존 능력/약점/피해식을 유지하고 환경에 없는 특수 능력이나 강제 조우를 새로 붙이지 않는다. 전투 없이 목표를 지키거나 빠져나오는 성과도 인정한다.
**목표망의 깊이와 자연스러운 분량:** 대사건을 E01~E04 같은 연대기 일정으로 만들지 않고 원작 생활→첫 실제 갈등→여러 서로 다른 필수 국면→대명제 결산의 **목표·결과 의존 연결**로 만든다. 길이를 보장할 것은 대기 시간이나 강제 방문 횟수가 아니라 **많은 준비된 사건/사이드·행동·정보·자원·관계의 실제 선택**이다. 한 목표가 신속히 해결돼도 후속 국면/사이드 후보가 충분하고, 기존 목표를 우회해도 다른 의미 있는 연결이 열린다. 세계의 밤낮·이동거리·통신/작업·추격/폭풍·침수의 물리 속도는 실제 행동 중 유지하지만 **그것을 대명제 진행의 전역 시나리오 시간표로 전환하지 않는다.**
**세계 인과와 PC에게 닿는 목표의 분리:** 세계의 원인·실제 실행자/NPC/적·위치/지식·전파/이동 수단은 미리 정하고 PC와 무관하게 살아 움직인다. 각 사건에는 (1) 시작을 성립시키는 **사전 정해진 상태/인과 조건**, (2) PC 현재 일상·업무/생존 루트에서 관측할 수 있는 전조/접촉의 복수 경로, (3) 대응·피해 완화·우회와 다음 목표/사이드·실제 결말의 분기를 연결한다. 세계에서 발생함, NPC가 알아챔, PC가 직접 경험함을 구별하며 화면 밖 뉴스만으로 PC의 핵심 체험을 완료 처리하지 않는다. PC에게 아직 닿지 않은 사실은 공개하지 않고, 실제 도달 경로/위험을 무시한 순간이동 접촉도 하지 않는다. 신규 필수 국면은 특정 시각표로 재생하지 않는다.
**결과별 접촉 경로는 물리·정보 상태로 증명:** E/중간 목표의 성공·부분 성공·실패·우회·조기 차단·미개입에서 후속 목표가 생기는 경우, 해당 결과 직후 **PC/팀의 실제 위치·알고 있는 것·가지고 있는 수단**을 출발 상태로 둔다. 후속 E/S 또는 원래 업무에 연결되는 **최초 관측 가능한 사람/사물/현상과 정본 ref**까지 경로를 따라가며, 정보라면 최초 인지자→내용→전달 결심/목적→이동·통신 수단/통과 장소→수신자·수신 조건, 실물/위협이라면 소유·출발 위치→이동 가능 경로/차폐·접근 시간→PC가 감지할 조건을 확인한다. 다른 장소의 NPC나 고장난 수신기에 정보가 순간 전달되는 연결, 아직 결정되지 않은 PC의 방문/수락·협력이나 미래의 임의 NPC를 필수 운반자로 가정한 연결은 미완성이다. 한 경로가 닫히면 해당 ref를 억지 공개하지 않고 **이미 준비한 다른 현재 행동 가능성/정당한 안전·종결**을 사용한다. 현장 작업·대화·도보/통신의 실제 시간은 소요되지만 '새 E 발동 시각까지 대기'는 다음 행동이 아니다. 화면 밖에서 세계가 발생함·NPC가 알게 됨·PC가 듣거나 관측함·PC가 제안받음·PC가 수락/수행함을 서로 다른 상태로 취급한다.
**시나리오 시간표의 사용 금지:** 신규 정본은 주요 사건마다 '20:00 사고 / 21:40 폭풍 / 새벽 04:40 최종 작전'처럼 **발생 시각을 예약해서 메인 진행을 설계하지 않는다.** 앞 사건 종료+N분, 플레이어 퀘스트 수락, 플레이 진도/채팅 턴도 다음 재난의 발동 버튼이 아니다. 주요 국면의 세계 인과·대응/후속 기회는 사전에 준비된 사건/상태·실제 NPC/기관/적의 목적·지식/수단과 환경 법칙으로 전개한다. 개별 화재·침수·전투/작업 등 **현장에서 이미 발생한** 물리 현상·원작에 실제 존재하는 역사 시각은 사실대로 관리하되 **새 시나리오의 전역 E사건 시각표로 복제하지 않는다.** 구판의 예약 타이머는 비소급.
**정체 시 직접 다가오는 세계:** PC가 같은 장소에서 실제 게임 시간을 오래 보내거나 되풀이된 조사/대기·준비를 선택한다면, 그 지역의 기존 적/NPC/환경이 **원래 목적/정보/경로·수단·경과**에 따라 탐색 범위를 넓히고 교섭·구조 요청·정찰·공격·봉쇄/침수처럼 PC에게 닿는 결과를 만든다. 장면·대사 입력을 기다리는 현실 시간은 극중 시간이 0이고, 위험한 선택을 하지 않았다는 이유만으로 NPC·적이 모든 일을 멈추지도 않는다. 반대로 PC가 실제로 잘 숨었고 감지/전파 경로가 없다면 특정 적이 무조건 PC를 찾아오거나 '시간을 끌었으니 맞는다'는 벌을 주지 않는다. **압박의 진행과 최후 시한, 신호/정찰·감지·피해/실패·대응/안전의 조건은 원래 정본 인과에서 확인 가능**해야 하며 완료된 선택·판정/경과를 역산하여 딱 맞는 공격 시각을 꾸미지 않는다.
**참가 인원에 따른 사전 위협 규모 설계:** 새 게임 생성 때 실제 선택한 **PC 1~3명과 이미 확정된 기능·장비/카드 효과·동행 가능 NPC의 자율성**에 맞춰 위험의 **범위·활성 구역/독립 전선·유한 개체 수와 편제·적 전술/감지·환경 위해·구조 대상/목표·자원/엄호 필요**를 시나리오 생성 단계에서 정본으로 맞춘다. PC가 늘면 협력/기술·동시 행동/엄호가 늘 수 있으므로 두세 명이 함께 있어도 실질 위험과 목표의 규모·행동 분산/위협 압박이 충분할 수 있게 준비한다. 하지만 **PC 수 × 고정 적 수/HP·피해량 배율**이나 모든 적을 무조건 상향하는 방식은 아니다. 1인이라 안전한 이야기/자동 명중 실패가 아니고 3인이라 무조건 적이 세 배·보스 HP 세 배인 것도 아니다. 인간 세력/원작 생태와 공간 규모상 존재할 합리적인 최초 전력·목적·보급과 실제 대응/우회·구조 경로가 우선한다. **정본 확정/플레이 시작 뒤 PC 수·현재 HP·연승/철수 의도에 맞춰 적을 새로 생성/회복·증원·피해식 조정하거나 이미 확보한 안전을 취소하지 않는다.** NPC가 실제 합류하거나 떨어질 때는 그 인물의 실제 능력·위치/정보·동의를 반영할 뿐 임의 난이도 증감은 없다.
**메인 무대의 유효 체류 시간과 사건 지속성:** 신규 세계/미확정 챕터의 실제 중심 거점에는 PC가 일상을 살펴보고 NPC와 교류·관계를 만들며, 시설/도구를 탐험·활용하고, 위협을 알아차려 준비·구조/방어하며 실제 성취를 확인할 **충분한 극중 행동 가능 구간**을 준비한다. 해당 거점의 핵심 사건은 첫 접촉/공격이 시작됐다는 이유로 모든 구조·발견·대면/저지 기회가 몇십 분 만에 소진되는 단발 장면이 아니라, 실제 원인에 따라 **준비/접근 → 국지적 접촉·압박 → 목표 수행/재정비·경계 변화 → 미개입 시 누적 결과** 등 현장 상태가 남고 바뀌는 지속적인 문제여야 한다. 이 순서를 필수 장면이나 임의 지연 스크립트로 만들지 않는다. 원작/물리적 사고의 긴급 속도는 그대로 유지하면서, 적의 임무·소식 전달·수색/회수·시설/기관 대응과 목표의 유효 기간에 실제로 걸리는 시간·공간·미완료 일을 나누어 설계한다. **정상적인 생활 교류·자발적인 탐험/준비를 충분히 즐겼더니 주요 목표와 모든 관계·대응 기회가 이미 끝나 있는 구조**는 대사건의 메인 무대로 미완성이다. 다만 PC가 실제로 미뤄 놓은 구조/화재·특정 인물의 상황처럼 시한이 촉박한 과제는 놓칠 수 있고, 플레이어가 매우 빨리 해결하거나 안전하게 떠나면 남은 시간을 강제로 소모시키지 않는다. 통상 생활 장면을 매 턴 무료 시간으로 취급하거나, PC가 생활을 즐기면 세계가 정지하는 방식도 아니다. 사건 종료/사람의 퇴장 이후에도 현장에 남은 물리적 피해·적의 다른 목적·생존자/기관의 자발 행동과 실제 복구/철수 기회가 있다면 후속 현장 상황으로 이어지게 한다.
**핵심 적대자의 초기 충돌·생존 수단과 사건 인과:** 나중의 작전에 필요한 지휘자/상급·최종 적을 초중반에 직접 노출할 경우, **첫 접촉의 목적이 무엇인지·어떤 거리/엄폐·경호/동료·실제 탈출 수단·위치와 시간·정보 한계·피해/탄약/사기**를 사전에 정해 무작정 결사전이나 죽을 때까지 추격하는 AI로 만들지 않는다. 정당하게 생존을 우선하는 적은 초기 패배·부상·자원 손실/목표 일부 포기 뒤 **물리적으로 가능한 후퇴·재집결·다음 작전**을 선택할 수 있다. 필요하다면 메인 적이 처음에는 직접 맞붙지 않고 정찰/대리인·먼 거리의 관측/교섭으로 모습을 드러내게 설계할 수 있다. 그러나 **지휘자의 중요성을 이유로 플레이어가 성공시킨 사살·체포·봉쇄를 강제로 실패 처리하거나 불사/자동 탈출을 부여하지 않는다.** 실제 퇴로를 막아 사살·체포에 성공했다면 그 결과를 확정하고, 원래 예정된 후속 재난의 **독립적인 인과·이미 진행 중인 작업/시설·유한한 다른 실행 주체/중단 없는 명령·조직의 실제 수단**이 사전에 존재할 때만 그 사건의 발생을 계속 처리한다. 사건을 특정 인물 한 명의 생존에만 의존시켜 놓고 동시에 '그가 죽어도 반드시 공격'이라고 적는 정본은 미완성이다. **필연적 주요 재난의 발생 원인은 실행자 개인의 생존과 분리해 사전 구성**하고, 조기 제압은 그 인물이 맡았던 지휘·기습/폭력·사후 확산/피해의 실질적인 차단으로 보상한다. 적 후퇴는 실패한 공격의 덮개가 아니라 실제 방어/대항·이동 성공과 생존 수단이 성립할 때의 결과다.
**지역별 압박과 호흡을 분리:** 즉각적인 생명 위협(침수·화재·추락/공격)은 원래 물리 속도와 전투/환경 담당 규칙대로 바로 처리하고, 적의 회수·추적/기관 동원·폭풍 확대 등은 실제 이동·준비·정보 전달·지형/상태 변화에 필요한 경과를 거쳐 단계적으로 도달시킨다. 플레이어가 위험에 대처하고 생긴 **짧은 실제 안전·구조 완료·동료와 대화·사물 탐색·여파를 경험하는 시간**도 세계에 마련하며, 위험이 끝났다고 모든 생존 원인이 끝나거나 새 위기가 임의로 바로 붙는 것은 아니다. 생활 장면을 늘린다고 재난의 불가역 발생 자체를 없애거나 무해화하지 않는다. 플레이어의 선택·실제 경과로 사건이 겹치면 그 결과를 인정하되 **임의로 30분마다 새 공격/시계 알림을 배치하지 않는다**. 진행이 무의미하게 길어질 때는 이미 선언한 통상 작업/이동을 목적 단위로 압축하고 새 위험·발견/교류/결과가 닿는 지점만 펼친다.
**철수도 재난 속에서 실행하는 플레이:** 주요 재난·습격의 발생은 거절·무관여·즉시 귀가 선언으로 취소되지 않는다. 신규 정본은 첫 재난이 PC의 출발 공간과 생활·이동 수단에 실제 도달하고, 안전 경계에 들어가기 전 어떤 합리적인 조기 철수 경로에도 이미 발동한 재난의 구체적 접점·관측·대응·실패 위해가 존재하도록 설계한다. 떠나겠다고 말한 뒤 난파·폭풍·구조 혼란·원작 적의 실제 접근과 반응을 장면 생략으로 없애 평온한 귀가 엔딩을 제공하지 않는다. 플레이어를 붙잡는 것은 정본에 준비된 원인과 PC에게 닿는 실제 위협이지, 탈출을 막기 위해 사후 추가한 적/봉쇄·마법 장벽·필수 보스전이 아니다. 플레이어는 모든 주요 재난의 발생을 예방할 수 없어도 **구조·우회·퇴각·격퇴로 후속 피해를 줄이거나 무상처로 위험을 돌파**할 수 있으며, 확보한 진짜 안전과 합당한 조기 종결은 인정한다. 모든 후반 재난을 반드시 직접 겪게 하거나 상처·광기를 할당한다는 뜻은 아니다.
**원작 고유의 공포는 게임 초입부터:** 도입부의 실제 일상·업무/사람·이동 공간에 첫 사건이 충돌하는 순간 원작 특유의 생물/현상/기이한 흔적·공간·행동·물성의 차이가 **PC가 관찰하거나 대응할 수 있는 형태**로 드러나고 실질적인 위험·판단/관계·안전 경로를 바꾸게 한다. 초기 철수 경로도 평범한 사고만 겪고 끝나는 길로 비우지 않는다. 전체 진상·적 정체를 미리 공개하거나 단순 긴장에 SAN을 부과하지 않는다. 적격 SAN 노출은 실제로 보거나 이해한 시점에만 담당 규칙으로 처리한다.
**방마다 살아 있는 세계가 있는 탐험:** 주요 건물의 각 의미 있는 방/출입 공간은 원래 용도·사람의 일상/근무·공간 구조·문/차폐·현재 상태와 더불어 확정된 실제 도구/자원·방문객/거주자·독립 NPC의 작업/도피·적의 접근·핵심 흔적 또는 생활 기록 가운데 현실적으로 적합한 구체 내용을 연결한다. 특히 사소한 근무 메모·요리법·돈 계산·편지·취향·사적 갈등/농담 등 **사건 해결과 무관해도 인물의 삶을 드러내는 물건/기록**을 원래 소유·장소·시점·짧은 실내용과 함께 준비한다. 모든 방의 전투/퍼즐/단서/보상을 의무화하지 않고, 모든 방을 열 때마다 즉흥적으로 장비 한 개를 생성하지 않는다. 살아 있는 NPC/적은 실제 위치와 이동 조건을 만족할 때만 만날 수 있다.
**유한한 조건부 무작위 인카운터:** 변화 가능한 사건에는 지역·실제 경과/소음/기상·NPC/적 위치와 목적·실제 준비된 개체 ID·발동/제외·감지/기습·결과/중지·소모/재방문 상태를 갖는 선택적 조우 후보/실제 난수 규칙을 마련한다. 정본이 미리 준비한 적 이동, 다른 일을 하던 NPC와 마주침, 환경 위험, 사람의 생활 흔적이나 선택적 자료 발견, 조용한 빈 시간 등이 가능하다. 무작위는 기존 인과가 허용하는 불확정 **접촉 여부·시점·후보**만 결정하며 새 적/생존자 무제한 생성·이미 죽은 자 복귀·물품/금화/탄약 복제·PC 피해/광기 확정의 도구가 아니다. 모든 문/턴에 무작위 검사를 강제하지 않으며 확정 조우·이미 차단한 위험을 난수로 다시 뒤집지 않는다.
**여러 장소에 분산한 추리의 재료:** 사고의 원인, 원작 적의 행동/약점, 인간 세력의 목적, 대응 가능한 경로처럼 플레이어의 선택을 바꾸는 중요한 진실은 서로 다른 방·현장 흔적·생존자의 부분적 증언·사물/기록·괴물의 실제 행동에 연결한다. 확인한 사실과 인물의 의심은 구분하고, 발견 시 전체 해답을 일괄 전달하지 않는다. 생존·우회·대화·자료 확인으로 서로 다른 일부를 모아 플레이어가 자기 가설을 세울 수 있어야 한다. 배경 소품은 전부 진실의 단서일 필요가 없고, 핵심 진실도 오직 한 잠긴 서랍/유일 기능/보스 처치에 종속되지 않는다. 힌트가 현재 위험 대응/관계/자원·탈출 선택에 실제 쓰이도록 한다.
**세계→시대/지역 전체 공간→시설/물품/사람→중심 사건의 접촉과 역검증:** 신규 세계는 먼저 원작의 시대·문화·지역·기술·생활양식과 중심 재난/세력·숨은 원인·핵심 진실을 설정한다. **사건 진행에 필요한 장소만 만들지 않고, 그 시대·지역·원작에 독립적으로 존재했을 법한 주거·생업·교통·공공시설·휴식/상업·자연 지형·주변 생활권을 실제 규모와 사회 구조에 맞게 지도에 충분히 구축한다.** 중심 사건에 직접 쓰이지 않더라도 역사·지리·인구·산업·생업상 존재할 이유가 있다면 배치하며, 플레이어가 무엇을 방문하고 어디서 머물지 자유롭게 결정할 수 있게 한다. 중요한 구역은 공간 연결·문/진입·시설 상태·기능·활용·우회·이동/퇴로를 구체화하고 주변 구역은 실제 운용할 만큼 깊이를 조절한다. 이후 그곳에서 살아온 인물·사건과 맞춰 지도를 역검토한다. 해당 장소에 실제 존재하는 자원/소유·양·소모, 물증/기록·개인사/생활 소품·사건 흔적·활용/오해와 변화 조건을 깔고, **거기에 있어야 할 이유가 있는 여러 NPC·적대 개체를 실재 위치·목적·이동/정보·수단에 따라 배치**한다. 장소만 먼저 기계적으로 확정해 사람을 거기에 끼워 넣는 일방향 작업은 아니다. NPC 직업·가족/거래·세력 충돌·피난 선택 때문에 생기는 공간/시설·물건과 통로가 있으면 앞의 세계/지도를 다시 맞춰 **인물·장소·물품·사건이 양방향 인과로 일치**하게 한다. 무관한 방/적/물건/인물을 채우기 위한 숫자 할당이나 가짜 탐험 보상으로 밀도를 가장하지 않는다.
**배치된 공간 전체의 핍진한 내용:** 세계에 실제 존재할 법한 각 주요 장소/시설·방에는 원래 용도에 맞는 가구·기물·도구·소모품·보급, 사용 흔적과 건물/시설의 현재 상태, 누가 남긴 일상 기록·물품·사연 또는 사건 증거/전조가 **실제 소유/위치·접근·내용/상태와 함께** 준비돼 있어야 한다. 중심 사건과 무관한 집·가게·휴게소·기숙사·골목에도 그곳 사람의 삶이 느껴지게 한다. 일부에는 유용한 단서·위험·NPC·적이 있고 일부에는 평범한 생활 내용만 있어도 된다. **모든 장소에 진상 힌트·보상·몬스터를 억지로 넣지 않되, 빈 방마다 키퍼가 그럴듯한 장비를 즉석 발명해 채우는 방식으로 미리 준비한 세계를 대신하지 않는다.** 시나리오 주요 장소의 물건/자료·사람·위험은 구체적으로, 주변 생활 장소의 통상 소품은 일관된 범위로 준비한다.
**사건 안으로 들어가게 하는 불가피한 현실과 이후의 철수:** 원작의 핵심 공간을 설계할 때 'PC가 관심 있으면 방문'만을 기본 관여 경로로 두지 않는다. **초기 생활·업무·귀가 동선에 반드시 발생하는 재난의 충돌**을 설계해, 사건 첫 국면/원작 특유의 위협을 PC가 자신의 위치에서 직접 겪고 대응하게 한다. 필요하면 원래부터 존재하는 파손·재난/통신 두절·구조 책임·안전한 대피시설/특정 장비의 실제 필요 때문에 핵심 거점으로 향해야 할 강한 물리적·사회적 이유를 만든다. **재난 속에 진입할 수밖에 없는 상황**은 사전 확정해도 PC가 특정 행동·방향·대사/동의·희생·성공을 선택했다고 대신 서술하지 않는다. 거점을 향하는 길과 PC가 실제로 이용할 수 있는 다른 방법은 정본에 물리적 상태·수단·난관/대가로 준비하고, 이미 성공한 우회/조기 안전/구조·격퇴를 '아직 핵심 장소를 안 갔다'는 이유로 취소하지 않는다. 초반 위기를 한번 겪은 뒤 실제로 철수·구조 대기·우회·심층 탐험을 결정할 때 후속 접촉/여파를 처리한다. PC가 원하면 무조건 무사 귀가하는 무료 경로나 플레이어 입력 없이 핵심 장소로 순간이동하는 각본 모두 금지한다.
**적의 역할이 다른 다층 필드 배치:** 원작에 맞는 유한 적 개체를 거점에 고정 배치하는 데서 끝내지 않고 **배회·순찰/영역 방어·이동 중 약탈/탐색·실제 흔적 추적·표적 추적/압박·출구/자원 차단·매복/지휘** 등 서로 다른 독립 임무에 분산한다. 각 적은 최초 위치/순찰 구역·경유 지점·유휴/활동 시간, 추적 대상/목적·감지 수단/거리·실제 속도·소음/빛/냄새 등 흔적 지속, 마지막 확인 위치·수색 포기/교대·다른 적과 연락/협동 범위, 관측 가능한 전조·공격/회피·격퇴/차단과 유한 전력·재방문 상태를 갖는다. **추적자**는 실제 목표를 발견하거나 흔적을 확보했을 때만 압박하며 거리/실패/정보 단절로 놓칠 수 있고, **배회자**는 PC가 없어도 자신의 경로를 움직여 뜻밖의 접촉이 생길 수 있다. 적의 접근 때문에 이동·작업·장기 체류가 위험해지도록 설계하되 모든 복도/방에 적이 있거나 시간을 끌었다고 무조건 발각되는 구조는 피한다. 중요 안전 지대·확정한 잠금/회피/격퇴와 적의 유한 개체 ID는 보존한다.
**원작 초반 직접 노출과 지역별 소규모 생활 사건:** 초반에 반드시 닥치는 첫 위기에는 단순 사고·어두운 분위기 이상의 **원작 고유의 비인간적 형상/움직임·물리적 접촉/습격·관측 가능한 흔적과 대응 수단**을 이미 존재하는 개체/세계 원인에 연결하고, 선박·건물·대피로 등 첫 선택의 실제 위치에서 볼/듣거나 피해를 줄일 기회를 준비한다. 전원에게 정체·진실을 해설하거나 SAN/피해를 일괄 배정하지 않는다. 주요 생활 공간마다 장소의 본래 기능·거주자/방문객과 별도로 **핵심 사건과 직접 관련 없는 작은 분쟁·분실/수리·가족/생업의 고민·사적인 기념물/기록·우연한 도움·오해/거절·지나가는 사람의 행동** 중 적합한 구체 사건/실물을 여러 지역에 분산한다. 각 소규모 사건에는 실재 사람·소유/원래 위치, 실제 계기/도달·미개입 행동, PC가 관찰/대화·도움·무시/도주할 때 바뀌는 관계/자원/위험을 갖추며 모두 보상·퀘스트·핵심 단서로 만들지 않는다. 일부는 조용히 생활만 이어지고 일부는 큰 재난의 경로와 충돌한다. 의미 없는 방마다 1회 조우 강제나 출처 없는 NPC·괴물/증거 즉흥 생성으로 밀도를 대신하지 않는다.
**핵심 장소·필연적 국면의 인과적 강제력:** 비공개 정본에서 주요 이야기 사건/생존 난관과 밀접한 핵심 장소·시설을 구별하고, **어떤 목표·재난의 영향·물리적/사회적 필요 때문에 누구에게 그곳의 접근이 필요해지는지**, 그 조건을 PC가 실제로 관측하는 방법·통상/우회 접근로·대체 시설/수단·접근 거부/철수·미개입 시 세계 결과를 확정한다. 예를 들어 유일하게 가동하는 실제 구조 통신 시설을 쓰려면 그 시설에 접근해야 할 수 있으나, PC는 다른 생존/구호 방법을 택하거나 해당 목표를 포기할 수 있다. 사건 자체는 PC의 거절로 멈추지 않고 원인에 따라 PC의 생활/퇴로로 도달한다. **키퍼가 PC를 특정 방으로 데려가는 행동·동의·갑작스러운 봉쇄를 대신 만들거나, 모든 핵심 장소 방문을 고정 클리어 목록으로 요구하지 않는다.** 주요 시설의 이용이 실제로 불가피한 경우는 이미 설계된 물리·사회 조건에서만 성립하며, 바꾼 환경/준비·국지적 차단으로 불가피성이 사라지면 그대로 인정한다.
**분산 이전부터 성립하는 생존 위협의 실효성:** 파티 분리 페널티로 부족한 위협을 보충하지 않는다. **전원이 함께 있어도 진지하게 감지·방어/전투·구조·우회·퇴각·준비를 고민할 만큼 실재하는 재난·적의 공격력/수·감지·이동·자율 전술·환경 위해와 자원 압박**을 정본에 설계한다. 평소 방문할 장소와 통상 이동/구호·탐험·이탈의 실제 경로에도 능동적 적대 개체/위협과 끔찍한 원작 현상이 발생/접근할 인과를 마련한다. **모든 난관을 4명이 함께해도 버티기 어려운 전면전으로 만들라는 뜻은 아니다.** 동료가 있을 때 경고/구조·공격/방어 행동 기회·도구 결합·엄호/퇴로 확보·정보 공유로 실제 위험을 줄일 수 있고, 그 도움이 없어지면 치명적인 공격/환경 노출·고립·구조 지연의 확률과 여파가 커지는 이유를 공간·적·자원과 함께 준비한다. 전원이 함께해도 위험하지 않고 두 소팀이 항상 손해 없이 업무를 완수한다면 **근본 위협의 도달·위해/자율 행동 설계가 부족**한 것이다. 반대로 한 명이라 무조건 사망/부상하고 둘 이상이라 자동 안전한 수치·숨은 증원·보정은 만들지 않는다. 실제 선행 관측과 대응 가능성, 정당한 성공·무상처 생존·위험한 실패를 모두 보존한다.
**파티 분리의 독립적 실질 위험을 사전 설계:** 1~3 PC와 실제 합류할 수 있는 NPC의 복수 현장 행동에 대해 단독/동행·분산 탐험 시 **합류 거리/소요시간, 문·층·차량/수로·전파·시야/음향 차폐, 통신/경보 도구와 실제 공유 가능 정보, 양쪽이 나눈 무기·의료품·광원·열쇠/운송 수단, 서로가 부재해 할 수 없는 구조·엄호·기술 조합, 적의 감지/기습·집단 공격/협박·고립/절도/미끼·침투 기회, NPC의 본래 의도와 변심/도움·배신 가능 접점**을 준비한다. 외부의 재난·적은 분리된 일행의 행동/소음/이동에 각자 반응하며 서로의 존재를 전지적으로 알지 못한다. 따로 움직이면 동시 수색 효율·위험 분산·적 회피 이득도 생길 수 있으므로, **분리했기 때문에 자동 피해·모든 NPC 배신·숨은 적 생성·주사위 페널티**는 없다. 미리 준비한 원인에 따라 구조가 늦어지고 대응·판돈/상처/사망 가능성이 달라지는 실제 분기를 만든다. NPC 동행은 다른 PC 동행과 동일한 통제력/신뢰/정보를 보장하지 않으며, 함께 있는 NPC도 보호·협력에 유능할 수 있다. PC 2명이 서로 곁에 있어야만 전투/탈출에 성공하도록 하는 일괄 규칙 대신 **공동 대응의 유리함과 분산의 대가가 실제 사건에서 체감되는 상황**을 설계한다.
**NPC의 동행·복종은 특별한 합의이지 기본값이 아니다:** 주민·동료 후보·전문가가 PC를 처음 본 순간 믿고 동행하거나 요청을 명령처럼 따르도록 준비하지 않는다. 중요 인물마다 현재 안전/위험 평가·자기 목적/보호할 사람·일/세력 책임·위험 감수 한계·지시를 따를 이유와 **거절할 지시·협력 조건·독립 행동/계획 변경·대안 제안·이탈 조건**을 준비한다. 도움의 대가가 반드시 금전·퀘스트인 것은 아니다. 가족을 지키기, 자기 물건 보호, 위험 피하기, 신뢰 부족, 원래 일의 책임, 전투 공포, 다른 안전 판단, 피로/부상만으로도 사리에 맞는 거절/한정 협력이 가능하다. **기본적인 협력이 성립한 뒤에도 위험한 곳 선행 정찰·혼자 남기·무기/의료품 인계·비밀 폭로·다른 PC 없이 동행 등의 새 요구는 NPC가 자기 의사로 다시 판단**한다. 반대로 확정한 합의 범위의 평범한 협조를 이유 없이 번복하거나 모든 명령을 자동 거절하지 않는다. 특정 NPC가 처음부터 살해/기만할 목적일 수 있으나 진짜 호의·일관된 책임감도 실존해야 한다.

이번 사건의 의미와 결정적 선택을 떠받치는 내막은 ‘알 수 없는 힘’으로 비워 두지 않는다. 정본에는 이번 사건에서 확정한 원인의 역할·이해관계·주요 소재의 의미와 한계, 그것이 드러날 실제 흔적/행동/위해를 둔다. 우주론 전체와 원작이 남긴 불가해함은 미지로 남길 수 있고, 설명되지 않은 근원도 실제 영향·한계·대응은 일관되게 운용한다. 새 진실을 만들기 위해 확정 과거·능력·소유·성과를 소급 변경하지 않는다.
핵심 원인은 행위자·수단/권한·접근/정보 전달 경로·발동 조건·관측 결과·차단 방법까지 실제로 연결한다. 중요한 기록/물건은 생성·변경·복사·이동 경로와 한계를 정하고 시간 항목/지도/고정 ID를 일치시킨다. 이것은 키퍼 내부 인과이며 플레이어의 매 단계 검증 과제가 아니다. 모든 방/문서/통신 절차를 사전 작성하지 않는다.
**첫 충격과 이후의 필수 재난 — 독립 원인:** 주요 재난/습격/확산은 PC가 퀘스트를 받거나 특정 장소에 도착할 때 '생성'되지 않도록 원작에서 확인된 이미 진행 중인 원인·인물·시설/자연의 과정과 여러 실제 실행 수단을 신규 정본에 준비한다. 첫 위험은 PC의 일상/직업·이동과 현실적으로 충돌하며 당면 대응을 만든다. 여러 후속 필수 국면은 목표망과 세계 원인의 실제 상태 변화에 따라 접근되고 큰 위험·공동체 손실이 남지만, **특정 시각·장면 분량에 맞춰 재난을 재생하거나, 이미 조기 차단/완화한 국지 피해를 복구하지 않는다.** PC·동료의 HP/SAN 피해·죽음·동행·해결 방식은 실제 상황과 판정에 맡긴다. 퇴로·생존·구조와 원작 대표 적의 실제 접촉을 여러 경로에 사전 준비하되 PC의 이동/선택을 대신하지 않는다.
 주요 재난의 희생·중요 전환을 게임 시작 전에 모두 끝낸 뒤 PC에게 뒤늦은 수사/구호만 맡기지 않는다. 가능하면 평범한 목적/생활을 직접 경험한 뒤, **게임 시작 후 중대한 사고·습격·봉쇄·변형·붕괴·구조 위기 등의 실제 발동 또는 확대**를 PC의 관측과 대응 가능한 범위에서 일으킨다. 시작부터 이미 사고가 발생한 상황이라면 **이후 실제 진행하는 중요한 변곡점과 PC가 후속 피해를 저지·완화/회피/구조할 구체적 기회**를 둔다. 후속 주요 사건의 발생도 확정하되 사고 이후의 피해·사망은 예약하지 않고 비공개 정본에 주체·수단·발동/취소·전조·대응/실패 결과를 연결한다.
**PC 중심 접촉:** **직업·배경은 사건에 들어온 자연스러운 이유와 도구만 제공해도 충분하다.** 중심 갈등은 다른 사건/세력·생존자/괴물 행동으로 형성해도 되지만 반드시 PC·동료의 현재 위기/선택에 닿게 한다. 원작의 살아 있는 괴물·NPC가 PC 또는 동행자에게 **찾아오고 공격·교섭·추적하는 조건**을 현재 위치/목적·감지/전달·이동 수단/시간·발동/중지·실제 위해/회피로 연결한다.
 원작의 중심 사건을 화면 밖에서만 진행시키지 말고, 실제 인물·세력·대표 적의 행동이 PC의 **직업/업무·일상·확정 관계·이동/생활수단·동료·안전**과 충돌하도록 구성한다. 의뢰·직무 요청·우연한 현장 사고·거래/책임·관계 갈등·위험한 물품 등의 경로는 시나리오마다 다르게 만들되 PC의 미선언 동의·부채·계약·감정을 발명하지 않는다. 직업만으로 반드시 중심 갈등의 비밀을 만들 필요는 없지만, 별도 중심 사건에서 발생한 위협과 NPC의 협력/적대·대응/퇴로·결말은 PC가 실제 겪는 선택을 바꿀 수 있어야 한다. 세계의 사실과 후속 진행은 자립하지만 **실제 위험과 중요한 선택이 PC에게 도달**해야 한다.
**초반 철수의 난관:** **플레이어가 실제로 철수·귀가를 선언하고 이동을 시도할 때, 이미 존재하던 폭풍/기상·파손된 교통/선박·괴물의 활동권/감지·NPC의 봉쇄/추적 조건을 그 퇴로에 적용**한다. 퇴장 의지만으로 자동 귀가 처리하지 않으며 도달한 위험과 대응·회피/돌파를 펼친다. **철수 선언 자체가 새 폭풍·괴물·순간이동 추격자를 창조하는 원인은 아니다.** 이미 위협을 해결하거나 안전을 획득했다면 정당하게 철수를 인정한다.
 신규 시나리오에서 평범한 일을 마치고 **원작다운 적·공포·위협을 실질적으로 경험하지 않고 아무 난관 없이 귀가하는 경로는 미완성 설계**다. 가장 빠른 정상 귀가/관여 거절/우회·도주 경로를 포함해, 출발 지점과 안전권 사이에 이미 존재하는 위험의 접근/활동 범위를 인과적으로 설계한다. 원작의 대표 적·괴이가 **직접 행동하며 PC가 관찰·회피·대처해야 할 실제 접촉 기회**를 만들고, 해난/화재·봉쇄·추적/구조 등 생존 난관이 실제 경로/대응·실패와 이어지게 한다. 괴물 흔적·소문만으로 원작을 충분히 경험했다고 처리하지 않는다. 그러나 이 목표는 **전투 의무·적 출현 횟수·고정 부상/피해를 요구하지 않는다**. PC가 후속 피해를 차단하거나 위험을 돌파해 안전권에 도달했다면 즉시 유효한 철수를 인정하고 나중에 새 적·길막·공격을 발명하지 않는다.
조사/의뢰 수락은 사건 발생 스위치가 아니다. 인물과 위협이 PC의 위치·관계·목적·안전에 먼저 닿는다. 초반의 작은 이상은 더 큰 원인·영향권과 연결되고, 밝혀진 사실은 대응법·목표·다음 난관을 바꾼다. 설명용 원인만 있고 실제 결과·해결이 사소한 설계는 수정한다.
일반 진행은 조건 성립을 우선하고 실제 일정이 있을 때만 시간 조건을 쓴다. 세밀한 시간표/숨은 마감/필수 왕복은 만들지 않는다. 큰 세계를 긴 피해 없는 조사로 대신하지 않는다. 실제 위협과 손실 가능성, 대응·획득·안전·성취가 진행 중 체감돼야 한다.
확정할 것은 원인·능력·주요 조건과 가능한 구조다. 주변 미확정 세부·후속 상황은 플레이에서 일관되게 창작할 수 있다. 성공을 취소할 새 비밀·능력·봉쇄를 소급 추가하지 않고 발생 후 조기에 해결한 성과도 인정한다. 정본은07-state, 실제 국면과 처리 결과는 현재 상태에 보존한다.
주요 연결은 실제 원인/장소/인물·발동/억제 조건·관측 현상·접근/피해·가능한 대응·차단/실패 뒤 상태로 구체화한다. ‘위협이 커질 수 있다’·‘안전하면 탈출한다’는 가능성만으로 설계 완료라 하지 않는다. 평범한 목적에서 깊은 관여와 큰 난관으로 이어질 근거를 두되 발견/준비/관계가 실제 다음 선택을 바꾸게 한다. 주요 사건의 발생 외에 PC 행동/피해/결말을 예약하지 않으며 발생 후 국지적 차단/철수도 남긴다. 필수 물건의 기준 소유/위치는 하나로 정하고 실제 복수 사본은 각각 구분한다. 문장 틀/추가 필드/별도 파일은 강제하지 않는다.

신규 캠페인은 시작 배치부터 자연스러운 귀가·우회·관여 축소와 의도적 도주가 실제 위험권을 지나는 생존 경로가 되게 설계한다. PC가 위험권에 들어온 근거·현재 영향 범위·정상 이동/이탈 경로·바깥 안전 경계를 정하고, 경로별 기존 위협의 접근/추적·차단 조건·관측/대응·준비/우회·실패 뒤 상태를 연결한다. 서로 다른 경로/수단은 위험과 이점·필요한 준비가 달라지게 한다. 조사/의뢰/핵심 장소 방문에 동의해야만 모든 위험이 켜지고 초반 귀가에는 아무 원인도 닿지 않는 설계는 보완한다. 출발 의도 자체를 공격 스위치로 쓰지 않고 NPC는 실제 인지/전달·위치/시간·수단이 있어야 가로막을 수 있다. 탈출 선택 뒤 적·봉쇄·능력을 소급 발명하거나 모든 경로를 같은 장면으로 돌려보내지 않는다. 실제로 접근 원인을 끊거나 유효한 안전 경계에 도달한 성과는 유지한다.
새 세계/미확정 챕터에서는 선택한 정확한 원작 작품·시대·지역에 속하는 상징적 대표 적을 비공개 정본에 필수로 구현한다. 그 외 일반·특수 원작 적과 이번 시나리오의 원인/법칙에 맞는 원작 기반 창작 변종 및 완전 신규 창작 적도 다양하게 준비한다. 다른 작품의 대표 적을 무조건 끌어오거나 적 수/고정 보스전·전원 출현을 강제하지 않는다.
 각 적은 원작 출처와 이번 각색 여부, 외형, HP·특성/기능·공격/피해·방어/저항·위협 Tier, 이동/감지/추적·행동 성향·특수 능력/한계, 출현 장소/범위·발동 조건·SAN 노출 조건, 약점·회피/격퇴/봉쇄/탈출 수단과 무력화/재등장 조건을 필요한 범위에서 실행 가능한 프로필로 만든다. 원작 법칙에 없는 능력을 후회 없이 추가하거나 PC의 예방/도주/해결을 전투 예약을 위해 취소하지 않는다.

**대형 사건과 플레이어가 겪는 사건을 구별:** 독립 원인과 실행 수단이 남은 주요 재난·습격은 PC의 수락과 무관하게 세계에서 진행되되, 이미 실행 불가로 차단된 국지 재난은 발생 처리하지 않고, 그 사건이 세계 상태값/뉴스만 바꾸고 PC 그룹에게 플레이 장면을 남기지 못하면 **플레이어의 주요 사건 체험을 완료한 것으로 보지 않는다.** 신규 정본은 각 주요 사건이 관련 PC/파티의 실제 위치·생활·현재 목적에 닿을 수 있는 복수의 인과적 접점을 설계한다. 세계가 혼자 진행하는 사건 수나 단순 통보의 양을 풍부함으로 평가하지 않는다.
**PC 접점의 세 가지 핵심:** 각 접촉 상황은 (A) **직접 위협**: 적·환경·추격·봉쇄·실제 구조/보호 위해가 도달해 대응 가능, (B) **사건 관점 재해석**: 이미 본 인물·현상·물건의 의미가 바뀌어 신뢰·안전·대응을 달리 판단할 근거가 생김, (C) **당면 목표의 변화**: 새로운 사건 결과가 기존 목적/수단/보호 대상과 충돌하여 PC가 우선순위·계속할지/철수할지를 새로 판단해야 함 중 적어도 하나를 **실제 장면의 관측·접근·선택·위험/이익**으로 구현한다. 소식 보고·지도 아이콘 변화·단순 자원±1만으로는 주요 체험 접점을 충족하지 못한다. 인물의 요청이나 발생한 조건을 제시할 수 있으나 PC가 무엇을 목표로 받아들이고 무엇을 느끼는지 대신 확정하지 않는다.
**접촉 경로의 분산 설계:** 정본 각 주요 사건 ref에는 발생 위치/주체와 별도로 중심 거점, 일상/업무 장소, 구조·탈출선, 다른 생활권, 파티 분산 현장 등 **실제로 개연적인 대표 활동 경로 2~4개를 우선 검토**하고 각 경로에서 도달할 수 있는 위협·발견·목표 충돌 장면 후보를 연결한다. 2~4는 설계 검토를 돕는 범위이지 의무 등장 수·최소 공격량이 아니다. 이동 시간·통신망·누가 무엇을 알고 무엇을 들고 이동하는지, 감지/추적 거리·장비/피난·물리적 장애를 기존 NPC·적·물건·경로 ref로 미리 명시한다. 가능한 접점이 적으면 숫자만 채우지 말고 실제 세계 인과와 주요 경로를 보완한다.
**사건 한 번, 접촉 경험은 경로별 상이:** 하나의 습격을 각 지역에서 별도의 무한 습격으로 복제하지 않는다. 실제 사건 이후 도망친 NPC, 이동 중인 기존 유한 적, 현장 물리적 확산, 이동 가능한 물자/정보, 구조/피해의 결과가 조건에 맞을 때에만 해당 PC의 현재 위치로 도달한다. PC가 공격을 차단하거나 생존자를 구하고 자원을 확보하면 후속 접점의 내용·강도·행위자·결말이 실제로 달라진다. 부상·SAN 손실·희생·미발견 사실 공개를 접촉 충족을 위해 할당하지 않는다.
**연쇄적 체험:** 사건의 직접 경험→PC가 선언한 준비·구조·도주/협상→실제 결과→기존 다른 인물/시설/위협의 반응→새 선택의 구조를 준비한다. 위협만 연달아 추가하지 않고, 원작 고유의 발견/관계/성취가 관점이나 목표를 바꾸는 국면도 포함한다. 전초 사건과 후속 사건에 가능한 실제 도달 범위를 연계하되 PC 행동·대사·성공을 미리 예약하지 않는다.
**화면 밖 사건과 안전 경계:** PC가 해당 현장에 없으면 장면 밖 사건 자체는 실제 원인으로 진행하지만 전지적 장면·HUD 누출로 대신하지 않는다. 그 사건이 실제 전달·이동·감지·영향권을 통해 현재 PC에게 **도달**하면 그 현장 경험을 우선 펼친다. 물리적으로 닿지 않는 사건을 '플레이어가 겪은 사건'으로 계산하지 않고, 다른 기존 독립 원인에서 PC에게 닿는 현재의 생존·관계·진실 접촉을 실행한다. PC가 이미 적·파급을 막았거나 진짜 안전한 곳으로 철수했으면 그 결과는 보존하며, 분량을 채우려고 적/재난/추적·봉쇄를 뒤늦게 발명하지 않는다. 필연 사건의 발생과 가변적인 접촉·피해/국지적 종결은 별개다.

## FINAL_THREAT_DESIGN

최종 위험은 괴물·조직·환경·확산 과정·복합 원인일 수 있다. 다음 8개 내용이 서로 연결되어야 한다: 실체 / 목적과 진행 / 능력·한계 / 격화·차단 조건 / 결정적 난관 / 개입·제압·생존·탈출 수단 / 필요한 이해·준비·획득 / 실패·방치 영향.
독립5축 추첨이나 추가축 추첨은 의무가 아니다. 원작·중심 인과로 도출하고 실제 무작위가 필요할 때만 적격 목록을 먼저 고정해 Python을 쓴다. 수치/피해/방어/이동·실제 파급은 사용 전에 확정한다. 전투 Tier와 SAN Tier는 분리한다.
현재 세계에 존재/진행하는 위협이어야 하며 최후에 갑자기 무관한 보스를 붙이지 않는다. 최종 보스는 앞서 설계한 다층 적대 전력의 실제 고유 상대이며, 상급 적·중간 보스·변형 적과 구별되는 전술/목적/한계·사전 발견 가능한 공략/철수 경로를 갖춘다. 공격/봉쇄가 도달할 조건과 PC가 성과를 지키며 우회하는 조건을 모두 정한다. 앞선 정보·도구·동료·환경 변화가 최종 대응을 바꾸게 한다. PC의 불참이나 장면 순서만으로 독립 원인을 지우지 않으며, 실제 사전 원인·실행 수단 전체를 차단한 국지 사건은 예방/조기 종결로 인정한다. 발생 후 적의 격퇴·피해 억제·우회·구조·철수는 인정하고 억지 페이즈/재난으로 연장하지 않는다.
결정적 난관은 현재 원인이 만든 구체적 상황과 접근/실패 영향으로 정한다. 어떤 준비·도구·동료·이해가 무엇을 가능하게 하거나 위험을 줄이는지 연결한다. 심층 인과가 실제 진행으로 드러난 분기에서는 알게 된 의미와 앞선 선택/관계·준비·치른 대가가 해결 방식·생존·손실·여파에 함께 쓰이게 한다. 작업 완료 보고나 더 강한 적의 등장만으로 절정을 대신하지 않는다. 해결·구조·실제 이탈의 완료 경계와 남은 위험을 구분하고 원작에 맞는 생존/탈출도 유효한 결말로 준비한다. 근원 전체의 소멸·고정 보스전·모든 진상 규명은 공통 필수가 아니다.

신규 캠페인의 결정적 난관에는 앞서 겪을 주요 사건·형성 가능한 관계·얻거나 잃을 준비/수단이 어떤 구체적 행동·협력·차단·구조·포기/탈출을 가능하게 하고 생존/해결 방식·대가/여파를 어떻게 바꾸는지 조건부로 연결한다. 단순히 ‘동료/아이템이 유용함’이라 쓰거나 마지막에 회상/설명하는 것으로 완료하지 않는다. 실제로 형성된 신뢰·역할·준비와 현재 인과가 성립한 경우만 활용하고 미형성 관계·미선언 희생을 가정하지 않는다. 모든 경험/인물/물품의 사용, 고정 보스전·새 퍼즐·필수 손실은 요구하지 않는다. 이미 시작된 난관에서 피해를 줄이거나 국지적 차단·생존/탈출에 성공하면 인정하고 실제로 지킨 것과 남은 여파를 결말에 반영한다.

## WORLD_RULE_HOMAGE_DNA

원작의 정수와 테마에서 실제 필요한 세계 법칙을 도출한다. 기술·사회·환경·초자연 모두 가능하며 고정 개수는 없다. 법칙별 적용 조건·효과·한계/예외·감지 가능한 현상·차단·회피/대응을 정한다. 플레이어는 현상과 단서·실험·실패 결과로 체득한다. 이미 확정·검증한 법칙을 난이도 조절을 위해 바꾸지 않는다.
중요한 변화는 어떤 기존 상태/원인이 성립하면 어느 범위의 공간·접근·위해·사람/정보 전달이 달라지고 무엇은 유지되는지 정한다. ‘전환될 때 전환한다’처럼 조건을 되풀이하거나 필요할 때 길/능력을 바꾸는 설명은 운영 기준이 아니다. 원작의 설명 불가능한 공포는 남길 수 있지만 키퍼가 적용할 조건/범위·관측·대응은 일관돼야 한다. 모든 초자연 현상을 인공 스위치·정밀 시간표·해독 문제로 바꾸지 않는다.

## WORLD_PC_INPUT

원작·세계의 개연성을 중심으로 만들고 PC 설정은 선택적으로 활용한다. 확정된 PC 과거를 소급 변경하거나 플레이어 감정을 대신 설계하지 않는다. 복수 PC 각각의 실제 관계·책임·목적·직업 역량이 세계에 닿을 강한 연루 이유와 실제 형성·전달 경로를 준비한다. 관계·책임·배경 목적도 그 자체로 유효하며 모두의 피격/감금은 필요하지 않다.
남을 이유와 실제 이탈 장애는 구분한다. 아직 형성되지 않은 관계를 이미 중요한 사람이라고 가정하지 않는다. 주인공의 내적 수락/호감/의리는 플레이어가 정한다. 공동 사건/연락 경로를 만들되 물리적 합류·신뢰를 강요하지 않는다.

## ORGANIC_SKILL_INTEGRATION

세계 확정 전 각 PC의 직업 기능·취미·실제 경력이 고유한 행동·성과를 만들 실제 기회를 장소/시설/인물/경로/위협과 연결한다. 필요한 자격·도구·가능한 작업·바꿀 결과·실패/부재 때의 다른 진행을 고려한다. 시작 장비 1개 외의 도구를 실제 장소·사람·자원에서 얻을 선택과 우회를 연결하되 무료 장비를 보충하지 않는다. 판정 수치만 높게 쓰는 같은 조사로 끝내지 않는다.
해당 인물이기에 가능한 특별한 성과는 허용하고 모든 PC에게 같은 성과를 보장하지 않는다. 그러나 캠페인 전체를 특정 PC/기능의 단 한 번 성공에 잠그지는 않는다. 실제 다른 수단·지원·대가·우회·다른 목표·철수 가능성을 남긴다. 직함만으로 인맥/장비/권한을 자동 지급하지 않는다.
이미 확정된 세계에서는 타당한 새 활용을 인정하되 성공시키려고 과거/약점/전용 도구를 소급 발명하지 않는다. 성공으로 바뀐 접근·시설·구조·안전·협력은 유지한다.

## HARM_ECOLOGY

**신규 캠페인의 실제 위해·SAN 위기 설계:** 적/재난의 외형과 위협 등급만 준비하지 않고, PC가 게임 시작 후 일상·탐험·구조·교류·도주·중간 난관·중심 진실/절정에 접근하는 경로 중 원작에 맞는 여러 실질 접점에서 **신체적 중상·빈사·사망 가능성과 적격 SAN 손실·일시/장기 광기 가능성**이 생기도록 사전 인과를 연결한다. '치명적일 수 있다'는 설명이나 경고 HUD만으로 완료하지 않는다. 위험은 초기·중반·후반과 서로 다른 지역·행동 경로에 분포하며, 반드시 모든 경로/장면/PC에게 피해를 배분하거나 정해진 순서로 발생시키지 않는다. 실제로 위험권에서 탈출하거나 차단했다면 후속 안전을 존중한다.
각 중요한 위협/공포 노출 ref는 기존 HIDDEN_TRUTH/WORLD_RULES/LOCATION_BASELINES/DRIVER_BASELINES의 사실과 연결해 **원래 원인·개체/환경/사건 ID·처음 위치·목표/진행·PC 또는 NPC에게 도달하는 감지/접근/노출 경로·관측 가능한 구체 전조·유효 대응 시점과 회피/차단/협력/철수 수단·실제로 도달할 공격/환경 피해식·관련 CON/전투/HP/부상·SAN 적격 내용과 강도/손실 Tier·미개입 및 대응 실패의 여파·성공해 차단한 상태와 후속 선택**을 실행 가능한 수준으로 준비한다. 실제 필요하지 않은 피해·SAN 판정/특수 능력은 만들지 않는다. PC가 위험 근처에 있다는 이유만으로 무조건 피해를 입거나, 원인 불명의 몸값처럼 HP/SAN을 선차감하지 않는다.
공포의 서로 다른 얼굴도 세계의 의미로 만든다. 직접적인 괴물 공격뿐 아니라 실제 벌어진 참극, 인지 가능한 비인간적 변형·신체 침해, 생존자에게 닥친 사고와 구조 위기, 환경 노출, 이미 존재하던 비정상 현실이나 진실의 이해 등을 **해당 원작과 연결된 별개의 원인/관측 상황**으로 준비한다. 심각한 내용은 발견·이해·대면·탈출하는 순간 SAN_EXPOSURE_GATE를 통과할 때만 SAN_ROLL을 적용하며, 어둠·소문·가벼운 놀람·같은 장면의 반복 노출로 SAN을 갈취하지 않는다. 가시적인 부상·구호·공동체 상실·심리적 균열은 실제 판정 및 상태에서 생겨야지 정해진 희생/광기 대본이 아니다.

**시대 공간·핵심 목적지·분산 탐험 사전 대조:** 실제 지역의 생업/주거/공공·교통/자연 공간이 사건 기능과 무관해도 존재하는지, 의미 있는 각 장소/시설에 맞는 물품·생활 기록·증거/위험·사람의 활동/부재가 준비됐는지 확인한다. 정본에서 어떤 장소가 핵심인지와 **어떤 기존 재난·구조/통신·교통/물리 조건이 그곳의 접근 필요를 만드는지**, PC가 다른 목표·우회/철수·준비로 대응할 가능성을 함께 대조한다. 방문을 막는 사후 길막이나 필수 장소 순례는 미완성이다. PC+NPC 합계가 여러 명인 실제 가능한 분리 예시(예: PC1+NPC1 / PC2+NPC2)를 지도·통신/거리·도구/의료 자원·상대 NPC의 비공개 의도·실재 적/환경의 동선으로 따라간다. 동시에 떨어졌을 때 **실제로 놓칠 엄호/정보/구조와 더 얻을 시간/탐색 기회, 적대자/불신 인물이 이용할 수 있는 조건**이 있는지 확인한다. 분리 자체로 모든 판정을 불리하게 만드는 규칙이나 보장된 배신을 추가하지 않고, 분리 위험이 전혀 작동하지 않는 방치된 세계 연결은 생성 전에 보완한다. 이미 성립한 안전·우회·동행 성공도 존중한다.

**실제 참조·지형·물품·저장 프로비넌스 게이트:** 중심 사건과 원작 고유 위협→지역 지도/실내 구조·통행·방어/퇴로→소유된 물품/탄약·정확한 방/위치→실제 NPC/적·사건의 **동일 ID/ref**를 양쪽에서 대조한다. **정본의 사건/NPC/적·장비/위치/이동 경로가 미등록 ref를 가리키거나, 상위 지명/시설 별칭을 장소 ID인 것처럼 쓰거나, 동일한 단일 물건이 둘 이상의 위치/소유자에 존재하면 신규 정본 확정 실패**다. 필요하면 기존 LOCATION_BASELINES에 별칭→정규 ref를 명시하고, 동선/거리·신호/총성 전달·문/엄폐·적 감지·현장 위협/안전 탈출을 정합화한다. 모든 방의 상세 지도를 강제하진 않지만 **실제 교전/추격/수리·밀폐 공간**에는 출입구·엄폐·높이·피해원·실물 작업수단/퇴로를 이용해 판정할 충분한 지형이 있어야 한다. 파일 전달/DB/manifest에는 **실제 사용된 규칙판/커밋 또는 재현 가능한 배포 식별자**를 지원되는 기존 원본·메타데이터 범위에서 확인하고, 검증 SHA·체크포인트가 실제로 확정됐는지와 내부 `pending/last_verified` 상태가 일치하는지 대조한다. 원격 재조회 안 됐으면 미검증이라고 알리고 새 컬럼/성공 기록을 꾸며내지 않는다. 적·PC·원작 지식·통신/장비의 모든 원래 한계를 보존하고, 승인받지 않은 새 저장/운영 DB 필드 추가는 금지한다.

**TRPG 생존 공포 실전 대비 검토:** 신규 세계 확정 전, 현재 1인/2인/3인 PC 수와 확정 시작 물품·능력치를 기준으로 **정본을 수정하지 않는 가상 경로 대조**를 한다. 적이 실제 위치·이동/감지로 도달하는 초기 접촉, 다른 경로의 탐험/구조·사이드 개입, 중간 보스·상급 위험·중심 진실, 최단 귀가/도주와 장기 미개입을 각각 해당하는 ref로 따라간다. 장면별 실질 신체 위해/적격 SAN 노출의 원인·공격/피해식·회피/방어/도주/자원·NPC 협력·실패 여파가 모두 성립하는지 확인한다. **1명이라 공격을 자동 빗나가게 하거나 3명이라 숨은 증원을 더하지 않는다.** 실제 전술·위치·동시 공격·구조 여건의 타당성을 대조하고, 모든 합리적 대응이 불가능한 고정 몰살 관문이나 공포의 설명만 이어지는 무손실 경로가 설계상 비어 있다면 시작 전에 기존 원인/행동/수단 연결을 보완한다. 위험한 선택·고립/부족 자원·실제 실패에 따른 사망과 광기 가능성은 제거하지 않는다.
검토는 **미래 플레이를 실행하거나 미리 굴리는 절차가 아니다.** PC의 실제 선택·주사위·정해지지 않은 피해/희생·랜덤 보상을 창작하지 않고, 대본/체크리스트·필수 보스전·보장 치료·고정 피해 할당량도 만들지 않는다. 사건·위험의 발생과 개인의 명중/손실·국지적 격퇴·철수 성과를 별개로 검증한다. 실제 플레이 후의 계측 검증은 별도 시험이 필요하며 서면 정합성만으로 실전 밸런스를 보증하지 않는다.

세계 확정 전 원작/인과/진행/생존/실행을 함께 대조한다. TRPG의 탐험·획득·환경 활용·적의 패턴 학습·동료/사이드 사건이 플레이어의 자유 행동으로 성립하는지, 룰북/정본/키퍼의 역할이 실제로 구별되는지 확인한다. 주요 장소·자원·적/보스·NPC의 기초 사실과 대응 여지는 준비하되 고정 열쇠/정답·강제 전투·퀘스트 목록·보상 루프·게임 AI처럼 행동 순서를 강요하면 보완한다. 반대로 중요한 물리 사실과 전력을 키퍼 즉흥에 전부 미루어도 설계 미완료다. 신규 정본에 하급·변형·중급(중간 보스)·상급·최종 보스가 실제 개체/집단 ID·유한 수·개별 행동 패턴/약점/위해/이탈 조건으로 구현되고 초반·중반·후반과 독립 탈출로의 여러 지형에 선배치되었는지 확인한다. 세 마리의 동일 저급 적과 이름뿐인 지휘자로 나머지 전력 역할을 대신하면 미완성이다. 메인과 독립한 NPC 사이드 사건도 발동·직접 경험·미개입 결과·관계/생존/최종 위협에 대한 파급이 실제 ref로 이어져야 한다. **첫 장면부터 마지막 국면까지 독립 재난의 실제 발동/조기 차단과 PC·동료의 피해/구조 분기가 분리돼 있는지, 철수 선언을 했을 때 실제 존재하는 날씨·퇴로/괴물·NPC 조건이 작동하는지, 원작 적이 PC/일행에게 직접 찾아와 실제 위해를 줄 조건이 있는지** 기존 정본 ref로 대조한다. 직업은 자연스러운 사건 진입 계기로도 충분하다. **가장 빠른 초기 귀가/관여 거절**에서 원작 대표 적·공포의 실제 접촉/대응과 생존 난관이 존재하는지, 직업·생활·관계가 **PC를 중심 사건에 직접 연결**하는지, **게임 시작 후 중대한 위기가 실제 발생·확대되며** PC의 선택으로 후속 피해·확산을 막거나 완화할 수 있는지를 정본 ref로 대조한다. 문제 발견 시 시작 전 원인/공간/행동 연결을 보강하고 플레이 중 소급 장애물은 만들지 않는다. 기존 비공개 정본의 HIDDEN_TRUTH·WORLD_RULES·DRIVER_BASELINES·ENDING_CONDITIONS에 기록된 실제 원인·진행·위해·부재 분기·결과 ref를 따라 주요 경로를 대조한다. 수문 고장·종 원판·한 사람의 범죄처럼 현장 장치/소규모 동기를 제거하고도 원작의 중심 위협·큰 피해와 해결의 의미가 성립하는지 살핀다. 그 하나를 제거하면 사건이 실제로 끝나는 설계도 허용하지만, 그 행동이 사전에 존재했던 중대한 위험을 실제로 막은 것인지 정본에서 확인한다. PC가 평범한 업무만 하고 귀가할 경우 세계와 NPC의 실제 진행/차단·위험권/안전·남는 여파를 확인한다. 단지 떠나도 아무 위협이나 변화가 없고 해결해도 아무 차이가 없다면 규모·사건 연결 미완료다. 반대로 실제 예방/조기 차단과 확보한 안전을 손해·추가 괴물로 뒤집지 않는다. 원작 요소가 실제 체험되는가, 중요한 소재의 의미와 큰 원인/위협·해결이 탄탄한가, PC별 직접 연루와 현재 접근/후속 국면이 연결되는가, 실제 위험과 성취 가능한 대응이 있는가, 수치·지도·NPC·단서·정본이 실행 가능한가를 본다.
의미 없는 공정·문서·왕복을 압축하고 유효한 교류/선택·고유 전문 성과는 보존한다. 처음부터 모든 방/직원을 작성하거나 개수/턴/회차 목표를 채우지 않는다. 미래의 선택 결과를 검수 명목으로 실행하지 않는다.
주요한 진행을 따라 당면 목적·행동/관계 선택·위험과 대응·준비/획득·여파가 실제로 달라지는지 대조한다. 단서와 범인의 동기가 있어도 나머지가 문의/서류 확인뿐이면 체험 설계 미완료다. 서로 다른 원작/선택에서도 같은 수사 절차만 남으면 다시 설계한다. 원작을 체험한 평가와 인과/참조 일치 검사를 구분하며 표를 채웠다는 이유로 실플레이 검증 완료라 하지 않는다.
완료 판단은 실제 정본의 참조된 원인·조건·장소/인물·대응·결과로 한다. 가능성만 적고 발동/억제·체험 접점·대응·실제 안전/종결이 비었으면 그 연결은 미완료다. 주된 경로의 진행·다른 수단/사건 후 국지적 차단·실패/철수를 조건부로 대조해 준비/관계와 성과가 살아 있는지 확인한다. 고정 분기 수나 전모 공개는 요구하지 않는다. 시작 전 한 번, 새 챕터/주요 미확정 국면 설계·실제 관련 모순/누락 발견 때 해당 연결만 보완한다. 기존 성과/진실을 지키며 미확정 미래의 빈 연결을 메우고, 매 응답 전수 검토·검토표 출력·추가 검수 모델/저장 호출은 만들지 않는다.
운용 가능한 인과와 서사의 깊이를 따로 대조한다. 주요 진실의 전후에 경험·문제의 의미·관계 선택·위험/대응·대가·결말 중 무엇이 실제로 달라지는지 정본에서 확인한다. 그 진실을 빼도 모든 경험/선택/결과가 같고 피해 대상 수·작업량·설명 분량만 늘면 서사 심화를 보완한다. 주 경로와 조기 이해/피해 완화·다른 대응의 분기에서 이 차이를 살피며, 모든 진실이 모든 항목을 바꾸거나 반전/새 피해를 반드시 거치게 만들지는 않는다. 기술적 조건을 갖췄다는 이유만으로 시나리오 품질 검토를 완료하지 않는다.

공포의 형상/공간 체험과 절정 활용을 구체화하는 위 생성 기준은 신규 캠페인에 적용한다. 기존 캠페인의 새 채팅 재개는 신규 생성이 아니며 이 보강을 이유로 저장된 정본·진행을 재설계하지 않는다. 주요 동기를 더 복잡하게 만들거나 목표를 뒤집는 충격적 반전을 합격 조건으로 추가하지 않는다. 신규 설계에서는 핵심 공포의 실제 접촉/행동과 누적 경험이 쓰이는 결정적 대응을 해당 본문/ref로 대조한다. 공포를 기술 절차 뒤 설명으로만 두거나 관계/준비가 결말 회상에만 등장하면 그 연결은 미완료다. 소박한 동기·간단한 해결도 의미 있는 체험/선택/결과로 이어지면 유효하다.

신규 정본 확정 전 정상 동선을 따라 관여를 줄이는 분기와 초반부터 의도적으로 이탈하는 분기에서 위협 원인→접근/관측→대응/판정→실제 결과→바깥 안전 경계가 본문/ref로 연결되는지 대조한다. 단순 운항 일정/요금만 두고 생존 위협이 없거나, 본편 수락/최종 의례에만 모든 위해를 모아 두면 이탈 설계는 미완료다. 원작별로 다른 생존 난관을 사용하고 고정 관문 수·필수 보스/상처·정밀 마감은 추가하지 않는다. 후속 위해를 줄이는 우회·실제로 확보한 안전은 그대로 인정한다. 이 생성 보강은 이후 신규 캠페인에 적용하며 기존 캠페인 재개를 소급 재설계하지 않는다.

## START_BRIEFING_FOG

원작/장르의 정확한 명칭은 세션 메타 정보로 공개한다. PC가 당연히 아는 시대·지역·기술·사회·화폐·교통·직업/기관·일상과 현재 방문 이유·이미 들은 사건을 선택에 필요한 만큼 알려준다. 백과사전식 전체 설명은 하지 않고 필요할 때 상식을 보충한다.
숨은 원인·진실·비공개 세계 법칙·능력/약점·미발견 장소/증거·미래 결과는 발견 전에 해설하지 않는다. 원작명 공개가 이번 사건의 정답 공개는 아니다. 이미 알고 온 의뢰·피해까지 숨겨 시작 동기를 지우지 않는다.
