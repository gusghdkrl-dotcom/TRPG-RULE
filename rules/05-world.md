## INVENTORY

메인5칸: 한 손 휴대 중형 장비1개 또는 그에 준하는 실제 묶음. 파우치3칸: 같은 계열의 소형 소모품 묶음이며 수량을 최초 획득 때 확정한다. 가벼운 진행 키템은0칸, 크거나 무거운 키템/목표물은 실제 크기에 따라 메인 또는 별도 운반 상태다. 중량 무기/핵심 목표물은 메인2칸+관련 도주/은밀행동 패널티.
일반 무기·의료·생존/유틸은 실제 크기에 맞게 보통 메인1칸, 작은 탄창·약·전지 등은 파우치. 신규 캠페인 HP 회복용 붕대/간이 응급 꾸러미·구급상자/야전 구호 세트·전문 일회용 처치 키트는 각각 실제 1개씩 독립 실물이며 파우치의 소모품 묶음 규칙으로 다수 중첩하지 않는다. 같은 물품의 칸을 편의로 바꾸지 않는다. 단지 가방을 발견하거나 들었다고 기본 용량이 늘어나지 않는다. 실제 획득·착용한 운반 장비만 아래 전용 확장칸을 연다. 들어 있는 물건·소지자/소유자·위치·묶음 수량·사용/소모/이전/파손을 보존한다.
**HP 회복 의료품 종류별 1개 소지 상한(신규 캠페인):** PC 1인당 소형 붕대·간이 응급 꾸러미 계열 **최대 1개**, 일반 구급상자·야전 구호 세트 계열 **최대 1개**, 전문 일회용 처치 키트 계열 **최대 1개**까지 휴대한다. 이름·브랜드·카드 출처만 다른 동등 기능 의료품을 별개 종류로 세거나 같은 계열 두 개를 손·메인/파우치·의료 가방/등짐으로 나눠 우회 소지하지 않는다. 가방 의료 +3칸은 **서로 다른 최대 세 종류를 실제 크기에 맞춰 담는 선택 수납**이지 의료품을 공짜로 만들거나 종류별 소지 상한을 늘리지 않는다. 같은 종류의 새 의료품을 발견하면 기존 1개를 실제 장소에 남기거나 다른 사람에게 건네거나 보관한 뒤 하나만 택할 수 있다. 두 개가 동시에 생겼다고 자동 삭제/교환하거나 소유자·동료의 물건을 임의 인계하지 않는다. HP 회복용 아이템은 사용 판정 성공·실패와 무관하게 **실물 1개 전부 소모**한다. 빈 운반 가방·재사용 가능한 도구는 이 1회용 약품이 아니다. 기존 verified 소지품/카드 분량은 소급 축소하지 않는다.
**획득형 수납 확장:** 모든 신규 PC는 기존 메인5칸·파우치3칸에서 시작하고, 의료 가방을 실제 획득·착용하면 **의료품 전용 +3칸**, 호환 무기 둘을 고정할 수 있는 홀스터/무기 운반구를 실제 착용하면 **무기 전용 +2칸**, 일반 등짐·배낭을 실제 획득·착용하면 **메인 +2칸**을 추가한다. 특수한 크기의 가방은 신규 세계 설계 시 물리적 크기·확장칸 수·착용 부위를 사전 정본에 확정하고 발견한 뒤 임의 상향하지 않는다. 가방을 획득해도 내용물·약·무기·탄약은 생성되지 않으며 직업명만으로 무료 가방을 지급하지 않는다.
**호환·실물·상실:** 의료품은 실제 들어가는 의료 전용칸에, 무기는 해당 고정부에 맞는 무기칸에만 넣는다(권총 홀스터에 장총 불가). 같은 고정부·같은 종류의 운반 장비를 겹쳐 무한 합산하지 않으며 다른 장비도 실제 몸·무게·크기상 병용 가능해야 한다. 큰 가방의 실제 좁은 통로·수영·은밀 이동 제약은 물리 조건으로 판단하고 모두에게 자동 고정 페널티를 주지 않는다. 확장칸은 그 장비를 실제 소유·착용할 때만 PC에게 활성화된다. 가방을 내려놓거나 잃거나 파손·인계하면 **내용물은 가방과 함께 실제 위치에 남고**, 그 칸은 PC에서 제외된다. 넘친 물품을 자동 삭제·이동·복제하지 않고 PC가 꺼내기·손에 들기·재수납·놓고 가기 등을 직접 선언하며 위험 중이라면 실제 행동/시간을 처리한다. 획득·착용·내용물·점유·위치·소유는 기존 물품/인벤토리 상태에만 기록하고 새 DB 필드를 가정하지 않는다. 기존 검증 세계·세이브는 소급 확장/재배치하지 않는다.
용기/키트는 실제 알려진 contents를 연결하고 내용물을 공짜 수량/공간으로 중복 계산하지 않는다. 미확인 내용은 공개하지 않는다. 매 일반 HUD에는 메인/파우치와 실제 착용 중인 확장칸의 **모든 현재 소지품 실물명·Stack 수량·점유량**을 구획별로 상시 제공한다. 장착 상태·한정 소모품/탄약을 빠뜨리거나 같은 실물을 중복 소지로 세지 않으며 빈 칸과 실제 위치도 확인한다. 실제 전체 물품·위치·Stack 수량은 계속 추적하고 요청, 사용/획득·소모/인계·위험/용량 갈등 때 해당 구획을 상세 공개한다. 물건마다 생활 흔적 문장이나 무료 직업 소품을 만들 의무는 없다. 신규 시작 인벤토리의 **직업 기본 지급분**은 STARTING_EQUIPMENT_MINIMAL의 직업 필수 물품 1개만 가진다. 여기에 **별도 장착한 영구 자산 카드 실물**을 CARD_EQUIP_AND_ASSET의 캠페인 시작 1회 지급 조건으로 추가할 수 있으며, 실제 메인/파우치 점유·내용물/소모·동물 위치와 위험을 관리한다. 기존 캠페인 소지품은 소급 줄이지 않는다.
장착은 무료 추가 수납이나 장비 지급이 아니라 실제 소지품의 사용 준비 상태다. 단 위의 획득형 운반 장비를 실제 착용한 경우에만 그 실물에 명시된 확장칸을 사용한다. 오른손·왼손·몸에 착용·빠른 접근(홀스터/벨트) 네 위치를 실제로 구분하고, 양손 무기는 양손을 점유한다. 실제 착용한 보호구만 본래 기능이 있으며 장착 자체로 신규 방어/피해 보너스를 만들지 않는다. 장착 중에도 기존 메인/파우치 점유는 유지한다. HUD에서 같은 실물 이름을 두 번 늘어놓지 않는 것과 수납 점유를 없애는 것은 다르다. 소지 목록의 동일 물품에 손/착용/빠른 접근 상태를 연결해 표시한다. 단 실제 확장칸으로 내용물을 이전해 정산했다면 해당 물건은 기존 칸에서 빼고 확장칸에만 둔다. 같은 물품을 장착란에 복제하거나 중복 점유시키지 않는다. 빠른 접근에 고정 개수 상한은 없으며 장비의 크기/부착 부위·가림·자세·손이 닿는지를 적용한다.
 두 손이 찬 상태에서 다른 장비를 쓰려면 기존 장비를 놓기·떨어뜨리기·실제 보관·동료 인계 중 PC가 방법을 선언한다. 키퍼는 임의로 버리거나 가방에 집어넣지 않는다. 떨어뜨린 물품은 휴대 인벤토리/손에서 제외하고 낙하 위치와 접근을 보존한다. 회수는 거리·자세·적의 방해·장애물에 따른 행동과 시간을 반영한다. 안전한 회수는 무판정이며 실제 위험/성패 불확실성만 FICTION_FIRST_ROLL_TRIGGER_GATE를 따른다. 가방이 가득 찬 상태에서 다른 물건을 주워도 장착을 공짜 휴대 공간으로 우회하지 않는다. 기존 세이브의 미기록 장착 위치는 임의로 추정하지 않는다.

## PERSONAL_CASH_LEDGER

PC별 실제 휴대 현금·통화를 자산/외상/공동 자금과 구분한다. 거래의 가격·지급자·수량·미지급 조건·실제 소유 이전을 한 번 반영한다. 시대에 맞는 가격은 필요할 때 확정해 유지하고 일당/식사/교통/숙박 전체 가격표를 미리 만들지 않는다. 타당한 통상 구매는 별도 판정 없이 처리하고 실제 불확실한 교섭만 판정한다.
 상점에 간다는 선언은 관찰/교류를 여는 것이며 구매·가격 동의·퇴장을 대신 실행하지 않는다. 방문할 때 실제 공간·손님·점원의 행동/대화를 서술하고, PC가 진열·가격표·공개 목록·실제 전달로 확인할 수 있는 상품·가격/통화·재고와 조건을 함께 보여준다. 창고/비공개 품목·점원만 아는 정보는 발견/전달 전에 누출하지 않는다. 매번 희귀품/특별 사건/흥정을 만들지 않는다.
 공개 가격·수량에 대해 플레이어가 명확히 구매를 선언하면 현금/재고·자격·인계/휴대 가능성을 확인해 정상 구매는 무판정으로 즉시 정산한다. 현금 차감·재고 감소·소유권 이전·인벤토리 반영을 한 번 처리한다. 현금 부족·공간 부족·조건 변경·판매 거절에서는 외상/물건 포기를 자동 확정하지 않고 플레이어에게 선택을 받는다. 여러 품목을 확실히 주문했다면 거래 단위로 압축한다.
 판매·매입·물물교환·흥정은 상점의 실제 업종/수요·자금·물건 상태/가격·시대·법/관계로 매입 여부와 제안가를 결정한다. 고정 매입률이나 흥정 실패의 자동 관계 악화는 없다. 실제 협상 여지와 의미 있는 실패 위험이 있을 때만 FICTION_FIRST_ROLL_TRIGGER_GATE를 적용한다. 재방문 재고는 실제 입고/배송·다른 손님·공급 중단/봉쇄·지역 변화에 따라 변하고 날짜/방문만으로 리셋하지 않는다.
 주요 상점은 점원의 생활·거래처·고유 정보·문제·부탁/퀘스트·관계 및 실제 공급/보상 변화를 풍부하게 준비한다. 일반 상점은 실제 상황이 있을 때 정보/의뢰를 갖도록 하고 모든 가게에 퀘스트를 강제하지 않는다. NPC의 실제 지식과 제안 이유/수단을 보존하며 수락·거절과 비용은 PC가 정한다.

## CLUE_FUNCTION

**절차적 조사 연쇄 금지:** 자료 찾기→진위 확인→다른 증언→추가 기록 조회를 메인 사건 진행의 반복 관문으로 만들지 않는다. 현재 관찰/읽기/전문 상식으로 성립한 정보는 즉시 활용 가능하며, 증거의 법적 입증이나 추가 확인을 원래 목표가 요구하지 않는다면 강제하지 않는다. 플레이어가 선택한 심층 탐구는 펼치되 세계·NPC·적은 그 선택과 무관하게 실제 목적대로 행동하고, 발견은 현장의 대응·구조·교섭·전술·준비·탈출을 바꾸는 경험으로 이어간다.
단서는 실제 내용·배치/접근·발견 조건·무엇을 밝히고 가능하게 하는지가 있어야 한다. 주요 증거는 중심 인과·위협 대응·관계·다음 접근과 연결한다. 소유자/이동/손상·공개·발견 결과를 보존한다. 물건/장소의 수나 자료의 양으로 깊이를 대신하지 않는다.
발견은 행동 중 겪는 현상·인물 반응·실패/피해·도구 사용·공간 변화에서도 생긴다. 모든 발견을 문서/증언으로 바꾸거나 다음 정보원을 찾아가는 과제로 마무리하지 않는다. 알아낸 것이 준비·신뢰·경로·수단·목표를 바꾸면 그 활용과 결과를 진행한다. 필수 사실을 읽고 다시 감정/원본 대조를 해야만 유효해지는 일반 절차는 없다.

## DEATH_AND_INHERITANCE

HP_AND_DEATH로 확정한 사망 또는 SAN_CORE의 SAN 0 게임 오버에 적용한다. 비PC는 HP 0 즉사이며 PC의 구조형 HP 0과 구별한다. 신체적 사망·목격의 적격 SAN 노출·정신 붕괴를 실제 원인대로 서술하고 SAN 0을 임의의 시체로 바꾸지 않는다.

## SCENARIO_OBJECTIVES

**실제 사건·PC 목적의 분리:** E/G는 세계의 원인·상태/위험으로 계속 작동하지만 **모든 PC가 매 순간 공개 메인 목표를 수락·추구할 의무는 없다**. PC가 직접 선택한 일상·준비·관계·직업·구조/철수도 정상 활동이다. 주요 결과/장면 전환 때 SCENE_CONSEQUENCE_RULE로 기존 목적의 유효성, 해당 PC의 관측/접근 가능한 현재 상황, 세계의 자율적 움직임을 확인하고 선택을 기다린다. 외부 답변만 기다리거나 소진된 질문을 반복해야 다음 E가 열리는 구조는 생성/연결 결함이다. 안전한 휴식·정당한 종결은 목표 공백이 아니다.

현재 선택할 수 있는 공개 문제·사람·위험·요청·기회와 걸린 것을 보여준다. 단순히 세계에 문제가 있다는 사실을 PC가 수락한 목표로 쓰지 않는다. 목표는 실제 선언/수락, 계약/법적 책임, 즉시 생존처럼 실제 상황이 요구하는 범위다. 변경·거절·포기는 플레이어가 결정한다.
관심은 관계·탐험·구조·협상·경쟁·장비·거점·개인 성취 등으로 발전할 수 있고 메인 사건과 무관해도 유효하다. 실제 상대/수단/조건·다음 행동으로 구체화한다. 모든 작은 관심을 영구 퀘스트로 만들거나 모든 관계를 메인 비극에 연결하지 않는다.
확인된 발견·피해·얻거나 잃은 수단이 목표의 의미와 우선순위를 바꿀 수 있다. 목표/범위·변경/포기·접근·실제 결과를 보존하고 버린 목표를 로드 뒤 되살리지 않는다. 미해결 세계는 계속 움직이며 목표 포기가 자동 안전/성공은 아니다.

2. 적/NPC는 PC 방문·조사 수락을 기다리지 않고 자기 정보·목적·동선으로 수색/추적·거래/구조·공격/후퇴한다. 감지 실패/추적 상실·부상/자원 소진·실제 거절/합의 이행을 반영한다. PC 위치를 전지적으로 알거나 무한히 증원하지 않는다.
3. 실제 이동·소리·기록/통신·침수/화재 등 물리 경로가 PC에게 닿으면 관측 가능한 현상·누구에게 무엇이 걸렸는지·대응 가능한 수단을 현장 장면으로 펼친다. 화면 밖 비밀을 보고문/HUD로 누출하거나 죽은 전달자의 소식을 자동 발신하지 않는다.
4. PC의 실제 선언/판정과 NPC 반응·위해 도달을 처리하고 그 결과·지식·소유·위치·원인 잔존을 한 번 갱신한다. 물리 시간은 06-play, HP/SAN/명중/피해는 02-checks/03-danger를 따른다. 경고만 남기고 도달한 공격을 무기한 유예하지 않는다.

**E 체험/순서:** 참가 PC 전원이 각 E 현장에서 관측·대응 기회를 실제 겪은 뒤 최종 국면에 진입한다(04-setup PC_REACHED_EVENT_CONTRACT). 원격 기여는 체험으로 인정하지 않는다. 다른 위치에서 성립한 행위의 물리적 효과·정보 전달은 사실대로 처리하되 E 체험/자동 합류로 바꾸지 않는다. 먼저 도착한 PC의 유효 행동·실제 위험을 대기자 때문에 동결하거나 사건을 재연하지 않는다. 전원이 체험하기 전에 E가 완전히 소진되어 정상 경로가 없으면 생성 결함으로 기록하고 실제 성과를 보호한다. 새 적·원인·미선언 이동으로 숨기지 않는다.

**E 위기와 피해:** 개별 적의 조기 사살/포획·공격 차단·피해 0·중간 안전을 보존한다. 위기 발생 자체는 시작 정본의 독립 예비 인과로 반드시 성립해야 하며 예비 실행자의 실제 지식/이동/자원·차단 조건을 따른다. 사후 후계자·능력·부활·무적/자동 도주를 발명하지 않는다. 모든 E 뒤 최종 국면이며 성공 조기 종결은 없다. 전멸/불가역 실패는 실패 종결로 구별한다. 기존 verified 구판의 확정 시간표·완료/안전/종결은 소급 변경하지 않는다.

**살아 있는 생활과 S:** 평상 업무·교류·회복·구조·탐험/준비도 실제 플레이다. S는 실제 주체·물건·접촉·거절/미개입 뒤 자율 결과를 가지며 같은 심부름을 재포장하지 않는다. 조용한 결과·안도도 허용하고 모든 방에 전리품/적을 넣지 않는다. 충분히 준비된 정상 생활을 자동 기회 상실로 벌하지 않으며 이미 시작된 실제 화재/공격도 멈추지 않는다. PC 목적이 끝난 뒤의 연결은 SCENE_CONSEQUENCE_RULE 한 곳에서 처리한다.

**역할별 다음 실제 행동:** 04의 준비 전력을 실행할 때 추적자는 마지막 실제 흔적/보고에서 접근·수색/우회/차단하고, 경비는 실제 지킬 대상·감시/이탈 한계를 유지하며, 배회자는 경유점을 현재 경과에 맞춰 이동한다. 추적자가 움직였다고 다른 경비/배회 개체도 함께 순간 이동시키지 않는다. 수색 실패는 준비된 다음 구역/정보 확보·보고/복귀/추적 포기로 이어지고, 추적 단절 뒤에는 새 실제 단서를 얻기 전 PC 현재 위치를 찾아가지 않는다. 인과가 닿으면 대면·방어/도주·판정과 실제 위해를 처리해 경고/HUD 문구로만 지속 압박을 대신하지 않는다. 격퇴·사살/포획·경보 차단·합법적인 안전을 유지하고 새 적 필요 여부는 이미 확정한 풀의 실제 조건으로만 판단한다. 진행 상태는 STATE_WORKING_CONTEXT에 같은 ref로 이어간다.

## ACTIVE_DANGER_CONTINUITY

**소수 적의 지속 수색·추적:** 신규 G가 발발한 상태에서는 원래 존재한 적/NPC·환경이 PC가 와 주기를 기다리지 않는다. 각 개체의 현재 목표·실제 감지/소음·흔적의 유효 시간·이동 구역/속도와 다른 사람·자원/탈출 통로를 따라 활동·추적/수색 실패·접근 차단/재접촉을 처리한다. PC의 숨기/흔적 제거·격퇴/포획은 실제 반영하고 텔레파시 재탐지·풀 조건 없는 즉흥 증원/동일 개체 부활 금지. 적 유형·공급 한도와 실제 인과는 시작 정본에 준비하고, 적격 풀 개체는 진행 중 생성할 수 있다.
**파티 구성 이전의 위협을 실행:** 여러 PC와 실제 NPC가 한곳에 있더라도 정본의 재난·적·무장한 인간은 고유 목적·위치·감지·수단으로 먼저 움직일 수 있다. 플레이어가 분산 선언을 하지 않았다고 공격/환경 위해를 경고에서만 멈추거나 조우를 무손실 보고로 압축하지 않는다. 준비된 적이 접근해 공격/추격·엄폐/봉쇄·구조 저지를 시도하면 PC/NPC에게 실제 도달한 행동·방어/회피 판정, 피해·부상/SAN 조건과 후속 위험을 처리한다. 동료끼리 도움·엄호/구조·우회를 시도할 기회와 성공 효과도 유지한다. 적이 실제로 도달할 수 없거나 이미 해결됐으면 장르/난이도를 맞추려고 임의로 찾아온 적을 생성하지 않는다.

미해소 위협은 사건 진입부터 탐구·대면·이동·탈출·짧은 환기 중에도 실제 조건으로 진행한다. 공격/위험이 도달하면 REACHED_DANGER_EXECUTION_GATE로 처리한다. 조사를 선택할 때까지 멈추거나 전조만 반복하지 않는다.
반대로 처리한 원인을 되살리거나 안전 뒤의 공포 부채·필수 손실을 만들지 않는다. 무엇이 남았고 어떤 조건에서 도달하는지를 현재 상태에 연결한다. 영리한 적은 실제 정보/자원에서 전술을 바꾸지만 PC의 미공개 계획을 알거나 검증한 약점을 소급 변경하지 않는다.

일상 동선을 따라 관여를 줄이거나 귀가·우회·도주해도 실제로 지나는 위험권의 활성 원인은 같은 인과로 적용한다. 이동 목적만으로 위협을 꺼 주거나 이탈 선언만으로 새 적/봉쇄를 만들지 않는다. 해당 경로에 실제 닿은 접근·추격·환경 노출을 대응받고, 위험권 이탈/차단이 성립하면 그 결과를 유지한다.

## REACHED_DANGER_EXECUTION_GATE

**새로 닿은 사건은 실질적 판단을 요구한다:** 관련 현재 위협·현상/인물의 접근을 단순 상황 메시지로만 끝내지 않는다. 실제로 관측한 거리·출입구·위험이 미치는 대상·현재 목표와의 충돌을 명료하게 전개하고 방어/도주·구조·대면·준비 도구 활용 등 상황이 허용하는 행동을 PC에게 남긴다. 다만 공격/공포가 직접 도달하지 않았는데 피해·SAN을 예고 없이 산정하거나, 단서를 안다는 이유로 그 의도를 대신 결정하지 않는다. 사건 의미를 뒤집는 발견도 NPC가 실제 알고 전할 수 있는 정보와 PC가 직접 확인한 현상에서만 공개한다.

**실제 위협이 PC/NPC에게 도달한 순간:** 키퍼는 예정된 공포 장면의 순서가 아니라 현재 원인·개체 위치/감지·실제 경과와 정보에 따라 공격/노출을 실행한다. 먼저 현재 PC가 볼/들을 수 있는 접근·거리·공간의 변화와 긴급한 대응 가능한 지점을 분명하게 제시하고, 필요한 PC 선언/방어·d100 입력을 받은 뒤 실제 판정으로 명중·최종 피해/중상·PC HP0 구조/비PC 사망·적격 SAN 손실/게임 오버 결과를 한 번 반영한다. 이미 완료한 피해/노출·한 번의 공격을 다른 장면으로 중복 계산하지 않는다. NPC도 실제 위치·수단·인지와 담당 규칙으로 스스로 행동해 구조/방어/부상/사망 가능성을 감수한다.
**실제 여파의 지속:** 해당 결과로 달라진 이동·수납/탄약·의료 접근·부상·정신 상태·NPC 협력·문/지형·적의 추적/후퇴·구조 성패를 이후 장면에 반영한다. 일시/장기 광기는 담당 규칙의 강제 효과 범위만 적용하고 미선언 PC 생각·충성/배신·미래 행동을 만들어 넣지 않는다. 공포가 충분하지 않다고 기왕 성공한 방어를 실패로 바꾸거나 매 장면 SAN을 차감하지 않는다. 반대로 실제 명중/노출의 확정 위해를 분위기용 전조로 지우거나 사건을 무손실 조사로 축약하지 않는다.

공격·추격·환경 위해가 실제 도달하면 COMBAT_ORDER/DAMAGE/EXTREME_HAZARDS를 적용하고 HP_AND_DEATH/WOUNDS까지 처리한다. 적격 SAN 노출은 SAN_ROLL/SCALED_SANITY_LOSS/INSANITY_CONDITIONS/BOUTS_OF_MADNESS로 이어가고 UNDERLYING_INSANITY는 구판 호환·신규 발작 중 중첩 방지만 적용한다. 발견·탐사·대면·탈출에도 동일하다.
필요한 PC 대응과 굴림 전에 명중/피해를 확정하지 않는다. 회피/차단이 실제 성공하면 반영한다. 실패한 도달 위험을 분위기/경고로 되돌리거나 원인 없는 자동 구조로 지우지 않는다. PC/NPC 동일 원칙이며 동일 효과의 중복 적용을 막는다.

## SCENE_CONSEQUENCE_RULE

선언 목적 → 직접 경험 → 행동/관계/수단 선택 → 실제 결과 → 달라진 다음 상황으로 잇는다. 구조·탈출·준비·교류·성취도 진행이며 증거 완전성/추가 서류·같은 조사 반복을 요구하지 않는다. 실패는 실제 대가와 가능한 다음 접근을 만들되 실패한 목적을 자동 성공시키지 않는다. 잘못된 가설·소진된 방법에는 객관적 피드백으로 반복을 닫는다.

주요 결과/PC 교대에서 현재 PC의 실제 목적·위치/지식·소유, 원래 적/NPC/환경의 후속 행동과 실제 전달 경로를 확인한다. 관측 가능한 사람·현상·필요/위협과 선택을 보여주되 GO·임무 수락·다른 PC 합류를 대필하지 않는다. 전달자 생존/지식·위치·통신/이동 수단·시간·문/길의 접근이 성립하기 전에는 소식이 도착했다고 쓰지 않는다. 단일 물건 이중 위치·고장 수신기의 전언·PC 간 자동 정보 공유를 금지한다.

안전한 생활·휴식/독립 S는 목적 공백이 아니다. 하지만 메인 접점이 모두 끊겨 외부 전문가 대기·반복 조사·사이드만 남았다면 생성 결함이다. 준비된 실제 후속 인과를 실행하고, 없다면 결함을 드러내며 실제 성과/안전을 보존한다. 새 핵심 적·비밀·기관 의뢰·사후 출구 봉쇄로 봉합하지 않는다. 전원 각 E 현장 체험 이후의 최종 국면이라는 04-setup 계약을 유지한다. E 발생/세계 해결·PC 인지/제안·수락/체험은 별개다. 공개 목표는 해당 PC가 실제 아는 상황·선택한 목적만 반영한다.

미확정 생활 세부와 실제 대응의 여파는 기존 사실/능력/위치와 양립하게 현장에서 확정해 작업 상태에 잇는다. 과거 사건·자원·원래 적의 능력을 소급 바꾸지 않는다. 인물의 경험·안도·성취도 가치가 있으며 매 장면 보상/손실 점수를 요구하지 않는다. 적격 연대기 학습 경계는 SKILL_IMPROVEMENT를 따른다.

## NARRATIVE_TECHNIQUES

원작에 맞는 모티프·전조·위협의 학습 가능성·정보 재맥락화·개인적 관련성·딜레마·마지막 풍경·여운은 자율 작법이다. 고정 개수/순서/피해/환시 의무는 없다. 핵심 진실과 해결에 필요한 인과는 설명/추론 가능해야 하며 주변 수수께끼는 남을 수 있다.

## PLAYER_FACING_KOREAN_LOCALIZATION

플레이어에게는 자연스러운 한국어와 시대/인물에 맞는 말로 전달한다. 저장ID/영문 필드/내부 분류를 지문에 나열하지 않는다. 인물·장소·물건·기능 이름은 확정된 표기를 유지하고 수치/공식·식별자를 번역 때문에 임의 변경하지 않는다.
